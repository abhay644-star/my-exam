  1. JEE Advanced 2026, Paper 2 · Question 4
    The value of the definite integral

    $\displaystyle \int_0^2 \frac{1}{3^x + 3}\,dx$
    is

    1. $\dfrac{1}{2}$
    2. $\dfrac{1}{3}$
    3. $\dfrac{\log_e 3}{3}$
    4. $\dfrac{\log_e 3}{2}$
    Show answer and solution

    Answer: (b)

    Replace $x$ by $2-x$: $I=\int_0^2\dfrac{dx}{9/3^x+3}=\int_0^2\dfrac{3^x}{3(3^x+3)}dx$.
    Add to the original: $2I=\int_0^2\dfrac{1+3^x/3}{3^x+3}dx=\int_0^2\dfrac13dx=\dfrac23$.
    So $I=\dfrac13$.

  2. JEE Advanced 2025, Paper 2 · Question 16
    If

    $\displaystyle \alpha=\int_{1/2}^{2}\dfrac{\tan^{-1}x}{2x^2-3x+2}\,dx,$
    then the value of $\sqrt{7}\tan\left(\dfrac{2\alpha\sqrt{7}}{\pi}\right)$ is ________.
    (Here, the inverse trigonometric function $\tan^{-1}x$ assumes values in $\left(-\dfrac{\pi}{2},\dfrac{\pi}{2}\right)$.)

    Show answer and solution

    Answer: 21

    Put $x=\dfrac1u$: $dx=-\dfrac{du}{u^2}$ and $2x^2-3x+2=\dfrac{2-3u+2u^2}{u^2}$, so $\alpha=\displaystyle\int_{1/2}^{2}\dfrac{\tan^{-1}(1/u)}{2u^2-3u+2}du$.
    Adding ($\tan^{-1}x+\tan^{-1}\frac1x=\frac\pi2$ for $x>0$): $2\alpha=\dfrac\pi2\displaystyle\int_{1/2}^{2}\dfrac{dx}{2x^2-3x+2}$.
    $\displaystyle\int\dfrac{dx}{2\left[(x-\frac34)^2+\frac7{16}\right]}=\dfrac{2}{\sqrt7}\tan^{-1}\dfrac{4x-3}{\sqrt7}$; from $\frac12$ to $2$: $\dfrac{2}{\sqrt7}\left(\tan^{-1}\dfrac{5}{\sqrt7}+\tan^{-1}\dfrac{1}{\sqrt7}\right)=\dfrac{2}{\sqrt7}\tan^{-1}(3\sqrt7)$ (since $\dfrac{6/\sqrt7}{1-5/7}=3\sqrt7$).
    So $\alpha=\dfrac{\pi}{2\sqrt7}\tan^{-1}(3\sqrt7)$, i.e. $\dfrac{2\alpha\sqrt7}{\pi}=\tan^{-1}(3\sqrt7)$.
    $\sqrt7\tan\left(\dfrac{2\alpha\sqrt7}{\pi}\right)=\sqrt7\cdot3\sqrt7=21$.

  3. JEE Advanced 2024, Paper 2 · Question 13
    Let the function $f:[1,\infty)\to\mathbb{R}$ be defined by $$f(t)=\begin{cases}(-1)^{n+1}\,2, & \text{if } t=2n-1,\ n\in\mathbb{N},\\ \dfrac{(2n+1-t)}{2}f(2n-1)+\dfrac{(t-(2n-1))}{2}f(2n+1), & \text{if } 2n-1<t<2n+1,\ n\in\mathbb{N}.\end{cases}$$ Define $g(x)=\displaystyle\int_1^x f(t)\,dt$, $x\in(1,\infty)$. Let $\alpha$ denote the number of solutions of the equation $g(x)=0$ in the interval $(1,8]$ and $\beta=\displaystyle\lim_{x\to1+}\dfrac{g(x)}{x-1}$. Then the value of $\alpha+\beta$ is equal to _____.

    Show answer and solution

    Answer: 5

    $f(1)=2$, $f(3)=-2$, $f(5)=2$, $f(7)=-2$, $f(9)=2$, and $f$ is linear in between: a zigzag through zero at $t=2,4,6,8$.
    Each triangle has area $1$, so $g(2)=1$, $g(3)=0$, $g(4)=-1$, $g(5)=0$, $g(6)=1$, $g(7)=0$, $g(8)=-1$, with $g$ monotonic between these points.
    Zeros of $g$ in $(1,8]$: $x=3,5,7$, so $\alpha=3$.
    $\beta=\displaystyle\lim_{x\to1+}\dfrac{g(x)}{x-1}=g'(1^+)=f(1)=2$.
    $\alpha+\beta=5$.

  4. JEE Advanced 2024, Paper 2 · Question 16
    Let $f:\left[0,\dfrac{\pi}{2}\right]\to[0,1]$ be the function defined by $f(x)=\sin^2 x$ and let $g:\left[0,\dfrac{\pi}{2}\right]\to[0,\infty)$ be the function defined by $g(x)=\sqrt{\dfrac{\pi x}{2}-x^2}$.

    The value of

    $\displaystyle 2\int_0^{\frac{\pi}{2}}f(x)g(x)\,dx-\int_0^{\frac{\pi}{2}}g(x)\,dx$
    is __________.

    Show answer and solution

    Answer: 0

    $g\left(\dfrac\pi2-x\right)=\sqrt{\dfrac\pi2\left(\dfrac\pi2-x\right)-\left(\dfrac\pi2-x\right)^2}=\sqrt{\dfrac{\pi x}{2}-x^2}=g(x)$.
    Let $I=\displaystyle\int_0^{\pi/2}\sin^2x\,g(x)\,dx$. Replacing $x$ by $\dfrac\pi2-x$: $I=\displaystyle\int_0^{\pi/2}\cos^2x\,g(x)\,dx$.
    Adding: $2I=\displaystyle\int_0^{\pi/2}g(x)\,dx$.
    So the value is $0$.

  5. JEE Advanced 2024, Paper 2 · Question 17
    Let $f:\left[0,\dfrac{\pi}{2}\right]\to[0,1]$ be the function defined by $f(x)=\sin^2 x$ and let $g:\left[0,\dfrac{\pi}{2}\right]\to[0,\infty)$ be the function defined by $g(x)=\sqrt{\dfrac{\pi x}{2}-x^2}$.

    The value of

    $\displaystyle \dfrac{16}{\pi^3}\int_0^{\frac{\pi}{2}}f(x)g(x)\,dx$
    is ____________.

    Show answer and solution

    Answer: 0.24 to 0.26

    From the previous question, $\displaystyle\int_0^{\pi/2}f g\,dx=\dfrac12\int_0^{\pi/2}g\,dx$.
    $y=g(x)$ is the upper half of $\left(x-\dfrac\pi4\right)^2+y^2=\left(\dfrac\pi4\right)^2$, so $\displaystyle\int_0^{\pi/2}g\,dx=\dfrac12\pi\left(\dfrac\pi4\right)^2=\dfrac{\pi^3}{32}$.
    $\displaystyle\int_0^{\pi/2}fg\,dx=\dfrac{\pi^3}{64}$, and $\dfrac{16}{\pi^3}\cdot\dfrac{\pi^3}{64}=\dfrac14=0.25$.

  6. JEE Advanced 2022, Paper 1 · Question 9
    Consider the equation

    $\displaystyle \int_1^e\frac{\left(\log_e x\right)^{1/2}}{x\left(a-\left(\log_e x\right)^{3/2}\right)^2}\,dx=1,\qquad a\in(-\infty,0)\cup(1,\infty).$
    Which of the following statements is/are TRUE ?

    1. <b>No</b> $a$ satisfies the above equation
    2. An integer $a$ satisfies the above equation
    3. An irrational number $a$ satisfies the above equation
    4. More than one $a$ satisfy the above equation
    Show answer and solution

    Answer: (c), (d)

    Put $u=(\ln x)^{3/2}$, $du=\dfrac32\dfrac{(\ln x)^{1/2}}{x}dx$; $u$ runs from 0 to 1.
    Integral $=\dfrac23\displaystyle\int_0^1\dfrac{du}{(a-u)^2}=\dfrac23\left(\dfrac{1}{a-1}-\dfrac1a\right)=\dfrac{2}{3a(a-1)}$.
    Setting it equal to 1: $3a^2-3a-2=0\Rightarrow a=\dfrac{3\pm\sqrt{33}}{6}$.
    $\dfrac{3+\sqrt{33}}{6}\approx1.46>1$ and $\dfrac{3-\sqrt{33}}{6}\approx-0.46<0$: both are allowed and both are irrational.
    So (C) and (D) are true; (A) and (B) are false.

  7. JEE Advanced 2022, Paper 2 · Question 3
    The greatest integer less than or equal to

    $\displaystyle \int_1^2 \log_2(x^3+1)\,dx + \int_1^{\log_2 9} (2^x - 1)^{\frac13}\,dx$
    is ________.

    Show answer and solution

    Answer: 5

    In the second integral put $t = (2^x-1)^{1/3}$, i.e. $x = \log_2(t^3+1)$; $t$ runs from $1$ to $2$.
    $I_2 = \displaystyle\int_1^2 t\,d\big(\log_2(t^3+1)\big) = \big[t\log_2(t^3+1)\big]_1^2 - \int_1^2 \log_2(t^3+1)\,dt = 2\log_2 9 - 1 - I_1$.
    So $I_1 + I_2 = 2\log_2 9 - 1 = 4\log_2 3 - 1 \approx 4(1.585) - 1 = 5.34$.
    Greatest integer $= 5$.

  8. JEE Advanced 2022, Paper 2 · Question 18
    For positive integer $n$, define

    $\displaystyle f(n) = n + \frac{16 + 5n - 3n^2}{4n + 3n^2} + \frac{32 + n - 3n^2}{8n + 3n^2} + \frac{48 - 3n - 3n^2}{12n + 3n^2} + \cdots + \frac{25n - 7n^2}{7n^2}.$
    Then, the value of $\displaystyle\lim_{n\to\infty} f(n)$ is equal to

    1. $3 + \dfrac43\log_e 7$
    2. $4 - \dfrac34\log_e\left(\dfrac73\right)$
    3. $4 - \dfrac43\log_e\left(\dfrac73\right)$
    4. $3 + \dfrac34\log_e 7$
    Show answer and solution

    Answer: (b)

    The $k$-th fraction is $\dfrac{16k + (9-4k)n - 3n^2}{4kn + 3n^2}$; the last one is $k = n$ (denominator $7n^2$, numerator $25n - 7n^2$).
    Each fraction $= -1 + \dfrac{16k + 9n}{4kn + 3n^2}$, and the $n$ terms $-1$ cancel the leading $n$.
    $f(n) = \displaystyle\sum_{k=1}^{n} \frac1n\cdot\frac{16(k/n) + 9}{4(k/n) + 3} \to \int_0^1 \frac{16x + 9}{4x + 3}\,dx$.
    $\dfrac{16x+9}{4x+3} = 4 - \dfrac{3}{4x+3}$, so the integral $= 4 - \dfrac34\ln\dfrac73$ → (B).

  9. JEE Advanced 2021, Paper 2 · Question 11
    Let $g_i : \left[\dfrac{\pi}{8}, \dfrac{3\pi}{8}\right] \to \mathbb{R}$, $i = 1, 2$, and $f : \left[\dfrac{\pi}{8}, \dfrac{3\pi}{8}\right] \to \mathbb{R}$ be functions such that

    $\displaystyle g_1(x) = 1,\ g_2(x) = |4x - \pi| \text{ and } f(x) = \sin^2 x, \text{ for all } x \in \left[\frac{\pi}{8}, \frac{3\pi}{8}\right].$
    Define
    $\displaystyle S_i = \int_{\pi/8}^{3\pi/8} f(x) \cdot g_i(x)\,dx, \quad i = 1, 2.$
    The value of $\dfrac{16S_1}{\pi}$ is ___ .

    Show answer and solution

    Answer: 1.99 to 2.01

    $S_1 = \int_{\pi/8}^{3\pi/8}\dfrac{1 - \cos 2x}{2}\,dx = \dfrac{\pi}{8} - \dfrac14\left[\sin 2x\right]_{\pi/8}^{3\pi/8} = \dfrac{\pi}{8} - \dfrac14\left(\dfrac{1}{\sqrt2} - \dfrac{1}{\sqrt2}\right) = \dfrac{\pi}{8}$.
    $\dfrac{16S_1}{\pi} = 2$.

  10. JEE Advanced 2021, Paper 2 · Question 12
    Let $g_i : \left[\dfrac{\pi}{8}, \dfrac{3\pi}{8}\right] \to \mathbb{R}$, $i = 1, 2$, and $f : \left[\dfrac{\pi}{8}, \dfrac{3\pi}{8}\right] \to \mathbb{R}$ be functions such that

    $\displaystyle g_1(x) = 1,\ g_2(x) = |4x - \pi| \text{ and } f(x) = \sin^2 x, \text{ for all } x \in \left[\frac{\pi}{8}, \frac{3\pi}{8}\right].$
    Define
    $\displaystyle S_i = \int_{\pi/8}^{3\pi/8} f(x) \cdot g_i(x)\,dx, \quad i = 1, 2.$
    The value of $\dfrac{48S_2}{\pi^2}$ is ___.

    Show answer and solution

    Answer: 1.49 to 1.51

    Put $x \to \dfrac{\pi}{2} - x$: the interval and $|4x - \pi|$ are unchanged, $\sin^2 x \to \cos^2 x$. So $S_2 = \int \cos^2 x\,|4x - \pi|\,dx$ too.
    $2S_2 = \int_{\pi/8}^{3\pi/8}|4x - \pi|\,dx = 2\int_{\pi/4}^{3\pi/8}(4x - \pi)\,dx = 2\left[2x^2 - \pi x\right]_{\pi/4}^{3\pi/8} = 2\cdot\dfrac{\pi^2}{32} = \dfrac{\pi^2}{16}$.
    $S_2 = \dfrac{\pi^2}{32}$, so $\dfrac{48S_2}{\pi^2} = \dfrac{48}{32} = 1.5$.

  11. JEE Advanced 2021, Paper 2 · Question 16
    Let $\psi_1 : [0, \infty) \to \mathbb{R}$, $\psi_2 : [0, \infty) \to \mathbb{R}$, $f : [0, \infty) \to \mathbb{R}$ and $g : [0, \infty) \to \mathbb{R}$ be functions such that $f(0) = g(0) = 0$,

    $\displaystyle \psi_1(x) = e^{-x} + x, \quad x \ge 0,$
    $\displaystyle \psi_2(x) = x^2 - 2x - 2e^{-x} + 2, \quad x \ge 0,$
    $\displaystyle f(x) = \int_{-x}^{x}\left(|t| - t^2\right)e^{-t^2}\,dt, \quad x > 0$
    and
    $\displaystyle g(x) = \int_0^{x^2}\sqrt{t}\,e^{-t}\,dt, \quad x > 0.$
    Which of the following statements is TRUE ?

    1. $\psi_1(x) \le 1$, for all $x > 0$
    2. $\psi_2(x) \le 0$, for all $x > 0$
    3. $f(x) \ge 1 - e^{-x^2} - \dfrac23x^3 + \dfrac25x^5$, for all $x \in \left(0, \dfrac12\right)$
    4. $g(x) \le \dfrac23x^3 - \dfrac25x^5 + \dfrac17x^7$, for all $x \in \left(0, \dfrac12\right)$
    Show answer and solution

    Answer: (d)

    (A) $\psi_1'(x) = 1 - e^{-x} > 0$, so $\psi_1(x) > \psi_1(0) = 1$ for $x > 0$ → false.
    (B) $\psi_2' = 2(\psi_1 - 1) > 0$, so $\psi_2(x) > 0$ for $x > 0$ → false.
    $g(x) = 2\int_0^x u^2e^{-u^2}du = 2\int_0^x\left(u^2 - u^4 + \dfrac{u^6}{2} - \dfrac{u^8}{6} + \cdots\right)du = \dfrac23x^3 - \dfrac25x^5 + \dfrac17x^7 - \dfrac{1}{27}x^9 + \cdots$, an alternating series with decreasing terms for $0 < x < \dfrac12$.
    (D) Hence $g(x) \le \dfrac23x^3 - \dfrac25x^5 + \dfrac17x^7$ → true.
    (C) $f = 1 - e^{-x^2} - g$ and $g > \dfrac23x^3 - \dfrac25x^5$, so $f(x) < 1 - e^{-x^2} - \dfrac23x^3 + \dfrac25x^5$ → false.
    Answer (D).

  12. JEE Advanced 2021, Paper 2 · Question 19
    For any real number $x$, let $[x]$ denote the largest integer less than or equal to $x$. If

    $\displaystyle I = \int_0^{10}\left[\sqrt{\frac{10x}{x + 1}}\right]dx,$
    then the value of $9I$ is ___ .

    Show answer and solution

    Answer: 182

    $\dfrac{10x}{x + 1}$ increases from $0$ to $\dfrac{100}{11} < 16$ on $[0, 10]$, so the integrand takes values $0, 1, 2, 3$.
    $\dfrac{10x}{x+1} \ge 1 \iff x \ge \dfrac19$; $\ge 4 \iff x \ge \dfrac23$; $\ge 9 \iff x \ge 9$.
    $I = 1\left(\dfrac23 - \dfrac19\right) + 2\left(9 - \dfrac23\right) + 3(10 - 9) = \dfrac59 + \dfrac{50}{3} + 3 = \dfrac{182}{9}$.
    $9I = 182$.
