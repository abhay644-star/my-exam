  1. JEE Advanced 2025, Paper 1 · Question 12
    Let $\mathbb{R}$ denote the set of all real numbers. Let $f : \mathbb{R} \to \mathbb{R}$ be a function such that $f(x) \gt 0$ for all $x \in \mathbb{R}$, and $f(x + y) = f(x)f(y)$ for all $x, y \in \mathbb{R}$.

    Let the real numbers $a_1, a_2, \ldots, a_{50}$ be in an arithmetic progression. If $f(a_{31}) = 64f(a_{25})$, and

    $\displaystyle \sum_{i=1}^{50} f(a_i) = 3(2^{25} + 1),$
    then the value of
    $\displaystyle \sum_{i=6}^{30} f(a_i)$
    is ______.

    Show answer and solution

    Answer: 96

    Let $d$ be the common difference. $f(a_{31}) = f(a_{25})f(6d)$, so $f(6d) = 64 = f(d)^6$ and $f(d) = 2$ (as $f \gt 0$).
    So $f(a_i) = A\cdot2^{i-1}$ with $A = f(a_1)$: a GP with ratio $2$.
    $\sum_{i=1}^{50} f(a_i) = A(2^{50} - 1) = A(2^{25}-1)(2^{25}+1) = 3(2^{25}+1) \Rightarrow A = \dfrac{3}{2^{25}-1}$.
    $\sum_{i=6}^{30} f(a_i) = A(2^5 + 2^6 + \ldots + 2^{29}) = A\cdot2^5(2^{25} - 1) = 3 \times 32 = 96$.

  2. JEE Advanced 2023, Paper 1 · Question 10
    Let $7\overbrace{5\cdots5}^{r}7$ denote the $(r+2)$ digit number where the first and the last digits are $7$ and the remaining $r$ digits are $5$. Consider the sum $S = 77 + 757 + 7557 + \cdots + 7\overbrace{5\cdots5}^{98}7$. If $S = \dfrac{7\overbrace{5\cdots5}^{99}7 + m}{n}$, where $m$ and $n$ are natural numbers less than $3000$, then the value of $m+n$ is ______.

    Show answer and solution

    Answer: 1219

    $T_r = 7\overbrace{5\cdots5}^{r}7 = 7\cdot10^{r+1} + \dfrac{50(10^r-1)}{9} + 7$, so $9T_r = 680\cdot10^r + 13$ (check: $9\times77 = 693$).
    $9S = \displaystyle\sum_{r=0}^{98}(680\cdot10^r + 13) = \dfrac{680(10^{99}-1)}{9} + 1287$, so $81S = 680\cdot10^{99} + 10903$.
    Since $680\cdot10^{99} = 9T_{99} - 13$: $81S = 9T_{99} + 10890$, so $S = \dfrac{T_{99} + 1210}{9}$.
    $m = 1210$, $n = 9$, $m + n = 1219$.

  3. JEE Advanced 2022, Paper 1 · Question 6
    Let $l_1,l_2,\ldots,l_{100}$ be consecutive terms of an arithmetic progression with common difference $d_1$, and let $w_1,w_2,\ldots,w_{100}$ be consecutive terms of another arithmetic progression with common difference $d_2$, where $d_1d_2=10$. For each $i=1,2,\ldots,100$, let $R_i$ be a rectangle with length $l_i$, width $w_i$ and area $A_i$. If $A_{51}-A_{50}=1000$, then the value of $A_{100}-A_{90}$ is ______.

    Show answer and solution

    Answer: 18900

    $A_{51}-A_{50}=(l_{50}+d_1)(w_{50}+d_2)-l_{50}w_{50}=l_{50}d_2+w_{50}d_1+d_1d_2=1000$, so $l_{50}d_2+w_{50}d_1=990$.
    $A_{100}-A_{90}=(l_{90}+10d_1)(w_{90}+10d_2)-l_{90}w_{90}=10(l_{90}d_2+w_{90}d_1)+100d_1d_2$.
    $l_{90}d_2+w_{90}d_1=(l_{50}+40d_1)d_2+(w_{50}+40d_2)d_1=990+80\cdot10=1790$.
    $A_{100}-A_{90}=17900+1000=18900$.

  4. JEE Advanced 2022, Paper 1 · Question 10
    Let $a_1,a_2,a_3,\ldots$ be an arithmetic progression with $a_1=7$ and common difference $8$. Let $T_1,T_2,T_3,\ldots$ be such that $T_1=3$ and $T_{n+1}-T_n=a_n$ for $n\ge1$. Then, which of the following is/are TRUE ?

    1. $T_{20}=1604$
    2. $\displaystyle\sum_{k=1}^{20}T_k=10510$
    3. $T_{30}=3454$
    4. $\displaystyle\sum_{k=1}^{30}T_k=35610$
    Show answer and solution

    Answer: (b), (c)

    $a_k=8k-1$, so $T_n=3+\sum_{k=1}^{n-1}(8k-1)=3+4n(n-1)-(n-1)=4n^2-5n+4$.
    $T_{20}=1600-100+4=1504$ — (A) false. $T_{30}=3600-150+4=3454$ — (C) true.
    $\sum_{k=1}^{n}T_k=\dfrac{2n(n+1)(2n+1)}{3}-\dfrac{5n(n+1)}{2}+4n$.
    $n=20$: $11480-1050+80=10510$ — (B) true.
    $n=30$: $37820-2325+120=35615\ne35610$ — (D) false.

  5. JEE Advanced 2021, Paper 2 · Question 13
    Let

    $\displaystyle M = \{(x, y) \in \mathbb{R} \times \mathbb{R} : x^2 + y^2 \le r^2\},$
    where $r > 0$. Consider the geometric progression $a_n = \dfrac{1}{2^{n-1}}$, $n = 1, 2, 3, \ldots$. Let $S_0 = 0$ and, for $n \ge 1$, let $S_n$ denote the sum of the first $n$ terms of this progression. For $n \ge 1$, let $C_n$ denote the circle with center $(S_{n-1}, 0)$ and radius $a_n$, and $D_n$ denote the circle with center $(S_{n-1}, S_{n-1})$ and radius $a_n$.

    Consider $M$ with $r = \dfrac{1025}{513}$. Let $k$ be the number of all those circles $C_n$ that are inside $M$. Let $l$ be the maximum possible number of circles among these $k$ circles such that no two circles intersect. Then

    1. $k + 2l = 22$
    2. $2k + l = 26$
    3. $2k + 3l = 34$
    4. $3k + 2l = 40$
    Show answer and solution

    Answer: (d)

    $S_{n-1} = 2 - \dfrac{1}{2^{n-2}}$, so the farthest point of $C_n$ from the origin is at $S_{n-1} + a_n = 2 - \dfrac{1}{2^{n-1}}$.
    $C_n \subset M$ iff $2 - \dfrac{1}{2^{n-1}} \le 2 - \dfrac{1}{513}$ iff $2^{n-1} \le 513$ iff $n \le 10$. So $k = 10$.
    $C_n, C_{n+1}$: centre distance $a_n$, radii sum $\dfrac32a_n$ → they intersect.
    $C_n, C_{n+2}$: centre distance $\dfrac32a_n$, radii sum $\dfrac54a_n$ → disjoint. So at most every other circle: $l = 5$.
    $3k + 2l = 30 + 10 = 40$ → (D).

  6. JEE Advanced 2021, Paper 2 · Question 14
    Let

    $\displaystyle M = \{(x, y) \in \mathbb{R} \times \mathbb{R} : x^2 + y^2 \le r^2\},$
    where $r > 0$. Consider the geometric progression $a_n = \dfrac{1}{2^{n-1}}$, $n = 1, 2, 3, \ldots$. Let $S_0 = 0$ and, for $n \ge 1$, let $S_n$ denote the sum of the first $n$ terms of this progression. For $n \ge 1$, let $C_n$ denote the circle with center $(S_{n-1}, 0)$ and radius $a_n$, and $D_n$ denote the circle with center $(S_{n-1}, S_{n-1})$ and radius $a_n$.

    Consider $M$ with $r = \dfrac{(2^{199} - 1)\sqrt2}{2^{198}}$. The number of all those circles $D_n$ that are inside $M$ is

    1. $198$
    2. $199$
    3. $200$
    4. $201$
    Show answer and solution

    Answer: (b)

    $r = \sqrt2\left(2 - 2^{-198}\right)$. The farthest point of $D_n$ from the origin is at $\sqrt2\,S_{n-1} + a_n = \sqrt2\left(2 - 2^{2-n}\right) + 2^{1-n}$.
    Condition: $\sqrt2\left(2 - 2^{2-n}\right) + 2^{1-n} \le \sqrt2\left(2 - 2^{-198}\right)$
    $\iff 2^{1-n}\left(2\sqrt2 - 1\right) \ge \sqrt2 \cdot 2^{-198} \iff 2^{199-n} \ge \dfrac{\sqrt2}{2\sqrt2 - 1} \approx 0.77$.
    This holds for $199 - n \ge 0$ and fails for $199 - n = -1$ ($0.5 < 0.77$). So $n = 1, 2, \ldots, 199$: 199 circles → (B).
