  1. JEE Advanced 2026, Paper 1 · Question 12
    Let

    $\displaystyle \alpha = \left(1 - 2\cos\left(\frac{\pi}{11}\right)\right)\left(1 - 2\cos\left(\frac{3\pi}{11}\right)\right)\left(1 - 2\cos\left(\frac{9\pi}{11}\right)\right)\left(1 - 2\cos\left(\frac{27\pi}{11}\right)\right)\left(1 - 2\cos\left(\frac{81\pi}{11}\right)\right).$
    Then the value of $5 - \alpha^2$ is ______.

    Show answer and solution

    Answer: 3.9 to 4.1

    Identity: $1 - 2\cos\theta = -\dfrac{\cos(3\theta/2)}{\cos(\theta/2)}$ (from $\sin 3\phi / \sin\phi = 1 + 2\cos 2\phi$ with $\theta \to \pi - \theta$).
    With $\theta = \frac{k\pi}{11}$, $k = 1, 3, 9, 27, 81$, the product telescopes: $\alpha = (-1)^5 \dfrac{\cos(243\pi/22)}{\cos(\pi/22)}$.
    $\frac{243\pi}{22} = 11\pi + \frac{\pi}{22}$, so $\cos(243\pi/22) = -\cos(\pi/22)$.
    Hence $\alpha = 1$ and $5 - \alpha^2 = 4$.

  2. JEE Advanced 2026, Paper 1 · Question 14
    Match each entry in List-I to the correct entry in List-II and choose the correct option.

    List-IList-II
    (P) The number of elements in the set $\{x \in [-\pi, \pi] : \sin^6 x + \cos^4 x = 1\}$(1) is $1$
    (Q) The number of elements in the set $\left\{x \in \left[-\frac{\pi}{2}, \frac{\pi}{2}\right] : \sin^2 x + \cos^6 x = 1\right\}$(2) is $2$
    (R) The number of elements in the set $\left\{x \in [-\pi, \pi] : \cos^2\left(\frac{x}{2}\right) - \sin^2 x = \frac{1}{2}\right\}$(3) is $3$
    (S) The number of elements in the set $\left\{x \in [-2\pi, 2\pi] : 6\sin^2\left(\frac{x}{2}\right) - \cos 3x = 3\right\}$(4) is $4$
    (5) is $5$

    1. (P) → (2), (Q) → (5), (R) → (3), (S) → (4)
    2. (P) → (5), (Q) → (3), (R) → (2), (S) → (4)
    3. (P) → (5), (Q) → (4), (R) → (1), (S) → (3)
    4. (P) → (4), (Q) → (3), (R) → (2), (S) → (5)
    Show answer and solution

    Answer: (b)

    (P) With $s = \sin^2 x$: $s^3 + (1-s)^2 = 1 \Rightarrow s(s-1)(s+2) = 0$, so $\sin x = 0$ or $\sin^2 x = 1$: $x = -\pi, 0, \pi, \pm\frac{\pi}{2}$ → 5 → (5).
    (Q) $\cos^6 x = \cos^2 x \Rightarrow \cos x = 0$ or $\cos^2 x = 1$: $x = \pm\frac{\pi}{2}, 0$ → 3 → (3).
    (R) $\frac{1+\cos x}{2} - (1 - \cos^2 x) = \frac12 \Rightarrow 2\cos^2 x + \cos x - 2 = 0 \Rightarrow \cos x = \frac{\sqrt{17}-1}{4} \approx 0.78$: 2 solutions → (2).
    (S) $3(1 - \cos x) - \cos 3x = 3 \Rightarrow -3\cos x - (4\cos^3 x - 3\cos x) = 0 \Rightarrow \cos x = 0$: $x = \pm\frac{\pi}{2}, \pm\frac{3\pi}{2}$ → 4 → (4).
    Answer (B).

  3. JEE Advanced 2026, Paper 2 · Question 15
    Consider the curve $C_1$ given by

    $\displaystyle y = e^{-x} \qquad \text{for } x \in [0, 10\pi],$
    and the curve $C_2$ given by
    $\displaystyle y = e^{-x}(\sin x + \cos x) \qquad \text{for } x \in [0, 10\pi].$
    Let $n$ be the total number of points of intersection of the curves $C_1$ and $C_2$ .

    Suppose that $\alpha_1 , \alpha_2 , \ldots, \alpha_n \in [0, 10\pi]$ are the $x$ - coordinates of the points of intersection of the curves $C_1$ and $C_2$ such that
    $\displaystyle \alpha_1 < \alpha_2 < \cdots < \alpha_n .$


    The value of $n$ is ________.

    Show answer and solution

    Answer: 11

    Intersection: $\sin x+\cos x=1\iff\sin\left(x+\frac\pi4\right)=\frac1{\sqrt2}$.
    So $x=2k\pi$ or $x=\frac\pi2+2k\pi$.
    In $[0,10\pi]$: $x=0,2\pi,\dots,10\pi$ (6 values) and $\frac\pi2,\frac{5\pi}2,\dots,\frac{17\pi}2$ (5 values).
    $n=11$.

  4. JEE Advanced 2025, Paper 2 · Question 15
    Let

    $\displaystyle \alpha=\dfrac{1}{\sin60^\circ\sin61^\circ}+\dfrac{1}{\sin62^\circ\sin63^\circ}+\cdots+\dfrac{1}{\sin118^\circ\sin119^\circ}.$
    Then the value of
    $\displaystyle \left(\dfrac{\operatorname{cosec}1^\circ}{\alpha}\right)^2$
    is ________.

    Show answer and solution

    Answer: 3

    $\dfrac{1}{\sin a\sin(a+1^\circ)}=\dfrac{\sin\left((a+1^\circ)-a\right)}{\sin1^\circ\sin a\sin(a+1^\circ)}=\dfrac{\cot a-\cot(a+1^\circ)}{\sin1^\circ}$.
    So $\alpha\sin1^\circ=\cot60^\circ-\cot61^\circ+\cot62^\circ-\cot63^\circ+\cdots+\cot118^\circ-\cot119^\circ$.
    Since $\cot(180^\circ-\theta)=-\cot\theta$: the even angles $62^\circ,\ldots,118^\circ$ cancel in pairs ($\cot90^\circ=0$) and the odd angles $61^\circ,\ldots,119^\circ$ cancel in pairs.
    So $\alpha\sin1^\circ=\cot60^\circ=\dfrac{1}{\sqrt3}$, i.e. $\dfrac{\operatorname{cosec}1^\circ}{\alpha}=\sqrt3$.
    Value $=3$.

  5. JEE Advanced 2024, Paper 1 · Question 3
    Let $\dfrac{\pi}{2} \lt x \lt \pi$ be such that $\cot x = \dfrac{-5}{\sqrt{11}}$. Then

    $\displaystyle \left(\sin\frac{11x}{2}\right)\left(\sin 6x - \cos 6x\right) + \left(\cos\frac{11x}{2}\right)\left(\sin 6x + \cos 6x\right)$
    is equal to

    1. $\dfrac{\sqrt{11}-1}{2\sqrt{3}}$
    2. $\dfrac{\sqrt{11}+1}{2\sqrt{3}}$
    3. $\dfrac{\sqrt{11}+1}{3\sqrt{2}}$
    4. $\dfrac{\sqrt{11}-1}{3\sqrt{2}}$
    Show answer and solution

    Answer: (b)

    Let $a = \dfrac{11x}{2}$. Regroup: $(\sin 6x\cos a - \cos 6x\sin a) + (\cos 6x\cos a + \sin 6x\sin a) = \sin(6x - a) + \cos(6x - a)$.
    $6x - a = \dfrac{x}{2}$, so the expression is $\sin\dfrac{x}{2} + \cos\dfrac{x}{2}$.
    $\csc^2 x = 1 + \dfrac{25}{11} = \dfrac{36}{11}$; $x$ in the second quadrant gives $\sin x = \dfrac{\sqrt{11}}{6}$, $\cos x = -\dfrac56$.
    $\dfrac{x}{2} \in \left(\dfrac{\pi}{4}, \dfrac{\pi}{2}\right)$: $\cos\dfrac{x}{2} = \sqrt{\dfrac{1+\cos x}{2}} = \dfrac{1}{2\sqrt3}$, $\sin\dfrac{x}{2} = \sqrt{\dfrac{1-\cos x}{2}} = \dfrac{\sqrt{11}}{2\sqrt3}$.
    Sum $= \dfrac{\sqrt{11}+1}{2\sqrt3}$ → (B).

  6. JEE Advanced 2024, Paper 2 · Question 4
    Let $f:\mathbb{R}\to\mathbb{R}$ be a function defined by $$f(x)=\begin{cases} x^2\sin\left(\dfrac{\pi}{x^2}\right), & \text{if } x\ne 0,\\ 0, & \text{if } x=0.\end{cases}$$ Then which of the following statements is TRUE?

    1. $f(x)=0$ has infinitely many solutions in the interval $\left[\dfrac{1}{10^{10}},\infty\right)$.
    2. $f(x)=0$ has no solutions in the interval $\left[\dfrac{1}{\pi},\infty\right)$.
    3. The set of solutions of $f(x)=0$ in the interval $\left(0,\dfrac{1}{10^{10}}\right)$ is finite.
    4. $f(x)=0$ has more than 25 solutions in the interval $\left(\dfrac{1}{\pi^2},\dfrac{1}{\pi}\right)$.
    Show answer and solution

    Answer: (d)

    For $x\ne0$: $f(x)=0\iff \dfrac{\pi}{x^2}=n\pi\iff x=\pm\dfrac{1}{\sqrt n}$, $n\in\mathbb{N}$.
    (A) $\dfrac{1}{\sqrt n}\ge10^{-10}\iff n\le10^{20}$: finitely many → false.
    (B) $x=1\ge\dfrac1\pi$ is a solution → false. (C) $n>10^{20}$ gives infinitely many → false.
    (D) $\dfrac{1}{\pi^2}<\dfrac{1}{\sqrt n}<\dfrac1\pi\iff \pi^2<n<\pi^4$, i.e. $n=10,11,\ldots,97$: $88$ solutions, more than $25$ → (D).

  7. JEE Advanced 2023, Paper 2 · Question 14
    Consider an obtuse angled triangle $ABC$ in which the difference between the largest and the smallest angle is $\dfrac{\pi}{2}$ and whose sides are in arithmetic progression. Suppose that the vertices of this triangle lie on a circle of radius 1.

    Let $a$ be the area of the triangle $ABC$. Then the value of $(64a)^2$ is ________.

    Show answer and solution

    Answer: 1007.99 to 1008.01

    Let $A > B > C$ with $A = C + \dfrac{\pi}{2}$, so $B = \dfrac{\pi}{2} - 2C$ and $C < \dfrac{\pi}{4}$.
    Sides in AP with $R = 1$: $2\sin B = \sin A + \sin C \Rightarrow 2\cos 2C = \cos C + \sin C$.
    Dividing by $\cos C + \sin C$: $\cos C - \sin C = \dfrac12$; squaring, $\sin 2C = \dfrac34$, so $\cos 2C = \dfrac{\sqrt7}{4}$.
    Area $a = 2R^2\sin A\sin B\sin C = 2\cos C\cos 2C\sin C = \sin 2C\cos 2C = \dfrac{3\sqrt7}{16}$.
    $(64a)^2 = (12\sqrt7)^2 = 1008$.

  8. JEE Advanced 2023, Paper 2 · Question 15
    Consider an obtuse angled triangle $ABC$ in which the difference between the largest and the smallest angle is $\dfrac{\pi}{2}$ and whose sides are in arithmetic progression. Suppose that the vertices of this triangle lie on a circle of radius 1.

    Then the inradius of the triangle $ABC$ is ________.

    Show answer and solution

    Answer: 0.24 to 0.26

    From Q.14: $\cos 2C = \dfrac{\sqrt7}{4}$ and area $\Delta = \dfrac{3\sqrt7}{16}$.
    Middle side $b = 2R\sin B = 2\cos 2C = \dfrac{\sqrt7}{2}$; sides in AP, so $a + b + c = 3b$ and $s = \dfrac{3b}{2} = \dfrac{3\sqrt7}{4}$.
    $r = \dfrac{\Delta}{s} = \dfrac{3\sqrt7/16}{3\sqrt7/4} = \dfrac14 = 0.25$.

  9. JEE Advanced 2022, Paper 1 · Question 15
    Consider the following lists:

    List-IList-II
    (I) $\left\{x\in\left[-\frac{2\pi}{3},\frac{2\pi}{3}\right]:\cos x+\sin x=1\right\}$(P) has two elements
    (II) $\left\{x\in\left[-\frac{5\pi}{18},\frac{5\pi}{18}\right]:\sqrt3\tan3x=1\right\}$(Q) has three elements
    (III) $\left\{x\in\left[-\frac{6\pi}{5},\frac{6\pi}{5}\right]:2\cos(2x)=\sqrt3\right\}$(R) has four elements
    (IV) $\left\{x\in\left[-\frac{7\pi}{4},\frac{7\pi}{4}\right]:\sin x-\cos x=1\right\}$(S) has five elements
    (T) has six elements
    The correct option is:

    1. (I) → (P); (II) → (S); (III) → (P); (IV) → (S)
    2. (I) → (P); (II) → (P); (III) → (T); (IV) → (R)
    3. (I) → (Q); (II) → (P); (III) → (T); (IV) → (S)
    4. (I) → (Q); (II) → (S); (III) → (P); (IV) → (R)
    Show answer and solution

    Answer: (b)

    (I) $\sin\left(x+\frac\pi4\right)=\frac1{\sqrt2}\Rightarrow x=2k\pi$ or $\frac\pi2+2k\pi$; in range: $0,\frac\pi2$ — two (P).
    (II) $\tan3x=\frac1{\sqrt3}\Rightarrow x=\frac{\pi}{18}+\frac{k\pi}{3}$; in range: $\frac{\pi}{18},-\frac{5\pi}{18}$ — two (P).
    (III) $\cos2x=\frac{\sqrt3}{2}\Rightarrow x=\pm\frac{\pi}{12}+k\pi$; in $[-1.2\pi,1.2\pi]$: $\pm\frac{\pi}{12},\pm\frac{11\pi}{12},\pm\frac{13\pi}{12}$ — six (T).
    (IV) $\sin\left(x-\frac\pi4\right)=\frac1{\sqrt2}\Rightarrow x=\frac\pi2+2k\pi$ or $\pi+2k\pi$; in range: $\frac\pi2,-\frac{3\pi}2,\pi,-\pi$ — four (R).
    Answer (B).

  10. JEE Advanced 2022, Paper 2 · Question 1
    Let $\alpha$ and $\beta$ be real numbers such that $-\dfrac{\pi}{4} < \beta < 0 < \alpha < \dfrac{\pi}{4}$. If $\sin(\alpha+\beta) = \dfrac{1}{3}$ and $\cos(\alpha-\beta) = \dfrac{2}{3}$, then the greatest integer less than or equal to

    $\displaystyle \left(\frac{\sin\alpha}{\cos\beta} + \frac{\cos\beta}{\sin\alpha} + \frac{\cos\alpha}{\sin\beta} + \frac{\sin\beta}{\cos\alpha}\right)^2$
    is ________.

    Show answer and solution

    Answer: 1

    Pair the terms: $\dfrac{\sin\alpha}{\cos\beta} + \dfrac{\cos\alpha}{\sin\beta} = \dfrac{\cos(\alpha-\beta)}{\sin\beta\cos\beta}$ and $\dfrac{\cos\beta}{\sin\alpha} + \dfrac{\sin\beta}{\cos\alpha} = \dfrac{\cos(\alpha-\beta)}{\sin\alpha\cos\alpha}$.
    So $E = 2\cos(\alpha-\beta)\,\dfrac{\sin2\alpha + \sin2\beta}{\sin2\alpha\,\sin2\beta}$.
    $\sin2\alpha + \sin2\beta = 2\sin(\alpha+\beta)\cos(\alpha-\beta) = 2\cdot\dfrac13\cdot\dfrac23 = \dfrac49$.
    $\sin2\alpha\sin2\beta = \dfrac12[\cos2(\alpha-\beta) - \cos2(\alpha+\beta)] = \dfrac12\left[-\dfrac19 - \dfrac79\right] = -\dfrac49$.
    $E = 2\cdot\dfrac23\cdot\dfrac{4/9}{-4/9} = -\dfrac43$, so $E^2 = \dfrac{16}{9} \approx 1.78$.
    Greatest integer $= 1$.

  11. JEE Advanced 2022, Paper 2 · Question 9
    Let $PQRS$ be a quadrilateral in a plane, where $QR = 1$, $\angle PQR = \angle QRS = 70^\circ$, $\angle PQS = 15^\circ$ and $\angle PRS = 40^\circ$. If $\angle RPS = \theta^\circ$, $PQ = \alpha$ and $PS = \beta$, then the interval(s) that contain(s) the value of $4\alpha\beta\sin\theta^\circ$ is/are

    1. $(0, \sqrt{2})$
    2. $(1, 2)$
    3. $(\sqrt{2}, 3)$
    4. $(2\sqrt{2}, 3\sqrt{2})$
    Show answer and solution

    Answer: (a), (b)

    $\triangle PQR$: $\angle PQR = 70^\circ$, $\angle PRQ = 70^\circ - 40^\circ = 30^\circ$, so $\angle QPR = 80^\circ$ and $\alpha = PQ = \dfrac{\sin30^\circ}{\sin80^\circ}$.
    $\triangle QRS$: $\angle RQS = 70^\circ - 15^\circ = 55^\circ$, $\angle QRS = 70^\circ$, so $\angle QSR = 55^\circ$ and $RS = QR = 1$.
    $\triangle PRS$, sine rule: $\dfrac{RS}{\sin\theta} = \dfrac{PS}{\sin40^\circ}$, so $\beta\sin\theta = \sin40^\circ$.
    $4\alpha\beta\sin\theta = \dfrac{4\sin30^\circ\sin40^\circ}{\sin80^\circ} = \dfrac{2\sin40^\circ}{2\sin40^\circ\cos40^\circ} = \sec40^\circ \approx 1.305$.
    This lies in $(0, \sqrt2)$ and in $(1, 2)$ → (A), (B).

  12. JEE Advanced 2021, Paper 1 · Question 18
    In a triangle $ABC$, let $AB = \sqrt{23}$, $BC = 3$ and $CA = 4$. Then the value of

    $\displaystyle \dfrac{\cot A + \cot C}{\cot B}$
    is ___ .

    Show answer and solution

    Answer: 2

    With $a = BC = 3$, $b = CA = 4$, $c = AB = \sqrt{23}$ and area $\Delta$: $\cot A = \dfrac{b^2 + c^2 - a^2}{4\Delta}$ and similarly for $B, C$.
    $\cot A + \cot C = \dfrac{2b^2}{4\Delta}$, $\cot B = \dfrac{a^2 + c^2 - b^2}{4\Delta}$.
    Ratio $= \dfrac{2b^2}{a^2 + c^2 - b^2} = \dfrac{32}{9 + 23 - 16} = 2$.

  13. JEE Advanced 2021, Paper 2 · Question 2
    Consider a triangle $PQR$ having sides of lengths $p, q$ and $r$ opposite to the angles $P, Q$ and $R$, respectively. Then which of the following statements is (are) TRUE ?

    1. $\cos P \ge 1 - \dfrac{p^2}{2qr}$
    2. $\cos R \ge \left(\dfrac{q - r}{p + q}\right)\cos P + \left(\dfrac{p - r}{p + q}\right)\cos Q$
    3. $\dfrac{q + r}{p} < 2\dfrac{\sqrt{\sin Q \sin R}}{\sin P}$
    4. If $p < q$ and $p < r$, then $\cos Q > \dfrac{p}{r}$ and $\cos R > \dfrac{p}{q}$
    Show answer and solution

    Answer: (a), (b)

    (A) $\cos P = \dfrac{q^2 + r^2 - p^2}{2qr} \ge \dfrac{2qr - p^2}{2qr} = 1 - \dfrac{p^2}{2qr}$, since $q^2 + r^2 \ge 2qr$ → true.
    (B) Projection formulae: $p = q\cos R + r\cos Q$, $q = p\cos R + r\cos P$ and $r = q\cos P + p\cos Q$.
    Adding the first two: $(p + q)\cos R = p + q - r(\cos P + \cos Q)$.
    Also $(q - r)\cos P + (p - r)\cos Q = r - r(\cos P + \cos Q)$.
    So the inequality is $p + q - r(\cos P + \cos Q) \ge r - r(\cos P + \cos Q)$, i.e. $p + q \ge r$, which holds in a triangle → true.
    (C) By the sine rule the statement is $\dfrac{q + r}{p} < \dfrac{2\sqrt{qr}}{p}$, i.e. $q + r < 2\sqrt{qr}$, which contradicts AM ≥ GM → false.
    (D) $r\cos Q = p - q\cos R$, so $\cos Q > \dfrac{p}{r}$ needs $\cos R < 0$; similarly $\cos R > \dfrac{p}{q}$ needs $\cos Q < 0$. A triangle cannot have both $Q$ and $R$ obtuse → false.
    Answer (A), (B).
