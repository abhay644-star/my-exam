  1. JEE Advanced 2026, Paper 1 · Question 7
    Let $\mathbb{R}$ denote the set of all real numbers. Let $f : \mathbb{R} \to \mathbb{R}$ be an arbitrary function and let $g : \mathbb{R} \to \mathbb{R}$ be the function defined by

    $\displaystyle g(x) = x f(x)\,, \quad \text{for all } x \in \mathbb{R}\,.$
    Then which of the following statements is (are) TRUE ?

    1. The function $g$ is always continuous at $x = 0$
    2. If $f$ is continuous at $x = 0$ , then $g$ is differentiable at $x = 0$
    3. If $g$ is differentiable at $x = 0$ , then $f$ is continuous at $x = 0$
    4. If $g$ is differentiable at $x = 0$ , then $\lim\limits_{x \to 0} f(x)$ exists
    Show answer and solution

    Answer: (b), (d)

    $g(0) = 0$ and $\dfrac{g(x) - g(0)}{x} = f(x)$ for $x \ne 0$, so $g'(0)$ exists iff $\lim_{x\to0} f(x)$ exists.
    (A) false: $f(x) = 1/x$ ($x\ne0$), $f(0)=0$ gives $g = 1$ for $x \ne 0$ but $g(0) = 0$.
    (B) true: if $f$ is continuous at 0, $g'(0) = \lim f(x) = f(0)$.
    (C) false: take $f(x) = 0$ for $x \ne 0$, $f(0) = 1$; then $g \equiv 0$ is differentiable but $f$ is discontinuous.
    (D) true by the first line. Answer (B), (D).

  2. JEE Advanced 2026, Paper 1 · Question 10
    Consider the function $f : \left(-\frac{\pi}{2}, \frac{\pi}{2}\right) \to (-\infty, \infty)$ defined by

    $\displaystyle f(x) = (|x| + |x-1|)\sin x + [x \sin x]\,,$
    where $[x \sin x]$ is the greatest integer less than or equal to $x \sin x$ .

    Let $\alpha$ be the total number of points in the interval $\left(-\frac{\pi}{2}, \frac{\pi}{2}\right)$ at which $f$ is NOT continuous, and let $\beta$ be the total number of points in the interval $\left(-\frac{\pi}{2}, \frac{\pi}{2}\right)$ at which $f$ is NOT differentiable.

    Then the value of $\alpha + \beta$ is ______.

    Show answer and solution

    Answer: 5

    $h(x) = x\sin x$ is even, $h(0) = 0$, increasing on $[0, \pi/2)$ with values in $[0, \pi/2)$.
    $[h(x)]$ jumps from 0 to 1 only where $x\sin x = 1$, i.e. at $x = \pm a$ ($a \approx 1.11$). So $\alpha = 2$.
    $|x|\sin x$ is differentiable at 0 (it behaves like $x|x|$), while $|x-1|\sin x$ is not differentiable at $x = 1$ since $\sin 1 \ne 0$; $1 \ne a$.
    Non-differentiable points: $\pm a$ and $1$, so $\beta = 3$.
    $\alpha + \beta = 5$.

  3. JEE Advanced 2026, Paper 2 · Question 14
    For a real number $\alpha$ , let $[\alpha]$ denote the greatest integer less than or equal to $\alpha$. For a finite set $S$ , let $|S|$ denote the number of elements in the set $S$ .

    Consider the functions $f : (-3, 3) \to (-\infty,\ \infty)$ and $g : (-3, 3) \to (-\infty,\ \infty)$ defined by

    $\displaystyle f(x) = [x^3]\log_e\big(1 + \sin^2(\pi(x - [x]))\big)$
    and
    $\displaystyle g(x) = x^3 \sin^2(\pi \log_e(1 + x - [x])).$
    Let
    $\displaystyle A = \{x \in (-3, 3) : f \text{ is discontinuous at } x\}$
    and
    $\displaystyle B = \{x \in (-3, 3) : g \text{ is discontinuous at } x\}.$
    Then the value of $|A| + 2|B| - |A \cap B|$ is ________.

    Show answer and solution

    Answer: 56

    $\sin^2(\pi(x-[x]))=\sin^2\pi x$, so the log factor is continuous and vanishes exactly at integers.
    $[x^3]$ jumps where $x^3=k$, $k=-26,\dots,26$ (53 points). At integer $x$ ($-2..2$, 5 points) the log factor is 0 and $f$ stays continuous; elsewhere it jumps. $|A|=48$.
    For $g$: as $x\to n^+$, factor $\to\sin^2 0=0$ ($=g(n)$); as $x\to n^-$, $\to n^3\sin^2(\pi\log_e2)\ne0$ unless $n=0$.
    $B=\{-2,-1,1,2\}$, $|B|=4$, $A\cap B=\varnothing$.
    Value $=48+8-0=56$.

  4. JEE Advanced 2025, Paper 2 · Question 14
    Let $\mathbb{R}$ denote the set of all real numbers. Let $f:\mathbb{R}\to\mathbb{R}$ and $g:\mathbb{R}\to(0,4)$ be functions defined by

    $\displaystyle f(x)=\log_e(x^2+2x+4),\quad\text{and}\quad g(x)=\dfrac{4}{1+e^{-2x}}.$
    Define the composite function $f\circ g^{-1}$ by $(f\circ g^{-1})(x)=f\left(g^{-1}(x)\right)$, where $g^{-1}$ is the inverse of the function $g$.

    Then the value of the derivative of the composite function $f\circ g^{-1}$ at $x=2$ is ________.

    Show answer and solution

    Answer: 0.2 to 0.3

    $g(a)=2\Rightarrow1+e^{-2a}=2\Rightarrow a=0$, so $g^{-1}(2)=0$.
    $(f\circ g^{-1})'(2)=\dfrac{f'(0)}{g'(0)}$.
    $f'(x)=\dfrac{2x+2}{x^2+2x+4}\Rightarrow f'(0)=\dfrac12$; $g'(x)=\dfrac{8e^{-2x}}{(1+e^{-2x})^2}\Rightarrow g'(0)=2$.
    Value $=\dfrac{1/2}{2}=0.25$.

  5. JEE Advanced 2024, Paper 1 · Question 17
    Let $f : \mathbb{R} \to \mathbb{R}$ and $g : \mathbb{R} \to \mathbb{R}$ be functions defined by $$f(x) = \begin{cases} x|x|\sin\left(\dfrac{1}{x}\right), & x \neq 0, \\ 0, & x = 0, \end{cases} \qquad \text{and} \qquad g(x) = \begin{cases} 1 - 2x, & 0 \le x \le \dfrac{1}{2}, \\ 0, & \text{otherwise}. \end{cases}$$Let $a, b, c, d \in \mathbb{R}$. Define the function $h : \mathbb{R} \to \mathbb{R}$ by

    $\displaystyle h(x) = a\,f(x) + b\left(g(x) + g\left(\frac{1}{2} - x\right)\right) + c\left(x - g(x)\right) + d\,g(x), \quad x \in \mathbb{R}.$
    Match each entry in List-I to the correct entry in List-II.
    List-IList-II
    (P) If $a = 0$, $b = 1$, $c = 0$, and $d = 0$, then(1) $h$ is one-one.
    (Q) If $a = 1$, $b = 0$, $c = 0$, and $d = 0$, then(2) $h$ is onto.
    (R) If $a = 0$, $b = 0$, $c = 1$, and $d = 0$, then(3) $h$ is differentiable on $\mathbb{R}$.
    (S) If $a = 0$, $b = 0$, $c = 0$, and $d = 1$, then(4) the range of $h$ is $[0, 1]$.
    (5) the range of $h$ is $\{0, 1\}$.

    1. P→4, Q→3, R→1, S→2
    2. P→5, Q→2, R→4, S→3
    3. P→5, Q→3, R→2, S→4
    4. P→4, Q→2, R→1, S→3
    Show answer and solution

    Answer: (c)

    (P) $h(x) = g(x) + g\left(\frac12 - x\right)$. For $0 \le x \le \frac12$ both arguments lie in $[0, \frac12]$: $h = (1 - 2x) + 2x = 1$. Otherwise both terms are 0. Range $\{0, 1\}$ → (5).
    (Q) $h = f$. For $x \neq 0$, $f$ is differentiable, and $f'(0) = \lim_{x\to0}|x|\sin\frac1x = 0$. So $h$ is differentiable on $\mathbb{R}$ → (3).
    (R) $h(x) = x - g(x)$: equal to $x$ for $x \lt 0$ and $x > \frac12$, and $3x - 1$ on $[0, \frac12]$ (from $-1$ to $\frac12$). The pieces cover $(-\infty, 0) \cup [-1, \frac12] \cup (\frac12, \infty) = \mathbb{R}$: onto (not one-one, e.g. $h = -\frac12$ twice) → (2).
    (S) $h = g$, with range $[0, 1]$ → (4).
    P→5, Q→3, R→2, S→4 → (C).

  6. JEE Advanced 2023, Paper 1 · Question 1
    Let $S=(0,1)\cup(1,2)\cup(3,4)$ and $T=\{0,1,2,3\}$. Then which of the following statements is(are) true?

    1. There are infinitely many functions from $S$ to $T$
    2. There are infinitely many strictly increasing functions from $S$ to $T$
    3. The number of continuous functions from $S$ to $T$ is at most $120$
    4. Every continuous function from $S$ to $T$ is differentiable
    Show answer and solution

    Answer: (a), (c), (d)

    (A) $S$ is infinite and $T$ has 4 elements, so there are infinitely many functions $S \to T$ (in fact uncountably many). True.
    (B) A strictly increasing function is one-one, but an infinite set cannot map one-one into a 4-element set. So there is none. False.
    (C) A continuous function into the discrete set $T$ is constant on each interval $(0,1)$, $(1,2)$, $(3,4)$. So there are $4^3 = 64 \le 120$ continuous functions. True.
    (D) Each continuous function is locally constant, so its derivative exists and equals $0$ everywhere on $S$. True.
    Answer (A), (C), (D).

  7. JEE Advanced 2023, Paper 2 · Question 6
    Let $f : (0, 1) \to \mathbb{R}$ be the function defined as $f(x) = [4x]\left(x - \dfrac14\right)^2\left(x - \dfrac12\right)$, where $[x]$ denotes the greatest integer less than or equal to $x$. Then which of the following statements is(are) true?

    1. The function $f$ is discontinuous exactly at one point in $(0, 1)$
    2. There is exactly one point in $(0, 1)$ at which the function $f$ is continuous but NOT differentiable
    3. The function $f$ is NOT differentiable at more than three points in $(0, 1)$
    4. The minimum value of the function $f$ is $-\dfrac{1}{512}$
    Show answer and solution

    Answer: (a), (b)

    $[4x] = 0, 1, 2, 3$ on $\left(0,\tfrac14\right), \left[\tfrac14,\tfrac12\right), \left[\tfrac12,\tfrac34\right), \left[\tfrac34,1\right)$. Let $g(x) = \left(x-\tfrac14\right)^2\left(x-\tfrac12\right)$.
    $x = \tfrac14$: $g$ has a double zero, so $f$ is continuous and differentiable there (both one-sided derivatives are 0).
    $x = \tfrac12$: $g = 0$ so $f$ is continuous; one-sided derivatives are $1\cdot g'(\tfrac12)$ and $2\cdot g'(\tfrac12)$ with $g'(\tfrac12) = \tfrac{1}{16} \ne 0$: not differentiable.
    $x = \tfrac34$: $g(\tfrac34) = \tfrac{1}{16} \ne 0$, so the jump in $[4x]$ makes $f$ discontinuous.
    So (A) and (B) are true; $f$ fails to be differentiable at only two points, so (C) is false.
    (D): $f < 0$ only on $\left(\tfrac14, \tfrac12\right)$ where $f = g$; $g'(x) = \left(x-\tfrac14\right)\left(3x - \tfrac54\right) = 0$ at $x = \tfrac{5}{12}$, $g = \tfrac{1}{36}\cdot\left(-\tfrac{1}{12}\right) = -\tfrac{1}{432} \ne -\tfrac{1}{512}$: false.
    Answer (A), (B).

  8. JEE Advanced 2021, Paper 2 · Question 3
    Let $f : \left[-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right] \to \mathbb{R}$ be a continuous function such that

    $\displaystyle f(0) = 1 \text{ and } \int_0^{\pi/3} f(t)\,dt = 0.$
    Then which of the following statements is (are) TRUE ?

    1. The equation $f(x) - 3\cos 3x = 0$ has at least one solution in $\left(0, \dfrac{\pi}{3}\right)$
    2. The equation $f(x) - 3\sin 3x = -\dfrac{6}{\pi}$ has at least one solution in $\left(0, \dfrac{\pi}{3}\right)$
    3. $\lim\limits_{x \to 0} \dfrac{x\int_0^x f(t)\,dt}{1 - e^{x^2}} = -1$
    4. $\lim\limits_{x \to 0} \dfrac{\sin x \int_0^x f(t)\,dt}{x^2} = -1$
    Show answer and solution

    Answer: (a), (b), (c)

    Let $F(x) = \int_0^x f(t)\,dt$; then $F(0) = F\left(\dfrac{\pi}{3}\right) = 0$ and $F'(x) = f(x)$.
    (A) $h(x) = F(x) - \sin 3x$ has $h(0) = 0 = h\left(\dfrac{\pi}{3}\right)$. By Rolle's theorem $h'(c) = f(c) - 3\cos 3c = 0$ for some $c \in \left(0, \dfrac{\pi}{3}\right)$ → true.
    (B) $h(x) = F(x) + \cos 3x + \dfrac{6x}{\pi}$ has $h(0) = 1$ and $h\left(\dfrac{\pi}{3}\right) = 0 - 1 + 2 = 1$. Rolle: $f(c) - 3\sin 3c + \dfrac{6}{\pi} = 0$ → true.
    (C) $1 - e^{x^2} \sim -x^2$, so the limit is $-\lim\limits_{x\to0}\dfrac{F(x)}{x} = -F'(0) = -f(0) = -1$ → true.
    (D) $\dfrac{\sin x \, F(x)}{x^2} \to 1 \cdot f(0) = 1 \ne -1$ → false.
    Answer (A), (B), (C).
