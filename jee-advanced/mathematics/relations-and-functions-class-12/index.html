  1. JEE Advanced 2026, Paper 1 · Question 9
    Let $S = \{1, 2, 3, \ldots, 10\}$ . Consider the set

    $\displaystyle X = \{R : R \text{ is an equivalence relation on the set } S \text{ such that } R \text{ has exactly } 42 \text{ elements}\}.$
    Then the number of elements in $X$ is ______.

    Show answer and solution

    Answer: 2520

    An equivalence relation with classes of sizes $n_1, n_2, \ldots$ has $\sum n_i^2$ ordered pairs, with $\sum n_i = 10$.
    Need $\sum n_i^2 = 42$: the only partitions of 10 are $\{5,4,1\}$ ($25+16+1$) and $\{6,2,1,1\}$ ($36+4+1+1$).
    $\{5,4,1\}$: $\dfrac{10!}{5!\,4!\,1!} = 1260$ relations.
    $\{6,2,1,1\}$: $\dfrac{10!}{6!\,2!\,1!\,1!\cdot 2!} = 1260$ relations.
    Total $= 2520$.

  2. JEE Advanced 2026, Paper 2 · Question 10
    Let $\mathbb{N}$ denote the set of all positive integers. Consider the sets

    $\displaystyle A = \{1, 2, 3, 4, 5\} \text{ and } B = \{1, 2, 3, 4, 5, 6, 7\}.$
    Let $S$ be the set of all functions $f : A \to B$ such that $f(2) \neq 2$ and $f(4) \neq 4$. Consider the set
    $\displaystyle T = \left\{ f \in S : \text{there exists a function } g : B \to \mathbb{N} \text{ such that } g\big(f(x)\big) = 2^x \text{ for all } x \in A \right\}.$
    Then the number of elements in the set $T$ is ________.

    Show answer and solution

    Answer: 1860

    $2^x$ takes distinct values on $A$, so such $g$ exists iff $f$ is one-one ($g$ can be anything off the range).
    One-one $f:A\to B$: $^7P_5=2520$.
    With $f(2)=2$: $^6P_4=360$; with $f(4)=4$: 360; both: $^5P_3=60$.
    $|T|=2520-720+60=1860$.

  3. JEE Advanced 2025, Paper 1 · Question 6
    Let $\mathbb{N}$ denote the set of all natural numbers, and $\mathbb{Z}$ denote the set of all integers. Consider the functions $f : \mathbb{N} \to \mathbb{Z}$ and $g : \mathbb{Z} \to \mathbb{N}$ defined by $$f(n) = \begin{cases} (n+1)/2 & \text{if } n \text{ is odd}, \\ (4-n)/2 & \text{if } n \text{ is even}, \end{cases}$$and $$g(n) = \begin{cases} 3 + 2n & \text{if } n \ge 0, \\ -2n & \text{if } n \lt 0. \end{cases}$$Define $(g\circ f)(n) = g(f(n))$ for all $n \in \mathbb{N}$, and $(f\circ g)(n) = f(g(n))$ for all $n \in \mathbb{Z}$.

    Then which of the following statements is (are) TRUE?

    1. $g\circ f$ is NOT one-one and $g\circ f$ is NOT onto
    2. $f\circ g$ is NOT one-one but $f\circ g$ is onto
    3. $g$ is one-one and $g$ is onto
    4. $f$ is NOT one-one but $f$ is onto
    Show answer and solution

    Answer: (a), (d)

    $f$: odd $n = 1, 3, 5, \ldots$ give $1, 2, 3, \ldots$; even $n = 2, 4, 6, \ldots$ give $1, 0, -1, \ldots$
    So $f(1) = f(2) = 1$ (not one-one) and every integer is attained (onto): (D) true.
    $g$: $n \ge 0$ gives $3, 5, 7, \ldots$; $n \lt 0$ gives $2, 4, 6, \ldots$. So $g$ is one-one, but $1$ is never attained: not onto; (C) false.
    $g\circ f$: not one-one since $f$ is not; its range is $g(\mathbb{Z}) = \mathbb{N}\setminus\{1\}$, so not onto: (A) true.
    $f\circ g$: $g$ is one-one with range $\{2,3,4,\ldots\}$; on this set odd values map to $2,3,\ldots$ and even values to $1,0,-1,\ldots$, all distinct, so $f\circ g$ is one-one: (B) false.
    Answer: (A), (D).

  4. JEE Advanced 2025, Paper 1 · Question 8
    Let the set of all relations $R$ on the set $\{a, b, c, d, e, f\}$, such that $R$ is reflexive and symmetric, and $R$ contains exactly $10$ elements, be denoted by $\mathcal{S}$.

    Then the number of elements in $\mathcal{S}$ is ______.

    Show answer and solution

    Answer: 105

    Reflexive: all $6$ pairs $(x,x)$ are in $R$, leaving $4$ more ordered pairs.
    Symmetric: off-diagonal pairs come in pairs $(x,y),(y,x)$, so $R$ contains exactly $2$ unordered pairs $\{x,y\}$.
    There are $\binom62 = 15$ unordered pairs, so the count is $\binom{15}{2} = 105$.

  5. JEE Advanced 2024, Paper 2 · Question 15
    Let $S=\{1,2,3,4,5,6\}$ and $X$ be the set of all relations $R$ from $S$ to $S$ that satisfy both the following properties:
    i. $R$ has exactly $6$ elements.
    ii. For each $(a,b)\in R$, we have $|a-b|\ge 2$.
    Let $Y=\{R\in X : \text{The range of } R \text{ has exactly one element}\}$ and $Z=\{R\in X : R \text{ is a function from } S \text{ to } S\}$.
    Let $n(A)$ denote the number of elements in a set $A$.

    If the value of $n(Y)+n(Z)$ is $k^2$, then $|k|$ is _____________.

    Show answer and solution

    Answer: 35.99 to 36.01

    $Y$: all $6$ pairs have the same second entry $b$, so we need at least $6$ values of $a$ with $|a-b|\ge2$; but for $b=1,\ldots,6$ there are only $4,3,3,3,3,4$ such $a$. So $n(Y)=0$.
    $Z$: a function assigns each $a$ one image $b$ with $|a-b|\ge2$: $4,3,3,3,3,4$ choices for $a=1,\ldots,6$.
    $n(Z)=4\cdot3^4\cdot4=1296$.
    $k^2=0+1296\Rightarrow|k|=36$.
