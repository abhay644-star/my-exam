  1. JEE Advanced 2025, Paper 1 · Question 1
    Let $\mathbb{R}$ denote the set of all real numbers. Let $a_i, b_i \in \mathbb{R}$ for $i \in \{1, 2, 3\}$.
    Define the functions $f : \mathbb{R} \to \mathbb{R}$, $g : \mathbb{R} \to \mathbb{R}$, and $h : \mathbb{R} \to \mathbb{R}$ by

    $\displaystyle f(x) = a_1 + 10x + a_2x^2 + a_3x^3 + x^4,$
    $\displaystyle g(x) = b_1 + 3x + b_2x^2 + b_3x^3 + x^4,$
    $\displaystyle h(x) = f(x+1) - g(x+2).$
    If $f(x) \neq g(x)$ for every $x \in \mathbb{R}$, then the coefficient of $x^3$ in $h(x)$ is

    1. $8$
    2. $2$
    3. $-4$
    4. $-6$
    Show answer and solution

    Answer: (c)

    $f(x) - g(x) = (a_3-b_3)x^3 + (a_2-b_2)x^2 + 7x + (a_1-b_1)$.
    A real cubic always has a real root, so $f - g$ can never be zero only if it is not a cubic: $a_3 = b_3$.
    Coefficient of $x^3$ in $f(x+1)$: from $(x+1)^4$ it is $4$, from $a_3(x+1)^3$ it is $a_3$.
    Coefficient of $x^3$ in $g(x+2)$: from $(x+2)^4$ it is $4\cdot 2 = 8$, from $b_3(x+2)^3$ it is $b_3$.
    Coefficient in $h$: $4 + a_3 - 8 - b_3 = -4$ → (C).

  2. JEE Advanced 2024, Paper 1 · Question 8
    Let $a = 3\sqrt{2}$ and $b = \dfrac{1}{5^{1/6}\sqrt{6}}$. If $x, y \in \mathbb{R}$ are such that

    $\displaystyle 3x + 2y = \log_a (18)^{\frac{5}{4}} \quad \text{and} \quad 2x - y = \log_b\left(\sqrt{1080}\right),$
    then $4x + 5y$ is equal to ________.

    Show answer and solution

    Answer: 8

    $a^2 = 18$, so $\log_a 18^{5/4} = \dfrac54 \cdot 2 = \dfrac52$: $3x + 2y = \dfrac52$.
    $b^{-6} = 5 \cdot 6^3 = 1080$, so $\sqrt{1080} = b^{-3}$ and $\log_b\sqrt{1080} = -3$: $2x - y = -3$.
    $y = 2x + 3 \Rightarrow 3x + 4x + 6 = \dfrac52 \Rightarrow x = -\dfrac12$, $y = 2$.
    $4x + 5y = -2 + 10 = 8$.

  3. JEE Advanced 2024, Paper 2 · Question 8
    Let $f:\mathbb{R}\to\mathbb{R}$ be a function such that $f(x+y)=f(x)+f(y)$ for all $x,y\in\mathbb{R}$, and $g:\mathbb{R}\to(0,\infty)$ be a function such that $g(x+y)=g(x)g(y)$ for all $x,y\in\mathbb{R}$. If $f\left(\dfrac{-3}{5}\right)=12$ and $g\left(\dfrac{-1}{3}\right)=2$, then the value of

    $\displaystyle \left(f\left(\dfrac14\right)+g(-2)-8\right)g(0)$
    is ________.

    Show answer and solution

    Answer: 51

    Additivity gives $f(r)=r\,f(1)$ for every rational $r$: $f\left(-\dfrac35\right)=-\dfrac35f(1)=12\Rightarrow f(1)=-20$, so $f\left(\dfrac14\right)=-5$.
    Similarly $g(r)=g(1)^r$ for rational $r$ and $g(0)=1$: $g(1)^{-1/3}=2\Rightarrow g(1)=\dfrac18$, so $g(-2)=8^2=64$.
    Value $=(-5+64-8)\times1=51$.

  4. JEE Advanced 2022, Paper 2 · Question 4
    The product of all positive real values of $x$ satisfying the equation

    $\displaystyle x^{\left(16(\log_5 x)^3 - 68\log_5 x\right)} = 5^{-16}$
    is ________.

    Show answer and solution

    Answer: 1

    Take $\log_5$ and let $t = \log_5 x$: $(16t^3 - 68t)\,t = -16$.
    $16t^4 - 68t^2 + 16 = 0 \Rightarrow 4t^4 - 17t^2 + 4 = 0 \Rightarrow t^2 = 4$ or $t^2 = \dfrac14$.
    $t = \pm2, \pm\dfrac12$, whose sum is $0$.
    Product of the $x$ values $= 5^{\sum t} = 5^0 = 1$.
