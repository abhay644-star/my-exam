  1. JEE Advanced 2026, Paper 1 · Question 13
    Match each entry in List-I to the correct entry in List-II and choose the correct option.

    List-IList-II
    (P) If $\alpha$ and $\beta$ are the distinct roots of the equation $x^2 + x + 1 = 0$, then the quadratic equation with roots $\frac{1}{(\alpha+1)^{2026}}$ and $\frac{1}{(\beta+1)^{2026}}$ is(1) $x^2 + x + 1 = 0$
    (Q) If $\alpha$ and $\beta$ are the distinct roots of the equation $x^2 + x + 1 = 0$, then the quadratic equation with roots $\frac{1}{(\alpha+1)^{2027}}$ and $\frac{1}{(\beta+1)^{2027}}$ is(2) $x^2 - x + 1 = 0$
    (R) If $\gamma$ and $\delta$ are the distinct roots of the equation $x^2 - x + 1 = 0$, then the value of $\frac{1}{(\gamma-1)^{2026}} + \frac{1}{(\delta-1)^{2026}}$ is(3) $x^2 + x - 1 = 0$
    (S) If $p$ and $r$ are the distinct roots of the equation $x^2 + x - 1 = 0$, then the value of $\frac{1}{(p+1)^3} + \frac{1}{(r+1)^3}$ is(4) $-1$
    (5) $-4$

    1. (P) → (1), (Q) → (2), (R) → (5), (S) → (4)
    2. (P) → (3), (Q) → (1), (R) → (4), (S) → (5)
    3. (P) → (1), (Q) → (2), (R) → (4), (S) → (5)
    4. (P) → (2), (Q) → (3), (R) → (5), (S) → (4)
    Show answer and solution

    Answer: (c)

    (P) $\alpha, \beta = \omega, \omega^2$ and $\omega + 1 = -\omega^2$, so $(\omega+1)^{2026} = \omega^{4052} = \omega^2$; roots become $\omega, \omega^2$: $x^2 + x + 1 = 0$ → (1).
    (Q) $(\omega+1)^{2027} = -\omega^{4054} = -\omega$; roots $-\omega^2, -\omega$ (sum 1, product 1): $x^2 - x + 1 = 0$ → (2).
    (R) $\gamma, \delta = -\omega, -\omega^2$; $\gamma - 1 = \omega^2$, $\delta - 1 = \omega$. Sum $= \omega^{-4052} + \omega^{-2026} = \omega + \omega^2 = -1$ → (4).
    (S) $y = p+1, r+1$ satisfy $y^2 - y - 1 = 0$, so $u = 1/y$ satisfies $u^2 + u - 1 = 0$ (sum $-1$, product $-1$). $u_1^3 + u_2^3 = (-1)^3 - 3(-1)(-1) = -4$ → (5).
    Answer (C).

  2. JEE Advanced 2026, Paper 2 · Question 6
    Let $a,\ b,\ c$ be positive integers in arithmetic progression such that the equation

    $\displaystyle ax^2 + bx + c = 0$
    has only integer solutions.

    Then which of the following statements is (are) TRUE ?

    1. $c - b$ is an integer multiple of $a$
    2. Both the roots of the equation $ax^2 + bx + c = 0$ are odd integers
    3. If $c = 15$ , then $ab = 8$
    4. If $b = 8$ , then $x = 3$ is a root of the equation $ax^2 + bx + c = 0$
    Show answer and solution

    Answer: (a), (b), (c)

    Integer roots give $b/a=m$, $c/a=n$ integers; AP gives $n=2m-1$, so $x^2+mx+2m-1=0$.
    Discriminant $m^2-8m+4=(m-4)^2-12$ must be a perfect square $k^2$: $(m-4-k)(m-4+k)=12$ with equal parity gives $m-4=\pm4$; $m>0$ so $m=8$, $n=15$.
    Equation $\equiv x^2+8x+15=0$, roots $-3,-5$; $b=8a$, $c=15a$.
    (A) $c-b=7a$ ✓. (B) $-3,-5$ odd ✓. (C) $c=15\Rightarrow a=1,b=8$, $ab=8$ ✓. (D) roots are $-3,-5$, not $3$ ✗.

  3. JEE Advanced 2025, Paper 1 · Question 7
    Let $\mathbb{R}$ denote the set of all real numbers. Let $z_1 = 1 + 2i$ and $z_2 = 3i$ be two complex numbers, where $i = \sqrt{-1}$. Let

    $\displaystyle S = \{(x, y) \in \mathbb{R}\times\mathbb{R} : |x + iy - z_1| = 2|x + iy - z_2|\}.$
    Then which of the following statements is (are) TRUE?

    1. $S$ is a circle with centre $\left(-\dfrac{1}{3}, \dfrac{10}{3}\right)$
    2. $S$ is a circle with centre $\left(\dfrac{1}{3}, \dfrac{8}{3}\right)$
    3. $S$ is a circle with radius $\dfrac{\sqrt{2}}{3}$
    4. $S$ is a circle with radius $\dfrac{2\sqrt{2}}{3}$
    Show answer and solution

    Answer: (a), (d)

    $(x-1)^2 + (y-2)^2 = 4\left[x^2 + (y-3)^2\right]$.
    $x^2 - 2x + y^2 - 4y + 5 = 4x^2 + 4y^2 - 24y + 36 \Rightarrow 3x^2 + 3y^2 + 2x - 20y + 31 = 0$.
    $x^2 + y^2 + \dfrac23x - \dfrac{20}{3}y + \dfrac{31}{3} = 0$: centre $\left(-\dfrac13, \dfrac{10}{3}\right)$.
    $r^2 = \dfrac19 + \dfrac{100}{9} - \dfrac{93}{9} = \dfrac89$, so $r = \dfrac{2\sqrt2}{3}$.
    Answer: (A), (D).

  4. JEE Advanced 2025, Paper 2 · Question 13
    For a non-zero complex number $z$, let $\arg(z)$ denote the principal argument of $z$, with $-\pi<\arg(z)\le\pi$. Let $\omega$ be the cube root of unity for which $0<\arg(\omega)<\pi$. Let

    $\displaystyle \alpha=\arg\left(\sum_{n=1}^{2025}(-\omega)^n\right).$
    Then the value of $\dfrac{3\alpha}{\pi}$ is ________.

    Show answer and solution

    Answer: -2

    $\omega=e^{2\pi i/3}$, so $-\omega=e^{-i\pi/3}$ is a primitive 6th root of unity; the sum over any 6 consecutive powers is $0$.
    $2025=6\times337+3$, so the sum $=(-\omega)+(-\omega)^2+(-\omega)^3=-\omega+\omega^2-1$.
    Using $1+\omega+\omega^2=0$: $-\omega+\omega^2-1=-2-2\omega=-2(1+\omega)=2\omega^2$.
    $\omega^2=e^{4\pi i/3}$ has principal argument $-\dfrac{2\pi}{3}$, so $\alpha=-\dfrac{2\pi}{3}$.
    $\dfrac{3\alpha}{\pi}=-2$.

  5. JEE Advanced 2024, Paper 1 · Question 5
    Let $S = \left\{a + b\sqrt{2} : a, b \in \mathbb{Z}\right\}$, $T_1 = \left\{\left(-1+\sqrt{2}\right)^n : n \in \mathbb{N}\right\}$, and $T_2 = \left\{\left(1+\sqrt{2}\right)^n : n \in \mathbb{N}\right\}$. Then which of the following statements is (are) TRUE?

    1. $\mathbb{Z} \cup T_1 \cup T_2 \subset S$
    2. $T_1 \cap \left(0, \dfrac{1}{2024}\right) = \phi$, where $\phi$ denotes the empty set.
    3. $T_2 \cap (2024, \infty) \neq \phi$
    4. For any given $a, b \in \mathbb{Z}$, $\cos\left(\pi\left(a + b\sqrt{2}\right)\right) + i\sin\left(\pi\left(a + b\sqrt{2}\right)\right) \in \mathbb{Z}$ if and only if $b = 0$, where $i = \sqrt{-1}$.
    Show answer and solution

    Answer: (a), (c), (d)

    (A) $\mathbb{Z} \subset S$ ($b = 0$), and $S$ is closed under multiplication, so every power of $-1+\sqrt2 \in S$ and of $1+\sqrt2 \in S$ lies in $S$. TRUE.
    (B) $0 \lt \sqrt2 - 1 \lt 1$, so $(\sqrt2-1)^n \to 0$ and some power lies in $\left(0, \dfrac{1}{2024}\right)$. FALSE.
    (C) $1 + \sqrt2 > 1$, so $(1+\sqrt2)^n \to \infty$ and exceeds 2024. TRUE.
    (D) The number is $e^{i\pi\theta}$ with $\theta = a + b\sqrt2$; it has modulus 1, so it is an integer only if it is $\pm1$, i.e. $\theta \in \mathbb{Z}$. As $\sqrt2$ is irrational, this happens if and only if $b = 0$. TRUE.
    Answer: (A), (C), (D).

  6. JEE Advanced 2024, Paper 1 · Question 9
    Let $f(x) = x^4 + ax^3 + bx^2 + c$ be a polynomial with real coefficients such that $f(1) = -9$. Suppose that $i\sqrt{3}$ is a root of the equation $4x^3 + 3ax^2 + 2bx = 0$, where $i = \sqrt{-1}$. If $\alpha_1, \alpha_2, \alpha_3$, and $\alpha_4$ are all the roots of the equation $f(x) = 0$, then $|\alpha_1|^2 + |\alpha_2|^2 + |\alpha_3|^2 + |\alpha_4|^2$ is equal to ______.

    Show answer and solution

    Answer: 20

    $4x^3 + 3ax^2 + 2bx = x(4x^2 + 3ax + 2b)$; with real coefficients, $\pm i\sqrt3$ are the roots of $4x^2 + 3ax + 2b = 0$.
    Sum of roots $0 \Rightarrow a = 0$; product $3 = \dfrac{2b}{4} \Rightarrow b = 6$.
    $f(1) = 1 + 6 + c = -9 \Rightarrow c = -16$, so $f(x) = x^4 + 6x^2 - 16 = (x^2 - 2)(x^2 + 8)$.
    Roots $\pm\sqrt2$ and $\pm 2\sqrt2\, i$: $|\alpha|^2 = 2, 2, 8, 8$.
    Sum $= 20$.

  7. JEE Advanced 2023, Paper 1 · Question 11
    Let $A = \left\{\dfrac{1967 + 1686\,i\sin\theta}{7 - 3i\cos\theta} : \theta \in \mathbb{R}\right\}$. If $A$ contains exactly one positive integer $n$, then the value of $n$ is ______.

    Show answer and solution

    Answer: 281

    Multiply by the conjugate: $\dfrac{(1967 + 1686 i\sin\theta)(7 + 3i\cos\theta)}{49 + 9\cos^2\theta}$.
    Imaginary part $0$: $5901\cos\theta + 11802\sin\theta = 0 \Rightarrow \cos\theta = -2\sin\theta$, so $\sin^2\theta = \dfrac15$, $\cos^2\theta = \dfrac45$, $\sin\theta\cos\theta = -\dfrac25$.
    Real part $= \dfrac{13769 - 5058\sin\theta\cos\theta}{49 + 9\cos^2\theta} = \dfrac{13769 + \frac{10116}{5}}{49 + \frac{36}{5}} = \dfrac{78961}{281} = 281$.
    So $n = 281$.

  8. JEE Advanced 2023, Paper 1 · Question 17
    Let $z$ be a complex number satisfying $|z|^3 + 2z^2 + 4\bar{z} - 8 = 0$, where $\bar{z}$ denotes the complex conjugate of $z$. Let the imaginary part of $z$ be nonzero.
    Match each entry in List-I to the correct entries in List-II.

    List-IList-II
    (P) $|z|^2$ is equal to(1) $12$
    (Q) $|z - \bar{z}|^2$ is equal to(2) $4$
    (R) $|z|^2 + |z + \bar{z}|^2$ is equal to(3) $8$
    (S) $|z + 1|^2$ is equal to(4) $10$
    (5) $7$

    1. (P) → (1), (Q) → (3), (R) → (5), (S) → (4)
    2. (P) → (2), (Q) → (1), (R) → (3), (S) → (5)
    3. (P) → (2), (Q) → (4), (R) → (5), (S) → (1)
    4. (P) → (2), (Q) → (3), (R) → (5), (S) → (4)
    Show answer and solution

    Answer: (b)

    Let $z = x + iy$, $r = |z|$. Imaginary part: $4xy - 4y = 0 \Rightarrow x = 1$ (as $y \ne 0$).
    Real part: $r^3 + 2(x^2 - y^2) + 4x - 8 = 0 \Rightarrow r^3 - 2y^2 - 2 = 0$. With $y^2 = r^2 - 1$: $r^3 - 2r^2 = 0 \Rightarrow r = 2$, $y^2 = 3$.
    (P) $|z|^2 = 4$ → (2). (Q) $|2iy|^2 = 4y^2 = 12$ → (1).
    (R) $4 + |2x|^2 = 4 + 4 = 8$ → (3). (S) $(x+1)^2 + y^2 = 4 + 3 = 7$ → (5).
    Answer (B).

  9. JEE Advanced 2023, Paper 2 · Question 11
    Let $A_1, A_2, A_3, \ldots, A_8$ be the vertices of a regular octagon that lie on a circle of radius 2. Let $P$ be a point on the circle and let $PA_i$ denote the distance between the points $P$ and $A_i$ for $i = 1, 2, \ldots, 8$. If $P$ varies over the circle, then the maximum value of the product $PA_1 \cdot PA_2 \cdots PA_8$, is ________.

    Show answer and solution

    Answer: 512

    Take the vertices as $2\omega^k$, $\omega = e^{2\pi i/8}$, the roots of $z^8 = 2^8$.
    For $P = z$ on the circle, $\prod_{k} |z - 2\omega^k| = |z^8 - 2^8|$.
    With $z = 2e^{i\theta}$: $|2^8 e^{8i\theta} - 2^8| = 256\,|e^{8i\theta} - 1| \le 256 \times 2$.
    Maximum $= 512$.

  10. JEE Advanced 2022, Paper 1 · Question 4
    Let $z$ be a complex number with non-zero imaginary part. If

    $\displaystyle \frac{2+3z+4z^2}{2-3z+4z^2}$
    is a real number, then the value of $|z|^2$ is ______.

    Show answer and solution

    Answer: 0.49 to 0.51

    Write the ratio as $\dfrac{1+u}{1-u}$ with $u=\dfrac{3z}{2+4z^2}$; it is real exactly when $u$ is real, i.e. when $\dfrac{2+4z^2}{z}=\dfrac{2}{z}+4z$ is real.
    With $z=re^{i\theta}$: $\operatorname{Im}\left(\dfrac2z+4z\right)=\sin\theta\left(4r-\dfrac2r\right)=0$.
    $\sin\theta\neq0$ (non-zero imaginary part), so $r^2=\dfrac12$, i.e. $|z|^2=0.5$.

  11. JEE Advanced 2022, Paper 1 · Question 5
    Let $\bar{z}$ denote the complex conjugate of a complex number $z$ and let $i=\sqrt{-1}$. In the set of complex numbers, the number of distinct roots of the equation

    $\displaystyle \bar{z}-z^2=i\left(\bar{z}+z^2\right)$
    is ______.

    Show answer and solution

    Answer: 4

    $\bar z(1-i)=z^2(1+i)\Rightarrow \bar z=\dfrac{1+i}{1-i}z^2=iz^2$.
    $z=0$ is a root.
    Otherwise $|z|=|z|^2\Rightarrow|z|=1$, so $\bar z=\dfrac1z$ and $\dfrac1z=iz^2\Rightarrow z^3=\dfrac1i=-i$, which has 3 distinct roots (all of modulus 1).
    Total: $1+3=4$ distinct roots.

  12. JEE Advanced 2022, Paper 2 · Question 11
    Let $\bar z$ denote the complex conjugate of a complex number $z$. If $z$ is a non-zero complex number for which both real and imaginary parts of

    $\displaystyle (\bar z)^2 + \frac{1}{z^2}$
    are integers, then which of the following is/are possible value(s) of $|z|$ ?

    1. $\left(\dfrac{43+3\sqrt{205}}{2}\right)^{\frac14}$
    2. $\left(\dfrac{7+\sqrt{33}}{4}\right)^{\frac14}$
    3. $\left(\dfrac{9+\sqrt{65}}{4}\right)^{\frac14}$
    4. $\left(\dfrac{7+\sqrt{13}}{6}\right)^{\frac14}$
    Show answer and solution

    Answer: (a)

    Let $z = re^{i\theta}$: $(\bar z)^2 + \dfrac1{z^2} = \left(r^2 + \dfrac1{r^2}\right)e^{-2i\theta}$.
    If its real and imaginary parts are integers $p, q$, then $\left(r^2 + \dfrac1{r^2}\right)^2 = r^4 + \dfrac1{r^4} + 2 = p^2 + q^2$ must be an integer that is a sum of two squares.
    (A) $r^4 = \dfrac{43+3\sqrt{205}}{2}$, $\dfrac1{r^4} = \dfrac{43-3\sqrt{205}}{2}$: $r^4 + \dfrac1{r^4} + 2 = 45 = 6^2 + 3^2$ ✓.
    (B) $r^4 + \dfrac1{r^4} = \dfrac72$, giving $\dfrac{11}2$; (C) $\dfrac92$, giving $\dfrac{13}2$; (D) $\dfrac73$, giving $\dfrac{13}3$ – not integers.
    Answer (A).

  13. JEE Advanced 2021, Paper 1 · Question 4
    Let $\theta_1, \theta_2, \ldots, \theta_{10}$ be positive valued angles (in radian) such that $\theta_1 + \theta_2 + \cdots + \theta_{10} = 2\pi$. Define the complex numbers $z_1 = e^{i\theta_1}$, $z_k = z_{k-1}e^{i\theta_k}$ for $k = 2, 3, \ldots, 10$, where $i = \sqrt{-1}$. Consider the statements $P$ and $Q$ given below:

    $\displaystyle P : |z_2 - z_1| + |z_3 - z_2| + \cdots + |z_{10} - z_9| + |z_1 - z_{10}| \le 2\pi$
    $\displaystyle Q : |z_2^2 - z_1^2| + |z_3^2 - z_2^2| + \cdots + |z_{10}^2 - z_9^2| + |z_1^2 - z_{10}^2| \le 4\pi$
    Then,

    1. $P$ is TRUE and $Q$ is FALSE
    2. $Q$ is TRUE and $P$ is FALSE
    3. both $P$ and $Q$ are TRUE
    4. both $P$ and $Q$ are FALSE
    Show answer and solution

    Answer: (c)

    $z_k = e^{i(\theta_1 + \cdots + \theta_k)}$, so $z_{10} = e^{2\pi i} = 1$ and $z_1 = z_{10}e^{i\theta_1}$.
    Each term of $P$ is $|e^{i\theta_k} - 1| = 2\left|\sin\dfrac{\theta_k}{2}\right| \le \theta_k$, so the sum is at most $\sum\theta_k = 2\pi$: $P$ is true (the points lie on the unit circle and the chords are shorter than the arcs).
    Each term of $Q$ is $|e^{2i\theta_k} - 1| = 2|\sin\theta_k| \le 2\theta_k$, so the sum is at most $4\pi$: $Q$ is true.
    Both are true → (C).

  14. JEE Advanced 2021, Paper 1 · Question 16
    For any complex number $w = c + id$, let $\arg(w) \in (-\pi, \pi]$, where $i = \sqrt{-1}$. Let $\alpha$ and $\beta$ be real numbers such that for all complex numbers $z = x + iy$ satisfying $\arg\left(\dfrac{z + \alpha}{z + \beta}\right) = \dfrac{\pi}{4}$, the ordered pair $(x, y)$ lies on the circle

    $\displaystyle x^2 + y^2 + 5x - 3y + 4 = 0$
    Then which of the following statements is (are) TRUE ?

    1. $\alpha = -1$
    2. $\alpha\beta = 4$
    3. $\alpha\beta = -4$
    4. $\beta = 4$
    Show answer and solution

    Answer: (b), (d)

    The locus $\arg\dfrac{z + \alpha}{z + \beta} = \dfrac\pi4$ is an arc of a circle through the points $-\alpha$ and $-\beta$ on the real axis.
    The circle meets $y = 0$ where $x^2 + 5x + 4 = 0$, i.e. $x = -1, -4$. So $\{\alpha, \beta\} = \{1, 4\}$ and $\alpha\beta = 4$.
    Centre $\left(-\dfrac52, \dfrac32\right)$, radius $\dfrac{3}{\sqrt2}$; the angle $\dfrac\pi4$ is subtended on the major arc, above the real axis. Take its top point $z \approx -2.5 + 3.62i$: with $\alpha = 1, \beta = 4$, $\arg(z + 1) - \arg(z + 4) \approx 1.963 - 1.178 = 0.785 = \dfrac\pi4$.
    So $\alpha = 1$, $\beta = 4$: (B) and (D) are true.

  15. JEE Advanced 2021, Paper 1 · Question 17
    For $x \in \mathbb{R}$, the number of real roots of the equation

    $\displaystyle 3x^2 - 4|x^2 - 1| + x - 1 = 0$
    is ___ .

    Show answer and solution

    Answer: 4

    For $|x| \ge 1$: $3x^2 - 4x^2 + 4 + x - 1 = 0 \Rightarrow x^2 - x - 3 = 0$, $x = \dfrac{1 \pm \sqrt{13}}{2} \approx 2.30, -1.30$; both satisfy $|x| \ge 1$.
    For $|x| < 1$: $3x^2 + 4x^2 - 4 + x - 1 = 0 \Rightarrow 7x^2 + x - 5 = 0$, $x = \dfrac{-1 \pm \sqrt{141}}{14} \approx 0.78, -0.92$; both satisfy $|x| < 1$.
    Number of real roots $= 4$.
