  1. JEE Advanced 2026, Paper 1 · Question 11
    The number of ways to distribute $10$ identical red pens and $14$ identical blue pens among four persons such that each person gets 6 pens, is ______.

    Show answer and solution

    Answer: 206

    Choose red counts $r_1 + r_2 + r_3 + r_4 = 10$ with $0 \le r_i \le 6$; blue counts $6 - r_i$ are then forced (and total $24 - 10 = 14$).
    Without the upper bound: $\binom{13}{3} = 286$.
    Subtract cases with some $r_i \ge 7$ (at most one): $4\binom{6}{3} = 80$.
    Answer $= 286 - 80 = 206$.

  2. JEE Advanced 2025, Paper 1 · Question 10
    Let $S$ be the set of all seven-digit numbers that can be formed using the digits $0$, $1$ and $2$. For example, $2210222$ is in $S$, but $0210222$ is NOT in $S$.
    Then the number of elements $x$ in $S$ such that at least one of the digits $0$ and $1$ appears exactly twice in $x$, is equal to ______.

    Show answer and solution

    Answer: 762

    The first digit is $1$ or $2$.
    $A$: $0$ appears exactly twice. The two $0$s go in the last $6$ places: $\binom62 = 15$; the other $5$ places are $1$ or $2$: $2^5$. $|A| = 480$.
    $B$: $1$ appears exactly twice. First digit $1$: $6 \times 2^5 = 192$; first digit $2$: $\binom62 \times 2^4 = 240$. $|B| = 432$.
    $A\cap B$: two $0$s, two $1$s, three $2$s: $\dfrac{7!}{2!\,2!\,3!} = 210$, minus those starting with $0$: $\dfrac{6!}{1!\,2!\,3!} = 60$. $|A\cap B| = 150$.
    $|A\cup B| = 480 + 432 - 150 = 762$.

  3. JEE Advanced 2024, Paper 1 · Question 11
    A group of 9 students, $s_1, s_2, \ldots, s_9$, is to be divided to form three teams $X, Y$, and $Z$ of sizes 2, 3, and 4, respectively. Suppose that $s_1$ cannot be selected for the team $X$, and $s_2$ cannot be selected for the team $Y$. Then the number of ways to form such teams, is _______.

    Show answer and solution

    Answer: 665

    Without restrictions: $\dfrac{9!}{2!\,3!\,4!} = 1260$.
    $s_1 \in X$: choose 1 more for $X$ from 8 and 3 for $Y$ from 7: $8 \times 35 = 280$.
    $s_2 \in Y$: choose 2 for $X$ from 8 and 2 more for $Y$ from 6: $28 \times 15 = 420$.
    Both: 1 more for $X$ from 7, 2 more for $Y$ from 6: $7 \times 15 = 105$.
    Required $= 1260 - 280 - 420 + 105 = 665$.

  4. JEE Advanced 2024, Paper 2 · Question 14
    Let $S=\{1,2,3,4,5,6\}$ and $X$ be the set of all relations $R$ from $S$ to $S$ that satisfy both the following properties:
    i. $R$ has exactly $6$ elements.
    ii. For each $(a,b)\in R$, we have $|a-b|\ge 2$.
    Let $Y=\{R\in X : \text{The range of } R \text{ has exactly one element}\}$ and $Z=\{R\in X : R \text{ is a function from } S \text{ to } S\}$.
    Let $n(A)$ denote the number of elements in a set $A$.

    If $n(X)={}^{m}C_6$, then the value of $m$ is __________.

    Show answer and solution

    Answer: 19.99 to 20.01

    Ordered pairs in $S\times S$ with $|a-b|\ge2$: $36-6$ (with $a=b$) $-10$ (with $|a-b|=1$) $=20$.
    $X$ consists of all $6$-element subsets of these $20$ pairs, so $n(X)={}^{20}C_6$.
    $m=20$.

  5. JEE Advanced 2022, Paper 1 · Question 7
    The number of 4-digit integers in the closed interval $[2022, 4482]$ formed by using the digits $0, 2, 3, 4, 6, 7$ is ______.

    Show answer and solution

    Answer: 569

    Digits may repeat; each place has 6 choices.
    First digit 2: $6^3=216$ numbers, minus those below 2022 (2000, 2002, 2003, 2004, 2006, 2007, 2020): $216-7=209$.
    First digit 3: $216$.
    First digit 4: second digit 0, 2 or 3 gives $3\times36=108$; second digit 4 gives $44ab$ with $a\in\{0,2,3,4,6,7\}$, all $\le 4482$: $36$; second digit 6 or 7 is too large. Total $144$.
    Answer $=209+216+144=569$.

  6. JEE Advanced 2022, Paper 2 · Question 15
    Consider 4 boxes, where each box contains 3 red balls and 2 blue balls. Assume that all 20 balls are distinct. In how many different ways can 10 balls be chosen from these 4 boxes so that from each box at least one red ball and one blue ball are chosen ?

    1. $21816$
    2. $85536$
    3. $12096$
    4. $156816$
    Show answer and solution

    Answer: (a)

    From one box, with at least one red and one blue: 2 balls in $3\cdot2 = 6$ ways, 3 balls in $\binom32\cdot2 + 3\cdot1 = 9$ ways, 4 balls in $2 + 3 = 5$ ways, 5 balls in $1$ way.
    Each box gives at least 2 balls (8 in all), so 2 extra balls are spread over the boxes.
    One box takes 4 balls: $4\cdot5\cdot6^3 = 4320$.
    Two boxes take 3 balls each: $\binom42\cdot9^2\cdot6^2 = 17496$.
    Total $= 21816$ → (A).

  7. JEE Advanced 2021, Paper 2 · Question 1
    Let

    $\displaystyle S_1 = \{(i, j, k) : i, j, k \in \{1, 2, \ldots, 10\}\},$
    $\displaystyle S_2 = \{(i, j) : 1 \le i < j + 2 \le 10,\ i, j \in \{1, 2, \ldots, 10\}\},$
    $\displaystyle S_3 = \{(i, j, k, l) : 1 \le i < j < k < l,\ i, j, k, l \in \{1, 2, \ldots, 10\}\}$
    and
    $\displaystyle S_4 = \{(i, j, k, l) : i, j, k \text{ and } l \text{ are distinct elements in } \{1, 2, \ldots, 10\}\}.$
    If the total number of elements in the set $S_r$ is $n_r$, $r = 1, 2, 3, 4$, then which of the following statements is (are) TRUE ?

    1. $n_1 = 1000$
    2. $n_2 = 44$
    3. $n_3 = 220$
    4. $\dfrac{n_4}{12} = 420$
    Show answer and solution

    Answer: (a), (b), (d)

    $n_1 = 10^3 = 1000$ → (A) true.
    $S_2$: $j + 2 \le 10$ gives $j \le 8$, and $i < j + 2$ gives $1 \le i \le j + 1$, so there are $j + 1$ choices of $i$.
    $n_2 = \sum_{j=1}^{8}(j + 1) = 2 + 3 + \cdots + 9 = 44$ → (B) true.
    $n_3 = \binom{10}{4} = 210 \ne 220$ → (C) false.
    $n_4 = 10 \cdot 9 \cdot 8 \cdot 7 = 5040$, so $\dfrac{n_4}{12} = 420$ → (D) true.
    Answer (A), (B), (D).
