  1. JEE Advanced 2026, Paper 1 · Question 4
    Considering only the principal values of the inverse trigonometric functions, the value of

    $\displaystyle \cot^{-1}(\cot(-11)) + 10\,\sin\left(2\cos^{-1}\left(\frac{1}{\sqrt{2}}\right)\right) + 10\sin(2\tan^{-1}(2))$
    is

    1. $3\pi + 7$
    2. $7$
    3. $4\pi + 7$
    4. $3\pi - 5$
    Show answer and solution

    Answer: (c)

    $\cot^{-1}$ has range $(0,\pi)$ and $\cot$ has period $\pi$; $4\pi - 11 \approx 1.566 \in (0,\pi)$, so $\cot^{-1}(\cot(-11)) = 4\pi - 11$.
    $\cos^{-1}(1/\sqrt2) = \pi/4$, so $10\sin(\pi/2) = 10$.
    $\sin(2\tan^{-1}2) = \dfrac{2\cdot 2}{1+4} = \dfrac45$, so the last term is $8$.
    Sum $= 4\pi - 11 + 10 + 8 = 4\pi + 7$. Answer (C).

  2. JEE Advanced 2025, Paper 2 · Question 3
    The total number of real solutions of the equation

    $\displaystyle \theta=\tan^{-1}(2\tan\theta)-\dfrac{1}{2}\sin^{-1}\left(\dfrac{6\tan\theta}{9+\tan^2\theta}\right)$
    is
    (Here, the inverse trigonometric functions $\sin^{-1}x$ and $\tan^{-1}x$ assume values in $\left[-\dfrac{\pi}{2},\dfrac{\pi}{2}\right]$ and $\left(-\dfrac{\pi}{2},\dfrac{\pi}{2}\right)$, respectively.)

    1. $1$
    2. $2$
    3. $3$
    4. $5$
    Show answer and solution

    Answer: (c)

    Let $t=\tan\theta$. Then $\dfrac{6t}{9+t^2}=\dfrac{2(t/3)}{1+(t/3)^2}$.
    Case $|t|\le3$: $\sin^{-1}\left(\dfrac{6t}{9+t^2}\right)=2\tan^{-1}\dfrac t3$, so $\theta=\tan^{-1}2t-\tan^{-1}\dfrac t3\in\left(-\dfrac\pi2,\dfrac\pi2\right)$, hence $\theta=\tan^{-1}t$.
    Taking tangents: $t=\dfrac{2t-t/3}{1+2t^2/3}=\dfrac{5t}{3+2t^2}\Rightarrow t=0$ or $t^2=1$, giving $\theta=0,\pm\dfrac\pi4$ (3 solutions).
    Case $t>3$: $\sin^{-1}(\cdot)=\pi-2\tan^{-1}\dfrac t3$, so $\theta=\tan^{-1}2t+\tan^{-1}\dfrac t3-\dfrac\pi2\in\left(0,\dfrac\pi2\right)$ and $\tan\theta=\dfrac{2t^2-3}{7t}$. Setting this $=t$ gives $5t^2=-3$: no solution. By symmetry ($\theta\to-\theta$) none for $t<-3$.
    Total $=3$. Answer (C).

  3. JEE Advanced 2024, Paper 2 · Question 1
    Considering only the principal values of the inverse trigonometric functions, the value of

    $\displaystyle \tan\left(\sin^{-1}\left(\dfrac{3}{5}\right)-2\cos^{-1}\left(\dfrac{2}{\sqrt5}\right)\right)$
    is

    1. $\dfrac{7}{24}$
    2. $\dfrac{-7}{24}$
    3. $\dfrac{-5}{24}$
    4. $\dfrac{5}{24}$
    Show answer and solution

    Answer: (b)

    Let $a=\sin^{-1}\dfrac35$, so $\tan a=\dfrac34$; let $b=\cos^{-1}\dfrac{2}{\sqrt5}$, so $\tan b=\dfrac12$.
    $\tan 2b=\dfrac{2\cdot\frac12}{1-\frac14}=\dfrac43$.
    $\tan(a-2b)=\dfrac{\frac34-\frac43}{1+\frac34\cdot\frac43}=\dfrac{-\frac{7}{12}}{2}=-\dfrac{7}{24}$ → (B).

  4. JEE Advanced 2023, Paper 1 · Question 8
    Let $\tan^{-1}(x) \in \left(-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right)$, for $x \in \mathbb{R}$. Then the number of real solutions of the equation

    $\displaystyle \sqrt{1+\cos(2x)} = \sqrt2\,\tan^{-1}(\tan x)$
    in the set $\left(-\dfrac{3\pi}{2}, -\dfrac{\pi}{2}\right) \cup \left(-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right) \cup \left(\dfrac{\pi}{2}, \dfrac{3\pi}{2}\right)$ is equal to ______.

    Show answer and solution

    Answer: 3

    $\sqrt{1+\cos 2x} = \sqrt2\,|\cos x|$, so the equation is $|\cos x| = \tan^{-1}(\tan x)$; the right side must be $\ge 0$.
    On $\left(-\dfrac\pi2, \dfrac\pi2\right)$: $\cos x = x$, one root in $\left(0, \dfrac\pi2\right)$.
    On $\left(\dfrac\pi2, \dfrac{3\pi}2\right)$: $\tan^{-1}(\tan x) = x - \pi = u$; need $u \in \left[0, \dfrac\pi2\right)$ and $|\cos x| = \cos u = u$: one root.
    On $\left(-\dfrac{3\pi}2, -\dfrac\pi2\right)$: $\tan^{-1}(\tan x) = x + \pi = u$, again $\cos u = u$ with $u \in \left[0, \dfrac\pi2\right)$: one root.
    Number of solutions $= 3$.

  5. JEE Advanced 2023, Paper 2 · Question 3
    For any $y \in \mathbb{R}$, let $\cot^{-1}(y) \in (0, \pi)$ and $\tan^{-1}(y) \in \left(-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right)$. Then the sum of all the solutions of the equation

    $\displaystyle \tan^{-1}\left(\dfrac{6y}{9-y^2}\right) + \cot^{-1}\left(\dfrac{9-y^2}{6y}\right) = \dfrac{2\pi}{3}$
    for $0 < |y| < 3$, is equal to

    1. $2\sqrt{3} - 3$
    2. $3 - 2\sqrt{3}$
    3. $4\sqrt{3} - 6$
    4. $6 - 4\sqrt{3}$
    Show answer and solution

    Answer: (c)

    Let $u = \dfrac{6y}{9-y^2}$; for $0 < |y| < 3$, $u$ has the sign of $y$.
    $0 < y < 3$: $\cot^{-1}\dfrac1u = \tan^{-1}u$, so $2\tan^{-1}u = \dfrac{2\pi}{3}$, $u = \sqrt3$: $\sqrt3 y^2 + 6y - 9\sqrt3 = 0 \Rightarrow y = \sqrt3$ (the root $-3\sqrt3$ is rejected).
    $-3 < y < 0$: $\cot^{-1}\dfrac1u = \pi + \tan^{-1}u$, so $2\tan^{-1}u = -\dfrac{\pi}{3}$, $u = -\dfrac{1}{\sqrt3}$: $y^2 - 6\sqrt3 y - 9 = 0 \Rightarrow y = 3\sqrt3 - 6$ (the root $3\sqrt3 + 6$ is rejected).
    Sum $= \sqrt3 + 3\sqrt3 - 6 = 4\sqrt3 - 6$ → (C).

  6. JEE Advanced 2022, Paper 1 · Question 1
    Considering only the principal values of the inverse trigonometric functions, the value of

    $\displaystyle \frac{3}{2}\cos^{-1}\sqrt{\frac{2}{2+\pi^2}}+\frac{1}{4}\sin^{-1}\frac{2\sqrt{2}\,\pi}{2+\pi^2}+\tan^{-1}\frac{\sqrt{2}}{\pi}$
    is ______.

    Show answer and solution

    Answer: 2.35 to 2.37

    Let $\theta=\tan^{-1}\dfrac{\pi}{\sqrt2}$, so $\cos\theta=\dfrac{\sqrt2}{\sqrt{2+\pi^2}}$ and the first angle is $\theta$; note $\theta>\dfrac{\pi}{4}$ since $\dfrac{\pi}{\sqrt2}>1$.
    $\sin2\theta=\dfrac{2\tan\theta}{1+\tan^2\theta}=\dfrac{2\sqrt2\,\pi}{2+\pi^2}$, and $2\theta\in\left(\dfrac{\pi}{2},\pi\right)$, so $\sin^{-1}\dfrac{2\sqrt2\,\pi}{2+\pi^2}=\pi-2\theta$.
    $\tan^{-1}\dfrac{\sqrt2}{\pi}=\dfrac{\pi}{2}-\theta$.
    Sum $=\dfrac32\theta+\dfrac{\pi-2\theta}{4}+\dfrac{\pi}{2}-\theta=\dfrac{3\pi}{4}\approx2.36$.

  7. JEE Advanced 2021, Paper 1 · Question 15
    For any positive integer $n$, let $S_n : (0, \infty) \to \mathbb{R}$ be defined by

    $\displaystyle S_n(x) = \sum_{k=1}^{n} \cot^{-1}\left(\dfrac{1 + k(k+1)x^2}{x}\right),$
    where for any $x \in \mathbb{R}$, $\cot^{-1}(x) \in (0, \pi)$ and $\tan^{-1}(x) \in \left(-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right)$. Then which of the following statements is (are) TRUE ?

    1. $S_{10}(x) = \dfrac{\pi}{2} - \tan^{-1}\left(\dfrac{1 + 11x^2}{10x}\right)$, for all $x > 0$
    2. $\displaystyle\lim_{n \to \infty} \cot(S_n(x)) = x$, for all $x > 0$
    3. The equation $S_3(x) = \dfrac{\pi}{4}$ has a root in $(0, \infty)$
    4. $\tan(S_n(x)) \le \dfrac12$, for all $n \ge 1$ and $x > 0$
    Show answer and solution

    Answer: (a), (b)

    For $x > 0$: $\cot^{-1}\dfrac{1 + k(k+1)x^2}{x} = \tan^{-1}\dfrac{(k+1)x - kx}{1 + (k+1)x\cdot kx} = \tan^{-1}(k+1)x - \tan^{-1}kx$.
    Telescoping: $S_n(x) = \tan^{-1}(n+1)x - \tan^{-1}x = \tan^{-1}\dfrac{nx}{1 + (n+1)x^2}$.
    (A) $S_{10}(x) = \tan^{-1}\dfrac{10x}{1 + 11x^2} = \dfrac\pi2 - \tan^{-1}\dfrac{1 + 11x^2}{10x}$: true.
    (B) $S_n(x) \to \dfrac\pi2 - \tan^{-1}x = \cot^{-1}x$, so $\cot S_n(x) \to x$: true.
    (C) $\dfrac{3x}{1 + 4x^2} = 1 \iff 4x^2 - 3x + 1 = 0$, discriminant $9 - 16 < 0$: no root, false.
    (D) At $x = 1$, $\tan S_n = \dfrac{n}{n + 2} > \dfrac12$ for $n \ge 3$: false.
    Answer (A), (B).
