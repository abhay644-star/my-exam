  1. JEE Advanced 2026, Paper 2 · Question 3
    Let $y : (-\infty, \infty) \to (0, \infty)$ be the solution of the differential equation

    $\displaystyle \frac{dy}{dx} = \frac{e^{5x}y^3 + y^3}{e^x + e^x y^4},$
    satisfying $y(0) = \frac{1}{\sqrt{2}}$. Then the value of $y(\log_e 2)$ is

    1. $\sqrt{\dfrac{5+\sqrt{35}}{2}}$
    2. $\sqrt{\dfrac{7+\sqrt{53}}{2}}$
    3. $\dfrac{7+\sqrt{53}}{2}$
    4. $\dfrac{5+\sqrt{35}}{2}$
    Show answer and solution

    Answer: (b)

    Separate: $\dfrac{1+y^4}{y^3}dy=\dfrac{e^{5x}+1}{e^x}dx=(e^{4x}+e^{-x})dx$.
    Integrate: $\dfrac{y^2}{2}-\dfrac{1}{2y^2}=\dfrac{e^{4x}}{4}-e^{-x}+C$.
    At $x=0$, $y^2=\tfrac12$: $\tfrac14-1=\tfrac14-1+C\Rightarrow C=0$.
    At $x=\log_e2$: RHS $=4-\tfrac12=\tfrac72$, so $y^4-7y^2-1=0$.
    $y^2=\dfrac{7+\sqrt{53}}{2}$, $y=\sqrt{\dfrac{7+\sqrt{53}}{2}}$.

  2. JEE Advanced 2026, Paper 2 · Question 8
    Let $y = f(x)$ be the real valued function defined on the interval $(0, \infty)$ , satisfying $y(1) = 0$ and the differential equation

    $\displaystyle x\frac{dy}{dx} = y - x^3 .$
    Then which of the following statements is (are) TRUE ?

    1. The function $f$ has a local minimum at $x = \frac{1}{\sqrt{3}}$
    2. The function $f$ has a local maximum at $x = \frac{1}{\sqrt{3}}$
    3. The function $f$ is increasing in the interval $(1,\ 2)$
    4. If $g(x) = 4x^3 - 5x^2 + \frac{3}{2}x$ for $x > 0$, then the number of elements in the set
      $\displaystyle \{x \in (0, \infty) :\ f(x) = g(x)\}$
      is $2$
    Show answer and solution

    Answer: (b), (d)

    $\left(\dfrac yx\right)'=\dfrac{xy'-y}{x^2}=-x\Rightarrow\dfrac yx=-\dfrac{x^2}{2}+C$; $y(1)=0\Rightarrow C=\tfrac12$.
    $f(x)=\dfrac{x-x^3}{2}$, $f'(x)=\dfrac{1-3x^2}{2}$, $f''=-3x<0$: local max at $x=\frac1{\sqrt3}$ (B), not min.
    $f'<0$ on $(1,2)$: decreasing, (C) false.
    $f=g\iff \tfrac92x^3-5x^2+x=0\iff 9x^2-10x+2=0$ (for $x>0$): discriminant $28>0$, both roots positive, so 2 elements (D).

  3. JEE Advanced 2025, Paper 1 · Question 13
    For all $x \gt 0$, let $y_1(x)$, $y_2(x)$, and $y_3(x)$ be the functions satisfying

    $\displaystyle \dfrac{dy_1}{dx} - (\sin x)^2y_1 = 0, \quad y_1(1) = 5,$
    $\displaystyle \dfrac{dy_2}{dx} - (\cos x)^2y_2 = 0, \quad y_2(1) = \dfrac13,$
    $\displaystyle \dfrac{dy_3}{dx} - \left(\dfrac{2 - x^3}{x^3}\right)y_3 = 0, \quad y_3(1) = \dfrac{3}{5e},$
    respectively. Then
    $\displaystyle \lim_{x\to0^+}\dfrac{y_1(x)y_2(x)y_3(x) + 2x}{e^{3x}\sin x}$
    is equal to ______.

    Show answer and solution

    Answer: 2

    $(y_1y_2)' = (\sin^2x + \cos^2x)\,y_1y_2 = y_1y_2$, so $y_1y_2 = y_1(1)y_2(1)e^{x-1} = \dfrac53e^{x-1}$.
    $\dfrac{y_3'}{y_3} = \dfrac{2}{x^3} - 1 \Rightarrow \ln y_3 = -\dfrac{1}{x^2} - x + c$; $y_3(1) = \dfrac{3}{5e}$ gives $y_3 = \dfrac35e^{1 - x - 1/x^2}$.
    $y_1y_2y_3 = e^{x-1}\cdot e^{1-x-1/x^2} = e^{-1/x^2}$.
    As $x\to0^+$: $\dfrac{e^{-1/x^2}}{\sin x} \to 0$ and $\dfrac{2x}{e^{3x}\sin x} \to 2$.
    Limit $= 2$.

  4. JEE Advanced 2025, Paper 2 · Question 9
    Let $y(x)$ be the solution of the differential equation

    $\displaystyle x^2\dfrac{dy}{dx}+xy=x^2+y^2,\qquad x>\dfrac{1}{e},$
    satisfying $y(1)=0$. Then the value of $2\dfrac{(y(e))^2}{y(e^2)}$ is ________.

    Show answer and solution

    Answer: 0.7 to 0.8

    Homogeneous: put $y=vx$. Then $x^2(v+xv')+x^2v=x^2+x^2v^2\Rightarrow x\dfrac{dv}{dx}=(v-1)^2$.
    $\displaystyle\int\dfrac{dv}{(v-1)^2}=\int\dfrac{dx}{x}\Rightarrow\dfrac{1}{1-v}=\ln x+c$; $y(1)=0\Rightarrow v=0$ at $x=1$, so $c=1$.
    $v=1-\dfrac{1}{1+\ln x}=\dfrac{\ln x}{1+\ln x}$, so $y=\dfrac{x\ln x}{1+\ln x}$.
    $y(e)=\dfrac e2$, $y(e^2)=\dfrac{2e^2}{3}$.
    $2\cdot\dfrac{e^2/4}{2e^2/3}=\dfrac34=0.75$.

  5. JEE Advanced 2024, Paper 1 · Question 1
    Let $f(x)$ be a continuously differentiable function on the interval $(0, \infty)$ such that $f(1) = 2$ and

    $\displaystyle \lim_{t \to x} \frac{t^{10} f(x) - x^{10} f(t)}{t^9 - x^9} = 1$
    for each $x > 0$. Then, for all $x > 0$, $f(x)$ is equal to

    1. $\dfrac{31}{11x} - \dfrac{9}{11}x^{10}$
    2. $\dfrac{9}{11x} + \dfrac{13}{11}x^{10}$
    3. $\dfrac{-9}{11x} + \dfrac{31}{11}x^{10}$
    4. $\dfrac{13}{11x} + \dfrac{9}{11}x^{10}$
    Show answer and solution

    Answer: (b)

    The limit is of the form $\dfrac00$; by L'Hospital's rule (differentiating in $t$): $\dfrac{10x^9 f(x) - x^{10} f'(x)}{9x^8} = 1$.
    So $10x f(x) - x^2 f'(x) = 9$, i.e. $f'(x) - \dfrac{10}{x} f(x) = -\dfrac{9}{x^2}$.
    Integrating factor $x^{-10}$: $\dfrac{d}{dx}\left(x^{-10} f(x)\right) = -9x^{-12} \Rightarrow x^{-10} f(x) = \dfrac{9}{11}x^{-11} + K$.
    So $f(x) = \dfrac{9}{11x} + Kx^{10}$; $f(1) = 2 \Rightarrow K = \dfrac{13}{11}$.
    $f(x) = \dfrac{9}{11x} + \dfrac{13}{11}x^{10}$ → (B).

  6. JEE Advanced 2023, Paper 2 · Question 1
    Let $f : [1, \infty) \to \mathbb{R}$ be a differentiable function such that $f(1) = \dfrac{1}{3}$ and

    $\displaystyle 3\int_1^x f(t)\,dt = x\,f(x) - \dfrac{x^3}{3}, \quad x \in [1, \infty).$
    Let $e$ denote the base of the natural logarithm. Then the value of $f(e)$ is

    1. $\dfrac{e^2+4}{3}$
    2. $\dfrac{\log_e 4 + e}{3}$
    3. $\dfrac{4e^2}{3}$
    4. $\dfrac{e^2-4}{3}$
    Show answer and solution

    Answer: (c)

    Differentiate: $3f(x) = f(x) + x f'(x) - x^2$, so $x f'(x) - 2f(x) = x^2$.
    Divide by $x^3$: $\left(\dfrac{f(x)}{x^2}\right)' = \dfrac{1}{x}$, so $f(x) = x^2(\ln x + C)$.
    $f(1) = C = \dfrac13$, hence $f(x) = x^2\left(\ln x + \dfrac13\right)$.
    $f(e) = e^2\left(1 + \dfrac13\right) = \dfrac{4e^2}{3}$ → (C).

  7. JEE Advanced 2023, Paper 2 · Question 9
    For $x \in \mathbb{R}$, let $y(x)$ be a solution of the differential equation

    $\displaystyle (x^2 - 5)\frac{dy}{dx} - 2xy = -2x(x^2 - 5)^2$
    such that $y(2) = 7$. Then the maximum value of the function $y(x)$ is ________.

    Show answer and solution

    Answer: 16

    Divide by $(x^2-5)^2$: $\dfrac{d}{dx}\left(\dfrac{y}{x^2-5}\right) = -2x$, so $\dfrac{y}{x^2-5} = -x^2 + C$.
    $y(2) = 7$: $\dfrac{7}{-1} = -4 + C \Rightarrow C = -3$.
    $y = -(x^2-5)(x^2+3)$. With $u = x^2 \ge 0$: $y = -u^2 + 2u + 15 = 16 - (u-1)^2$.
    Maximum $= 16$ (at $x^2 = 1$).

  8. JEE Advanced 2022, Paper 2 · Question 2
    If $y(x)$ is the solution of the differential equation

    $\displaystyle x\,dy - (y^2 - 4y)\,dx = 0 \quad \text{for } x > 0, \qquad y(1) = 2,$
    and the slope of the curve $y = y(x)$ is never zero, then the value of $10\,y(\sqrt{2})$ is ________.

    Show answer and solution

    Answer: 8

    Separate: $\dfrac{dy}{y(y-4)} = \dfrac{dx}{x}$, i.e. $\dfrac14\ln\left|\dfrac{y-4}{y}\right| = \ln x + C$.
    $y(1) = 2$: $\left|\dfrac{-2}{2}\right| = 1$, so $C = 0$ and $\left|\dfrac{y-4}{y}\right| = x^4$.
    The slope $\dfrac{y^2-4y}{x}$ is never zero, so $y$ stays strictly between $0$ and $4$: $\dfrac{4-y}{y} = x^4$, $y = \dfrac{4}{1+x^4}$.
    $y(\sqrt2) = \dfrac45$, so $10\,y(\sqrt2) = 8$.

  9. JEE Advanced 2022, Paper 2 · Question 14
    For $x \in \mathbb{R}$, let the function $y(x)$ be the solution of the differential equation

    $\displaystyle \frac{dy}{dx} + 12y = \cos\left(\frac{\pi}{12}x\right), \qquad y(0) = 0.$
    Then, which of the following statements is/are TRUE ?

    1. $y(x)$ is an increasing function
    2. $y(x)$ is a decreasing function
    3. There exists a real number $\beta$ such that the line $y = \beta$ intersects the curve $y = y(x)$ at infinitely many points
    4. $y(x)$ is a periodic function
    Show answer and solution

    Answer: (c)

    Let $\omega = \dfrac{\pi}{12}$. A particular solution $a\cos\omega x + b\sin\omega x$ needs $12a + b\omega = 1$, $12b - a\omega = 0$: $a = \dfrac{12}{144+\omega^2}$, $b = \dfrac{\omega}{144+\omega^2}$.
    With $y(0) = 0$: $y(x) = \dfrac{12\cos\omega x + \omega\sin\omega x - 12e^{-12x}}{144 + \omega^2}$.
    For large $x$, $y$ is essentially a sinusoid of period $24$, so it keeps rising and falling: (A), (B) false.
    The term $e^{-12x}$ makes $y$ not periodic: (D) false.
    For any $\beta$ strictly inside the range of the sinusoid (e.g. $\beta = 0$), the line $y = \beta$ cuts the curve once in every half-period: infinitely many points, (C) true.
    Answer (C).

  10. JEE Advanced 2021, Paper 2 · Question 4
    For any real numbers $\alpha$ and $\beta$, let $y_{\alpha,\beta}(x)$, $x \in \mathbb{R}$, be the solution of the differential equation

    $\displaystyle \frac{dy}{dx} + \alpha y = x e^{\beta x}, \quad y(1) = 1.$
    Let $S = \{y_{\alpha,\beta}(x) : \alpha, \beta \in \mathbb{R}\}$. Then which of the following functions belong(s) to the set $S$ ?

    1. $f(x) = \dfrac{x^2}{2}e^{-x} + \left(e - \dfrac12\right)e^{-x}$
    2. $f(x) = -\dfrac{x^2}{2}e^{-x} + \left(e + \dfrac12\right)e^{-x}$
    3. $f(x) = \dfrac{e^x}{2}\left(x - \dfrac12\right) + \left(e - \dfrac{e^2}{4}\right)e^{-x}$
    4. $f(x) = \dfrac{e^x}{2}\left(\dfrac12 - x\right) + \left(e + \dfrac{e^2}{4}\right)e^{-x}$
    Show answer and solution

    Answer: (a), (c)

    Integrating factor $e^{\alpha x}$: $(y e^{\alpha x})' = x e^{(\alpha + \beta)x}$.
    If $\alpha + \beta = 0$: $y = \dfrac{x^2}{2}e^{-\alpha x} + Ce^{-\alpha x}$.
    If $\alpha + \beta \ne 0$: $y = e^{\beta x}\left(\dfrac{x}{\alpha + \beta} - \dfrac{1}{(\alpha + \beta)^2}\right) + Ce^{-\alpha x}$.
    (A) $\alpha = 1, \beta = -1$: form $\dfrac{x^2}{2}e^{-x} + Ce^{-x}$, and $y(1) = \left(\dfrac12 + e - \dfrac12\right)e^{-1} = 1$ → belongs.
    (B) the coefficient of $x^2 e^{-x}$ must be $+\dfrac12$, not $-\dfrac12$ → does not belong.
    (C) $\alpha = \beta = 1$: $e^x\left(\dfrac{x}{2} - \dfrac14\right) = \dfrac{e^x}{2}\left(x - \dfrac12\right)$; $y(1) = \dfrac{e}{4} + \left(e - \dfrac{e^2}{4}\right)e^{-1} = 1$ → belongs.
    (D) the $e^{x}$ part $\dfrac{e^x}{2}\left(\dfrac12 - x\right)$ would need $\dfrac{1}{\alpha+\beta} = -\dfrac12$ and $-\dfrac{1}{(\alpha+\beta)^2} = +\dfrac14$, impossible → does not belong.
    Answer (A), (C).
