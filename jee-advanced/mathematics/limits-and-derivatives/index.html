  1. JEE Advanced 2025, Paper 1 · Question 11
    Let $\alpha$ and $\beta$ be the real numbers such that

    $\displaystyle \lim_{x\to0}\dfrac{1}{x^3}\left(\dfrac{\alpha}{2}\int_0^x \dfrac{1}{1-t^2}\,dt + \beta x\cos x\right) = 2.$
    Then the value of $\alpha + \beta$ is ______.

    Show answer and solution

    Answer: 2.35 to 2.45

    $\displaystyle\int_0^x \dfrac{dt}{1-t^2} = \int_0^x (1 + t^2 + \ldots)\,dt = x + \dfrac{x^3}{3} + \ldots$ and $\beta x\cos x = \beta x - \dfrac{\beta x^3}{2} + \ldots$
    Bracket $= \left(\dfrac\alpha2 + \beta\right)x + \left(\dfrac\alpha6 - \dfrac\beta2\right)x^3 + \ldots$
    For a finite limit: $\dfrac\alpha2 + \beta = 0$; then $\dfrac\alpha6 - \dfrac\beta2 = 2$.
    $\beta = -\dfrac\alpha2 \Rightarrow \dfrac\alpha6 + \dfrac\alpha4 = 2 \Rightarrow \alpha = \dfrac{24}{5}$, $\beta = -\dfrac{12}{5}$.
    $\alpha + \beta = \dfrac{12}{5} = 2.4$.

  2. JEE Advanced 2025, Paper 2 · Question 1
    Let $x_0$ be the real number such that $e^{x_0}+x_0=0$. For a given real number $\alpha$, define

    $\displaystyle g(x)=\dfrac{3xe^x+3x-\alpha e^x-\alpha x}{3(e^x+1)}$
    for all real numbers $x$.

    Then which one of the following statements is TRUE?

    1. For $\alpha=2$, $\lim_{x \to x_0}\left|\dfrac{g(x)+e^{x_0}}{x-x_0}\right|=0$
    2. For $\alpha=2$, $\lim_{x \to x_0}\left|\dfrac{g(x)+e^{x_0}}{x-x_0}\right|=1$
    3. For $\alpha=3$, $\lim_{x \to x_0}\left|\dfrac{g(x)+e^{x_0}}{x-x_0}\right|=0$
    4. For $\alpha=3$, $\lim_{x \to x_0}\left|\dfrac{g(x)+e^{x_0}}{x-x_0}\right|=\dfrac{2}{3}$
    Show answer and solution

    Answer: (c)

    $g(x)=\dfrac{3x(e^x+1)-\alpha(e^x+x)}{3(e^x+1)}=x-\dfrac{\alpha}{3}\cdot\dfrac{e^x+x}{e^x+1}$.
    At $x_0$: $e^{x_0}+x_0=0$, so $g(x_0)=x_0=-e^{x_0}$. Hence $g(x)+e^{x_0}=g(x)-g(x_0)$ and the limit is $|g'(x_0)|$.
    With $h(x)=e^x+x$ (so $h(x_0)=0$): $\dfrac{d}{dx}\dfrac{h}{e^x+1}\Big|_{x_0}=\dfrac{h'(x_0)}{e^{x_0}+1}=\dfrac{e^{x_0}+1}{e^{x_0}+1}=1$.
    So $g'(x_0)=1-\dfrac{\alpha}{3}$.
    $\alpha=2$: limit $=\dfrac13$ (A, B false); $\alpha=3$: limit $=0$ (C true, D false). Answer (C).

  3. JEE Advanced 2024, Paper 2 · Question 3
    Let $k\in\mathbb{R}$. If $\displaystyle\lim_{x\to0+}\left(\sin(\sin kx)+\cos x+x\right)^{\frac{2}{x}}=e^6$, then the value of $k$ is

    1. $1$
    2. $2$
    3. $3$
    4. $4$
    Show answer and solution

    Answer: (b)

    The form is $1^\infty$, so the limit is $e^{L}$ with $L=\displaystyle\lim_{x\to0+}\dfrac{2}{x}\left(\sin(\sin kx)+\cos x+x-1\right)$.
    $\sin(\sin kx)\approx kx$, $\cos x-1\approx -\dfrac{x^2}{2}$, so $L=2(k+1)$.
    $2(k+1)=6\Rightarrow k=2$ → (B).

  4. JEE Advanced 2024, Paper 2 · Question 5
    Let $S$ be the set of all $(\alpha,\beta)\in\mathbb{R}\times\mathbb{R}$ such that

    $\displaystyle \lim_{x\to\infty}\dfrac{\sin(x^2)(\log_e x)^{\alpha}\sin\left(\dfrac{1}{x^2}\right)}{x^{\alpha\beta}(\log_e(1+x))^{\beta}}=0.$
    Then which of the following is (are) correct?

    1. $(-1,3)\in S$
    2. $(-1,1)\in S$
    3. $(1,-1)\in S$
    4. $(1,-2)\in S$
    Show answer and solution

    Answer: (b), (c)

    As $x\to\infty$: $\sin\left(\dfrac1{x^2}\right)\sim\dfrac1{x^2}$ and $\log_e(1+x)\sim\log_e x$.
    So the expression behaves like $\sin(x^2)\,\dfrac{(\log_e x)^{\alpha-\beta}}{x^{2+\alpha\beta}}$; with $\sin(x^2)$ bounded and oscillating, the limit is $0$ iff $2+\alpha\beta>0$, or $2+\alpha\beta=0$ and $\alpha-\beta<0$.
    (A) $2+\alpha\beta=-1<0$ → not in $S$. (B) $2+\alpha\beta=1>0$ → in $S$. (C) $2+\alpha\beta=1>0$ → in $S$.
    (D) $2+\alpha\beta=0$ but $\alpha-\beta=3>0$, so $\sin(x^2)(\log_e x)^3$ does not tend to $0$ → not in $S$.
    Answer: (B), (C).

  5. JEE Advanced 2023, Paper 1 · Question 4
    Let $f : (0,1) \to \mathbb{R}$ be the function defined as $f(x) = \sqrt{n}$ if $x \in \left[\dfrac{1}{n+1}, \dfrac{1}{n}\right)$ where $n \in \mathbb{N}$. Let $g : (0,1) \to \mathbb{R}$ be a function such that $\displaystyle\int_{x^2}^{x} \sqrt{\dfrac{1-t}{t}}\,dt < g(x) < 2\sqrt{x}$ for all $x \in (0,1)$. Then $\displaystyle\lim_{x\to0} f(x)g(x)$

    1. does NOT exist
    2. is equal to $1$
    3. is equal to $2$
    4. is equal to $3$
    Show answer and solution

    Answer: (c)

    For $x \in \left[\dfrac{1}{n+1}, \dfrac1n\right)$: $\dfrac{n}{n+1} \le nx < 1$, so $f(x)\sqrt{x} = \sqrt{nx} \to 1$ as $x \to 0$ ($n \to \infty$).
    Upper bound: $f(x)g(x) < 2\sqrt{nx} \to 2$.
    Lower bound: for $t \le x$, $\sqrt{\dfrac{1-t}{t}} \ge \dfrac{\sqrt{1-x}}{\sqrt t}$, so $\displaystyle\int_{x^2}^{x} \ge \sqrt{1-x}\,(2\sqrt x - 2x)$, and $f(x)g(x) > 2\sqrt{nx}\,\sqrt{1-x}\,(1 - \sqrt x) \to 2$.
    By the sandwich theorem the limit is $2$. Answer (C).

  6. JEE Advanced 2022, Paper 1 · Question 2
    Let $\alpha$ be a positive real number. Let $f:\mathbb{R}\to\mathbb{R}$ and $g:(\alpha,\infty)\to\mathbb{R}$ be the functions defined by

    $\displaystyle f(x)=\sin\left(\frac{\pi x}{12}\right)\qquad\text{and}\qquad g(x)=\frac{2\log_e\left(\sqrt{x}-\sqrt{\alpha}\right)}{\log_e\left(e^{\sqrt{x}}-e^{\sqrt{\alpha}}\right)}.$
    Then the value of $\displaystyle\lim_{x\to\alpha^+}f(g(x))$ is ______.

    Show answer and solution

    Answer: 0.49 to 0.51

    Put $t=\sqrt x-\sqrt\alpha\to0^+$. Then $e^{\sqrt x}-e^{\sqrt\alpha}=e^{\sqrt\alpha}(e^{t}-1)$.
    $g(x)=\dfrac{2\ln t}{\sqrt\alpha+\ln(e^t-1)}=\dfrac{2\ln t}{\sqrt\alpha+\ln t+\ln\dfrac{e^t-1}{t}}$.
    As $t\to0^+$, $\ln t\to-\infty$ and $\ln\dfrac{e^t-1}{t}\to0$, so $g(x)\to2$.
    $f$ is continuous, so the limit is $f(2)=\sin\dfrac{\pi}{6}=0.5$.

  7. JEE Advanced 2022, Paper 2 · Question 5
    If

    $\displaystyle \beta = \lim_{x\to0} \frac{e^{x^3} - (1-x^3)^{\frac13} + \left((1-x^2)^{\frac12} - 1\right)\sin x}{x\sin^2 x},$
    then the value of $6\beta$ is ________.

    Show answer and solution

    Answer: 5

    Expand to order $x^3$: $e^{x^3} = 1 + x^3 + \ldots$, $(1-x^3)^{1/3} = 1 - \dfrac{x^3}{3} + \ldots$, so $e^{x^3} - (1-x^3)^{1/3} = \dfrac{4x^3}{3} + \ldots$
    $\left((1-x^2)^{1/2} - 1\right)\sin x = \left(-\dfrac{x^2}{2} + \ldots\right)(x + \ldots) = -\dfrac{x^3}{2} + \ldots$
    Numerator $= \left(\dfrac43 - \dfrac12\right)x^3 + \ldots = \dfrac56x^3 + \ldots$; denominator $x\sin^2x = x^3 + \ldots$
    $\beta = \dfrac56$, so $6\beta = 5$.
