  1. JEE Advanced 2026, Paper 1 · Question 1
    Consider the function $f : (0, \infty) \to (-\infty, \infty)$ given by

    $\displaystyle f(x) = \sqrt{x}\,\log_e(x) - x + 1 .$
    Then which one of the following statements is TRUE ?

    1. The derivative of the function $f$ is decreasing in the interval $(0, 1)$
    2. The function $f$ has a local maximum at some point $a \in (0, \infty)$
    3. The function $f$ has a local minimum at some point $b \in (0, \infty)$
    4. The function $f$ has NEITHER a point of local maximum NOR a point of local minimum in the interval $(0, \infty)$
    Show answer and solution

    Answer: (d)

    $f'(x) = \dfrac{\ln x}{2\sqrt{x}} + \dfrac{1}{\sqrt{x}} - 1 = \dfrac{\ln x + 2 - 2\sqrt{x}}{2\sqrt{x}}$.
    Let $g(x) = \ln x + 2 - 2\sqrt{x}$; then $g'(x) = \dfrac{1}{x} - \dfrac{1}{\sqrt{x}} = \dfrac{1-\sqrt{x}}{x}$, so $g$ increases on $(0,1)$ and decreases on $(1,\infty)$.
    Hence $g(x) \le g(1) = 0$, with equality only at $x = 1$.
    So $f'(x) \le 0$ with equality only at $x=1$: $f$ is strictly decreasing and has no local extremum. (Also $f'(x) \to -\infty$ as $x \to 0^+$ and $f'(1)=0$, so $f'$ is not decreasing on $(0,1)$.) Answer (D).

  2. JEE Advanced 2026, Paper 2 · Question 17
    Consider the ellipses given by

    $\displaystyle x^2 + 4y^2 = 1 \quad \text{and} \quad 4x^2 + y^2 = 1 .$


    Let $P$ be the point in the first quadrant where the given ellipses intersect. If $\theta$ is the acute angle between the tangents to the given ellipses at the point $P$, then the value of $4\tan\theta$ is ________.

    Show answer and solution

    Answer: 7.4 to 7.6

    Subtracting: $x^2=y^2=\frac15$, $P=\left(\frac1{\sqrt5},\frac1{\sqrt5}\right)$.
    Slopes: $x^2+4y^2=1\Rightarrow y'=-\frac{x}{4y}=-\frac14$; $4x^2+y^2=1\Rightarrow y'=-\frac{4x}{y}=-4$.
    $\tan\theta=\left|\dfrac{-\frac14+4}{1+1}\right|=\dfrac{15}{8}$.
    $4\tan\theta=7.5$.

  3. JEE Advanced 2025, Paper 1 · Question 3
    Let $\mathbb{R}$ denote the set of all real numbers. Define the function $f : \mathbb{R} \to \mathbb{R}$ by $$f(x) = \begin{cases} 2 - 2x^2 - x^2\sin\dfrac{1}{x} & \text{if } x \neq 0, \\ 2 & \text{if } x = 0. \end{cases}$$Then which one of the following statements is TRUE?

    1. The function $f$ is NOT differentiable at $x = 0$
    2. There is a positive real number $\delta$, such that $f$ is a decreasing function on the interval $(0, \delta)$
    3. For any positive real number $\delta$, the function $f$ is NOT an increasing function on the interval $(-\delta, 0)$
    4. $x = 0$ is a point of local minima of $f$
    Show answer and solution

    Answer: (c)

    $f'(0) = \lim_{x\to0}\dfrac{-2x^2 - x^2\sin(1/x)}{x} = 0$, so $f$ is differentiable at $0$: (A) is false.
    For $x \neq 0$: $f'(x) = -4x - 2x\sin\dfrac1x + \cos\dfrac1x$.
    As $x \to 0$ the first two terms tend to $0$ while $\cos(1/x)$ keeps taking the values $+1$ and $-1$, so $f'$ takes both signs in every interval $(0,\delta)$ and $(-\delta,0)$.
    Hence $f$ is neither increasing nor decreasing on any such interval: (B) is false and (C) is true.
    $f(x) - f(0) = -x^2\left(2 + \sin\dfrac1x\right) \lt 0$ for $x \neq 0$, so $x=0$ is a local maximum, not a minimum: (D) is false.
    Answer (C).

  4. JEE Advanced 2025, Paper 1 · Question 15
    Let $\mathbb{R}$ denote the set of all real numbers. For a real number $x$, let $[x]$ denote the greatest integer less than or equal to $x$. Let $n$ denote a natural number.

    Match each entry in List-I to the correct entry in List-II and choose the correct option.

    List-IList-II
    (P) The minimum value of $n$ for which the function $f(x) = \left[\dfrac{10x^3 - 45x^2 + 60x + 35}{n}\right]$ is continuous on the interval $[1, 2]$, is(1) $8$
    (Q) The minimum value of $n$ for which $g(x) = (2n^2 - 13n - 15)(x^3 + 3x)$, $x \in \mathbb{R}$, is an increasing function on $\mathbb{R}$, is(2) $9$
    (R) The smallest natural number $n$ which is greater than $5$, such that $x = 3$ is a point of local minima of $h(x) = (x^2 - 9)^n(x^2 + 2x + 3)$, is(3) $5$
    (S) Number of $x_0 \in \mathbb{R}$ such that $l(x) = \displaystyle\sum_{k=0}^{4}\left(\sin|x - k| + \cos\left|x - k + \dfrac12\right|\right)$, $x \in \mathbb{R}$, is NOT differentiable at $x_0$, is(4) $6$
    (5) $10$

    1. (P) $\rightarrow$ (1) (Q) $\rightarrow$ (3) (R) $\rightarrow$ (2) (S) $\rightarrow$ (5)
    2. (P) $\rightarrow$ (2) (Q) $\rightarrow$ (1) (R) $\rightarrow$ (4) (S) $\rightarrow$ (3)
    3. (P) $\rightarrow$ (5) (Q) $\rightarrow$ (1) (R) $\rightarrow$ (4) (S) $\rightarrow$ (3)
    4. (P) $\rightarrow$ (2) (Q) $\rightarrow$ (3) (R) $\rightarrow$ (1) (S) $\rightarrow$ (5)
    Show answer and solution

    Answer: (b)

    (P) $p(x) = 10x^3 - 45x^2 + 60x + 35$, $p'(x) = 30(x-1)(x-2) \le 0$ on $[1,2]$, so $p$ falls from $p(1) = 60$ to $p(2) = 55$.
    $[p/n]$ is continuous iff no integer lies in $\left(\dfrac{55}{n}, \dfrac{60}{n}\right]$. $n = 1,\ldots,8$ fail (e.g. $n = 8$: $7 \in (6.875, 7.5]$); $n = 9$: $(6.11, 6.67]$ has no integer. So $n = 9$ → (2).
    (Q) $x^3 + 3x$ is increasing, so need $2n^2 - 13n - 15 = (2n - 15)(n + 1) \gt 0 \Rightarrow n \gt 7.5$: $n = 8$ → (1).
    (R) Near $x = 3$: $h(x) = (x-3)^n\cdot(x+3)^n(x^2+2x+3)$ with the second factor positive, so $x = 3$ is a local minimum iff $n$ is even: $n = 6$ → (4).
    (S) $\cos|x - k + \frac12| = \cos(x - k + \frac12)$ is smooth; $\sin|x - k|$ has a corner at $x = k$ (slopes $-1$ and $+1$). So $x_0 = 0, 1, 2, 3, 4$: $5$ points → (3).
    Match: P→2, Q→1, R→4, S→3 → (B).

  5. JEE Advanced 2025, Paper 2 · Question 8
    Let $\mathbb{R}$ denote the set of all real numbers. Let $f:\mathbb{R}\to\mathbb{R}$ be defined by $$f(x)=\begin{cases}\dfrac{6x+\sin x}{2x+\sin x} & \text{if } x\neq0,\\[2mm] \dfrac{7}{3} & \text{if } x=0.\end{cases}$$ Then which of the following statements is (are) TRUE?

    1. The point $x=0$ is a point of local maxima of $f$
    2. The point $x=0$ is a point of local minima of $f$
    3. Number of points of local maxima of $f$ in the interval $[\pi,6\pi]$ is $3$
    4. Number of points of local minima of $f$ in the interval $[2\pi,4\pi]$ is $1$
    Show answer and solution

    Answer: (b), (c), (d)

    $f(x)=1+\dfrac{4x}{2x+\sin x}$. Near $0$: $2x+\sin x=3x-\dfrac{x^3}{6}+\ldots$, so $f(x)=\dfrac73+\dfrac{2x^2}{27}+\ldots>\dfrac73$. So $x=0$ is a local minimum (B true, A false).
    $f'(x)=\dfrac{4(\sin x-x\cos x)}{(2x+\sin x)^2}$. Let $\varphi(x)=\sin x-x\cos x$; $\varphi'(x)=x\sin x$.
    Critical points: $\tan x=x$, one root $x_k\in\left(k\pi,k\pi+\dfrac\pi2\right)$ for each $k\ge1$: $x_1\approx4.49$, $x_2\approx7.73$, $x_3\approx10.90$, $x_4\approx14.07$, $x_5\approx17.22$ ($6\pi\approx18.85$).
    At $x_k$, $\varphi'$ has the sign of $\sin x$, i.e. $(-1)^k$: $f'$ changes $+\to-$ for odd $k$ (maxima) and $-\to+$ for even $k$ (minima).
    Maxima in $[\pi,6\pi]$: $x_1,x_3,x_5$ → 3 (C true). Minima in $[2\pi,4\pi]$: only $x_2$ → 1 (D true).
    Answer (B), (C), (D).

  6. JEE Advanced 2024, Paper 2 · Question 10
    Let the function $f:\mathbb{R}\to\mathbb{R}$ be defined by

    $\displaystyle f(x)=\dfrac{\sin x}{e^{\pi x}}\,\dfrac{\left(x^{2023}+2024x+2025\right)}{\left(x^2-x+3\right)}+\dfrac{2}{e^{\pi x}}\,\dfrac{\left(x^{2023}+2024x+2025\right)}{\left(x^2-x+3\right)}.$
    Then the number of solutions of $f(x)=0$ in $\mathbb{R}$ is ______.

    Show answer and solution

    Answer: 1

    $f(x)=\dfrac{(\sin x+2)\left(x^{2023}+2024x+2025\right)}{e^{\pi x}\left(x^2-x+3\right)}$.
    $\sin x+2>0$, $e^{\pi x}>0$ and $x^2-x+3>0$ (discriminant $-11$), so $f(x)=0\iff h(x)=x^{2023}+2024x+2025=0$.
    $h'(x)=2023x^{2022}+2024>0$, so $h$ is strictly increasing with exactly one real root ($h(-1)=0$).
    Number of solutions $=1$.

  7. JEE Advanced 2023, Paper 2 · Question 7
    Let $S$ be the set of all twice differentiable functions $f$ from $\mathbb{R}$ to $\mathbb{R}$ such that $\dfrac{d^2 f}{dx^2}(x) > 0$ for all $x \in (-1, 1)$. For $f \in S$, let $X_f$ be the number of points $x \in (-1, 1)$ for which $f(x) = x$. Then which of the following statements is(are) true?

    1. There exists a function $f \in S$ such that $X_f = 0$
    2. For every function $f \in S$, we have $X_f \le 2$
    3. There exists a function $f \in S$ such that $X_f = 2$
    4. There does NOT exist any function $f$ in $S$ such that $X_f = 1$
    Show answer and solution

    Answer: (a), (b), (c)

    $h(x) = f(x) - x$ has $h'' = f'' > 0$ on $(-1,1)$, so $h'$ is strictly increasing and $h$ has at most two zeros there: (B) true.
    (A): $f(x) = x^2 + 1$ gives $x^2 - x + 1 > 0$, no solution: $X_f = 0$, true.
    (C): $f(x) = 2x^2$ gives $x = 0, \tfrac12$: $X_f = 2$, true.
    (D): $f(x) = x^2$ gives $x = 0$ only (the root $x = 1$ is outside $(-1,1)$): $X_f = 1$ exists, so (D) is false.
    Answer (A), (B), (C).

  8. JEE Advanced 2023, Paper 2 · Question 8
    For $x \in \mathbb{R}$, let $\tan^{-1}(x) \in \left(-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right)$. Then the minimum value of the function $f : \mathbb{R} \to \mathbb{R}$ defined by

    $\displaystyle f(x) = \int_0^{x\tan^{-1}x} \frac{e^{(t - \cos t)}}{1 + t^{2023}}\,dt$
    is ________.

    Show answer and solution

    Answer: 0

    $x\tan^{-1}x \ge 0$ for every real $x$ (both factors have the same sign), with equality only at $x = 0$.
    For $t \ge 0$ the integrand $\dfrac{e^{t-\cos t}}{1+t^{2023}}$ is positive, so $f(x) \ge 0$.
    $f(0) = \int_0^0 = 0$, so the minimum value is $0$.

  9. JEE Advanced 2022, Paper 2 · Question 10
    Let

    $\displaystyle \alpha = \sum_{k=1}^{\infty} \sin^{2k}\left(\frac{\pi}{6}\right).$
    Let $g : [0, 1] \to \mathbb{R}$ be the function defined by
    $\displaystyle g(x) = 2^{\alpha x} + 2^{\alpha(1-x)}.$
    Then, which of the following statements is/are TRUE ?

    1. The minimum value of $g(x)$ is $2^{\frac76}$
    2. The maximum value of $g(x)$ is $1 + 2^{\frac13}$
    3. The function $g(x)$ attains its maximum at more than one point
    4. The function $g(x)$ attains its minimum at more than one point
    Show answer and solution

    Answer: (a), (b), (c)

    $\alpha = \displaystyle\sum_{k\ge1}\left(\frac14\right)^k = \frac13$, so $g(x) = 2^{x/3} + 2^{(1-x)/3}$.
    By AM–GM, $g(x) \ge 2\sqrt{2^{1/3}} = 2^{7/6}$, with equality only at $x = \dfrac12$: (A) true, (D) false.
    $g$ is convex and symmetric about $x = \dfrac12$, so its maximum is at both ends: $g(0) = g(1) = 1 + 2^{1/3}$: (B) and (C) true.
    Answer (A), (B), (C).

  10. JEE Advanced 2021, Paper 1 · Question 12
    Let $f : \mathbb{R} \to \mathbb{R}$ be defined by

    $\displaystyle f(x) = \dfrac{x^2 - 3x - 6}{x^2 + 2x + 4}$
    Then which of the following statements is (are) TRUE ?

    1. $f$ is decreasing in the interval $(-2, -1)$
    2. $f$ is increasing in the interval $(1, 2)$
    3. $f$ is onto
    4. Range of $f$ is $\left[-\dfrac32, 2\right]$
    Show answer and solution

    Answer: (a), (b)

    $f'(x) = \dfrac{(2x - 3)(x^2 + 2x + 4) - (x^2 - 3x - 6)(2x + 2)}{(x^2 + 2x + 4)^2} = \dfrac{5x(x + 4)}{(x^2 + 2x + 4)^2}$.
    $f' < 0$ on $(-4, 0)$, so (A) is true; $f' > 0$ on $(0, \infty)$, so (B) is true.
    Extreme values: $f(0) = -\dfrac32$ (minimum), $f(-4) = \dfrac{22}{12} = \dfrac{11}{6}$ (maximum), and $f \to 1$ at $\pm\infty$.
    Range $= \left[-\dfrac32, \dfrac{11}{6}\right]$, so $f$ is not onto and (D) is false.
    Answer (A), (B).

  11. JEE Advanced 2021, Paper 2 · Question 9
    Let $f_1 : (0, \infty) \to \mathbb{R}$ and $f_2 : (0, \infty) \to \mathbb{R}$ be defined by

    $\displaystyle f_1(x) = \int_0^x \prod_{j=1}^{21}(t - j)^j\,dt, \qquad x > 0$
    and
    $\displaystyle f_2(x) = 98(x - 1)^{50} - 600(x - 1)^{49} + 2450, \quad x > 0,$
    where, for any positive integer $n$ and real numbers $a_1, a_2, \ldots, a_n$, $\prod_{i=1}^{n} a_i$ denotes the product of $a_1, a_2, \ldots, a_n$. Let $m_i$ and $n_i$, respectively, denote the number of points of local minima and the number of points of local maxima of function $f_i$, $i = 1, 2$, in the interval $(0, \infty)$.

    The value of $2m_1 + 3n_1 + m_1n_1$ is ___ .

    Show answer and solution

    Answer: 56.9 to 57.1

    $f_1'(x) = \prod_{j=1}^{21}(x - j)^j$ changes sign only at the odd $j$: $1, 3, 5, \ldots, 21$ (11 points).
    For $x > 21$, $f_1' > 0$; just left of 21 it is negative, so $x = 21$ is a minimum, and the type alternates going left: minima at $21, 17, 13, 9, 5, 1$ and maxima at $19, 15, 11, 7, 3$.
    $m_1 = 6$, $n_1 = 5$.
    $2m_1 + 3n_1 + m_1n_1 = 12 + 15 + 30 = 57$.

  12. JEE Advanced 2021, Paper 2 · Question 10
    Let $f_1 : (0, \infty) \to \mathbb{R}$ and $f_2 : (0, \infty) \to \mathbb{R}$ be defined by

    $\displaystyle f_1(x) = \int_0^x \prod_{j=1}^{21}(t - j)^j\,dt, \qquad x > 0$
    and
    $\displaystyle f_2(x) = 98(x - 1)^{50} - 600(x - 1)^{49} + 2450, \quad x > 0,$
    where, for any positive integer $n$ and real numbers $a_1, a_2, \ldots, a_n$, $\prod_{i=1}^{n} a_i$ denotes the product of $a_1, a_2, \ldots, a_n$. Let $m_i$ and $n_i$, respectively, denote the number of points of local minima and the number of points of local maxima of function $f_i$, $i = 1, 2$, in the interval $(0, \infty)$.

    The value of $6m_2 + 4n_2 + 8m_2n_2$ is ___.

    Show answer and solution

    Answer: 5.9 to 6.1

    $f_2'(x) = 4900(x - 1)^{49} - 29400(x - 1)^{48} = 4900(x - 1)^{48}(x - 7)$.
    At $x = 1$ the factor $(x - 1)^{48}$ does not change sign: no extremum.
    At $x = 7$, $f_2'$ goes from negative to positive: one local minimum.
    $m_2 = 1$, $n_2 = 0$, so $6m_2 + 4n_2 + 8m_2n_2 = 6$.

  13. JEE Advanced 2021, Paper 2 · Question 15
    Let $\psi_1 : [0, \infty) \to \mathbb{R}$, $\psi_2 : [0, \infty) \to \mathbb{R}$, $f : [0, \infty) \to \mathbb{R}$ and $g : [0, \infty) \to \mathbb{R}$ be functions such that $f(0) = g(0) = 0$,

    $\displaystyle \psi_1(x) = e^{-x} + x, \quad x \ge 0,$
    $\displaystyle \psi_2(x) = x^2 - 2x - 2e^{-x} + 2, \quad x \ge 0,$
    $\displaystyle f(x) = \int_{-x}^{x}\left(|t| - t^2\right)e^{-t^2}\,dt, \quad x > 0$
    and
    $\displaystyle g(x) = \int_0^{x^2}\sqrt{t}\,e^{-t}\,dt, \quad x > 0.$
    Which of the following statements is TRUE ?

    1. $f\left(\sqrt{\ln 3}\right) + g\left(\sqrt{\ln 3}\right) = \dfrac13$
    2. For every $x > 1$, there exists an $\alpha \in (1, x)$ such that $\psi_1(x) = 1 + \alpha x$
    3. For every $x > 0$, there exists a $\beta \in (0, x)$ such that $\psi_2(x) = 2x\left(\psi_1(\beta) - 1\right)$
    4. $f$ is an increasing function on the interval $\left[0, \dfrac32\right]$
    Show answer and solution

    Answer: (c)

    $f(x) = 2\int_0^x (t - t^2)e^{-t^2}dt$ (even integrand); with $t = u^2$, $g(x) = 2\int_0^x u^2e^{-u^2}du$.
    (A) $f + g = 2\int_0^x te^{-t^2}dt = 1 - e^{-x^2}$; at $x = \sqrt{\ln 3}$ this is $\dfrac23 \ne \dfrac13$ → false.
    (B) MVT on $[0, x]$: $\psi_1(x) = 1 + x\left(1 - e^{-c}\right)$ with $0 < 1 - e^{-c} < 1$, so the required $\alpha$ would be $< 1$, not in $(1, x)$ → false.
    (C) $\psi_2(0) = 0$ and $\psi_2'(x) = 2x - 2 + 2e^{-x} = 2\left(\psi_1(x) - 1\right)$. MVT: $\psi_2(x) = x\,\psi_2'(\beta) = 2x\left(\psi_1(\beta) - 1\right)$ for some $\beta \in (0, x)$ → true.
    (D) $f'(x) = 2(x - x^2)e^{-x^2} < 0$ for $x > 1$ → false.
    Answer (C).
