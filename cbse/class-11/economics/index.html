Sample questions

A few questions from the Class 11 Economics bank. Every test picks a fresh mix.

  1. Collection of Data
    Data collected by an investigator for the first time, for a specific purpose, are called ______ data.

    1. sample
    2. primary
    3. census
    4. secondary
    Show answer

    Answer: primary

    Primary data are first-hand data; secondary data are already collected by someone else and used again.

  2. Measures of Central Tendency
    The value that occurs most frequently in a series is called the ______.

    1. mean
    2. range
    3. median
    4. mode
    Show answer

    Answer: mode

    The mode is the most frequently occurring value in a distribution.

  3. Correlation
    The value of the coefficient of correlation always lies between ______ and +1.

    1. 0
    2. -0.5
    3. -2
    4. -1
    Show answer

    Answer: -1

    r lies between −1 (perfect negative) and +1 (perfect positive); r = 0 means no linear correlation.

  4. Index Numbers
    The index number for the base year is always taken as ______.

    1. 10
    2. 0
    3. 1
    4. 100
    Show answer

    Answer: 100

    The base year is the reference period, and its index is set at 100.

  5. Indian Economy 1950–1990
    In which year was India's First Five Year Plan launched?

    1. 1956
    2. 1961
    3. 1951
    4. 1947
    Show answer

    Answer: 1951

    The First Five Year Plan covered 1951–56 and gave priority to agriculture.
