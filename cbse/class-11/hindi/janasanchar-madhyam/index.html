A few questions from this chapter. Open each one to see the answer.

  1. जनसंचार का सबसे पुराना माध्यम कौन-सा है?

    1. रेडियो
    2. प्रिंट माध्यम
    3. इंटरनेट
    4. टेलीविज़न
    Show answer

    Answer: प्रिंट माध्यम

    मुद्रण के आविष्कार के बाद समाचार पत्र जैसे प्रिंट माध्यम सबसे पहले विकसित हुए।

  2. संचार प्रक्रिया में संदेश को भाषा या संकेतों में ढालना क्या कहलाता है?

    1. शोर
    2. फ़ीडबैक
    3. एनकोडिंग
    4. डिकोडिंग
    Show answer

    Answer: एनकोडिंग

    संदेश को शब्दों, संकेतों या ध्वनि में बदलना एनकोडिंग (कूटीकरण) है; प्राप्तकर्ता उसे डिकोड करता है।

  3. संचार प्रक्रिया में प्राप्तकर्ता की प्रतिक्रिया को क्या कहते हैं?

    1. शोर
    2. फ़ीडबैक
    3. माध्यम
    4. एनकोडिंग
    Show answer

    Answer: फ़ीडबैक

    प्राप्तकर्ता की प्रतिक्रिया संचारक तक लौटती है, इसे फ़ीडबैक कहते हैं।

  4. किसी समाचार पत्र में संपादक तय करता है कि आई हुई ढेर सारी ख़बरों में से कौन-सी छपेंगी और कौन-सी नहीं। जनसंचार में इस भूमिका को क्या कहते हैं?

    1. फ़ीडबैक
    2. शोर
    3. द्वारपाल
    4. एनकोडिंग
    Show answer

    Answer: द्वारपाल

    सामग्री को छाँटकर तय करने वाले व्यक्ति या संस्था को द्वारपाल (गेटकीपर) कहते हैं; जनसंचार में यह भूमिका संपादक जैसे लोग निभाते हैं।

  5. हिंदी का पहला साप्ताहिक समाचार पत्र कौन-सा था?

    1. हंस
    2. बंगाल गज़ट
    3. सरस्वती
    4. उदंत मार्तंड
    Show answer

    Answer: उदंत मार्तंड

    'उदंत मार्तंड' हिंदी का पहला साप्ताहिक समाचार पत्र था।
