A few questions from this chapter. Open each one to see the answer.

  1. Evaluate limx→5 (x4 − 625) / (x − 5).

    Show answer and solution

    Answer: 500

    lim (xⁿ − aⁿ)/(x − a) = n·aⁿ⁻¹ = 4 × 53 = 500

  2. If f(x) = 2x³ + 2x² − 3x, find f′(−1).

    Show answer and solution

    Answer: −1

    f′(x) = 6x² + 4x − 3, so f′(−1) = −1.

  3. Evaluate limx→1 (x3 − 1) / (x − 1).

    Show answer and solution

    Answer: 3

    lim (xⁿ − aⁿ)/(x − a) = n·aⁿ⁻¹ = 3 × 12 = 3

  4. If f(x) = 4x³ + 2x² + 4x, find f′(2).

    Show answer and solution

    Answer: 60

    f′(x) = 12x² + 4x + 4, so f′(2) = 60.

  5. Evaluate limx→4 (x2 − 16) / (x − 4).

    Show answer and solution

    Answer: 8

    lim (xⁿ − aⁿ)/(x − a) = n·aⁿ⁻¹ = 2 × 41 = 8

  6. If f(x) = 3x³ − 4x² + x, find f′(1).

    Show answer and solution

    Answer: 2

    f′(x) = 9x² − 8x + 1, so f′(1) = 2.
