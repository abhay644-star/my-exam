A few questions from this chapter. Open each one to see the answer.

  1. If set A has 3 elements and set B has 2 elements, how many elements does A × B have?

    Show answer and solution

    Answer: 6

    n(A × B) = n(A) × n(B) = 3 × 2 = 6.

  2. If the ordered pairs (x + 1, y − 2) and (3, 1) are equal, find x + y.

    Show answer and solution

    Answer: 5

    x + 1 = 3 gives x = 2 and y − 2 = 1 gives y = 3, so x + y = 5.

  3. If f(x) = x² − 3x + 2, find f(4).

    Show answer and solution

    Answer: 6

    f(4) = 16 − 12 + 2 = 6.

  4. If n(A) = 2 and n(B) = 3, how many relations are there from A to B?

    Show answer and solution

    Answer: 64

    A × B has 2 × 3 = 6 elements; every subset is a relation, so there are 2⁶ = 64 relations.

  5. If f(x) = 2x + 3 and g(x) = x² are real functions, find (fg)(2).

    Show answer and solution

    Answer: 28

    (fg)(2) = f(2) × g(2) = 7 × 4 = 28.

  6. If A = {1, 2}, how many elements does A × A × A have?

    Show answer and solution

    Answer: 8

    n(A × A × A) = 2 × 2 × 2 = 8.
