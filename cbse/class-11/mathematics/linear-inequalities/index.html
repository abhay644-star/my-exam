A few questions from this chapter. Open each one to see the answer.

  1. Find the greatest integer x that satisfies 5x + 6 < x + 46.

    Show answer and solution

    Answer: 9

    4x < 40, so x < 10. The greatest integer is 9.

  2. Find the greatest integer x that satisfies 3x + 1 < x + 17.

    Show answer and solution

    Answer: 7

    2x < 16, so x < 8. The greatest integer is 7.

  3. Find the greatest integer x that satisfies 7x − 3 < x + 51.

    Show answer and solution

    Answer: 8

    6x < 54, so x < 9. The greatest integer is 8.

  4. Find the greatest integer x that satisfies 5x + 7 < 3x + 15.

    Show answer and solution

    Answer: 3

    2x < 8, so x < 4. The greatest integer is 3.

  5. Find the greatest integer x that satisfies 5x − 9 < 3x − 13.

    Show answer and solution

    Answer: −3

    2x < −4, so x < −2. The greatest integer is −3.

  6. Find the greatest integer x that satisfies 4x + 2 < x + 26.

    Show answer and solution

    Answer: 7

    3x < 24, so x < 8. The greatest integer is 7.
