A few questions from this chapter. Open each one to see the answer.

  1. One card is drawn from a well-shuffled pack of 52 cards. Find the probability that it is a face card.

    Show answer and solution

    Answer: 3/13

    There are 12 favourable cards, so the probability is 12/52 = 3/13.

  2. One card is drawn from a well-shuffled pack of 52 cards. Find the probability that it is a king or a heart.

    Show answer and solution

    Answer: 4/13

    There are 16 favourable cards, so the probability is 16/52 = 4/13.

  3. One card is drawn from a well-shuffled pack of 52 cards. Find the probability that it is neither a heart nor a king.

    Show answer and solution

    Answer: 9/13

    There are 36 favourable cards, so the probability is 36/52 = 9/13.

  4. One card is drawn from a well-shuffled pack of 52 cards. Find the probability that it is a black card that is not a king.

    Show answer and solution

    Answer: 6/13

    There are 24 favourable cards, so the probability is 24/52 = 6/13.

  5. One card is drawn from a well-shuffled pack of 52 cards. Find the probability that it is a red card or a queen.

    Show answer and solution

    Answer: 7/13

    There are 28 favourable cards, so the probability is 28/52 = 7/13.

  6. One card is drawn from a well-shuffled pack of 52 cards. Find the probability that it is an ace or a spade.

    Show answer and solution

    Answer: 4/13

    There are 16 favourable cards, so the probability is 16/52 = 4/13.
