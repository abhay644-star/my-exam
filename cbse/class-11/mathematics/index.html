Sample questions

A few questions from the Class 11 Mathematics bank. Every test picks a fresh mix.

  1. Sets
    If A = {1, 2, 3, 4} and B = {3, 4, 5}, how many elements does A ∪ B have?

    1. 2
    2. 7
    3. 5
    4. 4
    Show answer

    Answer: 5

    A ∪ B = {1, 2, 3, 4, 5}, which has 5 elements.

  2. Relations and Functions
    If set A has 3 elements and set B has 2 elements, how many elements does A × B have?

    1. 9
    2. 5
    3. 6
    4. 8
    Show answer

    Answer: 6

    n(A × B) = n(A) × n(B) = 3 × 2 = 6.

  3. Trigonometric Functions
    Convert π/4 radians into degrees.

    1. 90 °
    2. 45 °
    3. 30 °
    4. 60 °
    Show answer

    Answer: 45 °

    π radians = 180°, so π/4 = 45°.

  4. Complex Numbers
    What is the value of i²?

    1. 0
    2. -1
    3. 1
    4. 2
    Show answer

    Answer: -1

    By definition i = √−1, so i² = −1.

  5. Linear Inequalities
    What is the largest integer x that satisfies 3x < 12?

    1. 12
    2. 3
    3. 4
    4. 9
    Show answer

    Answer: 3

    3x < 12 gives x < 4, so the largest integer is 3.
