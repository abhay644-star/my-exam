Sample questions

A few questions from the Class 11 Mathematics bank. Every test picks a fresh mix.

  1. Relations and Functions
    If set A has 3 elements and set B has 2 elements, how many elements does A × B have?

    1. 9
    2. 5
    3. 6
    4. 8
    Show answer

    Answer: 6

    n(A × B) = n(A) × n(B) = 3 × 2 = 6.

  2. Relations and Functions
    If the ordered pairs (x + 1, y − 2) and (3, 1) are equal, find x + y.

    1. 4
    2. 1
    3. 5
    4. 6
    Show answer

    Answer: 5

    x + 1 = 3 gives x = 2 and y − 2 = 1 gives y = 3, so x + y = 5.

  3. Relations and Functions
    If f(x) = x² − 3x + 2, find f(4).

    1. 2
    2. 6
    3. 4
    4. 14
    Show answer

    Answer: 6

    f(4) = 16 − 12 + 2 = 6.

  4. Relations and Functions
    If n(A) = 2 and n(B) = 3, how many relations are there from A to B?

    1. 8
    2. 64
    3. 6
    4. 32
    Show answer

    Answer: 64

    A × B has 2 × 3 = 6 elements; every subset is a relation, so there are 2⁶ = 64 relations.

  5. Relations and Functions
    If f(x) = 2x + 3 and g(x) = x² are real functions, find (fg)(2).

    1. 14
    2. 49
    3. 11
    4. 28
    Show answer

    Answer: 28

    (fg)(2) = f(2) × g(2) = 7 × 4 = 28.
