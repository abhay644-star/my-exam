Sample questions

A few questions from the Class 11 Computer Science bank. Every test picks a fresh mix.

  1. Computer System and Encoding
    A group of 4 bits is called a ______.

    1. byte
    2. kilobyte
    3. word
    4. nibble
    Show answer

    Answer: nibble

    4 bits = 1 nibble and 8 bits = 1 byte.

  2. Boolean Logic
    What is the output of a NOT gate when its input is 1?

    1. 2
    2. 10
    3. 0
    4. 1
    Show answer

    Answer: 0

    A NOT gate inverts its input, so 1 becomes 0 and 0 becomes 1.

  3. Python Fundamentals
    What is the output of print(17 % 5)?

    1. 3
    2. 2
    3. 3.4
    4. 12
    Show answer

    Answer: 2

    % gives the remainder: 17 = 5 × 3 + 2.

  4. Flow of Control
    Which Python keyword ends a loop immediately and transfers control to the statement after the loop?

    1. pass
    2. continue
    3. exit
    4. break
    Show answer

    Answer: break

    break terminates the loop; continue only skips the rest of the current iteration.

  5. Strings
    Strings in Python are ______, i.e. their characters cannot be changed in place.

    1. flexible
    2. editable
    3. immutable
    4. mutable
    Show answer

    Answer: immutable

    Strings are immutable; an assignment like s[0] = 'A' raises a TypeError.
