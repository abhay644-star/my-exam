  1. The modern periodic law states that properties of elements are a periodic function of their ______.

    1. number of neutrons
    2. atomic mass
    3. atomic number
    4. mass number
    Show answer

    Answer: atomic number

    Moseley showed atomic number, not atomic mass, is the fundamental property; this is the modern periodic law.

  2. The most electronegative element in the periodic table is ______.

    1. fluorine
    2. chlorine
    3. oxygen
    4. nitrogen
    Show answer

    Answer: fluorine

    Fluorine has the highest electronegativity (4.0 on the Pauling scale) due to its small size and high nuclear attraction.

  3. An element has the electronic configuration 1s2 2s2 2p6 3s2 3p5. To which group of the periodic table does it belong?

    1. 16
    2. 5
    3. 15
    4. 17
    Show answer

    Answer: 17

    It is a p-block element with 7 valence electrons (ns2 np5), so group = 10 + 7 = 17 (it is chlorine).

  4. How many groups are there in the long form of the modern periodic table?

    1. 7
    2. 16
    3. 18
    4. 8
    Show answer

    Answer: 18

    The IUPAC long form has 18 vertical columns (groups) and 7 periods.

  5. On moving from left to right across a period, the atomic radius generally ______.

    1. increases
    2. remains constant
    3. decreases
    4. doubles
    Show answer

    Answer: decreases

    Nuclear charge increases while electrons enter the same shell, so they are pulled closer and the radius decreases.

  6. Elements in the same group have the same number of ______ electrons.

    1. core
    2. valence
    3. total
    4. unpaired
    Show answer

    Answer: valence

    This is why elements in a group have similar chemical properties.

  7. The elements of group 18 are called ______ gases.

    1. noble
    2. alkali
    3. coinage
    4. halogen
    Show answer

    Answer: noble

    Helium, neon, argon, krypton, xenon and radon have completely filled valence shells.

  8. The energy needed to remove an electron from an isolated gaseous atom in its ground state is called ______ enthalpy.

    1. lattice
    2. ionisation
    3. electron gain
    4. hydration
    Show answer

    Answer: ionisation

    It is measured in kJ/mol.
