A few questions from this chapter. Open each one to see the answer.

  1. In terms of electron transfer, oxidation is defined as the loss of ______.

    1. oxygen
    2. protons
    3. neutrons
    4. electrons
    Show answer

    Answer: electrons

    Oxidation is loss of electrons and reduction is gain of electrons.

  2. What is the oxidation number of manganese in KMnO4?

    1. 2
    2. 7
    3. 6
    4. 5
    Show answer

    Answer: 7

    +1 + x + 4(−2) = 0, so x = +7.

  3. What is the oxidation number of chromium in K2Cr2O7?

    1. 6
    2. 12
    3. 3
    4. 7
    Show answer

    Answer: 6

    2(+1) + 2x + 7(−2) = 0 gives 2x = 12, so x = +6.

  4. In acidic medium, MnO4- is reduced to Mn2+ and Fe2+ is oxidised to Fe3+. How many moles of KMnO4 are needed to oxidise 5 moles of Fe2+?

    1. 0.2 mol
    2. 1 mol
    3. 2 mol
    4. 5 mol
    Show answer

    Answer: 1 mol

    Each MnO4- gains 5 electrons (Mn +7 → +2) and each Fe2+ loses 1, so 1 mol MnO4- oxidises 5 mol Fe2+.

  5. In terms of electron transfer, reduction is the ______ of electrons.

    1. sharing
    2. gain
    3. loss
    4. pairing
    Show answer

    Answer: gain

    OIL RIG: oxidation is loss, reduction is gain.

  6. What is the oxidation number of oxygen in hydrogen peroxide, H2O2?

    1. 0
    2. 1
    3. -1
    4. -2
    Show answer

    Answer: -1

    2(+1) + 2x = 0, so x = −1. Peroxides are an exception to the usual −2.

  7. What is the average oxidation number of sulphur in sodium thiosulphate, Na2S2O3?

    1. 2
    2. 6
    3. 4
    4. 2.5
    Show answer

    Answer: 2

    2(+1) + 2x + 3(−2) = 0 gives 2x = 4, so x = +2.

  8. A substance that is itself reduced and oxidises another substance is called an ______ agent.

    1. oxidising
    2. reducing
    3. catalytic
    4. neutral
    Show answer

    Answer: oxidising

    KMnO4 and K2Cr2O7 are common oxidising agents.
