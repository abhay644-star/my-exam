A few questions from this chapter. Open each one to see the answer.

  1. A property whose value depends only on the state of the system and not on the path followed is called a ______ function.

    1. state
    2. path
    3. work
    4. process
    Show answer

    Answer: state

    Internal energy, enthalpy and entropy are state functions; heat and work are path functions.

  2. For the reaction N2(g) + 3H2(g) → 2NH3(g), what is Δng (change in number of moles of gas)?

    1. -4
    2. 4
    3. -2
    4. 2
    Show answer

    Answer: -2

    Δng = moles of gaseous products − reactants = 2 − 4 = −2; this is used in ΔH = ΔU + ΔngRT.

  3. For a reaction at 300 K, ΔH = −10 kJ/mol and ΔS = +20 J/K/mol. Calculate ΔG in kJ/mol.

    1. 16 kJ/mol
    2. -16 kJ/mol
    3. 6000 kJ/mol
    4. -4 kJ/mol
    Show answer

    Answer: -16 kJ/mol

    ΔG = ΔH − TΔS = −10 − 300 × 0.020 = −16 kJ/mol, so the reaction is spontaneous.

  4. An isolated system can exchange neither energy nor ______ with its surroundings.

    1. volume
    2. pressure
    3. temperature
    4. matter
    Show answer

    Answer: matter

    Water in a perfectly insulated, closed thermos flask is an example of an isolated system.

  5. What is the standard enthalpy of formation of an element in its standard state?

    1. negative
    2. one
    3. positive
    4. zero
    Show answer

    Answer: zero

    By convention, ΔfH° of O2(g), C(graphite) and similar elements is zero.

  6. A reaction has ΔH = +30 kJ/mol and ΔS = +100 J/K/mol. Above what temperature does it become spontaneous?

    1. 300 K
    2. 30 K
    3. 0.3 K
    4. 3000 K
    Show answer

    Answer: 300 K

    At equilibrium ΔG = 0, so T = ΔH/ΔS = 30000/100 = 300 K; above this, TΔS exceeds ΔH.

  7. A system that can exchange energy but not matter with its surroundings is called a ______ system.

    1. closed
    2. adiabatic
    3. open
    4. isolated
    Show answer

    Answer: closed

    A sealed metal container of gas is a closed system.

  8. By Hess's law, the total enthalpy change of a reaction is the same whether it happens in one step or in ______ steps.

    1. fast
    2. several
    3. reversible
    4. no
    Show answer

    Answer: several

    Enthalpy is a state function, so it depends only on the initial and final states.
