Sample questions

A few questions from the Class 11 Chemistry bank. Every test picks a fresh mix.

  1. Some Basic Concepts of Chemistry
    The SI unit of amount of substance is the ______.

    1. gram
    2. litre
    3. kilogram
    4. mole
    Show answer

    Answer: mole

    One mole contains 6.022 × 10^23 elementary entities (Avogadro's number).

  2. Structure of Atom
    The neutron was discovered by ______.

    1. Chadwick
    2. Bohr
    3. Rutherford
    4. Thomson
    Show answer

    Answer: Chadwick

    James Chadwick discovered the neutron in 1932 by bombarding beryllium with alpha particles.

  3. Classification of Elements and Periodicity in Properties
    The modern periodic law states that properties of elements are a periodic function of their ______.

    1. number of neutrons
    2. atomic mass
    3. atomic number
    4. mass number
    Show answer

    Answer: atomic number

    Moseley showed atomic number, not atomic mass, is the fundamental property; this is the modern periodic law.

  4. Chemical Bonding and Molecular Structure
    A bond formed by mutual sharing of electrons between two atoms is called a/an ______ bond.

    1. hydrogen
    2. covalent
    3. metallic
    4. ionic
    Show answer

    Answer: covalent

    In a covalent bond, each atom contributes electrons to a shared pair, as in H2 or Cl2.

  5. Thermodynamics
    A property whose value depends only on the state of the system and not on the path followed is called a ______ function.

    1. state
    2. path
    3. work
    4. process
    Show answer

    Answer: state

    Internal energy, enthalpy and entropy are state functions; heat and work are path functions.
