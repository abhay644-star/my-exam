A few questions from this chapter. Open each one to see the answer.

  1. जो दिखाई न दे — उसके लिए एक शब्द लिखो।

    1. अदृश्य
    2. दृश्य
    3. अंधा
    4. अद्भुत
    Show answer

    Answer: अदृश्य

    दिखाई देने वाला दृश्य; जो दिखाई न दे वह अदृश्य।

  2. जिसका कोई अंत न हो — उसके लिए एक शब्द लिखो।

    1. आरंभ
    2. अनंत
    3. सीमित
    4. अंतिम
    Show answer

    Answer: अनंत

    अन् (नहीं) + अंत = अनंत, यानी जिसका अंत न हो।

  3. जो सब कुछ जानता हो — उसके लिए एक शब्द लिखो।

    1. अज्ञानी
    2. सर्वज्ञ
    3. सर्वशक्तिमान
    4. सर्वव्यापी
    Show answer

    Answer: सर्वज्ञ

    सर्व (सब) + ज्ञ (जानने वाला) = सर्वज्ञ।

  4. जिसे क्षमा न किया जा सके — उसके लिए एक शब्द लिखो।

    1. क्षम्य
    2. क्षमाशील
    3. अक्षम्य
    4. असहनीय
    Show answer

    Answer: अक्षम्य

    क्षमा करने योग्य क्षम्य; जिसे क्षमा न किया जा सके वह अक्षम्य। क्षमा करने वाला क्षमाशील कहलाता है।

  5. जिसकी कोई उपमा (तुलना) न हो — उसके लिए एक शब्द लिखो।

    1. समान
    2. उपमान
    3. अनुपम
    4. साधारण
    Show answer

    Answer: अनुपम

    अन् (नहीं) + उपम = अनुपम, यानी जिसके जैसा कोई दूसरा न हो।
