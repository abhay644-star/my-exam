Sample questions

A few questions from the Class 5 Hindi bank. Every test picks a fresh mix.

  1. संज्ञा
    ‘सेना’, ‘कक्षा’, ‘भीड़’ जैसे शब्द, जो किसी समूह का बोध कराते हैं, कौन-सी संज्ञा हैं?

    1. भाववाचक
    2. समूहवाचक
    3. द्रव्यवाचक
    4. व्यक्तिवाचक
    Show answer

    Answer: समूहवाचक

    समूह का बोध कराने वाले शब्द समूहवाचक संज्ञा कहलाते हैं।

  2. सर्वनाम
    ‘मैं, हम, तुम, वह’ — ये ______ सर्वनाम हैं।

    1. पुरुषवाचक
    2. प्रश्नवाचक
    3. संबंधवाचक
    4. निजवाचक
    Show answer

    Answer: पुरुषवाचक

    बोलने वाले, सुनने वाले या जिसके बारे में बात हो, उसके लिए पुरुषवाचक सर्वनाम आते हैं।

  3. विशेषण
    जिस शब्द की विशेषता बताई जाती है, उसे ______ कहते हैं।

    1. विशेष्य
    2. विशेषण
    3. क्रिया
    4. प्रविशेषण
    Show answer

    Answer: विशेष्य

    ‘सुंदर फूल’ में ‘फूल’ विशेष्य और ‘सुंदर’ विशेषण है।

  4. क्रिया
    जिस क्रिया के साथ कर्म हो, वह ______ क्रिया कहलाती है।

    1. सकर्मक
    2. सहायक
    3. प्रेरणार्थक
    4. अकर्मक
    Show answer

    Answer: सकर्मक

    जैसे — ‘राम आम खाता है’ में कर्म ‘आम’ है, इसलिए ‘खाता है’ सकर्मक क्रिया है।

  5. काल
    काल के कितने मुख्य भेद होते हैं?

    1. 3
    2. 4
    3. 5
    4. 2
    Show answer

    Answer: 3

    काल के तीन भेद हैं — भूतकाल, वर्तमान काल और भविष्यत् काल।
