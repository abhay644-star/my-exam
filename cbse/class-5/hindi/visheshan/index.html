A few questions from this chapter. Open each one to see the answer.

  1. जिस शब्द की विशेषता बताई जाती है, उसे ______ कहते हैं।

    1. विशेष्य
    2. विशेषण
    3. क्रिया
    4. प्रविशेषण
    Show answer

    Answer: विशेष्य

    ‘सुंदर फूल’ में ‘फूल’ विशेष्य और ‘सुंदर’ विशेषण है।

  2. ‘काला घोड़ा’ में ‘काला’ कौन-सा विशेषण है?

    1. गुणवाचक
    2. परिमाणवाचक
    3. संख्यावाचक
    4. सार्वनामिक
    Show answer

    Answer: गुणवाचक

    रंग, रूप, गुण, दोष बताने वाले विशेषण गुणवाचक होते हैं।

  3. ‘मुझे दो लीटर दूध चाहिए।’ — ‘दो लीटर’ कौन-सा विशेषण है?

    1. परिमाणवाचक
    2. गुणवाचक
    3. सार्वनामिक
    4. संख्यावाचक
    Show answer

    Answer: परिमाणवाचक

    ‘दो लीटर’ दूध की नाप-तोल (मात्रा) बताता है, इसलिए परिमाणवाचक विशेषण है।

  4. ‘बहुत सुंदर चित्र’ में ‘बहुत’ शब्द विशेषण ‘सुंदर’ की विशेषता बता रहा है। ऐसे शब्द को क्या कहते हैं?

    1. प्रविशेषण
    2. विशेष्य
    3. क्रियाविशेषण
    4. सर्वनाम
    Show answer

    Answer: प्रविशेषण

    विशेषण की भी विशेषता बताने वाला शब्द प्रविशेषण कहलाता है।

  5. ‘पुराना मकान’ में विशेषण कौन-सा है?

    1. मकान
    2. घर
    3. ईंट
    4. पुराना
    Show answer

    Answer: पुराना

    ‘पुराना’ मकान की विशेषता बताता है, इसलिए वह विशेषण है और ‘मकान’ विशेष्य।
