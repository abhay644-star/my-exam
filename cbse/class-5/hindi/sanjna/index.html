Practice questions with answers

A few questions from this chapter. Open each one to see the answer.

  1. ‘सेना’, ‘कक्षा’, ‘भीड़’ जैसे शब्द, जो किसी समूह का बोध कराते हैं, कौन-सी संज्ञा हैं?

    1. भाववाचक
    2. समूहवाचक
    3. द्रव्यवाचक
    4. व्यक्तिवाचक
    Show answer

    Answer: समूहवाचक

    समूह का बोध कराने वाले शब्द समूहवाचक संज्ञा कहलाते हैं।

  2. ‘मित्र’ शब्द से भाववाचक संज्ञा बनाओ।

    1. मित्रों
    2. मित्रवत
    3. मित्रा
    4. मित्रता
    Show answer

    Answer: मित्रता

    मित्र — मित्रता (या मैत्री) भाववाचक संज्ञा है।

  3. ‘मधुर’ से भाववाचक संज्ञा बनाकर वाक्य पूरा करो: उसकी वाणी की ______ सबको अच्छी लगती है।

    1. मधुरता
    2. मीठा
    3. मधुर
    4. मधुरी
    Show answer

    Answer: मधुरता

    मधुर (विशेषण) — मधुरता (भाववाचक संज्ञा)।

  4. ‘मनुष्य’ जातिवाचक संज्ञा से भाववाचक संज्ञा बनाओ।

    1. मनुष्यों
    2. मानव
    3. मानवीय
    4. मनुष्यता
    Show answer

    Answer: मनुष्यता

    मनुष्य — मनुष्यता (मानवता); ‘मानव’ जातिवाचक संज्ञा और ‘मानवीय’ विशेषण है।

  5. सोना, चाँदी, दूध जैसी नापी-तोली जाने वाली वस्तुओं के नाम ______ संज्ञा कहलाते हैं।

    1. द्रव्यवाचक
    2. व्यक्तिवाचक
    3. समूहवाचक
    4. जातिवाचक
    Show answer

    Answer: द्रव्यवाचक

    जिन पदार्थों को गिना नहीं, नापा-तोला जाता है, उनके नाम द्रव्यवाचक संज्ञा हैं।

  6. ‘लखनऊ एक शहर है।’ — इस वाक्य में ‘शहर’ कौन-सी संज्ञा है?

    1. भाववाचक
    2. द्रव्यवाचक
    3. जातिवाचक
    4. व्यक्तिवाचक
    Show answer

    Answer: जातिवाचक

    ‘शहर’ सभी शहरों की पूरी जाति का नाम है, जबकि ‘लखनऊ’ व्यक्तिवाचक संज्ञा है।

  7. ‘बुरा’ से भाववाचक संज्ञा बनाकर वाक्य पूरा करो: हमें समाज से ______ को दूर करना चाहिए।

    1. बुराई
    2. बुरी
    3. बुरे
    4. बुरा
    Show answer

    Answer: बुराई

    बुरा (विशेषण) + आई = बुराई (भाववाचक संज्ञा)।

  8. ‘हमारे देश में आज भी कई जयचंद हैं।’ — यहाँ ‘जयचंद’ (देश से धोखा करने वाले) किस संज्ञा के रूप में आया है?

    1. जातिवाचक
    2. व्यक्तिवाचक
    3. भाववाचक
    4. समूहवाचक
    Show answer

    Answer: जातिवाचक

    यहाँ ‘जयचंद’ एक व्यक्ति नहीं, बल्कि सभी देशद्रोहियों के वर्ग के लिए आया है, इसलिए जातिवाचक संज्ञा है।
