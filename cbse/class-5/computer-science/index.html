Sample questions

A few questions from the Class 5 Computer Science bank. Every test picks a fresh mix.

  1. Operating System and Windows
    The first screen we see after Windows starts is called the ______.

    1. start menu
    2. window
    3. taskbar
    4. desktop
    Show answer

    Answer: desktop

    The desktop is the main screen of Windows, with icons, the taskbar and the Start button.

  2. MS PowerPoint
    Each page of a PowerPoint presentation is called a ______.

    1. sheet
    2. cell
    3. slide
    4. frame
    Show answer

    Answer: slide

    A presentation is made of slides that are shown one after another.

  3. Hardware and Software
    Software that manages the computer and helps other programs to run is called ______ software.

    1. system
    2. application
    3. entertainment
    4. graphics
    Show answer

    Answer: system

    System software, such as an operating system, controls the computer; application software does specific tasks.

  4. Memory and Storage
    1 megabyte (MB) is equal to how many kilobytes (KB)?

    1. 8 KB
    2. 1024 KB
    3. 100 KB
    4. 1000 KB
    Show answer

    Answer: 1024 KB

    1 MB = 1024 KB.

  5. Input and Output Devices
    Which input device is used to record our voice into the computer?

    1. scanner
    2. printer
    3. speaker
    4. microphone
    Show answer

    Answer: microphone

    A microphone takes sound as input; a speaker gives sound as output.
