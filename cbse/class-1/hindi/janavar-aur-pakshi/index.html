A few questions from this chapter. Open each one to see the answer.

  1. ‘म्याऊँ-म्याऊँ’ कौन बोलती है?

    1. बकरी
    2. गाय
    3. बिल्ली
    4. चिड़िया
    Show answer

    Answer: बिल्ली

    बिल्ली म्याऊँ-म्याऊँ बोलती है।

  2. मैं दूध देती हूँ। मेरे बच्चे को बछड़ा कहते हैं। मैं कौन हूँ?

    1. बकरी
    2. गाय
    3. घोड़ी
    4. भेड़
    Show answer

    Answer: गाय

    गाय के बच्चे को बछड़ा कहते हैं।

  3. पहेली बूझो: लंबी सूँड़, बड़े-बड़े कान, मैं हूँ कौन?

    1. घोड़ा
    2. गैंडा
    3. ऊँट
    4. हाथी
    Show answer

    Answer: हाथी

    हाथी की लंबी सूँड़ और बड़े कान होते हैं।

  4. भेड़, घोड़ा, मुर्गी, गाय — इनमें से किससे हमें ऊन मिलती है?

    1. मुर्गी
    2. गाय
    3. भेड़
    4. घोड़ा
    Show answer

    Answer: भेड़

    भेड़ के बालों से ऊन बनती है।

  5. कौन-सा जानवर ‘जंगल का राजा’ कहलाता है?

    1. हाथी
    2. शेर
    3. भालू
    4. बंदर
    Show answer

    Answer: शेर

    शेर को जंगल का राजा कहा जाता है।

  6. कौन-सा पक्षी ‘काँव-काँव’ करता है?

    1. कौआ
    2. तोता
    3. मोर
    4. कोयल
    Show answer

    Answer: कौआ

    कौआ काँव-काँव करता है।

  7. पहेली बूझो: पेड़ों पर उछलता-कूदता हूँ, केले बड़े शौक से खाता हूँ, मेरी लंबी पूँछ है। मैं कौन हूँ?

    1. गिलहरी
    2. बंदर
    3. हिरन
    4. भालू
    Show answer

    Answer: बंदर

    बंदर पेड़ों पर उछलता-कूदता है और केले खाता है।

  8. हरे रंग और लाल चोंच वाला कौन-सा पक्षी है, जो बोलना भी सीख लेता है?

    1. कबूतर
    2. कौआ
    3. मोर
    4. तोता
    Show answer

    Answer: तोता

    तोता हरा होता है, उसकी चोंच लाल होती है और वह हमारी बातें दोहरा सकता है।
