A few questions from this chapter. Open each one to see the answer.

  1. ‘कमल’ शब्द में कितने वर्ण हैं?

    1. 2
    2. 3
    3. 4
    4. 5
    Show answer

    Answer: 3

    कमल = क + म + ल, यानी तीन वर्ण।

  2. मोर, घर, पतंग — इनमें ‘म’ से शुरू होने वाला शब्द कौन-सा है?

    1. कमल
    2. पतंग
    3. घर
    4. मोर
    Show answer

    Answer: मोर

    ‘मोर’ का पहला वर्ण ‘म’ है।

  3. ‘कमल’ शब्द के बीच में कौन-सा वर्ण है?

    1. ल
    2. म
    3. क
    4. अ
    Show answer

    Answer: म

    कमल = क + म + ल; बीच में ‘म’ है।

  4. ‘नगर’ शब्द से बीच का वर्ण ‘ग’ हटा दो। कौन-सा शब्द बचेगा?

    1. नर
    2. नग
    3. गर
    4. नगर
    Show answer

    Answer: नर

    नगर = न + ग + र; ‘ग’ हटाने पर न + र = नर।

  5. ‘नल’ शब्द का पहला वर्ण कौन-सा है?

    1. ल
    2. म
    3. न
    4. र
    Show answer

    Answer: न

    नल = न + ल; पहला वर्ण ‘न’ है।

  6. वर्ण जोड़कर शब्द बनाओ: घ + र = ______

    1. घार
    2. गर
    3. घर
    4. रघ
    Show answer

    Answer: घर

    घ और र जोड़ने से ‘घर’ बनता है।

  7. ‘जग’ शब्द का अंतिम वर्ण कौन-सा है?

    1. अ
    2. ज
    3. क
    4. ग
    Show answer

    Answer: ग

    जग = ज + ग; अंतिम वर्ण ‘ग’ है।

  8. ‘रस’ शब्द को उल्टी ओर से (पीछे से) पढ़ो। कौन-सा शब्द बनेगा?

    1. रस
    2. सर
    3. सार
    4. रास
    Show answer

    Answer: सर

    रस = र + स; पीछे से पढ़ने पर स + र = सर।
