A few questions from this chapter. Open each one to see the answer.

  1. हिंदी वर्णमाला का पहला स्वर कौन-सा है?

    1. इ
    2. क
    3. आ
    4. अ
    Show answer

    Answer: अ

    हिंदी वर्णमाला ‘अ’ स्वर से शुरू होती है।

  2. हिंदी वर्णमाला का पहला व्यंजन कौन-सा है?

    1. अ
    2. क
    3. ग
    4. ख
    Show answer

    Answer: क

    व्यंजन ‘क’ से शुरू होते हैं; ‘अ’ स्वर है।

  3. क, इ, ग, म — इनमें से स्वर कौन-सा है?

    1. क
    2. इ
    3. म
    4. ग
    Show answer

    Answer: इ

    ‘इ’ स्वर है; क, ग, म व्यंजन हैं।

  4. कमल, इमली, गमला, नल — इनमें से कौन-सा शब्द स्वर से शुरू होता है?

    1. नल
    2. गमला
    3. कमल
    4. इमली
    Show answer

    Answer: इमली

    ‘इमली’ स्वर ‘इ’ से शुरू होता है; बाकी शब्द व्यंजन (क, ग, न) से शुरू होते हैं।

  5. ‘प’ के बाद कौन-सा वर्ण आता है?

    1. ब
    2. भ
    3. फ
    4. म
    Show answer

    Answer: फ

    क्रम है — प, फ, ब, भ, म।
