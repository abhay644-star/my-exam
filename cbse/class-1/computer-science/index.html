Sample questions

A few questions from the Class 1 Computer Science bank. Every test picks a fresh mix.

  1. Computer – A Machine
    A computer is a ______.

    1. machine
    2. toy
    3. plant
    4. bird
    Show answer

    Answer: machine

    A computer is a machine. It helps us do many kinds of work.

  2. Parts of a Computer
    The part of a computer that looks like a TV is the ______.

    1. mouse
    2. keyboard
    3. monitor
    4. CPU
    Show answer

    Answer: monitor

    The monitor looks like a TV. It shows pictures and words.

  3. Uses of Computers
    Which of these can we do on a computer?

    1. take a bath
    2. grow plants
    3. cook food
    4. play games
    Show answer

    Answer: play games

    We can play games, watch cartoons and draw on a computer. We cannot cook or bathe with it.

  4. Smart Devices Around Us
    A smart device we use to talk to people far away is a ______.

    1. mobile phone
    2. bottle
    3. pencil
    4. chair
    Show answer

    Answer: mobile phone

    A mobile phone is a smart device. We use it to call people far away.

  5. Caring for a Computer
    We should keep the computer clean and free from ______.

    1. sound
    2. dust
    3. light
    4. air
    Show answer

    Answer: dust

    Dust can harm the computer, so we keep it clean.
