Sample questions

A few questions from the Class 6 Computer Science bank. Every test picks a fresh mix.

  1. Computer Basics
    What is the full form of CPU?

    1. Control Processing Unit
    2. Central Program Unit
    3. Computer Processing Unit
    4. Central Processing Unit
    Show answer

    Answer: Central Processing Unit

    CPU stands for Central Processing Unit, the brain of the computer.

  2. Hardware And Software
    What are the physical parts of a computer that we can touch called?

    1. software
    2. data
    3. hardware
    4. malware
    Show answer

    Answer: hardware

    Hardware is the set of physical, touchable parts of a computer.

  3. Input And Output Devices
    Which input device is used to type letters and numbers into a computer?

    1. speaker
    2. mouse
    3. keyboard
    4. monitor
    Show answer

    Answer: keyboard

    A keyboard has keys for letters, numbers and symbols.

  4. Memory Units
    How many bits make one byte?

    1. 4 bits
    2. 8 bits
    3. 16 bits
    4. 10 bits
    Show answer

    Answer: 8 bits

    One byte is a group of 8 bits.

  5. Memory And Storage
    What is the full form of RAM?

    1. Rapid Access Memory
    2. Random Access Memory
    3. Random Active Memory
    4. Read Access Memory
    Show answer

    Answer: Random Access Memory

    RAM stands for Random Access Memory, the computer's main working memory.
