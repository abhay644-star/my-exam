A few questions from this chapter. Open each one to see the answer.

  1. ‘उत्तीर्ण’ का विलोम शब्द क्या है?

    1. अनुत्तीर्ण
    2. उत्तम
    3. सफल
    4. प्रथम
    Show answer

    Answer: अनुत्तीर्ण

    उत्तीर्ण (पास) का विलोम अनुत्तीर्ण (फेल) है।

  2. ‘कृष्ण’ का एक पर्यायवाची शब्द लिखो।

    1. शिव
    2. इंद्र
    3. राम
    4. कन्हैया
    Show answer

    Answer: कन्हैया

    कन्हैया, गोपाल, केशव, माधव — कृष्ण के पर्यायवाची हैं।

  3. ‘जलज’ शब्द का प्रचलित अर्थ क्या है?

    1. नदी
    2. कमल
    3. समुद्र
    4. बादल
    Show answer

    Answer: कमल

    जल + ज (जन्म लेने वाला) = जलज, यानी जल में उत्पन्न होने वाला कमल।

  4. इनमें से कौन-सा शब्द ‘जल’ का पर्यायवाची नहीं है — नीर, वारि, अनल, तोय?

    1. अनल
    2. तोय
    3. नीर
    4. वारि
    Show answer

    Answer: अनल

    नीर, वारि और तोय जल के पर्यायवाची हैं; ‘अनल’ का अर्थ आग है।

  5. ‘आशा’ का विलोम शब्द क्या है?

    1. भाषा
    2. इच्छा
    3. निराशा
    4. अभिलाषा
    Show answer

    Answer: निराशा

    निर् उपसर्ग लगाकर आशा का विलोम निराशा बनता है।
