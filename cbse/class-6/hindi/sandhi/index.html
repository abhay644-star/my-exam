A few questions from this chapter. Open each one to see the answer.

  1. दो वर्णों के मेल से होने वाले परिवर्तन को ______ कहते हैं।

    1. उपसर्ग
    2. समास
    3. संधि
    4. प्रत्यय
    Show answer

    Answer: संधि

    जैसे — विद्या + आलय = विद्यालय में आ + आ मिलकर ‘आ’ हो गए; यह संधि है।

  2. संधि करो: विद्या + आलय = ______

    1. विद्याआलय
    2. विद्यालाय
    3. विद्यालय
    4. विद्योलय
    Show answer

    Answer: विद्यालय

    आ + आ = आ (दीर्घ संधि), इसलिए विद्या + आलय = विद्यालय।

  3. संधि करो: सूर्य + उदय = ______

    1. सूर्युदय
    2. सूर्यादय
    3. सूर्यउदय
    4. सूर्योदय
    Show answer

    Answer: सूर्योदय

    अ + उ = ओ (गुण संधि), इसलिए सूर्य + उदय = सूर्योदय।

  4. ‘महेश’ (महा + ईश) में कौन-सी संधि है?

    1. वृद्धि संधि
    2. दीर्घ संधि
    3. गुण संधि
    4. यण संधि
    Show answer

    Answer: गुण संधि

    आ + ई = ए होता है; अ/आ के बाद इ/ई आने पर ‘ए’ बनना गुण संधि है।

  5. संधि के मुख्य रूप से कितने भेद होते हैं?

    1. 4
    2. 3
    3. 2
    4. 5
    Show answer

    Answer: 3

    संधि के तीन भेद हैं — स्वर संधि, व्यंजन संधि और विसर्ग संधि।
