Practice questions with answers

A few questions from this chapter. Open each one to see the answer.

  1. जो शब्दांश किसी शब्द के आरंभ में जुड़कर उसका अर्थ बदल देते हैं, उन्हें ______ कहते हैं।

    1. समास
    2. संधि
    3. उपसर्ग
    4. प्रत्यय
    Show answer

    Answer: उपसर्ग

    जैसे — ‘अ’ + ज्ञान = अज्ञान; यहाँ ‘अ’ उपसर्ग है।

  2. ‘अपमान’ शब्द में कौन-सा उपसर्ग है?

    1. मान
    2. अप
    3. अपम
    4. अ
    Show answer

    Answer: अप

    अप + मान = अपमान; ‘अप’ उपसर्ग है।

  3. ‘पढ़’ में ‘आई’ प्रत्यय जोड़ने से कौन-सा शब्द बनेगा?

    1. पढ़ना
    2. पढ़ई
    3. पढ़ाई
    4. पढ़ाया
    Show answer

    Answer: पढ़ाई

    पढ़ + आई = पढ़ाई, जैसे लिख + आई = लिखाई।

  4. ‘धार्मिक’ शब्द में मूल शब्द और प्रत्यय कौन-से हैं?

    1. धर्म + मिक
    2. धा + र्मिक
    3. धार्म + इक
    4. धर्म + इक
    Show answer

    Answer: धर्म + इक

    धर्म + इक = धार्मिक; ‘इक’ प्रत्यय लगने पर पहला स्वर ‘अ’ बदलकर ‘आ’ हो जाता है।

  5. जो शब्दांश किसी शब्द के अंत में जुड़कर नया शब्द बनाते हैं, उन्हें ______ कहते हैं।

    1. प्रत्यय
    2. धातु
    3. विभक्ति
    4. उपसर्ग
    Show answer

    Answer: प्रत्यय

    जैसे — लिख + आवट = लिखावट; ‘आवट’ प्रत्यय है।

  6. ‘मिठास’ शब्द में कौन-सा प्रत्यय है?

    1. ठास
    2. मीठा
    3. आस
    4. इस
    Show answer

    Answer: आस

    मीठा + आस = मिठास; ‘आस’ प्रत्यय है।

  7. ‘अनुशासन’ शब्द में कौन-सा उपसर्ग है?

    1. अन
    2. आसन
    3. अनु
    4. शासन
    Show answer

    Answer: अनु

    अनु + शासन = अनुशासन; ‘अनु’ उपसर्ग है।

  8. ‘बचपन’ शब्द में कौन-सा प्रत्यय है?

    1. चपन
    2. बच
    3. पन
    4. अपन
    Show answer

    Answer: पन

    बच्चा + पन = बचपन; ‘पन’ प्रत्यय है, जैसे लड़कपन, अपनापन।
