  1. पका हुआ केला ______ रंग का होता है।

    1. बैंगनी
    2. काला
    3. पीला
    4. नीला
    Show answer

    Answer: पीला

    पकने पर केले का छिलका पीला हो जाता है।

  2. गाजर का रंग अक्सर कैसा होता है?

    1. सफ़ेद
    2. काला
    3. नीला
    4. लाल
    Show answer

    Answer: लाल

    गाजर प्रायः लाल या नारंगी रंग की होती है।

  3. पहेली बूझो: बाहर से हरा, अंदर से लाल, काले-काले बीज, गर्मी का फल।

    1. अनार
    2. खरबूज़ा
    3. तरबूज़
    4. पपीता
    Show answer

    Answer: तरबूज़

    तरबूज़ बाहर से हरा और अंदर से लाल होता है।

  4. नीला और पीला रंग मिलाने पर कौन-सा रंग बनता है?

    1. नारंगी
    2. लाल
    3. बैंगनी
    4. हरा
    Show answer

    Answer: हरा

    नीला + पीला = हरा।

  5. पालक की पत्तियों का रंग कैसा होता है?

    1. पीला
    2. लाल
    3. नीला
    4. हरा
    Show answer

    Answer: हरा

    पालक एक हरी पत्तेदार सब्ज़ी है।
