  1. ‘हिनहिनाना’ किस जानवर की आवाज़ है?

    1. घोड़ा
    2. हाथी
    3. गधा
    4. शेर
    Show answer

    Answer: घोड़ा

    घोड़ा हिनहिनाता है।

  2. गधे की आवाज़ को क्या कहते हैं?

    1. रेंकना
    2. मिमियाना
    3. दहाड़ना
    4. भौंकना
    Show answer

    Answer: रेंकना

    गधा रेंकता है।

  3. पहेली बूझो: मैं ‘टर्र-टर्र’ करता हूँ और पानी व ज़मीन दोनों पर रहता हूँ।

    1. मेंढक
    2. मछली
    3. साँप
    4. कछुआ
    Show answer

    Answer: मेंढक

    मेंढक टर्राता है और पानी व ज़मीन दोनों पर रहता है।

  4. शेर दहाड़ता है, हाथी चिंघाड़ता है, तो साँप क्या करता है?

    1. हिनहिनाता है
    2. फुफकारता है
    3. रेंकता है
    4. टर्राता है
    Show answer

    Answer: फुफकारता है

    साँप की आवाज़ को फुफकारना कहते हैं।

  5. कुत्ते के बच्चे को क्या कहते हैं?

    1. बछड़ा
    2. पिल्ला
    3. चूज़ा
    4. मेमना
    Show answer

    Answer: पिल्ला

    कुत्ते का बच्चा पिल्ला कहलाता है।

  6. शेर की आवाज़ को क्या कहते हैं?

    1. रंभाना
    2. चहचहाना
    3. दहाड़
    4. टर्राना
    Show answer

    Answer: दहाड़

    शेर दहाड़ता है।

  7. पहेली बूझो: मेरा रंग हरा है, चोंच लाल है और मैं ‘टें-टें’ करता हूँ। मैं कौन हूँ?

    1. तोता
    2. कौआ
    3. कबूतर
    4. मोर
    Show answer

    Answer: तोता

    तोता हरे रंग का होता है, उसकी चोंच लाल होती है और वह टें-टें करता है।

  8. कोयल की आवाज़ को क्या कहते हैं?

    1. दहाड़ना
    2. रेंकना
    3. भौंकना
    4. कूकना
    Show answer

    Answer: कूकना

    कोयल मीठी आवाज़ में कूकती है।
