Sample questions

A few questions from the Class 7 Computer Science bank. Every test picks a fresh mix.

  1. Number Systems
    What is the base of the binary number system?

    1. 10
    2. 2
    3. 16
    4. 8
    Show answer

    Answer: 2

    Binary uses two digits, so its base is 2.

  2. Spreadsheets
    In a spreadsheet, what is the box formed where a row and a column meet called?

    1. column header
    2. cell
    3. sheet
    4. range
    Show answer

    Answer: cell

    A cell is the intersection of a row and a column.

  3. Presentations
    What is each page of a presentation called?

    1. frame
    2. page break
    3. slide
    4. sheet
    Show answer

    Answer: slide

    A presentation is made up of slides.

  4. Internet And Email
    What is the full form of email?

    1. electronic mail
    2. electric mail
    3. express mail
    4. easy mail
    Show answer

    Answer: electronic mail

    Email means electronic mail.

  5. Cyber Safety And Ethics
    What is copying someone else's work and presenting it as your own called?

    1. plagiarism
    2. spamming
    3. phishing
    4. hacking
    Show answer

    Answer: plagiarism

    Plagiarism is using others' work without giving credit.
