A few questions from this chapter. Open each one to see the answer.

  1. 'विद्यालय' शब्द का संधि-विच्छेद ______ है।

    1. विद्य + आलय
    2. विद्या + लय
    3. विद + यालय
    4. विद्या + आलय
    Show answer

    Answer: विद्या + आलय

    विद्या + आलय में आ + आ मिलकर आ बनता है, इसलिए शब्द 'विद्यालय' बनता है।

  2. 'सूर्योदय' (सूर्य + उदय) में कौन-सी संधि है?

    1. गुण संधि
    2. दीर्घ संधि
    3. वृद्धि संधि
    4. यण संधि
    Show answer

    Answer: गुण संधि

    अ + उ = ओ होता है; अ/आ के बाद इ, उ, ऋ आने पर गुण संधि होती है।

  3. 'पुस्तकालय' (पुस्तक + आलय) में कौन-सी संधि है?

    1. दीर्घ संधि
    2. गुण संधि
    3. वृद्धि संधि
    4. यण संधि
    Show answer

    Answer: दीर्घ संधि

    अ + आ = आ; दो सजातीय स्वर मिलकर दीर्घ हो जाते हैं, इसलिए यह दीर्घ संधि है।

  4. 'उज्ज्वल' शब्द का सही संधि-विच्छेद और संधि का भेद कौन-सा है?

    1. उद् + ज्वल, विसर्ग संधि
    2. उत + ज्वल, दीर्घ संधि
    3. उज् + ज्वल, स्वर संधि
    4. उत् + ज्वल, व्यंजन संधि
    Show answer

    Answer: उत् + ज्वल, व्यंजन संधि

    उत् + ज्वल में त् का ज् हो गया है; व्यंजन में परिवर्तन होने से यह व्यंजन संधि है।

  5. संधि कीजिए: गिरि + ईश = ______

    1. गिरैश
    2. गिरेश
    3. गिरीश
    4. गिरिश
    Show answer

    Answer: गिरीश

    इ + ई = ई होता है; दो सजातीय स्वर मिलकर दीर्घ हो जाते हैं, यह दीर्घ संधि है।

  6. 'सदैव' शब्द का संधि-विच्छेद ______ है।

    1. सदा + ऐव
    2. सद + एव
    3. सदै + व
    4. सदा + एव
    Show answer

    Answer: सदा + एव

    सदा + एव में आ + ए = ऐ होता है, यह वृद्धि संधि है।

  7. 'एकैक' (एक + एक) में कौन-सी संधि है?

    1. दीर्घ संधि
    2. वृद्धि संधि
    3. गुण संधि
    4. यण संधि
    Show answer

    Answer: वृद्धि संधि

    अ + ए = ऐ होता है; अ/आ के बाद ए/ऐ या ओ/औ आने पर वृद्धि संधि होती है।

  8. संधि कीजिए: रत्न + आकर = ______

    1. रत्नोकर
    2. रत्नआकर
    3. रत्नकर
    4. रत्नाकर
    Show answer

    Answer: रत्नाकर

    अ + आ = आ (दीर्घ संधि): रत्न + आकर = रत्नाकर।
