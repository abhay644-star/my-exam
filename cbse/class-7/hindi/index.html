Sample questions

A few questions from the Class 7 Hindi bank. Every test picks a fresh mix.

  1. संधि
    'विद्यालय' शब्द का संधि-विच्छेद ______ है।

    1. विद्य + आलय
    2. विद्या + लय
    3. विद + यालय
    4. विद्या + आलय
    Show answer

    Answer: विद्या + आलय

    विद्या + आलय में आ + आ मिलकर आ बनता है, इसलिए शब्द 'विद्यालय' बनता है।

  2. समास
    'माता-पिता' में कौन-सा समास है?

    1. द्वंद्व समास
    2. तत्पुरुष
    3. द्विगु
    4. बहुव्रीहि
    Show answer

    Answer: द्वंद्व समास

    माता और पिता दोनों पद प्रधान हैं और 'और' से जुड़े हैं, इसलिए द्वंद्व समास है।

  3. उपसर्ग और प्रत्यय
    'अपमान' शब्द में उपसर्ग ______ है।

    1. अपम
    2. मान
    3. अप
    4. आन
    Show answer

    Answer: अप

    'अप' उपसर्ग 'मान' से पहले जुड़कर उल्टा अर्थ देता है: अप + मान = अपमान।

  4. पर्यायवाची और विलोम
    'आकाश' का एक पर्यायवाची शब्द लिखिए।

    1. पवन
    2. सागर
    3. गगन
    4. धरती
    Show answer

    Answer: गगन

    गगन, नभ, अंबर, व्योम सभी आकाश के पर्यायवाची शब्द हैं।

  5. मुहावरे और लोकोक्तियाँ
    मुहावरा 'आँखों का तारा' का अर्थ ______ है।

    1. बहुत दुष्ट
    2. बहुत प्यारा
    3. बहुत दूर
    4. बहुत चालाक
    Show answer

    Answer: बहुत प्यारा

    'आँखों का तारा' का अर्थ है बहुत प्यारा, जैसे: अर्जुन अपनी माँ की आँखों का तारा है।
