A few questions from this chapter. Open each one to see the answer.

  1. 'अपमान' शब्द में उपसर्ग ______ है।

    1. अपम
    2. मान
    3. अप
    4. आन
    Show answer

    Answer: अप

    'अप' उपसर्ग 'मान' से पहले जुड़कर उल्टा अर्थ देता है: अप + मान = अपमान।

  2. 'पराजय' शब्द में उपसर्ग ______ है।

    1. पर
    2. पराज
    3. परा
    4. जय
    Show answer

    Answer: परा

    परा + जय = पराजय; 'परा' उपसर्ग ने 'जय' का अर्थ उल्टा कर दिया।

  3. इनमें से किस शब्द में 'अन' उपसर्ग है?

    1. अनपढ़
    2. बेईमान
    3. निडर
    4. अपमान
    Show answer

    Answer: अनपढ़

    अन + पढ़ = अनपढ़; अन्य शब्दों में अप, नि और बे उपसर्ग हैं।

  4. 'सफल' शब्द में आरंभ में 'अ' उपसर्ग और अंत में 'ता' प्रत्यय जोड़ने पर कौन-सा शब्द बनेगा?

    1. असफल
    2. असफली
    3. असफलता
    4. सफलता
    Show answer

    Answer: असफलता

    अ + सफल + ता = असफलता; 'अ' उपसर्ग अर्थ को उल्टा करता है और 'ता' प्रत्यय भाववाचक संज्ञा बनाता है।

  5. 'मिठास' शब्द में प्रत्यय ______ है।

    1. स
    2. आस
    3. मीठा
    4. इठास
    Show answer

    Answer: आस

    मीठा + आस = मिठास; 'आस' प्रत्यय शब्द के अंत में जुड़ा है।

  6. 'चमकीला' शब्द में प्रत्यय ______ है।

    1. कीला
    2. ला
    3. ईला
    4. चमक
    Show answer

    Answer: ईला

    चमक + ईला = चमकीला; इसी प्रकार रंग + ईला = रंगीला बनता है।

  7. इनमें से किस शब्द में 'ता' प्रत्यय है?

    1. सुंदरता
    2. लड़कपन
    3. बुढ़ापा
    4. मिठास
    Show answer

    Answer: सुंदरता

    सुंदर + ता = सुंदरता; अन्य शब्दों में 'आस', 'पन' और 'आपा' प्रत्यय हैं।

  8. 'विदेश' शब्द में उपसर्ग ______ है।

    1. विद
    2. देश
    3. दे
    4. वि
    Show answer

    Answer: वि

    वि + देश = विदेश; 'वि' उपसर्ग 'देश' से पहले जुड़कर नया अर्थ देता है।
