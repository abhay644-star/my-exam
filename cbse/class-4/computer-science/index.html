Sample questions

A few questions from the Class 4 Computer Science bank. Every test picks a fresh mix.

  1. Hardware and Software
    The physical parts of a computer that we can see and touch are called ______.

    1. hardware
    2. programs
    3. software
    4. data
    Show answer

    Answer: hardware

    Hardware means the physical parts like the monitor, keyboard and CPU that we can touch.

  2. Input and Output Devices
    Which input device is used to type letters and numbers into a computer?

    1. monitor
    2. keyboard
    3. speaker
    4. mouse
    Show answer

    Answer: keyboard

    The keyboard has keys for letters, numbers and symbols, so it is used for typing.

  3. Memory and Storage Devices
    The smallest unit of computer memory is a ______.

    1. bit
    2. kilobyte
    3. byte
    4. nibble
    Show answer

    Answer: bit

    A bit (binary digit) is either 0 or 1 and is the smallest unit of memory.

  4. Operating System and Files
    Windows is an example of an ______ system.

    1. input
    2. application
    3. operating
    4. storage
    Show answer

    Answer: operating

    Windows is an operating system; it manages the computer and lets us run other programs.

  5. MS Word Basics
    MS Word is a ______ processing software used to type letters and stories.

    1. picture
    2. number
    3. sound
    4. word
    Show answer

    Answer: word

    MS Word is a word processor used to type, edit and format text documents.
