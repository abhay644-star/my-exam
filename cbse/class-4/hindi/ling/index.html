Practice questions with answers

A few questions from this chapter. Open each one to see the answer.

  1. हिंदी में कितने लिंग होते हैं?

    1. 1
    2. 3
    3. 4
    4. 2
    Show answer

    Answer: 2

    हिंदी में दो लिंग हैं — पुल्लिंग और स्त्रीलिंग।

  2. ‘पानी’ शब्द पुल्लिंग है या स्त्रीलिंग?

    1. स्त्रीलिंग
    2. नपुंसकलिंग
    3. उभयलिंग
    4. पुल्लिंग
    Show answer

    Answer: पुल्लिंग

    हम कहते हैं ‘पानी ठंडा है’, इसलिए पानी पुल्लिंग है।

  3. ‘सेठ’ का स्त्रीलिंग शब्द क्या है?

    1. सेठिन
    2. सेठनी
    3. सेठी
    4. सेठानी
    Show answer

    Answer: सेठानी

    सेठ — सेठानी, जैसे नौकर — नौकरानी।

  4. ‘विद्वान’ का स्त्रीलिंग शब्द क्या है?

    1. विद्वानी
    2. विद्वाननी
    3. विदुषी
    4. विद्या
    Show answer

    Answer: विदुषी

    विद्वान का स्त्रीलिंग विदुषी होता है, जैसे — गार्गी एक विदुषी थीं।

  5. ‘कवि’ का स्त्रीलिंग शब्द क्या है?

    1. कवयित्री
    2. कविता
    3. कवित्री
    4. कविनी
    Show answer

    Answer: कवयित्री

    कवि का स्त्रीलिंग कवयित्री है; ‘कविता’ रचना का नाम है।

  6. ‘ऊँट’ का स्त्रीलिंग शब्द क्या है?

    1. ऊँटनी
    2. ऊँटी
    3. ऊँटिन
    4. ऊँटिया
    Show answer

    Answer: ऊँटनी

    ऊँट का स्त्रीलिंग ऊँटनी है, जैसे मोर — मोरनी।

  7. ‘मेरा भाई अच्छा गायक है।’ — इसे स्त्रीलिंग में बदलो: मेरी बहन अच्छी ______ है।

    1. गायनी
    2. गायिका
    3. गायकी
    4. गायकिन
    Show answer

    Answer: गायिका

    गायक का स्त्रीलिंग गायिका है, जैसे लेखक — लेखिका।

  8. ‘तपस्वी’ का स्त्रीलिंग शब्द क्या है?

    1. तपस्वीनी
    2. तपस्विनी
    3. तपस्विन
    4. तपस्वियाँ
    Show answer

    Answer: तपस्विनी

    तपस्वी — तपस्विनी, जैसे मनस्वी — मनस्विनी।
