Practice questions with answers

A few questions from this chapter. Open each one to see the answer.

  1. ‘दौड़ना, खाना, लिखना’ — ये सब ______ शब्द हैं।

    1. क्रिया
    2. विशेषण
    3. संज्ञा
    4. सर्वनाम
    Show answer

    Answer: क्रिया

    ये शब्द काम करने का बोध कराते हैं, इसलिए क्रिया हैं।

  2. ‘गीता हँसती है।’ — क्रिया का मूल रूप (धातु) क्या है?

    1. हँसी
    2. गीता
    3. हँस
    4. हँसती
    Show answer

    Answer: हँस

    ‘हँसती है’ का मूल रूप ‘हँस’ (हँसना) है।

  3. सही क्रिया भरो: दादी रोज़ रामायण ______ हैं।

    1. पढ़ता
    2. पढ़ती
    3. पढ़ो
    4. पढ़ा
    Show answer

    Answer: पढ़ती

    स्त्रीलिंग कर्ता ‘दादी’ के साथ आदर में ‘पढ़ती हैं’ आता है।

  4. सही क्रिया भरो: राजू ने सभा में एक सुंदर कविता ______।

    1. सुनाई
    2. सुनाए
    3. सुनाया
    4. सुनाता
    Show answer

    Answer: सुनाई

    ‘ने’ वाले वाक्य में क्रिया कर्म के अनुसार बदलती है; ‘कविता’ स्त्रीलिंग है, इसलिए ‘सुनाई’।

  5. ‘बच्चे मैदान में फ़ुटबॉल खेल रहे हैं।’ — इस वाक्य में क्रिया शब्द कौन-सा है?

    1. मैदान
    2. खेल रहे हैं
    3. बच्चे
    4. फ़ुटबॉल
    Show answer

    Answer: खेल रहे हैं

    ‘खेल रहे हैं’ से काम होने का पता चलता है, इसलिए यह क्रिया है।

  6. सही क्रिया भरो: माली पौधों को रोज़ पानी ______ है।

    1. दिया
    2. देते
    3. देता
    4. देती
    Show answer

    Answer: देता

    पुल्लिंग एकवचन कर्ता ‘माली’ के साथ ‘देता है’ आता है।

  7. ‘पढ़ाई’ एक संज्ञा शब्द है। इससे बनने वाली क्रिया कौन-सी है?

    1. पढ़ाकू
    2. पाठशाला
    3. पाठ
    4. पढ़ना
    Show answer

    Answer: पढ़ना

    पढ़ाई (संज्ञा) से पढ़ना (क्रिया) बनती है; पढ़ाकू विशेषण है।

  8. सही क्रिया भरो: धोबी ने कपड़े धोकर धूप में ______।

    1. सूखा
    2. सुखाए
    3. सुखाया
    4. सूखे
    Show answer

    Answer: सुखाए

    ‘कपड़े’ पुल्लिंग बहुवचन है और धोबी ने उन्हें सुखाने का काम किया, इसलिए ‘सुखाए’ आएगा।
