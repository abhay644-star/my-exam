A few questions from this chapter. Open each one to see the answer.

  1. जो संज्ञा किसी विशेष व्यक्ति, स्थान या वस्तु का नाम बताए, उसे ______ संज्ञा कहते हैं।

    1. समूहवाचक
    2. जातिवाचक
    3. व्यक्तिवाचक
    4. भाववाचक
    Show answer

    Answer: व्यक्तिवाचक

    जैसे — महात्मा गांधी, दिल्ली, गंगा व्यक्तिवाचक संज्ञाएँ हैं।

  2. ‘मिठास’ कौन-सी संज्ञा है?

    1. भाववाचक
    2. व्यक्तिवाचक
    3. द्रव्यवाचक
    4. जातिवाचक
    Show answer

    Answer: भाववाचक

    मिठास एक गुण/भाव है, इसलिए भाववाचक संज्ञा है।

  3. ‘गंगा’ व्यक्तिवाचक संज्ञा है। ‘गंगा’ के लिए जातिवाचक संज्ञा कौन-सी होगी?

    1. पानी
    2. पहाड़
    3. नदी
    4. हिमालय
    Show answer

    Answer: नदी

    गंगा एक विशेष नदी है; ‘नदी’ उसकी पूरी जाति का नाम है।

  4. ‘दिल्ली भारत की राजधानी है।’ — इस वाक्य में जातिवाचक संज्ञा कौन-सी है?

    1. है
    2. राजधानी
    3. दिल्ली
    4. भारत
    Show answer

    Answer: राजधानी

    दिल्ली और भारत विशेष नाम (व्यक्तिवाचक) हैं; ‘राजधानी’ हर देश की होती है, इसलिए जातिवाचक है।

  5. ‘ताजमहल’ कौन-सी संज्ञा है?

    1. भाववाचक
    2. जातिवाचक
    3. व्यक्तिवाचक
    4. समूहवाचक
    Show answer

    Answer: व्यक्तिवाचक

    ताजमहल एक विशेष इमारत का नाम है, इसलिए व्यक्तिवाचक संज्ञा है।

  6. ‘नदी’ शब्द कौन-सी संज्ञा है?

    1. व्यक्तिवाचक
    2. भाववाचक
    3. समूहवाचक
    4. जातिवाचक
    Show answer

    Answer: जातिवाचक

    ‘नदी’ किसी एक नदी का नहीं, पूरी जाति का नाम है।

  7. ‘बच्चा’ शब्द से भाववाचक संज्ञा बनाओ।

    1. बच्ची
    2. बच्चे
    3. बचपन
    4. बचाव
    Show answer

    Answer: बचपन

    बच्चा — बचपन, जैसे बूढ़ा — बुढ़ापा।

  8. ‘हिमालय’ कौन-सी संज्ञा है?

    1. समूहवाचक
    2. जातिवाचक
    3. व्यक्तिवाचक
    4. भाववाचक
    Show answer

    Answer: व्यक्तिवाचक

    ‘हिमालय’ एक विशेष पर्वत का नाम है, इसलिए व्यक्तिवाचक संज्ञा है।
