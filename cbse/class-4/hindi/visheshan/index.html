  1. संज्ञा या सर्वनाम की विशेषता बताने वाले शब्द को ______ कहते हैं।

    1. विशेषण
    2. क्रिया
    3. विशेष्य
    4. सर्वनाम
    Show answer

    Answer: विशेषण

    जैसे — ‘लाल गुलाब’ में ‘लाल’ विशेषण है।

  2. ‘चार किलो चीनी’ में ‘चार किलो’ किसकी विशेषता बताता है?

    1. किलो
    2. चीनी
    3. मात्रा
    4. चार
    Show answer

    Answer: चीनी

    ‘चार किलो’ चीनी की मात्रा बताता है; चीनी विशेष्य है।

  3. ‘ईमान’ शब्द से विशेषण बनाओ।

    1. ईमानदारी
    2. ईमानदार
    3. ईमानता
    4. बेईमानी
    Show answer

    Answer: ईमानदार

    ईमान + दार = ईमानदार (विशेषण); ईमानदारी भाववाचक संज्ञा है।

  4. ‘इस थैले में थोड़ा दूध और दो दर्जन केले हैं।’ — इसमें मात्रा (परिमाण) बताने वाला विशेषण कौन-सा है?

    1. इस
    2. दूध
    3. थोड़ा
    4. दो दर्जन
    Show answer

    Answer: थोड़ा

    ‘थोड़ा’ दूध की मात्रा बताता है; ‘दो दर्जन’ केलों की संख्या बताता है।

  5. ‘मोटा बंदर पेड़ पर उछल रहा है।’ — इस वाक्य में विशेषण कौन-सा है?

    1. पेड़
    2. उछल
    3. बंदर
    4. मोटा
    Show answer

    Answer: मोटा

    ‘मोटा’ बंदर की विशेषता बताता है, इसलिए विशेषण है।

  6. ‘भूख’ शब्द से विशेषण बनाओ।

    1. भूखापन
    2. भूखना
    3. भोग
    4. भूखा
    Show answer

    Answer: भूखा

    भूख (संज्ञा) से भूखा (विशेषण) बनता है, जैसे — भूखा बच्चा।

  7. ‘धन’ शब्द से विशेषण बनाओ।

    1. धन्य
    2. धनी
    3. निर्धनता
    4. धनराशि
    Show answer

    Answer: धनी

    धन (संज्ञा) से धनी या धनवान (विशेषण) बनता है, जैसे — धनी व्यापारी।

  8. ‘इस टोकरी में दस ताज़े आम हैं।’ — इसमें गुण बताने वाला (गुणवाचक) विशेषण कौन-सा है?

    1. टोकरी
    2. इस
    3. ताज़े
    4. दस
    Show answer

    Answer: ताज़े

    ‘ताज़े’ आमों का गुण बताता है; ‘दस’ संख्यावाचक और ‘इस’ सार्वनामिक विशेषण है।
