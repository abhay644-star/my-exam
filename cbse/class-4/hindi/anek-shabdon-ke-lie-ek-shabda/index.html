A few questions from this chapter. Open each one to see the answer.

  1. जो सदा सच बोले — उसके लिए एक शब्द लिखो।

    1. सत्यवादी
    2. झूठा
    3. ईमानदार
    4. सच्चाई
    Show answer

    Answer: सत्यवादी

    सदा सच बोलने वाले को सत्यवादी कहते हैं।

  2. जिसके माता-पिता न हों — उसके लिए एक शब्द लिखो।

    1. अकेला
    2. अनाथ
    3. अपाहिज
    4. असहाय
    Show answer

    Answer: अनाथ

    जिसके माता-पिता न हों, उसे अनाथ कहते हैं।

  3. जो बहुत कम बोलता हो — उसके लिए एक शब्द लिखो।

    1. मूक
    2. मितभाषी
    3. वाचाल
    4. मधुरभाषी
    Show answer

    Answer: मितभाषी

    कम बोलने वाला मितभाषी; बहुत बोलने वाला वाचाल कहलाता है।

  4. एक वीर राजा कभी कोई युद्ध नहीं हारा। कोई भी उसे जीत नहीं सका। ऐसे राजा को ______ कहेंगे।

    1. अजेय
    2. विजेता
    3. अमर
    4. निडर
    Show answer

    Answer: अजेय

    जिसे कोई जीत न सके, उसे अजेय कहते हैं; ‘अमर’ का अर्थ है जो कभी न मरे।

  5. जो दूसरों की भलाई करे — उसके लिए एक शब्द लिखो।

    1. कंजूस
    2. आलसी
    3. स्वार्थी
    4. परोपकारी
    Show answer

    Answer: परोपकारी

    दूसरों का उपकार (भलाई) करने वाला परोपकारी कहलाता है।

  6. जो सप्ताह में एक बार हो — उसके लिए एक शब्द लिखो।

    1. वार्षिक
    2. मासिक
    3. दैनिक
    4. साप्ताहिक
    Show answer

    Answer: साप्ताहिक

    सप्ताह में एक बार होने वाला साप्ताहिक; रोज़ होने वाला दैनिक।

  7. जो आँखों के सामने हो — उसके लिए एक शब्द लिखो।

    1. परोक्ष
    2. अदृश्य
    3. प्रत्यक्ष
    4. दूरदर्शी
    Show answer

    Answer: प्रत्यक्ष

    आँखों के सामने होने वाला प्रत्यक्ष कहलाता है; जो सामने न हो, वह परोक्ष होता है।

  8. जो मांस न खाए, केवल फल, सब्ज़ी और अनाज खाए — उसके लिए एक शब्द लिखो।

    1. फलाहारी
    2. सर्वाहारी
    3. शाकाहारी
    4. मांसाहारी
    Show answer

    Answer: शाकाहारी

    जो मांस न खाकर केवल पेड़-पौधों से मिला भोजन खाए, उसे शाकाहारी कहते हैं; मांस खाने वाला मांसाहारी कहलाता है।
