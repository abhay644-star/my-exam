A few questions from this chapter. Open each one to see the answer.

  1. Find k if x = 1, y = 2 is a solution of 5x + ky = 11.

    Show answer and solution

    Answer: 3

    5(1) + k(2) = 11, so 2k = 6 and k = 3.

  2. Find k if x = 1, y = 2 is a solution of 2x + ky = 10.

    Show answer and solution

    Answer: 4

    2(1) + k(2) = 10, so 2k = 8 and k = 4.

  3. Find k if x = 5, y = 2 is a solution of 3x + ky = 7.

    Show answer and solution

    Answer: −4

    3(5) + k(2) = 7, so 2k = −8 and k = −4.

  4. Find k if x = −2, y = 2 is a solution of 2x + ky = −12.

    Show answer and solution

    Answer: −4

    2(−2) + k(2) = −12, so 2k = −8 and k = −4.

  5. Find k if x = −2, y = 2 is a solution of 2x + ky = −14.

    Show answer and solution

    Answer: −5

    2(−2) + k(2) = −14, so 2k = −10 and k = −5.

  6. Find k if x = −3, y = 4 is a solution of 6x + ky = −6.

    Show answer and solution

    Answer: 3

    6(−3) + k(4) = −6, so 4k = 12 and k = 3.
