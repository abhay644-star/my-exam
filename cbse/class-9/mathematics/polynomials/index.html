A few questions from this chapter. Open each one to see the answer.

  1. If p(x) = 2x² − 4x + 7, find p(−1).

    Show answer and solution

    Answer: 13

    Substitute x = −1: p(−1) = 13.

  2. Find the remainder when x³ − 4x² − 2x − 2 is divided by (x + 1).

    Show answer and solution

    Answer: −5

    By the remainder theorem, the remainder is p(−1) = −5.

  3. (x − 1) is a factor of p(x) = x³ + kx² − 5x + 7.

    Show answer and solution
    • (a) Find k. −3
    • (b) Find p(1). 0
    • (c) Find p(−1). 8

    (a) By the factor theorem p(1) = 0, which gives 1k = −3 and k = −3. (b) p(1) = 1 + (−3) + (−5) + 7 = 0. (c) p(−1) = 8.

  4. If p(x) = 3x² − 5x + 9, find p(1).

    Show answer and solution

    Answer: 7

    Substitute x = 1: p(1) = 7.

  5. Find the remainder when x³ + 2x² + 3x − 8 is divided by (x − 2).

    Show answer and solution

    Answer: 14

    By the remainder theorem, the remainder is p(2) = 14.

  6. (x − 1) is a factor of p(x) = x³ + kx² − 5x − 3.

    Show answer and solution
    • (a) Find k. 7
    • (b) Find p(1). 0
    • (c) Find p(−1). 8

    (a) By the factor theorem p(1) = 0, which gives 1k = 7 and k = 7. (b) p(1) = 1 + 7 + (−5) + (−3) = 0. (c) p(−1) = 8.
