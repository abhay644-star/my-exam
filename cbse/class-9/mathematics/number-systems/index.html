A few questions from this chapter. Open each one to see the answer.

  1. Find the value of 322/5.

    Show answer and solution

    Answer: 4

    321/5 = 2, and 22 = 4.

  2. Rationalise the denominator of 1/(√6 − √2).

    Show answer and solution

    Answer: (√6 + √2)/4

    Multiply the numerator and denominator by (√6 + √2): the denominator becomes 6 − 2 = 4, giving (√6 + √2)/4.

  3. Find the value of 813/4.

    Show answer and solution

    Answer: 27

    811/4 = 3, and 33 = 27.

  4. Rationalise the denominator of 1/(√11 − √7).

    Show answer and solution

    Answer: (√11 + √7)/4

    Multiply the numerator and denominator by (√11 + √7): the denominator becomes 11 − 7 = 4, giving (√11 + √7)/4.

  5. Find the value of 163/4.

    Show answer and solution

    Answer: 8

    161/4 = 2, and 23 = 8.

  6. Find the value of 272/3.

    Show answer and solution

    Answer: 9

    271/3 = 3, and 32 = 9.
