A few questions from this chapter. Open each one to see the answer.

  1. Which subatomic particle did J.J. Thomson discover?

    1. electron
    2. proton
    3. neutron
    4. nucleus
    Show answer

    Answer: electron

    J.J. Thomson discovered the negatively charged electron.

  2. The atomic number of an element is equal to the number of ______ in the nucleus of its atom.

    1. nucleons
    2. electron shells
    3. neutrons
    4. protons
    Show answer

    Answer: protons

    Atomic number (Z) is the number of protons in the nucleus.

  3. The largest number of electrons in a shell is 2n2. How many electrons can the M shell (n = 3) hold?

    1. 18
    2. 8
    3. 9
    4. 32
    Show answer

    Answer: 18

    2 × 32 = 18.

  4. The neutron was discovered by ______.

    1. Bohr
    2. Goldstein
    3. Chadwick
    4. Rutherford
    Show answer

    Answer: Chadwick

    James Chadwick discovered the neutron in 1932.

  5. Atoms of the same element having the same atomic number but different mass numbers are called ______.

    1. isomers
    2. isotopes
    3. isobars
    4. isotones
    Show answer

    Answer: isotopes

    Protium, deuterium and tritium are isotopes of hydrogen.

  6. What is the electronic configuration of chlorine (atomic number 17)?

    1. 2, 8, 7
    2. 2, 8, 6, 1
    3. 8, 2, 7
    4. 2, 7, 8
    Show answer

    Answer: 2, 8, 7

    The K shell takes 2, the L shell 8 and the remaining 7 go into the M shell.

  7. Which scientist performed the alpha-particle scattering experiment with a thin gold foil?

    1. Thomson
    2. Rutherford
    3. Chadwick
    4. Bohr
    Show answer

    Answer: Rutherford

    The experiment showed that an atom has a small, dense, positively charged nucleus.

  8. What is the largest number of electrons the first shell (K shell) can hold?

    1. 8
    2. 18
    3. 1
    4. 2
    Show answer

    Answer: 2

    Using 2n2 with n = 1 gives 2.
