Sample questions

A few questions from the Class 9 Computer Science bank. Every test picks a fresh mix.

  1. Computer System
    Which unit of the CPU controls and coordinates all the operations of the computer?

    1. memory unit
    2. ALU
    3. register
    4. control unit
    Show answer

    Answer: control unit

    The control unit directs the flow of data and instructions.

  2. Memory And Storage
    Which non-volatile memory stores the start-up instructions and can usually only be read?

    1. ROM
    2. RAM
    3. cache
    4. register
    Show answer

    Answer: ROM

    ROM keeps its contents without power and stores boot instructions.

  3. Number Systems
    What is the base of the hexadecimal number system?

    1. 2
    2. 16
    3. 8
    4. 10
    Show answer

    Answer: 16

    Hexadecimal uses 16 symbols: 0-9 and A-F.

  4. Networking
    What is the unique numerical address given to each device on a network called?

    1. IP address
    2. URL
    3. email address
    4. domain name
    Show answer

    Answer: IP address

    An IP address such as 192.168.1.5 identifies a device on a network.

  5. Internet
    What is the full form of URL?

    1. Universal Resource Link
    2. Uniform Resource Link
    3. Uniform Resource Locator
    4. Universal Routing Locator
    Show answer

    Answer: Uniform Resource Locator

    URL stands for Uniform Resource Locator.
