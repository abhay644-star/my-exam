A few questions from this chapter. Open each one to see the answer.

  1. 'अभिमान' शब्द में उपसर्ग ______ है।

    1. मान
    2. आन
    3. अभिम
    4. अभि
    Show answer

    Answer: अभि

    अभि + मान = अभिमान; 'अभि' उपसर्ग है।

  2. 'प्रत्येक' शब्द में उपसर्ग ______ है।

    1. प्र
    2. प्रति
    3. प्रत
    4. एक
    Show answer

    Answer: प्रति

    प्रति + एक = प्रत्येक; 'प्रति' उपसर्ग है (यहाँ यण संधि भी हुई है)।

  3. इनमें से किस शब्द में उपसर्ग और प्रत्यय दोनों हैं?

    1. अपमानित
    2. सुंदर
    3. पढ़ाई
    4. विद्यालय
    Show answer

    Answer: अपमानित

    अप (उपसर्ग) + मान (मूल शब्द) + इत (प्रत्यय) = अपमानित।

  4. 'इतिहास' शब्द में 'इक' प्रत्यय जोड़ने पर कौन-सा शब्द बनेगा?

    1. इतिहासिक
    2. ऐतिहासिक
    3. इतिहासीक
    4. ऐतहासिक
    Show answer

    Answer: ऐतिहासिक

    'इक' प्रत्यय लगने पर पहले स्वर 'इ' की वृद्धि 'ऐ' हो जाती है: इतिहास + इक = ऐतिहासिक।

  5. 'बुढ़ापा' शब्द में प्रत्यय ______ है।

    1. बूढ़ा
    2. आ
    3. आपा
    4. पा
    Show answer

    Answer: आपा

    बूढ़ा + आपा = बुढ़ापा; 'आपा' भाववाचक प्रत्यय है।

  6. 'सामाजिक' शब्द का मूल शब्द ______ है।

    1. सामाज
    2. समाज
    3. समा
    4. सामा
    Show answer

    Answer: समाज

    समाज + इक = सामाजिक; 'इक' प्रत्यय लगने पर पहले स्वर में वृद्धि हो जाती है।

  7. 'अत्यधिक' शब्द में उपसर्ग ______ है।

    1. अति
    2. अधि
    3. अधिक
    4. अत
    Show answer

    Answer: अति

    अति + अधिक = अत्यधिक; 'अति' उपसर्ग है और यहाँ यण संधि हुई है।

  8. 'सुपुत्र' शब्द में उपसर्ग ______ है।

    1. सुप
    2. त्र
    3. सु
    4. पुत्र
    Show answer

    Answer: सु

    सु + पुत्र = सुपुत्र; 'सु' उपसर्ग का अर्थ है अच्छा।
