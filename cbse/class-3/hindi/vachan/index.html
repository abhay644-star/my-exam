A few questions from this chapter. Open each one to see the answer.

  1. ‘नदी’ का बहुवचन क्या है?

    1. नदीयाँ
    2. नदिये
    3. नदियाँ
    4. नदियों
    Show answer

    Answer: नदियाँ

    ई से खत्म होने वाले स्त्रीलिंग शब्दों में ‘इयाँ’ लगता है: नदी — नदियाँ।

  2. ‘तितली’ का बहुवचन क्या है?

    1. तितले
    2. तितलीयाँ
    3. तितलियों
    4. तितलियाँ
    Show answer

    Answer: तितलियाँ

    तितली — तितलियाँ।

  3. ‘बच्चा खेल रहा है।’ का बहुवचन: बच्चे खेल ______ हैं।

    1. रहा
    2. रहे
    3. रहीं
    4. रही
    Show answer

    Answer: रहे

    बहुवचन ‘बच्चे’ के साथ ‘रहे हैं’ आता है।

  4. वाक्य को बहुवचन में बदलो: ‘पेड़ पर एक पत्ता है।’ → ‘पेड़ पर कई ______ हैं।’

    1. पत्तों
    2. पत्ते
    3. पत्ता
    4. पत्ताएँ
    Show answer

    Answer: पत्ते

    ‘कई’ बहुवचन बताता है, इसलिए पत्ता — पत्ते और ‘है’ — ‘हैं’ होगा।

  5. ‘पुस्तक’ का बहुवचन क्या है?

    1. पुस्तकाएँ
    2. पुस्तकें
    3. पुस्तकियाँ
    4. पुस्तकों
    Show answer

    Answer: पुस्तकें

    पुस्तक — पुस्तकें, जैसे किताब — किताबें।

  6. ‘कपड़ा’ का बहुवचन क्या है?

    1. कपड़ियाँ
    2. कपड़ों
    3. कपड़ाएँ
    4. कपड़े
    Show answer

    Answer: कपड़े

    आ से खत्म होने वाले पुल्लिंग शब्दों में आ की जगह ए लगता है: कपड़ा — कपड़े।

  7. ‘मेरा भाई क्रिकेट खेलता है।’ का बहुवचन: मेरे भाई क्रिकेट ______ हैं।

    1. खेलती
    2. खेलते
    3. खेलता
    4. खेलना
    Show answer

    Answer: खेलते

    बहुवचन पुल्लिंग कर्ता के साथ ‘खेलते हैं’ आता है।

  8. ‘खिड़की’ का बहुवचन क्या है?

    1. खिड़कियों
    2. खिड़के
    3. खिड़कीयाँ
    4. खिड़कियाँ
    Show answer

    Answer: खिड़कियाँ

    ई से खत्म होने वाले स्त्रीलिंग शब्दों में ‘इयाँ’ लगता है: खिड़की — खिड़कियाँ।
