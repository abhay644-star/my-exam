Sample questions

A few questions from the Class 3 Hindi bank. Every test picks a fresh mix.

  1. संज्ञा
    किसी व्यक्ति, वस्तु, स्थान या भाव के नाम को ______ कहते हैं।

    1. संज्ञा
    2. सर्वनाम
    3. क्रिया
    4. विशेषण
    Show answer

    Answer: संज्ञा

    नाम बताने वाले शब्द संज्ञा कहलाते हैं, जैसे — राम, किताब, दिल्ली।

  2. सर्वनाम
    संज्ञा के स्थान पर आने वाले शब्द ______ कहलाते हैं।

    1. क्रिया
    2. संज्ञा
    3. विशेषण
    4. सर्वनाम
    Show answer

    Answer: सर्वनाम

    मैं, तुम, वह, हम जैसे शब्द संज्ञा की जगह आते हैं, इसलिए सर्वनाम हैं।

  3. विशेषण
    ‘काली गाय’ में विशेषण कौन-सा शब्द है?

    1. काली
    2. काली गाय
    3. काला
    4. गाय
    Show answer

    Answer: काली

    ‘काली’ शब्द गाय का रंग (विशेषता) बताता है।

  4. क्रिया
    ‘बच्चा सोता है।’ इस वाक्य में क्रिया कौन-सी है?

    1. है
    2. बच्चा
    3. सोता है
    4. बच्चे
    Show answer

    Answer: सोता है

    ‘सोता है’ से काम होने का पता चलता है, इसलिए यह क्रिया है।

  5. लिंग
    ‘लड़का’ का स्त्रीलिंग शब्द क्या है?

    1. लड़की
    2. लड़कों
    3. लड़के
    4. लड़कियाँ
    Show answer

    Answer: लड़की

    लड़का (पुल्लिंग) — लड़की (स्त्रीलिंग)।
