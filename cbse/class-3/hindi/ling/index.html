A few questions from this chapter. Open each one to see the answer.

  1. ‘लड़का’ का स्त्रीलिंग शब्द क्या है?

    1. लड़की
    2. लड़कों
    3. लड़के
    4. लड़कियाँ
    Show answer

    Answer: लड़की

    लड़का (पुल्लिंग) — लड़की (स्त्रीलिंग)।

  2. ‘धोबी’ का स्त्रीलिंग शब्द क्या है?

    1. धोबना
    2. धोबियाँ
    3. धोबीनी
    4. धोबिन
    Show answer

    Answer: धोबिन

    धोबी — धोबिन, जैसे माली — मालिन।

  3. ‘मोर नाचता है।’ को स्त्रीलिंग में बदलो: मोरनी ______ है।

    1. नाचती
    2. नाचता
    3. नाचना
    4. नाचते
    Show answer

    Answer: नाचती

    स्त्रीलिंग कर्ता के साथ क्रिया भी स्त्रीलिंग होती है — नाचती है।

  4. ‘घोड़ा’ का स्त्रीलिंग शब्द क्या है?

    1. घुड़िया
    2. घोड़ी
    3. घोड़ियाँ
    4. घोड़े
    Show answer

    Answer: घोड़ी

    घोड़ा — घोड़ी।

  5. ‘चूहा’ का स्त्रीलिंग शब्द क्या है?

    1. चूहे
    2. चुहिया
    3. चूहों
    4. चुहियाँ
    Show answer

    Answer: चुहिया

    चूहा — चुहिया, जैसे बंदर — बंदरिया।
