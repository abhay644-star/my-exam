A few questions from this chapter. Open each one to see the answer.

  1. संज्ञा के स्थान पर आने वाले शब्द ______ कहलाते हैं।

    1. क्रिया
    2. संज्ञा
    3. विशेषण
    4. सर्वनाम
    Show answer

    Answer: सर्वनाम

    मैं, तुम, वह, हम जैसे शब्द संज्ञा की जगह आते हैं, इसलिए सर्वनाम हैं।

  2. सही सर्वनाम भरो: मोहन बाज़ार गया। ______ फल लाया।

    1. वह
    2. हम
    3. तुम
    4. वे
    Show answer

    Answer: वह

    एक व्यक्ति (मोहन) के लिए ‘वह’ सर्वनाम आएगा।

  3. सही सर्वनाम भरो: राम और श्याम दोस्त हैं। ______ साथ खेलते हैं।

    1. मैं
    2. तुम
    3. वे
    4. वह
    Show answer

    Answer: वे

    दो लोगों के लिए बहुवचन सर्वनाम ‘वे’ आता है।

  4. रिया ने सहेली का पेन लौटाते हुए कहा, ‘यह पेन मेरा नहीं है, यह ______ है।’

    1. उसका
    2. तुम्हारा
    3. मेरा
    4. हमारा
    Show answer

    Answer: तुम्हारा

    पेन सामने खड़ी सहेली का है, इसलिए रिया उसके लिए ‘तुम्हारा’ कहेगी।

  5. मैं, पेड़, मीठा, भागना — इनमें से सर्वनाम कौन-सा है?

    1. भागना
    2. पेड़
    3. मैं
    4. मीठा
    Show answer

    Answer: मैं

    ‘मैं’ बोलने वाले के नाम की जगह आता है; पेड़ संज्ञा, मीठा विशेषण और भागना क्रिया है।
