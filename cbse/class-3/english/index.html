Sample questions

A few questions from the Class 3 English bank. Every test picks a fresh mix.

  1. Poem: Paper Boats
    Who wrote the poem 'Paper Boats'?

    1. R K Narayan
    2. Sarojini Naidu
    3. Rabindranath Tagore
    4. Ruskin Bond
    Show answer

    Answer: Rabindranath Tagore

    'Paper Boats' is a poem by Rabindranath Tagore.

  2. Nouns
    Find the noun: The peacock dances.

    1. dances
    2. dance
    3. danced
    4. peacock
    Show answer

    Answer: peacock

    Peacock is the name of a bird, so it is a noun.

  3. Pronouns
    Meera is reading. ______ is reading a story.

    1. she
    2. they
    3. he
    4. it
    Show answer

    Answer: she

    She is the pronoun used in place of a girl's name.

  4. Verbs
    Find the verb: Birds build nests.

    1. birds
    2. bird
    3. nests
    4. build
    Show answer

    Answer: build

    Build is the action word, so it is the verb.

  5. Adjectives
    Find the adjective: Riya has a sweet voice.

    1. has
    2. sweet
    3. Riya
    4. voice
    Show answer

    Answer: sweet

    Sweet describes the voice, so it is an adjective.
