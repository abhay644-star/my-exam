Sample questions

A few questions from the Class 3 Computer Science bank. Every test picks a fresh mix.

  1. Features of a Computer
    A computer works very fast. This feature is called ______.

    1. storage
    2. accuracy
    3. diligence
    4. speed
    Show answer

    Answer: speed

    Speed means a computer can do a lot of work in a very short time.

  2. Parts of a Computer
    CPU stands for Central ______ Unit.

    1. Printing
    2. Processing
    3. Program
    4. Power
    Show answer

    Answer: Processing

    CPU means Central Processing Unit, the brain of the computer.

  3. Input and Output Devices
    Devices used to give data or instructions to a computer are called ______ devices.

    1. input
    2. output
    3. storage
    4. smart
    Show answer

    Answer: input

    Input devices, like the keyboard and mouse, send data into the computer.

  4. Uses of Computers
    We can send messages in a few seconds using ______.

    1. post card
    2. email
    3. letter box
    4. pigeon
    Show answer

    Answer: email

    Email (electronic mail) sends messages through the internet in seconds.

  5. Keyboard Keys
    The ______ key moves the cursor forward by a few spaces at once.

    1. Alt
    2. Ctrl
    3. Shift
    4. Tab
    Show answer

    Answer: Tab

    Pressing Tab moves the cursor a fixed number of spaces ahead.
