Sample questions

A few questions from the Class 12 Computer Science bank. Every test picks a fresh mix.

  1. Functions
    Which keyword is used to define a function in Python?

    1. def
    2. define
    3. func
    4. function
    Show answer

    Answer: def

    A function is defined with def, e.g. def area(r):.

  2. Exception Handling
    Which block contains the statements that may raise an exception?

    1. try
    2. except
    3. finally
    4. else
    Show answer

    Answer: try

    Code that might cause an error is put in the try block; the except block handles the error.

  3. File Handling
    Which Python module provides dump() and load() to write and read objects in binary files, as used in CBSE programs?

    1. math
    2. pickle
    3. random
    4. csv
    Show answer

    Answer: pickle

    pickle.dump() serialises (pickles) an object into a binary file and pickle.load() reads it back.

  4. Data Structure: Stack
    A stack works on the ______ principle.

    1. FIFO
    2. LIFO
    3. random access
    4. priority
    Show answer

    Answer: LIFO

    In a stack the last element pushed is the first one popped: Last In First Out.

  5. Computer Networks
    What is the full form of LAN?

    1. Long Access Network
    2. Large Area Network
    3. Local Area Network
    4. Line Area Network
    Show answer

    Answer: Local Area Network

    A LAN connects devices within a small area such as a room, building or campus.
