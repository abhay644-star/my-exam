  1. The discontinuously synthesised fragments (Okazaki fragments) are joined by the enzyme DNA ______.

    1. polymerase
    2. gyrase
    3. helicase
    4. ligase
    Show answer

    Answer: ligase

    DNA ligase joins Okazaki fragments on the lagging strand during replication.

  2. A double-stranded DNA sample contains 20% cytosine. What percentage of adenine does it contain?

    1. 60 %
    2. 40 %
    3. 30 %
    4. 20 %
    Show answer

    Answer: 30 %

    By Chargaff's rule C = G = 20%, so A + T = 60% and A = 30%.

  3. The distance between two consecutive base pairs in B-DNA is 0.34 nm. What is the length of a DNA segment of 1000 base pairs (in nm)?

    1. 340 nm
    2. 34 nm
    3. 680 nm
    4. 3400 nm
    Show answer

    Answer: 340 nm

    Length = number of base pairs × 0.34 nm = 1000 × 0.34 = 340 nm.

  4. In RNA, the base thymine is replaced by ______.

    1. adenine
    2. guanine
    3. cytosine
    4. uracil
    Show answer

    Answer: uracil

    RNA contains uracil (5-demethylated thymine) in place of thymine.

  5. Meselson and Stahl proved semi-conservative replication by growing E. coli in a medium containing the heavy isotope of nitrogen, ______.

    1. 15N
    2. 35S
    3. 14N
    4. 32P
    Show answer

    Answer: 15N

    DNA labelled with 15N is denser than 14N DNA, so hybrid DNA could be separated by CsCl density gradient centrifugation.

  6. Which RNA acts as an adapter molecule that reads the code on one side and binds a specific amino acid on the other?

    1. mRNA
    2. rRNA
    3. tRNA
    4. hnRNA
    Show answer

    Answer: tRNA

    tRNA has an anticodon loop that pairs with the codon and an amino acid acceptor end.

  7. The process of copying genetic information from one strand of DNA into RNA is called ______.

    1. transformation
    2. transcription
    3. replication
    4. translation
    Show answer

    Answer: transcription

    Transcription produces RNA; translation then uses mRNA to make a polypeptide.

  8. Frederick Griffith's transformation experiments (1928) were done with the bacterium Streptococcus ______.

    1. typhi
    2. pneumoniae
    3. pyogenes
    4. lactis
    Show answer

    Answer: pneumoniae

    Heat-killed S strain bacteria transformed live R strain bacteria into the virulent S form in mice.
