  1. If y = (x + 3)4, find dy/dx at x = 0.

    Show answer and solution

    Answer: 108

    dy/dx = 4(x + 3)3 × 1; at x = 0: 4 × 33 × 1 = 108

  2. If y = (2x + 5)4, find dy/dx at x = 0.

    Show answer and solution

    Answer: 1000

    dy/dx = 4(2x + 5)3 × 2; at x = 0: 4 × 53 × 2 = 1000

  3. If y = (4x + 3)2, find dy/dx at x = −2.

    Show answer and solution

    Answer: −40

    dy/dx = 2(4x + 3)1 × 4; at x = −2: 2 × (−5)1 × 4 = −40

  4. If y = (4x − 4)4, find dy/dx at x = 1.

    Show answer and solution

    Answer: 0

    dy/dx = 4(4x − 4)3 × 4; at x = 1: 4 × 03 × 4 = 0

  5. If y = (3x + 3)2, find dy/dx at x = −2.

    Show answer and solution

    Answer: −18

    dy/dx = 2(3x + 3)1 × 3; at x = −2: 2 × (−3)1 × 3 = −18

  6. If y = (4x − 2)2, find dy/dx at x = 1.

    Show answer and solution

    Answer: 16

    dy/dx = 2(4x − 2)1 × 4; at x = 1: 2 × 21 × 4 = 16
