A few questions from this chapter. Open each one to see the answer.

  1. Find a · b for a = 2î + 0ĵ − 4k̂ and b = 1î + 1ĵ + 0k̂.

    Show answer and solution

    Answer: 2

    a · b = 2 + 0 + 0 = 2

  2. Find the magnitude of the vector −1î − 4ĵ − 8k̂.

    Show answer and solution

    Answer: 9

    √(1 + 16 + 64) = √81 = 9

  3. Find a · b for a = 4î − 4ĵ + 1k̂ and b = 1î + 2ĵ − 2k̂.

    Show answer and solution

    Answer: −6

    a · b = 4 + (−8) + (−2) = −6

  4. Find the magnitude of the vector −1î + 4ĵ + 8k̂.

    Show answer and solution

    Answer: 9

    √(1 + 16 + 64) = √81 = 9

  5. Find a · b for a = 5î + 1ĵ − 2k̂ and b = 5î − 3ĵ − 2k̂.

    Show answer and solution

    Answer: 26

    a · b = 25 + (−3) + 4 = 26

  6. Find the magnitude of the vector 6î − 2ĵ + 3k̂.

    Show answer and solution

    Answer: 7

    √(36 + 4 + 9) = √49 = 7
