A few questions from this chapter. Open each one to see the answer.

  1. What is the order of the differential equation d²y/dx² + (dy/dx)³ + y = 0?

    Show answer and solution

    Answer: 2

    The highest order derivative present is d²y/dx², so the order is 2.

  2. What is the degree of the differential equation (d²y/dx²)³ + (dy/dx)⁴ + y = 0?

    Show answer and solution

    Answer: 3

    The equation is a polynomial in derivatives; the highest order derivative d²y/dx² occurs with power 3, so the degree is 3.

  3. How many arbitrary constants are there in the general solution of a differential equation of order 3?

    Show answer and solution

    Answer: 3

    The general solution of an nth order differential equation contains n arbitrary constants, so here 3.

  4. Find the sum of the order and the degree of the differential equation (d³y/dx³)² + (d²y/dx²)³ + dy/dx + y = 0.

    Show answer and solution

    Answer: 5

    Highest order derivative is d³y/dx³ (order 3), and its power is 2 (degree 2); 3 + 2 = 5.

  5. Solve dy/dx = 2x with y(0) = 1. What is the value of y when x = 3?

    Show answer and solution

    Answer: 10

    y = x² + C; y(0) = 1 gives C = 1, so y = x² + 1 and y(3) = 10.

  6. Solve dy/dx = y with y(0) = 2. What is the value of y when x = ln 3?

    Show answer and solution

    Answer: 6

    dy/y = dx gives y = Ce^x; y(0) = 2 gives C = 2, so y = 2e^(ln 3) = 6.
