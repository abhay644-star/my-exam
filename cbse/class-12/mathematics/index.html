Sample questions

A few questions from the Class 12 Mathematics bank. Every test picks a fresh mix.

  1. Relations and Functions
    A relation R in a set A is called a ______ relation if R = A × A.

    1. inverse
    2. identity
    3. universal
    4. empty
    Show answer

    Answer: universal

    If every element of A is related to every element of A, i.e. R = A × A, the relation is called the universal relation.

  2. Inverse Trigonometric Functions
    Find the principal value of sin⁻¹(1/2), in degrees.

    1. 45 °
    2. 60 °
    3. 30 °
    4. 90 °
    Show answer

    Answer: 30 °

    sin 30° = 1/2, and 30° is in the principal range [−90°, 90°].

  3. Matrices
    How many elements does a matrix with 2 rows and 3 columns have?

    1. 5
    2. 2
    3. 6
    4. 3
    Show answer

    Answer: 6

    A 2 × 3 matrix has 2 × 3 = 6 elements.

  4. Determinants
    Find the determinant of [[2, 3], [1, 4]].

    1. 5
    2. -5
    3. 11
    4. 8
    Show answer

    Answer: 5

    2 × 4 − 3 × 1 = 5.

  5. Continuity and Differentiability
    Find dy/dx for y = sin x at x = 0.

    1. -1
    2. 1
    3. 0.5
    4. 0
    Show answer

    Answer: 1

    dy/dx = cos x = 1 at x = 0.
