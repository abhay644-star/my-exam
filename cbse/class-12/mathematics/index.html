Sample questions

A few questions from the Class 12 Mathematics bank. Every test picks a fresh mix.

  1. Relations and Functions
    A relation R in a set A is called a ______ relation if R = A × A.

    1. inverse
    2. identity
    3. universal
    4. empty
    Show answer

    Answer: universal

    If every element of A is related to every element of A, i.e. R = A × A, the relation is called the universal relation.

  2. Differential Equations
    What is the order of the differential equation d²y/dx² + (dy/dx)³ + y = 0?

    1. 3
    2. 2
    3. 6
    4. 1
    Show answer

    Answer: 2

    The highest order derivative present is d²y/dx², so the order is 2.

  3. Relations and Functions
    A function f : X → Y is said to be ______ if every element of Y is the image of some element of X under f.

    1. into
    2. constant
    3. onto
    4. one-one
    Show answer

    Answer: onto

    f is onto (surjective) if for every y ∈ Y there exists x ∈ X with f(x) = y, i.e. range = codomain.

  4. Differential Equations
    What is the degree of the differential equation (d²y/dx²)³ + (dy/dx)⁴ + y = 0?

    1. 3
    2. 2
    3. 4
    4. 7
    Show answer

    Answer: 3

    The equation is a polynomial in derivatives; the highest order derivative d²y/dx² occurs with power 3, so the degree is 3.

  5. Relations and Functions
    How many ordered pairs are there in the identity relation on a set having 4 elements?

    1. 4
    2. 16
    3. 0
    4. 8
    Show answer

    Answer: 4

    The identity relation contains only the pairs (a, a), one for each element, so it has 4 pairs.
