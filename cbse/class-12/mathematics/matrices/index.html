A few questions from this chapter. Open each one to see the answer.

  1. A is a 2 × 4 matrix and B is a 4 × 3 matrix. How many elements does AB have?

    Show answer and solution

    Answer: 6

    AB has order 2 × 3, so it has 6 elements.

  2. A = 320−1 and B = −1141. Let C = AB.

    Show answer and solution
    • (a) Find the element c₁₁. 5
    • (b) Find the element c₁₂. 5
    • (c) Find the element c₂₂. −1

    Multiply rows of A by columns of B: C = 55−4−1.

  3. A is a 4 × 4 matrix and B is a 4 × 3 matrix. How many elements does AB have?

    Show answer and solution

    Answer: 12

    AB has order 4 × 3, so it has 12 elements.

  4. A = 2−2−3−2 and B = 1−101. Let C = AB.

    Show answer and solution
    • (a) Find the element c₁₁. 2
    • (b) Find the element c₁₂. −4
    • (c) Find the element c₂₂. 1

    Multiply rows of A by columns of B: C = 2−4−31.

  5. A is a 4 × 4 matrix and B is a 4 × 4 matrix. How many elements does AB have?

    Show answer and solution

    Answer: 16

    AB has order 4 × 4, so it has 16 elements.

  6. A = 013−3 and B = −3−30−3. Let C = AB.

    Show answer and solution
    • (a) Find the element c₁₁. 0
    • (b) Find the element c₁₂. −3
    • (c) Find the element c₂₂. 0

    Multiply rows of A by columns of B: C = 0−3−90.
