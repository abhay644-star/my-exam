A few questions from this chapter. Open each one to see the answer.

  1. Evaluate ∫13 (4x − 2) dx.

    Show answer and solution

    Answer: 12

    [2x² − 2x] from 1 to 3 = 12

  2. Evaluate ∫03 (5x + 1) dx.

    Show answer and solution

    Answer: 51/2

    [5/2x² + 1x] from 0 to 3 = 51/2

  3. Evaluate ∫14 (4x + 4) dx.

    Show answer and solution

    Answer: 42

    [2x² + 4x] from 1 to 4 = 42

  4. Evaluate ∫01 (6x − 3) dx.

    Show answer and solution

    Answer: 0

    [3x² − 3x] from 0 to 1 = 0

  5. Evaluate ∫02 (5x − 1) dx.

    Show answer and solution

    Answer: 8

    [5/2x² − 1x] from 0 to 2 = 8

  6. Evaluate ∫25 (3x + 1) dx.

    Show answer and solution

    Answer: 69/2

    [3/2x² + 1x] from 2 to 5 = 69/2
