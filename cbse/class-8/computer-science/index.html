  1. Computer Networks
    What is the full form of LAN?

    1. Local Access Network
    2. Local Area Network
    3. Large Area Network
    4. Line Area Network
    Show answer

    Answer: Local Area Network

    LAN stands for Local Area Network.

  2. Network Devices And Topology
    In which topology are all computers connected to one central device such as a hub or switch?

    1. bus
    2. star
    3. ring
    4. mesh
    Show answer

    Answer: star

    In a star topology every node connects to a central device.

  3. HTML Basics
    What is the full form of HTML?

    1. HyperText Markup Language
    2. Hyperlink Text Markup Language
    3. High Text Markup Language
    4. HyperText Making Language
    Show answer

    Answer: HyperText Markup Language

    HTML stands for HyperText Markup Language.

  4. Spreadsheet Functions
    Which spreadsheet function adds all the numbers in a range?

    1. TOTAL
    2. ADD
    3. COUNT
    4. SUM
    Show answer

    Answer: SUM

    =SUM(range) adds the values.

  5. Python Basics
    Which Python function displays output on the screen?

    1. display
    2. print
    3. show
    4. input
    Show answer

    Answer: print

    print() shows output on the screen.
