Sample questions

A few questions from the Class 8 Hindi bank. Every test picks a fresh mix.

  1. संधि
    'देवालय' शब्द का संधि-विच्छेद ______ है।

    1. देवा + आलय
    2. देवा + लय
    3. देव + आलय
    4. दे + वालय
    Show answer

    Answer: देव + आलय

    देव + आलय में अ + आ = आ होता है, इसलिए 'देवालय' बनता है (दीर्घ संधि)।

  2. समास
    'दिन-रात' में कौन-सा समास है?

    1. अव्ययीभाव
    2. द्विगु
    3. तत्पुरुष
    4. द्वंद्व समास
    Show answer

    Answer: द्वंद्व समास

    दिन और रात दोनों पद प्रधान हैं और 'और' से जुड़े हैं, इसलिए द्वंद्व समास है।

  3. उपसर्ग और प्रत्यय
    'प्रहार' शब्द में उपसर्ग ______ है।

    1. प्र
    2. आर
    3. प्रह
    4. हार
    Show answer

    Answer: प्र

    प्र + हार = प्रहार; 'प्र' उपसर्ग है।

  4. पर्यायवाची और विलोम
    'कमल' का एक पर्यायवाची शब्द लिखिए।

    1. पवन
    2. जलधि
    3. अनल
    4. जलज
    Show answer

    Answer: जलज

    जलज, पंकज, नीरज, सरोज कमल के पर्याय हैं; जलधि का अर्थ समुद्र है।

  5. मुहावरे और लोकोक्तियाँ
    मुहावरा 'दाँत खट्टे करना' का अर्थ ______ है।

    1. दाँत साफ़ करना
    2. हराना
    3. हँसाना
    4. खट्टा खाना
    Show answer

    Answer: हराना

    'दाँत खट्टे करना' का अर्थ है बुरी तरह हराना, जैसे: सैनिकों ने शत्रु के दाँत खट्टे कर दिए।
