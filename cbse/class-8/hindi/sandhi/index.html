A few questions from this chapter. Open each one to see the answer.

  1. 'देवालय' शब्द का संधि-विच्छेद ______ है।

    1. देवा + आलय
    2. देवा + लय
    3. देव + आलय
    4. दे + वालय
    Show answer

    Answer: देव + आलय

    देव + आलय में अ + आ = आ होता है, इसलिए 'देवालय' बनता है (दीर्घ संधि)।

  2. 'इत्यादि' (इति + आदि) में कौन-सी संधि है?

    1. दीर्घ संधि
    2. वृद्धि संधि
    3. यण संधि
    4. गुण संधि
    Show answer

    Answer: यण संधि

    इ के बाद भिन्न स्वर आ आने पर इ का य हो जाता है (इ + आ = या), यह यण संधि है।

  3. 'जगन्नाथ' (जगत् + नाथ) में कौन-सी संधि है?

    1. स्वर संधि
    2. विसर्ग संधि
    3. दीर्घ संधि
    4. व्यंजन संधि
    Show answer

    Answer: व्यंजन संधि

    यहाँ व्यंजन 'त्' का 'न' से मेल होकर 'न्न' बना है, इसलिए यह व्यंजन संधि है।

  4. 'सुरेंद्र' (सुर + इंद्र) में किन दो स्वरों के मेल से 'ए' बना है?

    1. इ + अ
    2. आ + ए
    3. अ + ए
    4. अ + इ
    Show answer

    Answer: अ + इ

    सुर का अंतिम 'अ' और इंद्र का 'इ' मिलकर 'ए' बनाते हैं (अ + इ = ए), जो गुण संधि है।

  5. 'रवींद्र' (रवि + इंद्र) में कौन-सी संधि है?

    1. दीर्घ संधि
    2. गुण संधि
    3. वृद्धि संधि
    4. यण संधि
    Show answer

    Answer: दीर्घ संधि

    इ + इ = ई; सजातीय स्वर मिलकर दीर्घ बनते हैं, इसलिए दीर्घ संधि है।

  6. 'रमेश' (रमा + ईश) में कौन-सी संधि है?

    1. यण संधि
    2. गुण संधि
    3. दीर्घ संधि
    4. वृद्धि संधि
    Show answer

    Answer: गुण संधि

    आ + ई = ए होता है; यह गुण संधि का नियम है।

  7. 'नयन' (ने + अन) में कौन-सी संधि है?

    1. यण संधि
    2. वृद्धि संधि
    3. अयादि संधि
    4. गुण संधि
    Show answer

    Answer: अयादि संधि

    ए के बाद भिन्न स्वर आने पर ए का 'अय्' हो जाता है (ए + अ = अय), यह अयादि संधि है।

  8. 'शिवालय' शब्द का संधि-विच्छेद ______ है।

    1. शिव + आलय
    2. शिव + लय
    3. शिवा + आलय
    4. शि + वालय
    Show answer

    Answer: शिव + आलय

    शिव + आलय में अ + आ = आ होता है, इसलिए 'शिवालय' बनता है (दीर्घ संधि)।
