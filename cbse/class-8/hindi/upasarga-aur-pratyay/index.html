Practice questions with answers

A few questions from this chapter. Open each one to see the answer.

  1. 'प्रहार' शब्द में उपसर्ग ______ है।

    1. प्र
    2. आर
    3. प्रह
    4. हार
    Show answer

    Answer: प्र

    प्र + हार = प्रहार; 'प्र' उपसर्ग है।

  2. 'लिखावट' शब्द में प्रत्यय ______ है।

    1. लिख
    2. वट
    3. अट
    4. आवट
    Show answer

    Answer: आवट

    लिख + आवट = लिखावट; 'आवट' प्रत्यय है।

  3. 'भारतीय' शब्द में प्रत्यय ______ है।

    1. ई
    2. ईय
    3. य
    4. इय
    Show answer

    Answer: ईय

    भारत + ईय = भारतीय; 'ईय' प्रत्यय संबंध का अर्थ देता है।

  4. उपसर्ग 'अ', मूल शब्द 'ज्ञान' और प्रत्यय 'ई' को जोड़ने पर कौन-सा शब्द बनेगा?

    1. विज्ञानी
    2. ज्ञानी
    3. अज्ञानी
    4. अज्ञान
    Show answer

    Answer: अज्ञानी

    अ + ज्ञान + ई = अज्ञानी; 'ज्ञानी' में उपसर्ग नहीं है और 'अज्ञान' में प्रत्यय नहीं है।

  5. 'अवगुण' शब्द में उपसर्ग ______ है।

    1. अव
    2. अवगु
    3. गुण
    4. अ
    Show answer

    Answer: अव

    अव + गुण = अवगुण; 'अव' उपसर्ग बुरा या हीन का अर्थ देता है।

  6. 'दुर्बल' शब्द में उपसर्ग ______ है।

    1. दुब
    2. दुर्
    3. बल
    4. दु
    Show answer

    Answer: दुर्

    दुर् + बल = दुर्बल; 'दुर्' उपसर्ग बुरा या कम का अर्थ देता है।

  7. 'अत्याचार' शब्द में उपसर्ग ______ है।

    1. अति
    2. आचार
    3. अत्या
    4. अ
    Show answer

    Answer: अति

    अति + आचार = अत्याचार; 'अति' उपसर्ग है और जुड़ते समय इ + आ = या (यण संधि) हो जाता है।

  8. 'निर्दोष' शब्द में उपसर्ग ______ है।

    1. दोष
    2. निद
    3. निर्
    4. नि
    Show answer

    Answer: निर्

    निर् + दोष = निर्दोष।
