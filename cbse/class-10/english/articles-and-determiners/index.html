A few questions from this chapter. Open each one to see the answer.

  1. ______ sun sets in the west.

    1. an
    2. some
    3. a
    4. the
    Show answer

    Answer: the

    'The' is used before unique objects like the sun.

  2. It was ______ unique experience.

    1. any
    2. much
    3. a
    4. an
    Show answer

    Answer: a

    'Unique' begins with a 'yu' consonant sound, so it takes 'a'.

  3. There were ______ errors in his essay that the teacher returned it.

    1. so many
    2. too many
    3. so much
    4. such many
    Show answer

    Answer: so many

    'So many' is used with countable nouns before a 'that' clause of result.

  4. She wants to become ______ engineer.

    1. much
    2. an
    3. a
    4. some
    Show answer

    Answer: an

    'Engineer' begins with a vowel sound, so it takes 'an'.

  5. Mount Everest is ______ highest peak in the world.

    1. an
    2. the
    3. some
    4. a
    Show answer

    Answer: the

    'The' is used before a superlative adjective such as 'highest'.

  6. He has ______ knowledge of French; he cannot even read a menu.

    1. few
    2. a little
    3. a few
    4. little
    Show answer

    Answer: little

    'Little' (without 'a') means 'hardly any' and is used with uncountable nouns.

  7. I saw ______ elephant at the zoo.

    1. an
    2. many
    3. a
    4. much
    Show answer

    Answer: an

    'Elephant' begins with a vowel sound, so it takes 'an'.

  8. ______ Himalayas are the highest mountains in the world.

    1. an
    2. some
    3. the
    4. a
    Show answer

    Answer: the

    'The' is used before the names of mountain ranges.
