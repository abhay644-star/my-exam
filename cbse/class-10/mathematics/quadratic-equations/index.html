  1. Solve the quadratic equation x² − 15x + 50 = 0.

    Show answer and solution
    • (a) The larger root 10
    • (b) The smaller root 5

    (x − 5)(x − 10) = 0, so x = 5 or x = 10.

  2. The product of two consecutive positive integers is 90.

    Show answer and solution
    • (a) Find the smaller integer. 9
    • (b) Find the larger integer. 10
    • (c) Find the sum of their squares. 181

    x(x + 1) = 90 gives x² + x − 90 = 0, i.e. (x − 9)(x + 10) = 0, so x = 9. Sum of squares = 81 + 100 = 181.

  3. Solve the quadratic equation x² − 13x + 40 = 0.

  4. The product of two consecutive positive integers is 342.

    Show answer and solution
    • (a) Find the smaller integer. 18
    • (b) Find the larger integer. 19

    x(x + 1) = 342 gives x² + x − 342 = 0, i.e. (x − 18)(x + 19) = 0, so x = 18. Sum of squares = 324 + 361 = 685.

  5. Solve the quadratic equation x² + 13x + 42 = 0.

    Show answer and solution
    • (a) The larger root −6
    • (b) The smaller root −7

    (x + 6)(x + 7) = 0, so x = −6 or x = −7.
