Sample questions

A few questions from the Class 10 Computer Science bank. Every test picks a fresh mix.

  1. HTML Basics
    Which HTML tag defines a paragraph?

    1. <para>
    2. <pg>
    3. <p>
    4. <br>
    Show answer

    Answer: <p>

    <p> starts a new paragraph.

  2. HTML Lists
    Which HTML tag creates an unordered (bulleted) list?

    1. <ol>
    2. <li>
    3. <dl>
    4. <ul>
    Show answer

    Answer: <ul>

    <ul> makes a bulleted list.

  3. HTML Tables
    Which HTML tag creates a row in a table?

    1. <tr>
    2. <row>
    3. <td>
    4. <th>
    Show answer

    Answer: <tr>

    <tr> means table row.

  4. HTML Links And Images
    Which HTML tag inserts an image?

    1. <pic>
    2. <src>
    3. <img>
    4. <image>
    Show answer

    Answer: <img>

    <img> with the src attribute displays an image.

  5. HTML Forms
    Which HTML tag creates a form to collect user input?

    1. <table>
    2. <fieldset>
    3. <input>
    4. <form>
    Show answer

    Answer: <form>

    <form> contains input controls.
