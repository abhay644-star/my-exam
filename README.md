# My Exam Practice

Timed CBSE maths practice papers for Classes V to XII. Each paper is generated in the browser and marked instantly.

Live site: https://my-exam.in

## Hosting
- Hosted on GitHub Pages from the `main` branch (root folder).
- `CNAME` sets the custom domain `my-exam.in`.
- The site is a single static file (`index.html`), so there is no build step.
