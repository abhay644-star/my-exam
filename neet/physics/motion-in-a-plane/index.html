  1. NEET (UG) 2024, 5 May, Code T1 · Question 20
    A particle moving with uniform speed in a circular path maintains :

    1. constant velocity but varying acceleration.
    2. varying velocity and varying acceleration.
    3. constant velocity.
    4. constant acceleration.
    Show answer and solution

    Answer: (2)

    In uniform circular motion the speed is constant but the direction of motion changes continuously, so the velocity varies. The centripetal acceleration has constant magnitude $v^2/r$ but always points towards the centre, so its direction (and hence the acceleration vector) also varies.

  2. NEET (UG) 2023, 7 May, Code E1 · Question 35
    A bullet is fired from a gun at the speed of $280\ \text{m s}^{-1}$ in the direction 30° above the horizontal. The maximum height attained by the bullet is $\left(g = 9.8\ \text{m s}^{-2},\ \sin 30^\circ = 0.5\right)$ :

    1. 2800 m
    2. 2000 m
    3. 1000 m
    4. 3000 m
    Show answer and solution

    Answer: (3)

    $H = \dfrac{u^2\sin^2\theta}{2g} = \dfrac{280^2 \times 0.25}{2 \times 9.8} = \dfrac{19600}{19.6} = 1000$ m.
