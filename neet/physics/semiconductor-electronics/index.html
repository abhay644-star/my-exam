  1. NEET (UG) 2026, 21 June (re-exam), Code 50 · Question 16
    An ideal Zener diode with breakdown voltage of $-3$ V is reverse biased with a negative input voltage $V_i = -5$ V. The magnitude of voltage difference between point $B$ and $A$ is:

    1. 3 V
    2. 2 V
    3. 1 V
    4. 0 V
    Show answer and solution

    Answer: (2)

    The 5 V input exceeds the 3 V breakdown, so the Zener conducts and holds 3 V across $C$–$B$.
    The rest of the supply drops across $R$ (between $B$ and $A$): $5 - 3 = 2$ V.

  2. NEET (UG) 2026, 21 June (re-exam), Code 50 · Question 42
    Three identical p-n junction diodes $D_1$, $D_2$, and $D_3$ are connected across a battery as shown in the figure. If the width of the depletion regions of $D_1$, $D_2$ and $D_3$ are $W_1$, $W_2$ and $W_3$, respectively, then the correct option is:

    1. $W_1 > W_2 > W_3$
    2. $W_3 = W_1 > W_2$
    3. $W_3 > W_2 > W_1$
    4. $W_2 > W_1 = W_3$
    Show answer and solution

    Answer: (3)

    $D_1$ is forward biased: its depletion layer narrows.
    $D_2$'s branch is open, so no bias appears across it: equilibrium width.
    $D_3$ is reverse biased: its depletion layer widens. Hence $W_3 > W_2 > W_1$.

  3. NEET (UG) 2025, 4 May, Code 45 · Question 8
    The output (Y) of the given logic implementation is similar to the output of an/a _______ gate.

    1. AND
    2. NAND
    3. OR
    4. NOR
    Show answer and solution

    Answer: (4)

    The upper gate gives $\overline{A+B}$ (NOR) and the lower gate gives $\overline{A\cdot B}$ (NAND). The AND gate gives $Y = \overline{A+B}\cdot\overline{AB}$.
    $\overline{A+B} = 1$ only when $A = B = 0$, and then $\overline{AB} = 1$ too; otherwise $Y = 0$. So $Y = \overline{A+B}$, the NOR output.

  4. NEET (UG) 2025, 4 May, Code 45 · Question 40
    A full wave rectifier circuit with diodes ($D_1$) and ($D_2$) is shown in the figure. If input supply voltage $V_{in} = 220\sin(100\pi t)$ volt, then at $t$ = 15 $msec$

    1. $D_1$ is forward biased, $D_2$ is reverse biased
    2. $D_1$ is reverse biased, $D_2$ is forward biased
    3. $D_1$ and $D_2$ both are forward biased
    4. $D_1$ and $D_2$ both are reverse biased
    Show answer and solution

    Answer: (1) or (2) (either is accepted)

    At $t = 15$ ms, $V_{in} = 220\sin(1.5\pi) = -220$ V, so the input is in its negative half-cycle.
    In this centre-tap rectifier exactly one diode conducts in each half-cycle while the other is reverse biased, so (3) and (4) are wrong.
    Which diode conducts depends on the winding sense of the transformer, which the figure does not fix. The NTA final key accepts both (1) and (2).

  5. NEET (UG) 2024, 5 May, Code T1 · Question 3
    Consider the following statements A and B and identify the correct answer :
    A. For a solar-cell, the I-V characteristics lies in the IV quadrant of the given graph.
    B. In a reverse biased $pn$ junction diode, the current measured in $(\mu A)$, is due to majority charge carriers.

    1. Both A and B are correct.
    2. Both A and B are incorrect.
    3. A is correct but B is incorrect.
    4. A is incorrect but B is correct.
    Show answer and solution

    Answer: (3)

    A is correct: a solar cell gives a positive voltage while the current flows in the reverse direction, so its I-V curve is drawn in the fourth quadrant.
    B is incorrect: the small reverse current (of the order of $\mu A$) is due to the drift of minority charge carriers.

  6. NEET (UG) 2024, 5 May, Code T1 · Question 6
    The output ($Y$) of the given logic gate is similar to the output of an/a :

    1. OR gate
    2. AND gate
    3. NAND gate
    4. NOR gate
    Show answer and solution

    Answer: (2)

    The NAND gate with both inputs joined to $A$ gives $\overline{A}$. The NOR gate with both inputs joined to $B$ gives $\overline{B}$.
    The final NOR gate gives $Y = \overline{\overline{A} + \overline{B}} = A\cdot B$ (De Morgan's theorem), which is the AND output.

  7. NEET (UG) 2024, 5 May, Code T1 · Question 12
    A logic circuit provides the output $Y$ as per the following truth table :

    $A$$B$$Y$
    001
    010
    101
    110
    The expression for the output $Y$ is :

    1. $\overline{B}$
    2. $B$
    3. $A.B + \overline{A}$
    4. $A.\overline{B} + \overline{A}$
    Show answer and solution

    Answer: (1)

    $Y$ is 1 whenever $B = 0$ and 0 whenever $B = 1$, whatever the value of $A$. So $Y = \overline{B}$.

  8. NEET (UG) 2024, 5 May, Code T1 · Question 44
    Choose the correct circuit which can achieve the bridge balance.

    Show answer and solution

    Answer: (3)

    The two upper arms are equal (10 $\Omega$ each), so the bridge balances only if the two lower arms are equal: the arm with the 5 $\Omega$ resistor must have a total of 15 $\Omega$ ($\dfrac{10}{10} = \dfrac{15}{5 + R_D}$, so $R_D = 10\ \Omega$).
    This needs the diode $D$ to conduct, in series with the 5 $\Omega$ resistor, with a resistance of 10 $\Omega$. In circuit (3) the diode is in series with the 5 $\Omega$ resistor and is forward biased by the cell, so this circuit can be balanced.

    Note: The official answer assumes the forward-biased diode has a resistance of 10 $\Omega$; the question gives no value for it.

  9. NEET (UG) 2023, 7 May, Code E1 · Question 9
    A full wave rectifier circuit consists of two p-n junction diodes, a centre-tapped transformer, capacitor and a load resistance. Which of these components remove the ac ripple from the rectified output?

    1. A centre-tapped transformer
    2. p-n junction diodes
    3. Capacitor
    4. Load resistance
    Show answer and solution

    Answer: (3)

    The capacitor connected across the load acts as a filter: it charges at the peaks and discharges slowly between them, smoothing out the ac ripple.

  10. NEET (UG) 2023, 7 May, Code E1 · Question 12
    Given below are two statements:
    $\textbf{Statement I :}$ Photovoltaic devices can convert optical radiation into electricity.
    $\textbf{Statement II :}$ Zener diode is designed to operate under reverse bias in breakdown region.
    In the light of the above statements, choose the $\textit{most appropriate}$ answer from the options given below :

    1. Both Statement I and Statement II are correct.
    2. Both Statement I and Statement II are incorrect.
    3. Statement I is correct but Statement II is incorrect.
    4. Statement I is incorrect but Statement II is correct.
    Show answer and solution

    Answer: (1)

    Statement I is correct: photovoltaic devices such as solar cells convert light into electrical energy.
    Statement II is correct: a Zener diode is heavily doped and is used in reverse bias in the breakdown region (for example as a voltage regulator).

  11. NEET (UG) 2023, 7 May, Code E1 · Question 42
    For the following logic circuit, the truth table is:

    Show answer and solution

    Answer: (2)

    Each input passes through a NOT gate, and the two outputs $\overline{A}$ and $\overline{B}$ feed a NAND gate.
    $Y = \overline{\overline{A}\cdot\overline{B}} = A + B$ (De Morgan's theorem), the OR function: $Y = 0$ only when $A = B = 0$.
    This is truth table (2).
