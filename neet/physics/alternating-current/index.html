  1. NEET (UG) 2026, 21 June (re-exam), Code 50 · Question 30
    An ac voltage $V = 220\sin(2 \times 10^3 t)$ Volt is applied to a series LCR circuit. Then the current amplitude in this circuit is:
    (Given : $L = 10$ mH, $C = 25\ \mu$F, $R = 100\ \Omega$)

    1. 2.2 A
    2. 5.5 A
    3. 11.0 A
    4. 22.0 A
    Show answer and solution

    Answer: (1)

    $X_L = \omega L = 2000 \times 0.01 = 20\ \Omega$; $X_C = \dfrac{1}{\omega C} = \dfrac{1}{2000 \times 25 \times 10^{-6}} = 20\ \Omega$.
    Resonance, so $Z = R = 100\ \Omega$ and $I_0 = 220/100 = 2.2$ A.

  2. NEET (UG) 2025, 4 May, Code 45 · Question 16
    To an ac power supply of 220 V at 50 Hz, a resistor of 20 $\Omega$, a capacitor of reactance 25 $\Omega$ and an inductor of reactance 45 $\Omega$ are connected in series. The corresponding current in the circuit and the phase angle between the current and the voltage is, respectively -

    1. 7.8 A and $30^\circ$
    2. 7.8 A and $45^\circ$
    3. 15.6 A and $30^\circ$
    4. 15.6 A and $45^\circ$
    Show answer and solution

    Answer: (2)

    $X_L - X_C = 45 - 25 = 20\ \Omega$, so $Z = \sqrt{20^2 + 20^2} = 20\sqrt{2} \approx 28.3\ \Omega$.
    $I = 220/28.3 \approx 7.8$ A, and $\tan\phi = \dfrac{X_L - X_C}{R} = 1 \Rightarrow \phi = 45^\circ$.

  3. NEET (UG) 2024, 5 May, Code T1 · Question 26
    In an ideal transformer, the turns ratio is $\dfrac{N_p}{N_s} = \dfrac{1}{2}$. The ratio $V_s : V_p$ is equal to (the symbols carry their usual meaning) :

    1. 1 : 1
    2. 1 : 4
    3. 1 : 2
    4. 2 : 1
    Show answer and solution

    Answer: (4)

    For an ideal transformer $\dfrac{V_s}{V_p} = \dfrac{N_s}{N_p} = \dfrac{2}{1}$, so $V_s : V_p = 2 : 1$.

  4. NEET (UG) 2024, 5 May, Code T1 · Question 43
    A $10\ \mu F$ capacitor is connected to a 210 V, 50 Hz source as shown in figure. The peak current in the circuit is nearly $(\pi = 3.14)$ :

    1. 1.20 $A$
    2. 0.35 $A$
    3. 0.58 $A$
    4. 0.93 $A$
    Show answer and solution

    Answer: (4)

    $X_C = \dfrac{1}{2\pi fC} = \dfrac{1}{2 \times 3.14 \times 50 \times 10\times10^{-6}} = \dfrac{1000}{3.14}\ \Omega$.
    $I_{rms} = \dfrac{V_{rms}}{X_C} = \dfrac{210 \times 3.14}{1000} = 0.659$ A, and the peak current $I_0 = \sqrt{2}\,I_{rms} \approx 0.93$ A.

  5. NEET (UG) 2023, 7 May, Code E1 · Question 8
    A 12 V, 60 W lamp is connected to the secondary of a step down transformer, whose primary is connected to ac mains of 220 V. Assuming the transformer to be ideal, what is the current in the primary winding?

    1. 0.27 A
    2. 2.7 A
    3. 3.7 A
    4. 0.37 A
    Show answer and solution

    Answer: (1)

    For an ideal transformer the input power equals the output power: $V_pI_p = 60$ W.
    $I_p = \dfrac{60}{220} \approx 0.27$ A.

  6. NEET (UG) 2023, 7 May, Code E1 · Question 24
    An ac source is connected to a capacitor C. Due to decrease in its operating frequency :

    1. capacitive reactance decreases.
    2. displacement current increases.
    3. displacement current decreases.
    4. capacitive reactance remains constant
    Show answer and solution

    Answer: (3)

    $X_C = \dfrac{1}{\omega C}$, so a lower frequency increases the reactance and decreases the current $I = V/X_C$.
    The displacement current between the plates equals the conduction current in the wires, so it also decreases.

  7. NEET (UG) 2023, 7 May, Code E1 · Question 29
    In a series $LCR$ circuit, the inductance $L$ is 10 mH, capacitance $C$ is $1\ \mu F$ and resistance $R$ is $100\ \Omega$. The frequency at which resonance occurs is :

    1. 15.9 rad/s
    2. 15.9 kHz
    3. 1.59 rad/s
    4. 1.59 kHz
    Show answer and solution

    Answer: (4)

    $\nu_0 = \dfrac{1}{2\pi\sqrt{LC}} = \dfrac{1}{2\pi\sqrt{10^{-2} \times 10^{-6}}} = \dfrac{1}{2\pi \times 10^{-4}} \approx 1592$ Hz $\approx 1.59$ kHz.

  8. NEET (UG) 2023, 7 May, Code E1 · Question 37
    The net impedance of circuit (as shown in figure) will be :

    1. $10\sqrt{2}\ \Omega$
    2. $15\ \Omega$
    3. $5\sqrt{5}\ \Omega$
    4. $25\ \Omega$
    Show answer and solution

    Answer: (3)

    $\omega = 2\pi \times 50 = 100\pi$ rad/s.
    $X_L = \omega L = 100\pi \times \dfrac{50\times10^{-3}}{\pi} = 5\ \Omega$; $X_C = \dfrac{1}{\omega C} = \dfrac{1}{100\pi \times \frac{10^{3}\times10^{-6}}{\pi}} = 10\ \Omega$.
    $Z = \sqrt{R^2 + (X_C - X_L)^2} = \sqrt{100 + 25} = 5\sqrt{5}\ \Omega$.

  9. NEET (UG) 2022, 17 July, Code Q1 · Question 22
    The peak voltage of the ac source is equal to

    1. The value of voltage supplied to the circuit
    2. The rms value of the ac source
    3. $\sqrt{2}$ times the rms value of the ac source
    4. $1/\sqrt{2}$ times the rms value of the ac source
    Show answer and solution

    Answer: (3)

    $V_{rms} = V_0/\sqrt{2}$, so $V_0 = \sqrt{2}\,V_{rms}$.

  10. NEET (UG) 2022, 17 July, Code Q1 · Question 42
    A series LCR circuit with inductance 10 H, capacitance 10 $\mu$F, resistance 50 $\Omega$ is connected to an ac source of voltage, $V$ = 200sin(100$t$) volt. If the resonant frequency of the LCR circuit is $\nu_1$ and the frequency of the ac source is $\nu$, then

    1. $\nu_0 = \nu = 50$ Hz
    2. $\nu_0 = \nu = \dfrac{50}{\pi}$ Hz
    3. $\nu_0 = \dfrac{50}{\pi}$ Hz, $\nu = 50$ Hz
    4. $\nu = 100$ Hz; $\nu_0 = \dfrac{100}{\pi}$ Hz
    Show answer and solution

    Answer: (2)

    $\omega_0 = \dfrac{1}{\sqrt{LC}} = \dfrac{1}{\sqrt{10 \times 10 \times 10^{-6}}} = 100$ rad/s, so $\nu_0 = \dfrac{100}{2\pi} = \dfrac{50}{\pi}$ Hz.
    The source has $\omega = 100$ rad/s, so $\nu = \dfrac{50}{\pi}$ Hz as well. (The stem calls the resonant frequency $\nu_1$; the options call it $\nu_0$.)
