  1. NEET (UG) 2026, 21 June (re-exam), Code 50 · Question 4
    For sound waves, if the number of nodes for the 5$^{\text{th}}$ harmonic of an open-ended pipe is $n$ and that for the 9$^{\text{th}}$ harmonic of the same pipe with one of its ends closed is $m$, the ratio $\dfrac{n}{m}$ is

    1. $\dfrac{5}{9}$
    2. $\dfrac{9}{5}$
    3. $1$
    4. $\dfrac{3}{5}$
    Show answer and solution

    Answer: (3)

    Open pipe, $k$-th harmonic: $k$ (pressure) nodes $\Rightarrow n = 5$.
    Closed pipe, harmonic number $2p-1$ has $p$ nodes; $9 = 2p-1 \Rightarrow p = 5$, so $m = 5$.
    $n/m = 1$.

  2. NEET (UG) 2025, 4 May, Code 45 · Question 45
    A pipe open at both ends has a fundamental frequency $f$ in air. The pipe is now dipped vertically in a water drum to half of its length. The fundamental frequency of the air column is now equal to :

    1. $\dfrac{f}{2}$
    2. $f$
    3. $\dfrac{3f}{2}$
    4. $2f$
    Show answer and solution

    Answer: (2)

    Open pipe: $f = \dfrac{v}{2L}$. Dipped to half its length, it becomes a closed pipe of length $L/2$: $f' = \dfrac{v}{4(L/2)} = \dfrac{v}{2L} = f$.

  3. NEET (UG) 2023, 7 May, Code E1 · Question 31
    The ratio of frequencies of fundamental harmonic produced by an open pipe to that of closed pipe having the same length is :

    1. 1 : 2
    2. 2 : 1
    3. 1 : 3
    4. 3 : 1
    Show answer and solution

    Answer: (2)

    Fundamental frequency of an open pipe: $\dfrac{v}{2L}$; of a closed pipe: $\dfrac{v}{4L}$.
    Ratio $= \dfrac{v/2L}{v/4L} = 2 : 1$.

  4. NEET (UG) 2022, 17 July, Code Q1 · Question 11
    If the initial tension on a stretched string is doubled, then the ratio of the initial and final speeds of a transverse wave along the string is

    1. 1 : 1
    2. $\sqrt{2} : 1$
    3. $1 : \sqrt{2}$
    4. 1 : 2
    Show answer and solution

    Answer: (3)

    $v = \sqrt{T/\mu}$, so $v \propto \sqrt{T}$.
    $\dfrac{v_1}{v_2} = \sqrt{\dfrac{T}{2T}} = \dfrac{1}{\sqrt{2}}$, i.e. $1 : \sqrt{2}$.
