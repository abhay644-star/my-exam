  1. NEET (UG) 2026, 21 June (re-exam), Code 50 · Question 54
    Assertion A: For an ideal solution formed by mixing liquids P and Q, $\Delta_{mix}H = 0$ and $\Delta_{mix}V = 0$
    Reason R: No interactions occur between P and Q
    In the light of the above statements, choose the most appropriate answer from the options given below.

    1. Both A and R are correct and R is the correct explanation of A
    2. Both A and R are correct but R is NOT the correct explanation of A
    3. A is correct but R is not correct
    4. A is not correct but R is correct
    Show answer and solution

    Answer: (3)

    For an ideal solution, $\Delta_{mix}H = 0$ and $\Delta_{mix}V = 0$, so A is correct.
    P and Q do interact. In an ideal solution the P–Q interactions are equal in strength to the P–P and Q–Q interactions, so R is wrong.

  2. NEET (UG) 2026, 21 June (re-exam), Code 50 · Question 71
    Consider the following statements about the solutions formed by mixing two liquids.
    A. An ideal solution thus formed obeys Raoult’s law throughout the composition range.
    B. Mixture of chloroform and acetone shows negative deviation from Raoult’s law.
    C. Mixture of aniline and phenol shows positive deviation from Raoult’s law.

    1. A and B only
    2. B and C only
    3. A only
    4. A and C only
    Show answer and solution

    Answer: (1)

    A: true by definition of an ideal solution.
    B: true. Chloroform forms H-bonds with the C=O of acetone, so the mixture shows negative deviation.
    C: false. Phenol forms strong H-bonds with the N of aniline, so the deviation is negative, not positive.

  3. NEET (UG) 2025, 4 May, Code 45 · Question 66
    Match $\textbf{List - I}$ with $\textbf{List - II}$

    List-I (Example)List-II (Type of Solution)
    A.HumidityI.Solid in solid
    B.AlloysII.Liquid in gas
    C.AmalgamsIII.Solid in gas
    D.SmokeIV.Liquid in solid
    Choose the $\textbf{correct}$ answer from the options given below :

    1. A-II, B-IV, C-I, D-III
    2. A-II, B-I, C-IV, D-III
    3. A-III, B-I, C-IV, D-II
    4. A-III, B-II, C-I, D-IV
    Show answer and solution

    Answer: (2)

    Humidity is water vapour (liquid) in air: liquid in gas. Alloys: solid in solid. Amalgams (mercury in a metal such as sodium): liquid in solid. Smoke (solid particles in air): solid in gas.
    So A-II, B-I, C-IV, D-III.

  4. NEET (UG) 2025, 4 May, Code 45 · Question 79
    Which of the following aqueous solution will exhibit highest boiling point?

    1. 0.01M Urea
    2. 0.01M $\mathrm{KNO_3}$
    3. 0.01M $\mathrm{Na_2SO_4}$
    4. 0.015M $\mathrm{C_6H_{12}O_6}$
    Show answer and solution

    Answer: (3)

    Elevation of boiling point $\propto iC$ (effective particle concentration).
    Urea: $1\times0.01 = 0.01$; $\mathrm{KNO_3}$: $2\times0.01 = 0.02$; $\mathrm{Na_2SO_4}$: $3\times0.01 = 0.03$; glucose: $1\times0.015 = 0.015$.
    $\mathrm{Na_2SO_4}$ has the highest boiling point.

  5. NEET (UG) 2025, 4 May, Code 45 · Question 81
    5 moles of liquid X and 10 moles of liquid Y make a solution having a vapour pressure of 70 torr. The vapour pressures of pure X and Y are 63 torr and 78 torr respectively. Which of the following is true regarding the described solution?

    1. The solution shows positive deviation.
    2. The solution shows negative deviation.
    3. The solution is ideal.
    4. The solution has volume greater than the sum of individual volumes.
    Show answer and solution

    Answer: (2)

    For an ideal solution, by Raoult's law: $p = \tfrac{5}{15}\times63 + \tfrac{10}{15}\times78 = 21 + 52 = 73$ torr.
    The observed 70 torr is lower than 73 torr, so the solution shows negative deviation (and its volume would be less, not greater, than the sum).

  6. NEET (UG) 2024, 5 May, Code T1 · Question 77
    The Henry’s law constant ($\mathrm{K_H}$) values of three gases (A, B, C) in water are 145, $2\times10^{-5}$ and 35 kbar, respectively. The solubility of these gases in water follow the order:

    1. A > C > B
    2. A > B > C
    3. B > A > C
    4. B > C > A
    Show answer and solution

    Answer: (4)

    By Henry's law $p = K_H x$, so at a given pressure the solubility (mole fraction) is inversely proportional to $K_H$.
    $K_H$: B ($2\times10^{-5}$) < C (35) < A (145), so solubility: B > C > A.

  7. NEET (UG) 2024, 5 May, Code T1 · Question 93
    The plot of osmotic pressure ($\Pi$) vs concentration (mol $\mathrm{L^{-1}}$) for a solution gives a straight line with slope 25.73 L bar $\mathrm{mol^{-1}}$. The temperature at which the osmotic pressure measurement is done is:
    (Use R = 0.083 L bar $\mathrm{mol^{-1}\ K^{-1}}$)

    1. 25.73°C
    2. 12.05°C
    3. 37°C
    4. 310°C
    Show answer and solution

    Answer: (3)

    $\Pi = CRT$, so the slope of $\Pi$ against $C$ is $RT$.
    $T = \dfrac{25.73}{0.083} = 310$ K $= 310 - 273 = 37$°C.
