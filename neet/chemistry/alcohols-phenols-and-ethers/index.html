  1. NEET (UG) 2024, 5 May, Code T1 · Question 54
    Which one of the following alcohols reacts instantaneously with Lucas reagent?

    Show answer and solution

    Answer: (2)

    Lucas reagent (conc. HCl + anhydrous $\mathrm{ZnCl_2}$) reacts through a carbocation, so tertiary alcohols react at once (immediate turbidity), secondary alcohols within about five minutes and primary alcohols not at room temperature.
    Option (2), 2-methylpropan-2-ol, is the only tertiary alcohol.
