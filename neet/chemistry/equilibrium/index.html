  1. NEET (UG) 2026, 21 June (re-exam), Code 50 · Question 52
    The correct order of solubility of the given salts in water at 298 K is

    Salt$K_{sp}$ at 298 K
    $\mathrm{AgBr}$$5.0\times10^{-13}$
    $\mathrm{Zn(OH)_2}$$1.0\times10^{-15}$
    $\mathrm{Hg_2Cl_2}$$1.3\times10^{-18}$

    1. $\mathrm{Hg_2Cl_2 > Zn(OH)_2 > AgBr}$
    2. $\mathrm{AgBr > Zn(OH)_2 > Hg_2Cl_2}$
    3. $\mathrm{Hg_2Cl_2 > AgBr > Zn(OH)_2}$
    4. $\mathrm{Zn(OH)_2 > AgBr > Hg_2Cl_2}$
    Show answer and solution

    Answer: (4)

    AgBr (1:1): $s = \sqrt{5.0\times10^{-13}} \approx 7.1\times10^{-7}$ M.
    $\mathrm{Zn(OH)_2}$ (1:2): $s = (K_{sp}/4)^{1/3} = (2.5\times10^{-16})^{1/3} \approx 6.3\times10^{-6}$ M.
    $\mathrm{Hg_2Cl_2 \rightleftharpoons Hg_2^{2+} + 2Cl^-}$: $s = (3.25\times10^{-19})^{1/3} \approx 6.9\times10^{-7}$ M.
    So $\mathrm{Zn(OH)_2 > AgBr > Hg_2Cl_2}$.

  2. NEET (UG) 2025, 4 May, Code 45 · Question 59
    Phosphoric acid ionizes in three steps with their ionization constant values $K_{a_1}$, $K_{a_2}$ and $K_{a_3}$, respectively, while K is the overall ionization constant. Which of the following statements are true?
    A. $\log K = \log K_{a_1} + \log K_{a_2} + \log K_{a_3}$
    B. $\mathrm{H_3PO_4}$ is a stronger acid than $\mathrm{H_2PO_4^-}$ and $\mathrm{HPO_4^{2-}}$.
    C. $K_{a_1} > K_{a_2} > K_{a_3}$
    D. $K_{a_1} = \dfrac{K_{a_3} + K_{a_2}}{2}$
    Choose the $\textbf{correct}$ answer from the options given below:

    1. A and B only
    2. A and C only
    3. B, C and D only
    4. A, B and C only
    Show answer and solution

    Answer: (4)

    The overall constant is the product $K = K_{a_1}K_{a_2}K_{a_3}$, so A is true.
    Removing a proton from a neutral molecule is easier than from an anion, so $K_{a_1} > K_{a_2} > K_{a_3}$ (C true) and $\mathrm{H_3PO_4}$ is the strongest acid of the three (B true).
    D has no basis. Hence A, B and C only.

  3. NEET (UG) 2025, 4 May, Code 45 · Question 73
    For the reaction $\mathrm{A(g) \rightleftharpoons 2B(g)}$, the backward reaction rate constant is higher than the forward reaction rate constant by a factor of 2500, at 1000 K.
    [Given : R = 0.0831 L atm mol$^{-1}$ K$^{-1}$]
    $K_P$ for the reaction at 1000 K is

    1. 83.1
    2. $2.077\times10^{5}$
    3. 0.033
    4. 0.021
    Show answer and solution

    Answer: (3)

    $K_c = \dfrac{k_f}{k_b} = \dfrac{1}{2500} = 4\times10^{-4}$.
    $\Delta n_g = 2 - 1 = 1$, so $K_P = K_c(RT) = 4\times10^{-4}\times0.0831\times1000 = 0.0332 \approx 0.033$.

  4. NEET (UG) 2025, 4 May, Code 45 · Question 88
    Higher yield of NO in $\mathrm{N_2(g) + O_2(g) \rightleftharpoons 2NO(g)}$ can be obtained at
    [$\Delta H$ of the reaction = + 180.7 kJ mol$^{-1}$]
    A. higher temperature
    B. lower temperature
    C. higher concentration of $\mathrm{N_2}$
    D. higher concentration of $\mathrm{O_2}$
    Choose the $\textbf{correct}$ answer from the options given below:

    1. A, D only
    2. B, C only
    3. B, C, D only
    4. A, C, D only
    Show answer and solution

    Answer: (4)

    The forward reaction is endothermic, so by Le Chatelier's principle a higher temperature favours NO (A, not B).
    Adding either reactant, $\mathrm{N_2}$ or $\mathrm{O_2}$, shifts the equilibrium forward (C and D). Hence A, C, D only.

  5. NEET (UG) 2024, 5 May, Code T1 · Question 76
    For the reaction $\mathrm{2A \rightleftharpoons B + C}$, $\mathrm{K_c = 4\times10^{-3}}$. At a given time, the composition of reaction mixture is : $\mathrm{[A] = [B] = [C] = 2\times10^{-3}\ M}$.
    Then, which of the following is correct?

    1. Reaction has a tendency to go in backward direction.
    2. Reaction has gone to completion in forward direction.
    3. Reaction is at equilibrium.
    4. Reaction has a tendency to go in forward direction.
    Show answer and solution

    Answer: (1)

    Reaction quotient $Q_c = \dfrac{[B][C]}{[A]^2} = \dfrac{(2\times10^{-3})(2\times10^{-3})}{(2\times10^{-3})^2} = 1$.
    $Q_c = 1 > K_c = 4\times10^{-3}$, so there are too many products and the reaction tends to go in the backward direction.

  6. NEET (UG) 2024, 5 May, Code T1 · Question 79
    In which of the following equilibria, $\mathrm{K_p}$ and $\mathrm{K_c}$ are $\textbf{NOT}$ equal?

    1. $\mathrm{CO_{(g)} + H_2O_{(g)} \rightleftharpoons CO_{2(g)} + H_{2(g)}}$
    2. $\mathrm{2\ BrCl_{(g)} \rightleftharpoons Br_{2(g)} + Cl_{2(g)}}$
    3. $\mathrm{PCl_{5(g)} \rightleftharpoons PCl_{3(g)} + Cl_{2(g)}}$
    4. $\mathrm{H_{2(g)} + I_{2(g)} \rightleftharpoons 2\ HI_{(g)}}$
    Show answer and solution

    Answer: (3)

    $K_p = K_c(RT)^{\Delta n_g}$, so $K_p = K_c$ only when $\Delta n_g = 0$.
    For $\mathrm{PCl_5 \rightleftharpoons PCl_3 + Cl_2}$, $\Delta n_g = 2 - 1 = 1$, so $K_p \neq K_c$. In the other three $\Delta n_g = 0$.

  7. NEET (UG) 2024, 5 May, Code T1 · Question 87
    Consider the following reaction in a sealed vessel at equilibrium with concentrations of
    $\mathrm{N_2 = 3.0 \times 10^{-3}\ M}$, $\mathrm{O_2 = 4.2 \times 10^{-3}\ M}$ and $\mathrm{NO = 2.8 \times 10^{-3}\ M}$.
    $\mathrm{2NO_{(g)} \rightleftharpoons N_{2(g)} + O_{2(g)}}$
    If 0.1 mol $\mathrm{L^{-1}}$ of $\mathrm{NO_{(g)}}$ is taken in a closed vessel, what will be degree of dissociation $(\alpha)$ of $\mathrm{NO_{(g)}}$ at equilibrium?

    1. 0.8889
    2. 0.717
    3. 0.00889
    4. 0.0889
    Show answer and solution

    Answer: (2)

    $K_c = \dfrac{[N_2][O_2]}{[NO]^2} = \dfrac{3.0\times10^{-3} \times 4.2\times10^{-3}}{(2.8\times10^{-3})^2} = \dfrac{12.6}{7.84} = 1.607$.
    Starting with 0.1 M NO: at equilibrium $[NO] = 0.1(1 - \alpha)$ and $[N_2] = [O_2] = 0.05\alpha$.
    $\dfrac{0.05\alpha}{0.1(1 - \alpha)} = \sqrt{1.607} = 1.268 \Rightarrow \alpha = 2.536(1 - \alpha) \Rightarrow \alpha = \dfrac{2.536}{3.536} = 0.717$.

  8. NEET (UG) 2023, 7 May, Code E1 · Question 77
    Amongst the given options which of the following molecules / ion acts as a Lewis acid?

    1. $\mathrm{NH_3}$
    2. $\mathrm{H_2O}$
    3. $\mathrm{BF_3}$
    4. $\mathrm{OH^-}$
    Show answer and solution

    Answer: (3)

    A Lewis acid accepts an electron pair. In $\mathrm{BF_3}$ boron has only six electrons in its valence shell, so it accepts a pair. $\mathrm{NH_3}$, $\mathrm{H_2O}$ and $\mathrm{OH^-}$ have lone pairs to donate, so they are Lewis bases.

  9. NEET (UG) 2023, 7 May, Code E1 · Question 93
    The equilibrium concentrations of the species in the reaction $\mathrm{A + B \rightleftharpoons C + D}$ are 2, 3, 10 and 6 $\mathrm{mol\ L^{-1}}$, respectively at 300 K. $\Delta G^\circ$ for the reaction is (R = 2 cal / mol K)

    1. 1372.60 cal
    2. – 137.26 cal
    3. – 1381.80 cal
    4. – 13.73 cal
    Show answer and solution

    Answer: (3)

    $K = \dfrac{[C][D]}{[A][B]} = \dfrac{10 \times 6}{2 \times 3} = 10$.
    $\Delta G^\circ = -2.303\,RT \log K = -2.303 \times 2 \times 300 \times \log 10 = -1381.8$ cal.

  10. NEET (UG) 2022, 17 July, Code Q1 · Question 83
    The pH of the solution containing 50 mL each of 0.10 M sodium acetate and 0.01 M acetic acid is
    [Given pK$_a$ of CH$_3$COOH = 4.57]

    1. 5.57
    2. 3.57
    3. 4.57
    4. 2.57
    Show answer and solution

    Answer: (1)

    This is a buffer. Henderson equation: pH $=$ p$K_a + \log\dfrac{[\text{salt}]}{[\text{acid}]} = 4.57 + \log\dfrac{0.10}{0.01} = 4.57 + 1 = 5.57$ (equal volumes, so the ratio is unchanged on mixing).

  11. NEET (UG) 2022, 17 July, Code Q1 · Question 99
    $3\text{O}_2(\text{g}) \rightleftharpoons 2\text{O}_3(\text{g})$
    for the above reaction at 298 K, K$_\text{C}$ is found to be $3.0 \times 10^{-59}$. If the concentration of O$_2$ at equilibrium is 0.040 M then concentration of O$_3$ in M is

    1. $4.38 \times 10^{-32}$
    2. $1.9 \times 10^{-63}$
    3. $2.4 \times 10^{31}$
    4. $1.2 \times 10^{21}$
    Show answer and solution

    Answer: (1)

    $K_C = \dfrac{[\text{O}_3]^2}{[\text{O}_2]^3}$, so $[\text{O}_3]^2 = 3.0 \times 10^{-59} \times (0.040)^3 = 1.92 \times 10^{-63}$.
    $[\text{O}_3] = \sqrt{1.92 \times 10^{-63}} = 4.38 \times 10^{-32}$ M.
