  1. NEET (UG) 2026, 21 June (re-exam), Code 50 · Question 47
    Given below are two statements:
    Statement-I : $\mathrm{[Fe(ox)_3]^{3-}}$ is chiral.
    Statement-II : trans – $\mathrm{[Cr(H_2O)_2(ox)_2]^-}$ is chiral.
    (Given : $\mathrm{oxH_2 = HOOC - COOH}$)
    In light of the above statements, choose the most appropriate answer from the options given below:

    1. Both Statement-I and Statement-II are correct
    2. Both Statement-I and Statement-II are incorrect
    3. Statement-I is correct but Statement-II is incorrect
    4. Statement-I is incorrect but Statement-II is correct
    Show answer and solution

    Answer: (3)

    $\mathrm{[M(AA)_3]}$ complexes such as $\mathrm{[Fe(ox)_3]^{3-}}$ have a propeller shape with no mirror plane, so they exist as $\Delta/\Lambda$ enantiomers – chiral (Statement-I correct).
    In trans-$\mathrm{[Cr(H_2O)_2(ox)_2]^-}$ both oxalates lie in one plane, which is a mirror plane – achiral (Statement-II incorrect).

  2. NEET (UG) 2026, 21 June (re-exam), Code 50 · Question 49
    In potash alum, the ratio of $\mathrm{K^+}$ and $\mathrm{SO_4^{2-}}$ ions is

    1. $1 : 2$
    2. $2 : 1$
    3. $2 : 3$
    4. $3 : 2$
    Show answer and solution

    Answer: (1)

    Potash alum is $\mathrm{K_2SO_4\cdot Al_2(SO_4)_3\cdot 24H_2O}$, i.e. $\mathrm{KAl(SO_4)_2\cdot 12H_2O}$.
    It contains 2 $\mathrm{K^+}$ for 4 $\mathrm{SO_4^{2-}}$, so $\mathrm{K^+ : SO_4^{2-}} = 1 : 2$.

  3. NEET (UG) 2026, 21 June (re-exam), Code 50 · Question 58
    According to crystal field theory, the correct order of ligands with respect to their decreasing order of field strength is

    1. $\mathrm{CO > NH_3 > H_2O > Cl^-}$
    2. $\mathrm{CO > H_2O > NH_3 > Cl^-}$
    3. $\mathrm{Cl^- > H_2O > NH_3 > CO}$
    4. $\mathrm{Cl^- > NH_3 > H_2O > CO}$
    Show answer and solution

    Answer: (1)

    In the spectrochemical series, $\mathrm{Cl^- < H_2O < NH_3 < CO}$.
    CO, a $\pi$-acceptor, is the strongest of these ligands and the halide is the weakest. So in decreasing order: $\mathrm{CO > NH_3 > H_2O > Cl^-}$.

  4. NEET (UG) 2026, 21 June (re-exam), Code 50 · Question 66
    Among the species given below, the spin-only magnetic moment is highest for
    (Given: Atomic number of Ti = 22, Mn = 25, Fe = 26 and Co = 27)

    1. $\mathrm{[Mn(CN)_6]^{3-}}$
    2. $\mathrm{[Fe(CN)_6]^{3-}}$
    3. $\mathrm{[Co(NH_3)_6]^{3+}}$
    4. $\mathrm{[Ti(H_2O)_6]^{3+}}$
    Show answer and solution

    Answer: (1)

    $\mathrm{Mn^{3+}}$ $d^4$ with strong-field $\mathrm{CN^-}$: $t_{2g}^4$, 2 unpaired electrons.
    $\mathrm{Fe^{3+}}$ $d^5$ low spin: 1 unpaired. $\mathrm{Co^{3+}}$ $d^6$ low spin: 0. $\mathrm{Ti^{3+}}$ $d^1$: 1.
    Maximum unpaired electrons (2, $\mu = \sqrt{8} \approx 2.83$ BM) in $\mathrm{[Mn(CN)_6]^{3-}}$.

  5. NEET (UG) 2026, 21 June (re-exam), Code 50 · Question 68
    The formula of tetraammineaquachloridocobalt(III) chloride is

    1. $\mathrm{[Co(NH_3)_4Cl_2]\times H_2O}$
    2. $\mathrm{[Co(NH_3)_4]Cl_3\times H_2O}$
    3. $\mathrm{[Co(NH_3)_4(H_2O)Cl]Cl}$
    4. $\mathrm{[Co(NH_3)_4(H_2O)Cl]Cl_2}$
    Show answer and solution

    Answer: (4)

    The coordination sphere has 4 $\mathrm{NH_3}$, 1 $\mathrm{H_2O}$ and 1 $\mathrm{Cl^-}$ around $\mathrm{Co^{3+}}$, giving charge $+3 - 1 = +2$.
    Two chloride counter-ions are needed: $\mathrm{[Co(NH_3)_4(H_2O)Cl]Cl_2}$.

  6. NEET (UG) 2026, 21 June (re-exam), Code 50 · Question 78
    The complex which has facial and meridional isomers is
    (Given : py = pyridine and en = $\mathrm{H_2N - CH_2 - CH_2 - NH_2}$)

    1. $\mathrm{[Cr(py)_3(Cl)_3]}$
    2. $\mathrm{[Cr(H_2O)_6]^{3+}}$
    3. $\mathrm{[Co(NH_3)_4(H_2O)_2]^{3+}}$
    4. $\mathrm{[Ni(en)_2(H_2O)_2]^{2+}}$
    Show answer and solution

    Answer: (1)

    Fac/mer isomerism occurs in octahedral complexes of the type $\mathrm{[MA_3B_3]}$.
    $\mathrm{[Cr(py)_3Cl_3]}$ is of this type: the three Cl can lie on one face (fac) or around a meridian (mer).
    The other complexes are $\mathrm{MA_6}$, $\mathrm{MA_4B_2}$ (cis/trans) and $\mathrm{M(AA)_2B_2}$ (cis/trans).

  7. NEET (UG) 2026, 21 June (re-exam), Code 50 · Question 87
    A 1 : 3 electrolyte in an aqueous solution is

    1. $\mathrm{[CoCl_2(NH_3)_4]Cl}$
    2. $\mathrm{[CoCl(NH_3)_5]Cl_2}$
    3. $\mathrm{[Co(NH_3)_6]Cl_3}$
    4. $\mathrm{[Co(NH_3)_3(NO_2)_3]}$
    Show answer and solution

    Answer: (3)

    $\mathrm{[Co(NH_3)_6]Cl_3 \rightarrow [Co(NH_3)_6]^{3+} + 3Cl^-}$ gives one complex cation and three anions, a 1 : 3 electrolyte.
    The others are 1 : 1, 1 : 2 and a non-electrolyte, respectively.

  8. NEET (UG) 2025, 4 May, Code 45 · Question 51
    Which of the following are paramagnetic?
    A. $\mathrm{[NiCl_4]^{2-}}$
    B. $\mathrm{Ni(CO)_4}$
    C. $\mathrm{[Ni(CN)_4]^{2-}}$
    D. $\mathrm{[Ni(H_2O)_6]^{2+}}$
    E. $\mathrm{Ni(PPh_3)_4}$
    Choose the $\textbf{correct}$ answer from the options given below:

    1. A and C only
    2. B and E only
    3. A and D only
    4. A, D and E only
    Show answer and solution

    Answer: (3)

    $\mathrm{[NiCl_4]^{2-}}$: Ni(II), $d^8$, weak-field $\mathrm{Cl^-}$, tetrahedral, 2 unpaired electrons – paramagnetic.
    $\mathrm{[Ni(H_2O)_6]^{2+}}$: octahedral $d^8$ ($t_{2g}^6e_g^2$), 2 unpaired – paramagnetic.
    $\mathrm{[Ni(CN)_4]^{2-}}$ is square planar $d^8$ (all paired), and $\mathrm{Ni(CO)_4}$ and $\mathrm{Ni(PPh_3)_4}$ are Ni(0), $d^{10}$ – diamagnetic. Hence A and D only.

  9. NEET (UG) 2025, 4 May, Code 45 · Question 57
    The correct order of the wavelength of light absorbed by the following complexes is,
    A. $\mathrm{[Co(NH_3)_6]^{3+}}$
    B. $\mathrm{[Co(CN)_6]^{3-}}$
    C. $\mathrm{[Cu(H_2O)_4]^{2+}}$
    D. $\mathrm{[Ti(H_2O)_6]^{3+}}$
    Choose the $\textbf{correct}$ answer from the options given below:

    1. B < D < A < C
    2. B < A < D < C
    3. C < D < A < B
    4. C < A < D < B
    Show answer and solution

    Answer: (2)

    A larger crystal field splitting $\Delta$ means the light absorbed has higher energy, i.e. a smaller $\lambda$ ($\Delta = hc/\lambda$).
    $\mathrm{CN^-}$ is stronger than $\mathrm{NH_3}$, which is stronger than $\mathrm{H_2O}$, and $\mathrm{Co^{3+}}$ complexes have large $\Delta$; $\mathrm{[Cu(H_2O)_4]^{2+}}$ has the smallest $\Delta$.
    $\Delta$: B > A > D > C, so $\lambda$ absorbed: B < A < D < C.

  10. NEET (UG) 2025, 4 May, Code 45 · Question 63
    Out of the following complex compounds, which of the compound will be having the minimum conductance in solution?

    1. $\mathrm{[Co(NH_3)_3Cl_3]}$
    2. $\mathrm{[Co(NH_3)_4Cl_2]}$
    3. $\mathrm{[Co(NH_3)_6]Cl_3}$
    4. $\mathrm{[Co(NH_3)_5Cl]Cl}$
    Show answer and solution

    Answer: (1) or (2) (either is accepted)

    Conductance depends on the number of ions given in solution.
    $\mathrm{[Co(NH_3)_6]Cl_3}$ gives 4 ions and $\mathrm{[Co(NH_3)_5Cl]Cl}$ gives 2 ions.
    $\mathrm{[Co(NH_3)_3Cl_3]}$ is a neutral complex with no ionisable chloride, so it is a non-electrolyte with minimum conductance. $\mathrm{[Co(NH_3)_4Cl_2]}$, as written, is also a neutral species giving no ions, so the NTA final key accepts both (1) and (2).

  11. NEET (UG) 2025, 4 May, Code 45 · Question 80
    Match $\textbf{List - I}$ with $\textbf{List - II}$

    List-IList-II
    A.Haber processI.Fe catalyst
    B.Wacker oxidationII.$\mathrm{PdCl_2}$
    C.Wilkinson catalystIII.$\mathrm{[(PPh_3)_3RhCl]}$
    D.Ziegler catalystIV.$\mathrm{TiCl_4}$ with $\mathrm{Al(CH_3)_3}$
    Choose the $\textbf{correct}$ answer from the options given below :

    1. A-I, B-II, C-IV, D-III
    2. A-II, B-III, C-I, D-IV
    3. A-I, B-II, C-III, D-IV
    4. A-I, B-IV, C-III, D-II
    Show answer and solution

    Answer: (3)

    The Haber process uses an iron catalyst; Wacker oxidation of ethene to ethanal uses $\mathrm{PdCl_2}$; Wilkinson's catalyst is $\mathrm{[(PPh_3)_3RhCl]}$; the Ziegler catalyst is $\mathrm{TiCl_4}$ with a trialkylaluminium.
    So A-I, B-II, C-III, D-IV.

  12. NEET (UG) 2024, 5 May, Code T1 · Question 67
    Match List I with List II.

    List I (Complex)List II (Type of isomerism)
    A.$\mathrm{\left[Co(NH_3)_5(NO_2)\right]Cl_2}$I.Solvate isomerism
    B.$\mathrm{\left[Co(NH_3)_5(SO_4)\right]Br}$II.Linkage isomerism
    C.$\mathrm{\left[Co(NH_3)_6\right]\left[Cr(CN)_6\right]}$III.Ionization isomerism
    D.$\mathrm{\left[Co(H_2O)_6\right]Cl_3}$IV.Coordination isomerism
    Choose the correct answer from the options given below:

    1. A-I, B-IV, C-III, D-II
    2. A-II, B-IV, C-III, D-I
    3. A-II, B-III, C-IV, D-I
    4. A-I, B-III, C-IV, D-II
    Show answer and solution

    Answer: (3)

    A: the ambidentate $\mathrm{NO_2^-}$ can bind through N or O, giving linkage isomers (A-II).
    B: $\mathrm{SO_4^{2-}}$ inside and $\mathrm{Br^-}$ outside can exchange places, giving ionisation isomers (B-III).
    C: both ions are complex, so ligands can be exchanged between Co and Cr, giving coordination isomers (C-IV).
    D: water can be inside or outside the coordination sphere, e.g. $\mathrm{[Co(H_2O)_5Cl]Cl_2\cdot H_2O}$, giving solvate (hydrate) isomers (D-I).

  13. NEET (UG) 2024, 5 May, Code T1 · Question 81
    Given below are two statements :
    $\textbf{Statement I :}$ Both $\mathrm{\left[Co(NH_3)_6\right]^{3+}}$ and $\mathrm{\left[CoF_6\right]^{3-}}$ complexes are octahedral but differ in their magnetic behaviour.
    $\textbf{Statement II :}$ $\mathrm{\left[Co(NH_3)_6\right]^{3+}}$ is diamagnetic whereas $\mathrm{\left[CoF_6\right]^{3-}}$ is paramagnetic.
    In the light of the above statements, choose the $\textit{correct}$ answer from the options given below:

    1. Statement I is true but Statement II is false.
    2. Statement I is false but Statement II is true.
    3. Both Statement I and Statement II are true.
    4. Both Statement I and Statement II are false.
    Show answer and solution

    Answer: (3)

    Both complexes contain $\mathrm{Co^{3+}}$ ($3d^6$) with six ligands, so both are octahedral.
    $\mathrm{NH_3}$ is a strong field ligand: the six $d$ electrons pair up in the $t_{2g}$ set ($d^2sp^3$, inner orbital), so $\mathrm{[Co(NH_3)_6]^{3+}}$ is diamagnetic.
    $\mathrm{F^-}$ is a weak field ligand: $t_{2g}^4e_g^2$ with four unpaired electrons ($sp^3d^2$, outer orbital), so $\mathrm{[CoF_6]^{3-}}$ is paramagnetic. Both statements are true.

  14. NEET (UG) 2024, 5 May, Code T1 · Question 99
    Given below are two statements :
    $\textbf{Statement I :}$ $\mathrm{\left[Co(NH_3)_6\right]^{3+}}$ is a homoleptic complex whereas $\mathrm{\left[Co(NH_3)_4Cl_2\right]^{+}}$ is a heteroleptic complex.
    $\textbf{Statement II :}$ Complex $\mathrm{\left[Co(NH_3)_6\right]^{3+}}$ has only one kind of ligands but $\mathrm{\left[Co(NH_3)_4Cl_2\right]^{+}}$ has more than one kind of ligands.
    In the light of the above statements, choose the $\textit{correct}$ answer from the options given below:

    1. Statement I is true but Statement II is false.
    2. Statement I is false but Statement II is true.
    3. Both Statement I and Statement II are true.
    4. Both Statement I and Statement II are false.
    Show answer and solution

    Answer: (3)

    A homoleptic complex has only one kind of ligand and a heteroleptic complex has more than one kind.
    $\mathrm{[Co(NH_3)_6]^{3+}}$ has only $\mathrm{NH_3}$ (homoleptic), while $\mathrm{[Co(NH_3)_4Cl_2]^+}$ has $\mathrm{NH_3}$ and $\mathrm{Cl^-}$ (heteroleptic). Both statements are true.

  15. NEET (UG) 2023, 7 May, Code E1 · Question 80
    Homoleptic complex from the following complexes is :

    1. Potassium trioxalatoaluminate (III)
    2. Diamminechloridonitrito - N - platinum (II)
    3. Pentaamminecarbonatocobalt (III) chloride
    4. Triamminetriaquachromium (III) chloride
    Show answer and solution

    Answer: (1)

    A homoleptic complex has only one kind of ligand round the metal.
    Potassium trioxalatoaluminate(III), $\mathrm{K_3[Al(C_2O_4)_3]}$, has only oxalate ligands. The others have two or more kinds of ligand ($\mathrm{NH_3}$, $\mathrm{Cl^-}$, $\mathrm{NO_2^-}$; $\mathrm{NH_3}$, $\mathrm{CO_3^{2-}}$; $\mathrm{NH_3}$, $\mathrm{H_2O}$), so they are heteroleptic.

  16. NEET (UG) 2023, 7 May, Code E1 · Question 88
    Which complex compound is most stable?

    1. $\mathrm{[Co(NH_3)_4(H_2O)Br](NO_3)_2}$
    2. $\mathrm{[Co(NH_3)_3(NO_3)_3]}$
    3. $\mathrm{[CoCl_2(en)_2]NO_3}$
    4. $\mathrm{[Co(NH_3)_6]_2(SO_4)_3}$
    Show answer and solution

    Answer: (3)

    Chelating ligands form rings with the metal and give much more stable complexes than similar monodentate ligands (the chelate effect).
    Only $\mathrm{[CoCl_2(en)_2]NO_3}$ contains a chelating ligand (ethane-1,2-diamine, bidentate), so it is the most stable.
