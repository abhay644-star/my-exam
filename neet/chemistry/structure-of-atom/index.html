  1. NEET (UG) 2026, 21 June (re-exam), Code 50 · Question 88
    Consider the following schematic plots of orbital wavefunction ($\psi_r$) against distance (r) from the nucleus.
    The figure representing two radial nodes in the orbital is

    1. A
    2. B
    3. C
    4. D
    Show answer and solution

    Answer: (3)

    A radial node is a point at $r > 0$ where $\psi_r$ changes sign.
    A: no crossing (0 nodes, e.g. 1s). B: one crossing (e.g. 2s). C: crosses zero twice (2 radial nodes, e.g. 3s). D: starts at zero at $r = 0$, which is not a radial node, and crosses once (e.g. 3p).
    Answer: C.

  2. NEET (UG) 2025, 4 May, Code 45 · Question 46
    The ratio of the wavelengths of the light absorbed by a Hydrogen atom when it undergoes $n = 2 \rightarrow n = 3$ and $n = 4 \rightarrow n = 6$ transitions, respectively, is

    1. $\dfrac{1}{36}$
    2. $\dfrac{1}{16}$
    3. $\dfrac{1}{9}$
    4. $\dfrac{1}{4}$
    Show answer and solution

    Answer: (4)

    $\dfrac{1}{\lambda} = R\left(\dfrac{1}{n_1^2} - \dfrac{1}{n_2^2}\right)$.
    $2\rightarrow3$: $\dfrac{1}{4} - \dfrac{1}{9} = \dfrac{5}{36}$. $4\rightarrow6$: $\dfrac{1}{16} - \dfrac{1}{36} = \dfrac{5}{144}$.
    $\dfrac{\lambda_1}{\lambda_2} = \dfrac{5/144}{5/36} = \dfrac{1}{4}$.

  3. NEET (UG) 2025, 4 May, Code 45 · Question 50
    Energy and radius of first Bohr orbit of $\mathrm{He^+}$ and $\mathrm{Li^{2+}}$ are
    [Given $R_H = 2.18\times10^{-18}$ J, $a_0$ = 52.9 pm]

    1. $E_n(\mathrm{Li^{2+}}) = -19.62\times10^{-18}$ J; $r_n(\mathrm{Li^{2+}})$ = 17.6 pm
      $E_n(\mathrm{He^+}) = -8.72\times10^{-18}$ J; $r_n(\mathrm{He^+})$ = 26.4 pm
    2. $E_n(\mathrm{Li^{2+}}) = -8.72\times10^{-18}$ J; $r_n(\mathrm{Li^{2+}})$ = 26.4 pm
      $E_n(\mathrm{He^+}) = -19.62\times10^{-18}$ J; $r_n(\mathrm{He^+})$ = 17.6 pm
    3. $E_n(\mathrm{Li^{2+}}) = -19.62\times10^{-16}$ J; $r_n(\mathrm{Li^{2+}})$ = 17.6 pm
      $E_n(\mathrm{He^+}) = -8.72\times10^{-16}$ J; $r_n(\mathrm{He^+})$ = 26.4 pm
    4. $E_n(\mathrm{Li^{2+}}) = -8.72\times10^{-16}$ J; $r_n(\mathrm{Li^{2+}})$ = 17.6 pm
      $E_n(\mathrm{He^+}) = -19.62\times10^{-16}$ J; $r_n(\mathrm{He^+})$ = 17.6 pm
    Show answer and solution

    Answer: (1)

    For $n = 1$: $E = -R_H Z^2$ and $r = a_0/Z$.
    $\mathrm{Li^{2+}}$ ($Z = 3$): $E = -9\times2.18\times10^{-18} = -19.62\times10^{-18}$ J; $r = 52.9/3 = 17.6$ pm.
    $\mathrm{He^+}$ ($Z = 2$): $E = -4\times2.18\times10^{-18} = -8.72\times10^{-18}$ J; $r = 52.9/2 \approx 26.4$ pm.
