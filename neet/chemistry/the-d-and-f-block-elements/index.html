  1. NEET (UG) 2026, 21 June (re-exam), Code 50 · Question 61
    Given below are two statements: One is labelled as Assertion A and the other is labelled as Reason R.
    Assertion A: Generally, 3$d$ transition metals have high melting points.
    Reason R: Involvement of 3$d$-electrons in addition to 4$s$-electrons in the interatomic metallic bonding.
    In light of the above statements, choose the most appropriate answer from the options given below:

    1. Both A and R are correct and R is the correct explanation of A
    2. Both A and R are correct and R is NOT the correct explanation of A
    3. A is correct but R is not correct.
    4. A is not correct but R is correct
    Show answer and solution

    Answer: (1)

    In transition metals, unpaired $(n-1)d$ electrons join the $ns$ electrons in metallic bonding. This gives strong metallic bonds and so high melting points.
    Both A and R are correct, and R explains A.

  2. NEET (UG) 2026, 21 June (re-exam), Code 50 · Question 67
    The lanthanide ion having four unpaired electrons is
    (Given : Atomic numbers of Ce = 58, Nd = 60, Tb = 65 and Ho = 67)

    1. $\mathrm{Nd^{3+}}$
    2. $\mathrm{Ce^{3+}}$
    3. $\mathrm{Tb^{3+}}$
    4. $\mathrm{Ho^{3+}}$
    Show answer and solution

    Answer: (4)

    $\mathrm{Ln^{3+}}$ configurations: $\mathrm{Ce^{3+}}$ $4f^1$ (1 unpaired), $\mathrm{Nd^{3+}}$ $4f^3$ (3), $\mathrm{Tb^{3+}}$ $4f^8$ (6), $\mathrm{Ho^{3+}}$ $4f^{10}$ (4).
    So $\mathrm{Ho^{3+}}$ has four unpaired electrons.

  3. NEET (UG) 2026, 21 June (re-exam), Code 50 · Question 85
    The green paramagnetic species formed by heating $\mathrm{KMnO_4}$ at 513 K is

    1. $\mathrm{K_2MnO_4}$
    2. $\mathrm{Mn_3O_4}$
    3. $\mathrm{MnO}$
    4. $\mathrm{KO_2}$
    Show answer and solution

    Answer: (1)

    $\mathrm{2KMnO_4 \xrightarrow{513\,K} K_2MnO_4 + MnO_2 + O_2}$.
    Manganate, $\mathrm{MnO_4^{2-}}$ (Mn +6, $d^1$), is green and paramagnetic with one unpaired electron.

  4. NEET (UG) 2025, 4 May, Code 45 · Question 71
    Given below are two statements :
    $\textbf{Statement I :}$ Ferromagnetism is considered as an extreme form of paramagnetism.
    $\textbf{Statement II :}$ The number of unpaired electrons in a $\mathrm{Cr^{2+}}$ ion (Z = 24) is the same as that of a $\mathrm{Nd^{3+}}$ ion (Z = 60).
    In the light of the above statements, choose the $\textbf{correct}$ answer from the options given below :

    1. Both Statement I and Statement II are true
    2. Both Statement I and Statement II are false
    3. Statement I is true but Statement II is false
    4. Statement I is false but Statement II is true
    Show answer and solution

    Answer: (3)

    Ferromagnetism is an extreme form of paramagnetism in which the magnetic moments of many atoms align together, so Statement I is true.
    $\mathrm{Cr^{2+}}$ is $3d^4$ with 4 unpaired electrons; $\mathrm{Nd^{3+}}$ is $4f^3$ with 3 unpaired electrons, so Statement II is false.

  5. NEET (UG) 2024, 5 May, Code T1 · Question 56
    ‘Spin only’ magnetic moment is same for which of the following ions?
    A. $\mathrm{Ti^{3+}}$
    B. $\mathrm{Cr^{2+}}$
    C. $\mathrm{Mn^{2+}}$
    D. $\mathrm{Fe^{2+}}$
    E. $\mathrm{Sc^{3+}}$
    Choose the most appropriate answer from the options given below:

    1. B and C only
    2. A and D only
    3. B and D only
    4. A and E only
    Show answer and solution

    Answer: (3)

    Unpaired electrons: $\mathrm{Ti^{3+}}$ ($3d^1$) 1; $\mathrm{Cr^{2+}}$ ($3d^4$) 4; $\mathrm{Mn^{2+}}$ ($3d^5$) 5; $\mathrm{Fe^{2+}}$ ($3d^6$) 4; $\mathrm{Sc^{3+}}$ ($3d^0$) 0.
    $\mathrm{Cr^{2+}}$ and $\mathrm{Fe^{2+}}$ both have 4 unpaired electrons, so both have $\mu = \sqrt{4(4+2)} = 4.90$ BM. So B and D only.

  6. NEET (UG) 2024, 5 May, Code T1 · Question 65
    The E° value for the $\mathrm{Mn^{3+}/Mn^{2+}}$ couple is more positive than that of $\mathrm{Cr^{3+}/Cr^{2+}}$ or $\mathrm{Fe^{3+}/Fe^{2+}}$ due to change of

    1. $\mathrm{d^4}$ to $\mathrm{d^5}$ configuration
    2. $\mathrm{d^3}$ to $\mathrm{d^5}$ configuration
    3. $\mathrm{d^5}$ to $\mathrm{d^4}$ configuration
    4. $\mathrm{d^5}$ to $\mathrm{d^2}$ configuration
    Show answer and solution

    Answer: (1)

    $\mathrm{Mn^{3+}}$ is $3d^4$ and $\mathrm{Mn^{2+}}$ is $3d^5$. Reduction gives the extra-stable half-filled $d^5$ configuration, so $\mathrm{Mn^{3+}}$ is readily reduced and $E^\circ(\mathrm{Mn^{3+}/Mn^{2+}})$ is strongly positive (+1.57 V).

  7. NEET (UG) 2024, 5 May, Code T1 · Question 98
    The pair of lanthanoid ions which are diamagnetic is

    1. $\mathrm{Gd^{3+}}$ and $\mathrm{Eu^{3+}}$
    2. $\mathrm{Pm^{3+}}$ and $\mathrm{Sm^{3+}}$
    3. $\mathrm{Ce^{4+}}$ and $\mathrm{Yb^{2+}}$
    4. $\mathrm{Ce^{3+}}$ and $\mathrm{Eu^{2+}}$
    Show answer and solution

    Answer: (3)

    A diamagnetic ion has no unpaired electrons: an empty ($4f^0$) or full ($4f^{14}$) $4f$ subshell.
    $\mathrm{Ce^{4+}}$ is $4f^0$ and $\mathrm{Yb^{2+}}$ is $4f^{14}$, so both are diamagnetic. The other ions ($\mathrm{Gd^{3+}}$ $4f^7$, $\mathrm{Eu^{3+}}$ $4f^6$, $\mathrm{Pm^{3+}}$ $4f^4$, $\mathrm{Sm^{3+}}$ $4f^5$, $\mathrm{Ce^{3+}}$ $4f^1$, $\mathrm{Eu^{2+}}$ $4f^7$) have unpaired electrons.

  8. NEET (UG) 2023, 7 May, Code E1 · Question 74
    The stability of $\mathrm{Cu^{2+}}$ is more than $\mathrm{Cu^+}$ salts in aqueous solution due to -

    1. first ionisation enthalpy.
    2. enthalpy of atomization.
    3. hydration energy.
    4. second ionisation enthalpy.
    Show answer and solution

    Answer: (3)

    Forming $\mathrm{Cu^{2+}}$ needs the extra second ionisation enthalpy, but the small, highly charged $\mathrm{Cu^{2+}}$ ion has a much more negative hydration enthalpy ($\Delta_{hyd}H^\circ$), which more than makes up for it. So $\mathrm{Cu^{2+}}$ is more stable in water because of its hydration energy.

  9. NEET (UG) 2023, 7 May, Code E1 · Question 87
    Which of the following statements are $\textbf{INCORRECT}$?
    A. All the transition metals except scandium form MO oxides which are ionic.
    B. The highest oxidation number corresponding to the group number in transition metal oxides is attained in $\mathrm{Sc_2O_3}$ to $\mathrm{Mn_2O_7}$.
    C. Basic character increases from $\mathrm{V_2O_3}$ to $\mathrm{V_2O_4}$ to $\mathrm{V_2O_5}$.
    D. $\mathrm{V_2O_4}$ dissolves in acids to give $\mathrm{VO_4^{3-}}$ salts.
    E. CrO is basic but $\mathrm{Cr_2O_3}$ is amphoteric.
    Choose the $\textbf{correct}$ answer from the options given below :

    1. A and E only
    2. B and D only
    3. C and D only
    4. B and C only
    Show answer and solution

    Answer: (3)

    A, B and E are correct statements from NCERT.
    C is incorrect: as the oxidation state of vanadium rises, the oxides become more acidic, so basic character decreases from $\mathrm{V_2O_3}$ to $\mathrm{V_2O_4}$ to $\mathrm{V_2O_5}$.
    D is incorrect: $\mathrm{V_2O_4}$ dissolves in acids to give $\mathrm{VO^{2+}}$ salts.
    So C and D only.
