  1. NEET (UG) 2026, 21 June (re-exam), Code 50 · Question 60
    $2\mathrm{A}\xrightarrow{k}\mathrm{B}$ is a zero-order reaction, where $k = 1.0\ \mathrm{mol\ L^{-1}\ min^{-1}}$. If the initial concentration of A is 2 M, then the time taken to complete 75% of the reaction will be

    1. 1.5 min
    2. 0.75 min
    3. 1.0 min
    4. 2.0 min
    Show answer and solution

    Answer: (2)

    For $2\mathrm{A}\rightarrow\mathrm{B}$, rate $= -\dfrac{1}{2}\dfrac{d[\mathrm{A}]}{dt} = k$, so [A] falls at the rate $2k = 2.0\ \mathrm{M\ min^{-1}}$.
    75% of 2 M is 1.5 M of A consumed: $t = 1.5/2.0 = 0.75$ min.

  2. NEET (UG) 2026, 21 June (re-exam), Code 50 · Question 64
    For an elementary chemical reaction, the Arrhenius plot is given below.
    If the energy of activation is 6.64 kJ mol$^{-1}$ and R = 8.3 J K$^{-1}$ mol$^{-1}$, the temperature at which the rate constant becomes $e^2$ min$^{-1}$, is

    1. 125 K
    2. 150 K
    3. 200 K
    4. 250 K
    Show answer and solution

    Answer: (3)

    $\ln k = \ln A - \dfrac{E_a}{RT}$. The intercept (at $1/T = 0$) is $\ln A = 6$.
    For $k = e^2$: $2 = 6 - \dfrac{6640}{8.3\,T}$, so $\dfrac{800}{T} = 4$ and $T = 200$ K.

  3. NEET (UG) 2025, 4 May, Code 45 · Question 56
    If the half-life ($t_{1/2}$) for a first order reaction is 1 minute, then the time required for 99.9% completion of the reaction is closest to :

    1. 2 minutes
    2. 4 minutes
    3. 5 minutes
    4. 10 minutes
    Show answer and solution

    Answer: (4)

    $t = \dfrac{2.303}{k}\log\dfrac{100}{0.1} = \dfrac{2.303\times3}{0.693/t_{1/2}} \approx 9.97\,t_{1/2}$.
    With $t_{1/2} = 1$ min, $t \approx 10$ minutes.

  4. NEET (UG) 2025, 4 May, Code 45 · Question 89
    If the rate constant of a reaction is 0.03 s$^{-1}$, how much time does it take for 7.2 mol L$^{-1}$ concentration of the reactant to get reduced to 0.9 mol L$^{-1}$?
    (Given: log 2 = 0.301)

    1. 69.3 s
    2. 23.1 s
    3. 210 s
    4. 21.0 s
    Show answer and solution

    Answer: (1)

    The unit s$^{-1}$ shows a first order reaction, so $t_{1/2} = \dfrac{0.693}{0.03} = 23.1$ s.
    $7.2 \rightarrow 3.6 \rightarrow 1.8 \rightarrow 0.9$ is three half-lives: $t = 3\times23.1 = 69.3$ s.

  5. NEET (UG) 2024, 5 May, Code T1 · Question 59
    Activation energy of any chemical reaction can be calculated if one knows the value of

    1. orientation of reactant molecules during collision.
    2. rate constant at two different temperatures.
    3. rate constant at standard temperature.
    4. probability of collision.
    Show answer and solution

    Answer: (2)

    From the Arrhenius equation, $\log\dfrac{k_2}{k_1} = \dfrac{E_a}{2.303R}\left(\dfrac{1}{T_1} - \dfrac{1}{T_2}\right)$, so $E_a$ can be found from the rate constants at two different temperatures.

  6. NEET (UG) 2024, 5 May, Code T1 · Question 60
    Which plot of ln k vs $\dfrac{1}{\text{T}}$ is consistent with Arrhenius equation?

    Show answer and solution

    Answer: (2)

    $\ln k = \ln A - \dfrac{E_a}{R}\cdot\dfrac{1}{T}$. A plot of $\ln k$ against $1/T$ is a straight line with a negative slope ($-E_a/R$) and a positive intercept ($\ln A$) on the $\ln k$ axis: graph (2).

  7. NEET (UG) 2024, 5 May, Code T1 · Question 96
    The rate of a reaction quadruples when temperature changes from 27°C to 57°C. Calculate the energy of activation.
    Given R = 8.314 J $\mathrm{K^{-1}\ mol^{-1}}$, log 4 = 0.6021

    1. 3.80 kJ/mol
    2. 3804 kJ/mol
    3. 38.04 kJ/mol
    4. 380.4 kJ/mol
    Show answer and solution

    Answer: (3)

    $\log\dfrac{k_2}{k_1} = \dfrac{E_a}{2.303R}\left(\dfrac{T_2 - T_1}{T_1T_2}\right)$ with $T_1 = 300$ K, $T_2 = 330$ K.
    $0.6021 = \dfrac{E_a}{2.303 \times 8.314} \times \dfrac{30}{300 \times 330}$
    $E_a = \dfrac{0.6021 \times 2.303 \times 8.314 \times 3300}{1} \approx 38\,044$ J mol$^{-1}$ $= 38.04$ kJ/mol.
