  1. NEET (UG) 2026, 21 June (re-exam), Code 50 · Question 75
    Match the species in List-I with their geometry in List-II.

    List-IList-II
    A.$\mathrm{PCl_5}$I.Tetrahedral
    B.$\mathrm{BrF_5}$II.Square Planar
    C.$\mathrm{BF_4^-}$III.Trigonal bipyramidal
    D.$\mathrm{[Ni(CN)_4]^{2-}}$IV.Square pyramidal
    Choose the correct answer from the options given below:

    1. A-IV, B-III, C-I, D-II
    2. A-III, B-IV, C-I, D-II
    3. A-III, B-I, C-II, D-IV
    4. A-III, B-II, C-I, D-IV
    Show answer and solution

    Answer: (2)

    $\mathrm{PCl_5}$: $sp^3d$, 5 bond pairs, trigonal bipyramidal (III).
    $\mathrm{BrF_5}$: 5 bond pairs + 1 lone pair, square pyramidal (IV).
    $\mathrm{BF_4^-}$: $sp^3$, tetrahedral (I).
    $\mathrm{[Ni(CN)_4]^{2-}}$: $\mathrm{Ni^{2+}}$ $d^8$ with a strong field, $dsp^2$, square planar (II).

  2. NEET (UG) 2026, 21 June (re-exam), Code 50 · Question 89
    Arrange the following compounds in the increasing order of polarity
    A. $\mathrm{CH_3CH_2OCH_2CH_3}$
    B. $\mathrm{CH_3CH_2OH}$
    C. $\mathrm{CH_3COCH_3}$
    D. $\mathrm{CH_3COOH}$
    Choose the correct answer from the options given below.

    1. A $<$ B $<$ C $<$ D
    2. C $<$ A $<$ D $<$ B
    3. C $<$ A $<$ B $<$ D
    4. A $<$ C $<$ B $<$ D
    Show answer and solution

    Answer: (4)

    Diethyl ether, with a weakly polar C–O–C, is the least polar.
    Acetone has a strongly polar C=O.
    Ethanol is more polar still because its O–H can hydrogen-bond.
    Acetic acid, with both C=O and O–H, is the most polar.
    Order: A $<$ C $<$ B $<$ D.

  3. NEET (UG) 2026, 21 June (re-exam), Code 50 · Question 90
    The highest occupied molecular orbital for $\mathrm{Ne_2}$ is

    1. $\pi_{2p}$
    2. $\sigma_{2p}$
    3. $\pi^*_{2p}$
    4. $\sigma^*_{2p}$
    Show answer and solution

    Answer: (4)

    $\mathrm{Ne_2}$ has 20 electrons: $\sigma_{1s}^2\sigma^{*2}_{1s}\sigma_{2s}^2\sigma^{*2}_{2s}\sigma_{2p_z}^2\pi_{2p}^4\pi^{*4}_{2p}\sigma^{*2}_{2p_z}$.
    The last orbital filled is $\sigma^*_{2p}$, which is the HOMO (bond order 0).

  4. NEET (UG) 2025, 4 May, Code 45 · Question 62
    Given below are two statements :
    $\textbf{Statement I :}$ A hypothetical diatomic molecule with bond order zero is quite stable.
    $\textbf{Statement II :}$ As bond order increases, the bond length increases.
    In the light of the above statements, choose the $\textbf{most appropriate}$ answer from the options given below :

    1. Both Statement I and Statement II are true
    2. Both Statement I and Statement II are false
    3. Statement I is true but Statement II is false
    4. Statement I is false but Statement II is true
    Show answer and solution

    Answer: (2)

    A bond order of zero means no net bonding, so such a molecule does not exist (e.g. $\mathrm{He_2}$): Statement I is false.
    A higher bond order means a stronger, shorter bond, so bond length decreases: Statement II is false.

  5. NEET (UG) 2025, 4 May, Code 45 · Question 64
    Match $\textbf{List - I}$ with $\textbf{List - II}$

    List-IList-II
    A.$\mathrm{XeO_3}$I.$sp^3d$; linear
    B.$\mathrm{XeF_2}$II.$sp^3$; pyramidal
    C.$\mathrm{XeOF_4}$III.$sp^3d^3$; distorted octahedral
    D.$\mathrm{XeF_6}$IV.$sp^3d^2$; square pyramidal
    Choose the $\textbf{correct}$ answer from the options given below :

    1. A-II, B-I, C-IV, D-III
    2. A-II, B-I, C-III, D-IV
    3. A-IV, B-II, C-III, D-I
    4. A-IV, B-II, C-I, D-III
    Show answer and solution

    Answer: (1)

    $\mathrm{XeO_3}$: 3 bond pairs + 1 lone pair, $sp^3$, pyramidal.
    $\mathrm{XeF_2}$: 2 bond pairs + 3 lone pairs, $sp^3d$, linear.
    $\mathrm{XeOF_4}$: 5 bond pairs + 1 lone pair, $sp^3d^2$, square pyramidal.
    $\mathrm{XeF_6}$: 6 bond pairs + 1 lone pair, $sp^3d^3$, distorted octahedral.
    So A-II, B-I, C-IV, D-III.

  6. NEET (UG) 2025, 4 May, Code 45 · Question 87
    Identify the correct orders against the property mentioned
    A. $\mathrm{H_2O > NH_3 > CHCl_3}$ – dipole moment
    B. $\mathrm{XeF_4 > XeO_3 > XeF_2}$ – number of lone pairs on central atom
    C. O–H > C–H > N–O – bond length
    D. $\mathrm{N_2 > O_2 > H_2}$ – bond enthalpy
    Choose the $\textbf{correct}$ answer from the options given below :

    1. A, D only
    2. B, D only
    3. A, C only
    4. B, C only
    Show answer and solution

    Answer: (1)

    A: dipole moments are $\mathrm{H_2O}$ 1.85 D > $\mathrm{NH_3}$ 1.47 D > $\mathrm{CHCl_3}$ about 1.0 D – correct.
    B: lone pairs on Xe are $\mathrm{XeF_2}$ 3, $\mathrm{XeF_4}$ 2, $\mathrm{XeO_3}$ 1, so the order given is wrong.
    C: the O–H bond (about 96 pm) is shorter than C–H (about 109 pm) – wrong.
    D: bond enthalpies $\mathrm{N_2}$ 946 > $\mathrm{O_2}$ 498 > $\mathrm{H_2}$ 436 kJ mol$^{-1}$ – correct. Hence A, D only.

  7. NEET (UG) 2024, 5 May, Code T1 · Question 53
    Match List I with List II.

    List I
    (Molecule)    		List II
    (Number and types of bond/s between two carbon atoms)
    A.ethaneI.one $\sigma$-bond and two $\pi$-bonds
    B.etheneII.two $\pi$-bonds
    C.carbon molecule, $\mathrm{C_2}$III.one $\sigma$-bond
    D.ethyneIV.one $\sigma$-bond and one $\pi$-bond
    Choose the correct answer from the options given below:

    1. A-III, B-IV, C-II, D-I
    2. A-III, B-IV, C-I, D-II
    3. A-I, B-IV, C-II, D-III
    4. A-IV, B-III, C-II, D-I
    Show answer and solution

    Answer: (1)

    Ethane has a C–C single bond: one $\sigma$ (A-III). Ethene has C=C: one $\sigma$ and one $\pi$ (B-IV). In $\mathrm{C_2}$ (molecular orbital theory) both bonds are $\pi$ bonds (C-II). Ethyne has C≡C: one $\sigma$ and two $\pi$ (D-I).

  8. NEET (UG) 2024, 5 May, Code T1 · Question 66
    Match List I with List II.

    List I
    (Compound)    		List II
    (Shape/geometry)
    A.$\mathrm{NH_3}$I.Trigonal Pyramidal
    B.$\mathrm{BrF_5}$II.Square Planar
    C.$\mathrm{XeF_4}$III.Octahedral
    D.$\mathrm{SF_6}$IV.Square Pyramidal
    Choose the correct answer from the options given below:

    1. A-III, B-IV, C-I, D-II
    2. A-II, B-III, C-IV, D-I
    3. A-I, B-IV, C-II, D-III
    4. A-II, B-IV, C-III, D-I
    Show answer and solution

    Answer: (3)

    By VSEPR theory: $\mathrm{NH_3}$ (3 bond pairs, 1 lone pair) is trigonal pyramidal (A-I); $\mathrm{BrF_5}$ (5 bp, 1 lp) is square pyramidal (B-IV); $\mathrm{XeF_4}$ (4 bp, 2 lp) is square planar (C-II); $\mathrm{SF_6}$ (6 bp) is octahedral (D-III).

  9. NEET (UG) 2024, 5 May, Code T1 · Question 68
    Intramolecular hydrogen bonding is present in

    Show answer and solution

    Answer: (3)

    Intramolecular hydrogen bonding needs the H-bond donor and acceptor close together in the same molecule. In o-nitrophenol (option 3) the –OH and –$\mathrm{NO_2}$ groups are on adjacent carbons and form a six-membered hydrogen-bonded ring.
    m- and p-nitrophenol and HF form only intermolecular hydrogen bonds.

  10. NEET (UG) 2024, 5 May, Code T1 · Question 97
    Identify the $\textbf{correct}$ answer.

    1. Dipole moment of $\mathrm{NF_3}$ is greater than that of $\mathrm{NH_3}$.
    2. Three canonical forms can be drawn for $\mathrm{CO_3^{2-}}$ ion.
    3. Three resonance structures can be drawn for ozone.
    4. $\mathrm{BF_3}$ has non-zero dipole moment.
    Show answer and solution

    Answer: (2)

    The carbonate ion has three equivalent canonical forms (the C=O double bond can be on any of the three oxygens), so (2) is correct.
    (1) is wrong: in $\mathrm{NH_3}$ the lone pair moment adds to the N–H bond moments, but in $\mathrm{NF_3}$ it opposes the N–F bond moments, so $\mathrm{NH_3}$ has the larger dipole moment. (3) is wrong: ozone has two resonance structures. (4) is wrong: trigonal planar $\mathrm{BF_3}$ has zero dipole moment.
