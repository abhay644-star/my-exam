  1. NEET (UG) 2026, 21 June (re-exam), Code 50 · Question 56
    The standard electrode potential (E°) for the half-cell reaction $\mathrm{Fe^{3+} + e^- \rightarrow Fe^{2+}}$ at 298 K is
    (Given : $E^\circ(\mathrm{Fe^{3+}/Fe}) = -0.04$ V and $E^\circ(\mathrm{Fe^{2+}/Fe}) = -0.44$ V at 298 K)

    1. +0.40 V
    2. +0.76 V
    3. –0.48 V
    4. +0.92 V
    Show answer and solution

    Answer: (2)

    Add free energies: $\mathrm{Fe^{3+} + 3e^- \rightarrow Fe}$: $\Delta G^\circ = -3F(-0.04) = +0.12F$.
    $\mathrm{Fe \rightarrow Fe^{2+} + 2e^-}$: $\Delta G^\circ = +2F(-0.44) = -0.88F$.
    Sum: $\mathrm{Fe^{3+} + e^- \rightarrow Fe^{2+}}$, $\Delta G^\circ = -0.76F = -1\cdot F E^\circ$, so $E^\circ = +0.76$ V.

  2. NEET (UG) 2026, 21 June (re-exam), Code 50 · Question 62
    For a salt XY, which is a strong electrolyte, the plot of $\Lambda_m$ versus $\sqrt{c}$ has a slope of $-90.0\ \mathrm{S\ cm^2\ mol^{-3/2}\ L^{1/2}}$ at 298 K. At 0.01 M concentration of XY, the value of $\Lambda_m$ is $145.0\ \mathrm{S\ cm^2\ mol^{-1}}$. The limiting molar conductivity of $\mathrm{Y^-}$ ion ($\lambda^0_{\mathrm{Y^-}}$, in $\mathrm{S\ cm^2\ mol^{-1}}$) at 298 K will be
    (Given : $\lambda^0_{\mathrm{X^+}} = 74.0\ \mathrm{S\ cm^2\ mol^{-1}}$)

    1. 80.0
    2. 100.0
    3. 90.0
    4. 76.0
    Show answer and solution

    Answer: (1)

    Kohlrausch: $\Lambda_m = \Lambda_m^0 - A\sqrt{c}$, so $145.0 = \Lambda_m^0 - 90.0\times\sqrt{0.01} = \Lambda_m^0 - 9.0$, which gives $\Lambda_m^0 = 154.0$.
    $\lambda^0_{\mathrm{Y^-}} = 154.0 - 74.0 = 80.0\ \mathrm{S\ cm^2\ mol^{-1}}$.

  3. NEET (UG) 2025, 4 May, Code 45 · Question 61
    If the molar conductivity $(\Lambda_m)$ of a 0.050 mol $\mathrm{L^{-1}}$ solution of a monobasic weak acid is 90 S cm$^2$ mol$^{-1}$, its extent (degree) of dissociation will be
    [Assume $\Lambda^\circ_+ = 349.6$ S cm$^2$ mol$^{-1}$ and $\Lambda^\circ_- = 50.4$ S cm$^2$ mol$^{-1}$.]

    1. 0.115
    2. 0.125
    3. 0.225
    4. 0.215
    Show answer and solution

    Answer: (3)

    $\Lambda^\circ_m = 349.6 + 50.4 = 400$ S cm$^2$ mol$^{-1}$.
    $\alpha = \dfrac{\Lambda_m}{\Lambda^\circ_m} = \dfrac{90}{400} = 0.225$.

  4. NEET (UG) 2024, 5 May, Code T1 · Question 85
    Match List I with List II.

    List I
    (Conversion)    		List II
    (Number of Faraday required)
    A.1 mol of $\mathrm{H_2O}$ to $\mathrm{O_2}$I.3F
    B.1 mol of $\mathrm{MnO_4^-}$ to $\mathrm{Mn^{2+}}$II.2F
    C.1.5 mol of Ca from molten $\mathrm{CaCl_2}$III.1F
    D.1 mol of FeO to $\mathrm{Fe_2O_3}$IV.5F
    Choose the correct answer from the options given below:

    1. A-II, B-III, C-I, D-IV
    2. A-III, B-IV, C-II, D-I
    3. A-II, B-IV, C-I, D-III
    4. A-III, B-IV, C-I, D-II
    Show answer and solution

    Answer: (3)

    A: $\mathrm{H_2O \rightarrow \tfrac{1}{2}O_2 + 2H^+ + 2e^-}$: 2F (A-II).
    B: Mn goes from +7 to +2: 5F (B-IV).
    C: $\mathrm{Ca^{2+} + 2e^- \rightarrow Ca}$; 1.5 mol needs $1.5 \times 2 = 3$F (C-I).
    D: Fe goes from +2 in FeO to +3 in $\mathrm{Fe_2O_3}$: 1F per mol (D-III).

  5. NEET (UG) 2024, 5 May, Code T1 · Question 100
    Mass in grams of copper deposited by passing 9.6487 A current through a voltmeter containing copper sulphate solution for 100 seconds is:
    (Given : Molar mass of Cu : 63 g $\mathrm{mol^{-1}}$, 1F = 96487 C)

    1. 31.5 g
    2. 0.0315 g
    3. 3.15 g
    4. 0.315 g
    Show answer and solution

    Answer: (4)

    Charge $Q = It = 9.6487 \times 100 = 964.87$ C $= 0.01$ F.
    $\mathrm{Cu^{2+} + 2e^- \rightarrow Cu}$, so 2 F deposit 63 g. Mass $= \dfrac{0.01}{2} \times 63 = 0.315$ g.

  6. NEET (UG) 2023, 7 May, Code E1 · Question 55
    The conductivity of centimolar solution of KCl at 25°C is 0.0210 $\mathrm{ohm^{-1}\ cm^{-1}}$ and the resistance of the cell containing the solution at 25°C is 60 ohm. The value of cell constant is -

    1. 1.34 $\mathrm{cm^{-1}}$
    2. 3.28 $\mathrm{cm^{-1}}$
    3. 1.26 $\mathrm{cm^{-1}}$
    4. 3.34 $\mathrm{cm^{-1}}$
    Show answer and solution

    Answer: (3)

    Conductivity $\kappa = \dfrac{G^*}{R}$, so the cell constant $G^* = \kappa R = 0.0210 \times 60 = 1.26\ \mathrm{cm^{-1}}$.

  7. NEET (UG) 2023, 7 May, Code E1 · Question 85
    Given below are two statements : one is labelled as $\textbf{Assertion A}$ and the other is labelled as $\textbf{Reason R}$ :
    $\textbf{Assertion A :}$ In equation $\Delta_r\mathrm{G} = -\mathrm{nFE_{cell}}$, value of $\Delta_r\mathrm{G}$ depends on n.
    $\textbf{Reasons R :}$ $\mathrm{E_{cell}}$ is an intensive property and $\Delta_r\mathrm{G}$ is an extensive property.
    In the light of the above statements, choose the $\textbf{correct}$ answer from the options given below :

    1. Both A and R are true and R is the correct explanation of A.
    2. Both A and R are true and R is NOT the correct explanation of A.
    3. A is true but R is false.
    4. A is false but R is true.
    Show answer and solution

    Answer: (1)

    A is true: $\Delta_r G$ is proportional to n, the number of electrons transferred in the reaction as written.
    R is true, and it explains A: $\mathrm{E_{cell}}$ is intensive (it does not depend on how much reacts), whereas $\Delta_r G$ is extensive. Multiplying the intensive $\mathrm{E_{cell}}$ by n (and F) is what makes $\Delta_r G$ depend on the amount of reaction, as NCERT explains.
    So both are true and R is the correct explanation of A.

    Note: Some coaching keys gave option (2); the NTA final key gives option (1), in line with NCERT, which links the dependence on n to $\Delta_r G$ being extensive while $\mathrm{E_{cell}}$ is intensive.
