  1. NEET (UG) 2026, 21 June (re-exam), Code 50 · Question 57
    In an acidic medium, 10 mL of 0.25 M oxalic acid is titrated with $\mathrm{KMnO_4}$ solution. If the volume of $\mathrm{KMnO_4}$ solution required to reach end point is 10 mL, the strength of the $\mathrm{KMnO_4}$ solution is

    1. 0.10 M
    2. 0.20 M
    3. 0.25 M
    4. 0.15 M
    Show answer and solution

    Answer: (1)

    $\mathrm{2MnO_4^- + 5H_2C_2O_4 + 6H^+ \rightarrow 2Mn^{2+} + 10CO_2 + 8H_2O}$.
    Moles of oxalic acid $= 0.25\times10 = 2.5$ mmol, so $\mathrm{KMnO_4} = \tfrac{2}{5}\times2.5 = 1.0$ mmol.
    Molarity $= 1.0/10 = 0.10$ M.

  2. NEET (UG) 2026, 21 June (re-exam), Code 50 · Question 65
    Given below are two statements :
    Statement-I : Heating NaCl with concentrated $\mathrm{H_2SO_4}$ and $\mathrm{MnO_2}$ results in oxidation of Mn.
    Statement-II : Heating NaI with concentrated $\mathrm{H_2SO_4}$ and $\mathrm{MnO_2}$ results in reduction of Mn.
    In light of the above statements, choose the most appropriate answer from the options given below.

    1. Both Statement-I and Statement-II are correct
    2. Both Statement-I and Statement-II are incorrect
    3. Statement-I is correct but Statement-II is incorrect
    4. Statement-I is incorrect but Statement-II is correct
    Show answer and solution

    Answer: (4)

    $\mathrm{MnO_2}$ acts as the oxidant: $\mathrm{2X^- + MnO_2 + 4H^+ \rightarrow X_2 + Mn^{2+} + 2H_2O}$ (X = Cl or I).
    In both cases Mn is reduced from +4 to +2 while the halide is oxidised.
    So Statement-I (oxidation of Mn) is wrong and Statement-II is correct.

  3. NEET (UG) 2026, 21 June (re-exam), Code 50 · Question 81
    The correct decreasing order of oxidation state of the underlined atom in each molecule is

    1. $\mathrm{\underline{P}_4O_{10} > \underline{S}O_3 > H_2\underline{O}}$
    2. $\mathrm{\underline{N}_2O_5 > \underline{Al}_2O_3 > H_2\underline{S}}$
    3. $\mathrm{\underline{Pb}O_2 > \underline{N}_2O_3 > \underline{S}O_3}$
    4. $\mathrm{\underline{P}_4O_6 > \underline{Cl}_2O_7 > \underline{Al}H_3}$
    Show answer and solution

    Answer: (2)

    (1): P +5, S +6, O −2, which is not decreasing.
    (2): N +5, Al +3, S −2, which is decreasing, so (2) is correct.
    (3): Pb +4, N +3, S +6, which is not decreasing.
    (4): P +3, Cl +7, Al +3, which is not decreasing.

  4. NEET (UG) 2025, 4 May, Code 45 · Question 55
    Consider the following compounds :
    $\underline{\mathrm{K}}\mathrm{O_2}$, $\mathrm{H_2}\underline{\mathrm{O}}\mathrm{_2}$ and $\mathrm{H_2}\underline{\mathrm{S}}\mathrm{O_4}$.
    The oxidation states of the underlined elements in them are, respectively,

    1. +1, –1, and +6
    2. +2, –2, and +6
    3. +1, –2, and +4
    4. +4, –4, and +6
    Show answer and solution

    Answer: (1)

    $\mathrm{KO_2}$ is potassium superoxide ($\mathrm{O_2^-}$), so K is +1.
    In the peroxide $\mathrm{H_2O_2}$, O is –1.
    In $\mathrm{H_2SO_4}$: $2(+1) + x + 4(-2) = 0 \Rightarrow x = +6$.

  5. NEET (UG) 2024, 5 May, Code T1 · Question 80
    Which reaction is $\textbf{NOT}$ a redox reaction?

    1. $\mathrm{H_2 + Cl_2 \rightarrow 2\ HCl}$
    2. $\mathrm{BaCl_2 + Na_2SO_4 \rightarrow BaSO_4 + 2\ NaCl}$
    3. $\mathrm{Zn + CuSO_4 \rightarrow ZnSO_4 + Cu}$
    4. $\mathrm{2\ KClO_3 + I_2 \rightarrow 2\ KIO_3 + Cl_2}$
    Show answer and solution

    Answer: (2)

    In the precipitation reaction $\mathrm{BaCl_2 + Na_2SO_4 \rightarrow BaSO_4 + 2NaCl}$ no element changes its oxidation state (Ba +2, Cl –1, Na +1, S +6, O –2 throughout), so it is not a redox reaction.
    The other three involve changes in oxidation state (H and Cl; Zn and Cu; I and Cl).

  6. NEET (UG) 2023, 7 May, Code E1 · Question 92
    On balancing the given redox reaction,
    $\mathrm{a\,Cr_2O_7^{2-} + b\,SO_3^{2-}(aq) + c\,H^+(aq) \rightarrow 2a\,Cr^{3+}(aq) + b\,SO_4^{2-}(aq) + \dfrac{c}{2}\,H_2O(\ell)}$
    the coefficients a, b and c are found to be, respectively -

    1. 1, 3, 8
    2. 3, 8, 1
    3. 1, 8, 3
    4. 8, 1, 3
    Show answer and solution

    Answer: (1)

    Each Cr goes from +6 to +3, so one $\mathrm{Cr_2O_7^{2-}}$ gains 6 electrons. Each S goes from +4 to +6, losing 2 electrons, so 3 $\mathrm{SO_3^{2-}}$ are needed.
    $\mathrm{Cr_2O_7^{2-} + 3SO_3^{2-} + 8H^+ \rightarrow 2Cr^{3+} + 3SO_4^{2-} + 4H_2O}$ (charge: $-2 - 6 + 8 = 0 = +6 - 6$).
    So a = 1, b = 3, c = 8.
