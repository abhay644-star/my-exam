  1. NEET (UG) 2026, 21 June (re-exam), Code 50 · Question 53
    Among the following options, the correct trend in the electron gain enthalpy is

    1. F > Cl > Br > I
    2. Br > Cl > F > I
    3. Cl > F > Br > I
    4. I > Br > Cl > F
    Show answer and solution

    Answer: (3)

    The magnitude of electron gain enthalpy generally falls down the group, but F is an exception.
    Because F is very small, the added electron is strongly repelled by the crowded 2p electrons, so F releases less energy than Cl.
    Order: Cl > F > Br > I.

  2. NEET (UG) 2026, 21 June (re-exam), Code 50 · Question 70
    Given below are two statements: One is labelled as Assertion A and the other is labelled as Reason R.
    Assertion A: The first ionization enthalpy of O is lower than that of N and F.
    Reason R: The loss of an electron from O leads to stable half-filled $p$ orbital
    In light of the above statements, choose the most appropriate answer from the options given below:

    1. Both A and R are correct and R is the correct explanation of A
    2. Both A and R are correct and R is NOT the correct explanation of A
    3. A is correct but R is not correct.
    4. A is not correct but R is correct
    Show answer and solution

    Answer: (1)

    O is $2p^4$. Removing one electron gives the stable half-filled $2p^3$ configuration, so O ionises more easily.
    N already has a stable half-filled $2p^3$ shell, and F has a higher effective nuclear charge. Both have higher IE than O.
    A is true and R correctly explains it.

  3. NEET (UG) 2026, 21 June (re-exam), Code 50 · Question 73
    The correct statement is

    1. Boron has a maximum covalency of four.
    2. Beryllium has three valence orbitals.
    3. Magnesium has a maximum covalency of four.
    4. Aluminium has five valence orbitals.
    Show answer and solution

    Answer: (1)

    Second-period elements have only four valence orbitals (one 2s and three 2p), so boron can form at most four bonds, as in $\mathrm{[BF_4]^-}$. Statement (1) is correct.
    Be also has four valence orbitals, not three.
    Mg and Al can use 3d orbitals, so their maximum covalency is above four; Al has 3s, 3p and 3d orbitals, not five.

  4. NEET (UG) 2025, 4 May, Code 45 · Question 47
    Which of the following statements are true?
    A. Unlike Ga that has a very high melting point, Cs has a very low melting point.
    B. On Pauling scale, the electronegativity values of N and Cl are not the same.
    C. Ar, $\mathrm{K^+}$, $\mathrm{Cl^-}$, $\mathrm{Ca^{2+}}$, and $\mathrm{S^{2-}}$ are all isoelectronic species.
    D. The correct order of the first ionization enthalpies of Na, Mg, Al, and Si is Si > Al > Mg > Na.
    E. The atomic radius of Cs is greater than that of Li and Rb.
    Choose the $\textbf{correct}$ answer from the options given below :

    1. A, B, and E only
    2. C and E only
    3. C and D only
    4. A, C, and E only
    Show answer and solution

    Answer: (2)

    A is false: gallium has a very low melting point (303 K), like caesium.
    B is false: N and Cl both have electronegativity 3.0 on the Pauling scale.
    C is true: all five species have 18 electrons.
    D is false: the order is Si > Mg > Al > Na (Mg has a stable $3s^2$ configuration).
    E is true: atomic radius increases down the group, so Cs > Rb > Li. Hence C and E only.

  5. NEET (UG) 2025, 4 May, Code 45 · Question 53
    Which among the following electronic configurations belong to main group elements?
    A. [Ne]$3s^1$
    B. [Ar]$3d^34s^2$
    C. [Kr]$4d^{10}5s^25p^5$
    D. [Ar]$3d^{10}4s^1$
    E. [Rn]$5f^06d^27s^2$
    Choose the $\textbf{correct}$ answer from the option given below :

    1. B and E only
    2. A and C only
    3. D and E only
    4. A, C and D only
    Show answer and solution

    Answer: (2)

    Main group (s- and p-block) elements have their last electron in an s or p orbital.
    A (Na, s-block) and C (I, p-block) are main group elements.
    B (V) and D (Cu) are d-block, and E (Th) is f-block. Hence A and C only.

  6. NEET (UG) 2024, 5 May, Code T1 · Question 63
    Arrange the following elements in increasing order of first ionization enthalpy:
    Li, Be, B, C, N
    Choose the correct answer from the options given below:

    1. Li < Be < C < B < N
    2. Li < Be < N < B < C
    3. Li < Be < B < C < N
    4. Li < B < Be < C < N
    Show answer and solution

    Answer: (4)

    Ionisation enthalpy generally rises across period 2, but B ($2s^2 2p^1$) is lower than Be ($2s^2$): the $2p$ electron of B is less penetrating and is more easily removed than a $2s$ electron.
    So Li (520) < B (801) < Be (899) < C (1086) < N (1402 kJ mol$^{-1}$).

  7. NEET (UG) 2024, 5 May, Code T1 · Question 64
    Arrange the following elements in increasing order of electronegativity:
    N, O, F, C, Si
    Choose the correct answer from the options given below:

    1. O < F < N < C < Si
    2. F < O < N < C < Si
    3. Si < C < N < O < F
    4. Si < C < O < N < F
    Show answer and solution

    Answer: (3)

    Electronegativity increases across a period (C < N < O < F) and decreases down a group (Si < C).
    So Si (1.8) < C (2.5) < N (3.0) < O (3.5) < F (4.0).

  8. NEET (UG) 2023, 7 May, Code E1 · Question 71
    The element expected to form largest ion to achieve the nearest noble gas configuration is :

    1. O
    2. F
    3. N
    4. Na
    Show answer and solution

    Answer: (3)

    The ions formed are $\mathrm{O^{2-}}$, $\mathrm{F^-}$, $\mathrm{N^{3-}}$ and $\mathrm{Na^+}$, all isoelectronic with neon (10 electrons).
    For isoelectronic ions, the fewer the protons, the larger the ion. Nitrogen has the fewest protons (7), so $\mathrm{N^{3-}}$ is the largest.

  9. NEET (UG) 2022, 17 July, Code Q1 · Question 54
    The IUPAC name of an element with atomic number 119 is

    1. ununennium
    2. unnilennium
    3. unununnium
    4. ununoctium
    Show answer and solution

    Answer: (1)

    Digits 1, 1, 9 give un + un + enn, plus the ending -ium: ununennium (symbol Uue).
