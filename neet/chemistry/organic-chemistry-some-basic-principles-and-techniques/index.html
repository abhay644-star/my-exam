  1. NEET (UG) 2026, 21 June (re-exam), Code 50 · Question 48
    The following carbocation is stabilized by the interaction of the empty $p$ orbital with

    1. filled $\sigma$ and filled $\pi$ orbitals
    2. empty $\sigma$ and empty $\pi^*$ orbitals
    3. empty $\sigma^*$ and filled $\pi$ orbitals
    4. empty $\sigma^*$ and empty $\pi^*$ orbitals
    Show answer and solution

    Answer: (1)

    An empty orbital is stabilised only by donation from filled orbitals.
    The benzylic cation is stabilised by resonance (overlap with the filled $\pi$ orbitals of the ring) and by hyperconjugation with the filled C–H $\sigma$ orbitals of the $\mathrm{CH_3}$ group.

  2. NEET (UG) 2026, 21 June (re-exam), Code 50 · Question 55
    The amino acid that gives a red-blood colour on treating its sodium fusion extract with sodium nitroprusside is

    1. leucine
    2. threonine
    3. methionine
    4. serine
    Show answer and solution

    Answer: (3)

    The sodium nitroprusside test on the Lassaigne extract detects sulphur, which is present as $\mathrm{Na_2S}$.
    Leucine, threonine and serine contain only C, H, N and O. Methionine, $\mathrm{CH_3SCH_2CH_2CH(NH_2)COOH}$, contains S.
    So methionine is the only one that gives a positive test.

  3. NEET (UG) 2026, 21 June (re-exam), Code 50 · Question 83
    Among the following, the compound having conjugated double bonds is

    1. hepta-1,3-diene
    2. hepta-1,4-diene
    3. hepta-1,5-diene
    4. hepta-1,6-diene
    Show answer and solution

    Answer: (1)

    Conjugated double bonds alternate with a single bond, C=C–C=C.
    Only hepta-1,3-diene, $\mathrm{CH_2{=}CH{-}CH{=}CH{-}C_3H_7}$, has this arrangement. The others are isolated dienes.

  4. NEET (UG) 2025, 4 May, Code 45 · Question 58
    Which one of the following compounds can exist as cis-trans isomers?

    1. Pent-1-ene
    2. 2-Methylhex-2-ene
    3. 1,1-Dimethylcyclopropane
    4. 1,2-Dimethylcyclohexane
    Show answer and solution

    Answer: (4)

    Cis-trans isomerism needs two different groups on each of two carbons of a double bond or ring.
    Pent-1-ene has $=\mathrm{CH_2}$, 2-methylhex-2-ene has two $\mathrm{CH_3}$ on C2, and 1,1-dimethylcyclopropane has both methyls on one carbon, so none of these shows it.
    In 1,2-dimethylcyclohexane the two methyls can be on the same side (cis) or opposite sides (trans) of the ring.

  5. NEET (UG) 2025, 4 May, Code 45 · Question 72
    Match $\textbf{List I}$ with $\textbf{List II}$

    List I (Mixture)List II (Method of Separation)
    A.$\mathrm{CHCl_3 + C_6H_5NH_2}$I.Distillation under reduced pressure
    B.Crude oil in petroleum industryII.Steam distillation
    C.Glycerol from spent-lyeIII.Fractional distillation
    D.Aniline - waterIV.Simple distillation
    Choose the $\textbf{correct}$ answer from the options given below :

    1. A-IV, B-III, C-I, D-II
    2. A-IV, B-III, C-II, D-I
    3. A-III, B-IV, C-I, D-II
    4. A-III, B-IV, C-II, D-I
    Show answer and solution

    Answer: (1)

    Chloroform (b.p. 334 K) and aniline (b.p. 457 K) differ widely in boiling point: simple distillation.
    Crude oil is separated into fractions by fractional distillation.
    Glycerol decomposes at its boiling point, so it is recovered from spent-lye by distillation under reduced pressure.
    Aniline is steam volatile and immiscible with water: steam distillation. So A-IV, B-III, C-I, D-II.

  6. NEET (UG) 2025, 4 May, Code 45 · Question 86
    Total number of possible isomers (both structural as well as stereoisomers) of cyclic ethers of molecular formula $\mathrm{C_4H_8O}$ is :

    1. 6
    2. 8
    3. 10
    4. 11
    Show answer and solution

    Answer: (3)

    Five-membered ring: oxolane (tetrahydrofuran) – 1.
    Four-membered ring: 2-methyloxetane (chiral, 2) and 3-methyloxetane (1).
    Three-membered ring: 2-ethyloxirane (chiral, 2), 2,2-dimethyloxirane (1) and 2,3-dimethyloxirane (cis meso form 1 + trans pair 2 = 3).
    Total $= 1 + 3 + 6 = 10$.

  7. NEET (UG) 2025, 4 May, Code 45 · Question 90
    Which one of the following reactions does $\textbf{NOT}$ belong to “Lassaigne's test”?

    1. $\mathrm{Na + C + N \xrightarrow[\Delta]{} NaCN}$
    2. $\mathrm{2Na + S \xrightarrow[\Delta]{} Na_2S}$
    3. $\mathrm{Na + X \xrightarrow[\Delta]{} + NaX}$
    4. $\mathrm{2CuO + C \xrightarrow[\Delta]{} 2Cu + CO_2}$
    Show answer and solution

    Answer: (4)

    In Lassaigne's test the organic compound is fused with sodium, converting N, S and halogens into NaCN, $\mathrm{Na_2S}$ and NaX.
    Heating with copper(II) oxide, which oxidises carbon to $\mathrm{CO_2}$, is the test for carbon (and hydrogen), not part of Lassaigne's test.

  8. NEET (UG) 2024, 5 May, Code T1 · Question 57
    On heating, some solid substances change from solid to vapour state without passing through liquid state. The technique used for the purification of such solid substances based on the above principle is known as

    1. Distillation
    2. Chromatography
    3. Crystallization
    4. Sublimation
    Show answer and solution

    Answer: (4)

    The direct change from solid to vapour on heating (and back to solid on cooling) is sublimation, and it is used to separate sublimable solids from non-sublimable impurities.

  9. NEET (UG) 2024, 5 May, Code T1 · Question 75
    The most stable carbocation among the following is:

    Show answer and solution

    Answer: (2)

    Option (2) is a tertiary carbocation (the 1-methylcyclohexyl cation) with seven $\alpha$-hydrogens available for hyperconjugation, the most of any option.
    Option (1) is a primary carbocation, and options (3) and (4) are secondary carbocations with fewer $\alpha$-hydrogens. So (2) is the most stable.

  10. NEET (UG) 2024, 5 May, Code T1 · Question 78
    A compound with a molecular formula of $\mathrm{C_6H_{14}}$ has two tertiary carbons. Its IUPAC name is:

    1. 2,3-dimethylbutane
    2. 2,2-dimethylbutane
    3. n-hexane
    4. 2-methylpentane
    Show answer and solution

    Answer: (1)

    A tertiary carbon is bonded to three other carbons. In 2,3-dimethylbutane, $\mathrm{(CH_3)_2CH{-}CH(CH_3)_2}$, both C-2 and C-3 are tertiary.
    2,2-Dimethylbutane has one quaternary carbon, n-hexane has none, and 2-methylpentane has only one tertiary carbon.

  11. NEET (UG) 2023, 7 May, Code E1 · Question 54
    In Lassaigne’s extract of an organic compound, both nitrogen and sulphur are present, which gives blood red colour with $\mathrm{Fe^{3+}}$ due to the formation of -

    1. $\mathrm{Fe_4[Fe(CN)_6]_3 \cdot xH_2O}$
    2. $\mathrm{NaSCN}$
    3. $\mathrm{[Fe(CN)_5NOS]^{4-}}$
    4. $\mathrm{[Fe(SCN)]^{2+}}$
    Show answer and solution

    Answer: (4)

    When both N and S are present, fusion with sodium gives sodium thiocyanate, $\mathrm{NaSCN}$. With $\mathrm{Fe^{3+}}$ it forms the blood-red complex $\mathrm{[Fe(SCN)]^{2+}}$:
    $\mathrm{Fe^{3+} + SCN^- \rightarrow [Fe(SCN)]^{2+}}$.

  12. NEET (UG) 2022, 17 July, Code Q1 · Question 69
    The Kjeldahl’s method for the estimation of nitrogen can be used to estimate the amount of nitrogen in which one of the following compounds?

    Show answer and solution

    Answer: (3)

    Kjeldahl's method does not work for nitro and azo compounds or for nitrogen in a ring (such as pyridine), because that nitrogen is not converted to ammonium sulphate. Aniline (3) can be estimated.

  13. NEET (UG) 2022, 17 July, Code Q1 · Question 90
    The correct IUPAC name of the following compound is

    1. 1-bromo-5-chloro-4-methylhexan-3-ol
    2. 6-bromo-2-chloro-4-methythexan-4-ol
    3. 1-bromo-4-methyl-5-chlorohexan-3-ol
    4. 6-bromo-4-methyl-2-chlorohexan-4-ol
    Show answer and solution

    Answer: (1)

    The compound is BrCH₂CH₂CH(OH)CH(CH₃)CH(Cl)CH₃. The six-carbon chain is numbered from the bromine end so that the OH group (the principal group) gets the lower locant, 3. The substituents are then listed alphabetically: 1-bromo-5-chloro-4-methylhexan-3-ol.
