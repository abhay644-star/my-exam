  1. NEET (UG) 2026, 21 June (re-exam), Code 50 · Question 136
    Which of the following is used as a clot buster?

    1. Streptokinase
    2. Penicillin
    3. Cyclosporin A
    4. Statins
    Show answer and solution

    Answer: (1)

    Streptokinase, produced by Streptococcus, dissolves blood clots in the vessels of patients after myocardial infarction, so it is called a clot buster. Penicillin is an antibiotic, cyclosporin A is an immunosuppressant and statins lower blood cholesterol.

  2. NEET (UG) 2025, 4 May, Code 45 · Question 103
    Which of the following is an example of non-distilled alcoholic beverage produced by yeast?

    1. Whisky
    2. Brandy
    3. Beer
    4. Rum
    Show answer and solution

    Answer: (3)

    Wine and beer are produced by yeast fermentation without distillation, while whisky, brandy and rum are made by distilling the fermented broth.

  3. NEET (UG) 2025, 4 May, Code 45 · Question 105
    Streptokinase produced by $\textit{bacterium Streptococcus}$ is used for

    1. Curd production
    2. Ethanol production
    3. Liver disease treatment
    4. Removing clots from blood vessels
    Show answer and solution

    Answer: (4)

    Streptokinase, produced by the bacterium $\textit{Streptococcus}$ and modified by genetic engineering, is used as a 'clot buster' to remove clots from the blood vessels of patients who have had a heart attack.

  4. NEET (UG) 2025, 4 May, Code 45 · Question 177
    Which of the following microbes is $\textbf{NOT}$ involved in the preparation of household products?
    A. $\textit{Aspergillus niger}$
    B. $\textit{Lactobacillus}$
    C. $\textit{Trichoderma polysporum}$
    D. $\textit{Saccharomyces cerevisiae}$
    E. $\textit{Propionibacterium sharmanii}$
    Choose the $\textbf{correct}$ answer from the options given below:

    1. A and B only
    2. A and C only
    3. C and D only
    4. C and E only
    Show answer and solution

    Answer: (2)

    $\textit{Lactobacillus}$ (curd), $\textit{Saccharomyces cerevisiae}$ (bread) and $\textit{Propionibacterium sharmanii}$ (Swiss cheese) are used for household products.
    $\textit{Aspergillus niger}$ is used industrially for citric acid, and $\textit{Trichoderma polysporum}$ produces the immunosuppressant cyclosporin A. Hence A and C only.

  5. NEET (UG) 2024, 5 May, Code T1 · Question 106
    Match List I with List II

    List IList II
    A.$\textit{Clostridium butylicum}$I.Ethanol
    B.$\textit{Saccharomyces cerevisiae}$II.Streptokinase
    C.$\textit{Trichoderma polysporum}$III.Butyric acid
    D.$\textit{Streptococcus}$ sp.IV.Cyclosporin-A
    Choose the correct answer from the options given below:

    1. A-III, B-I, C-IV, D-II
    2. A-IV, B-I, C-III, D-II
    3. A-III, B-I, C-II, D-IV
    4. A-II, B-IV, C-III, D-I
    Show answer and solution

    Answer: (1)

    $\textit{Clostridium butylicum}$ produces butyric acid (A-III); $\textit{Saccharomyces cerevisiae}$ (brewer's yeast) produces ethanol (B-I); $\textit{Trichoderma polysporum}$ produces cyclosporin A, an immunosuppressant (C-IV); $\textit{Streptococcus}$ gives streptokinase, a clot buster (D-II).

  6. NEET (UG) 2022, 17 July, Code Q1 · Question 167
    Identify the microorganism which is responsible for the production of an immunosuppressive molecule cyclosporin A :

    1. $\textit{Trichoderma polysporum}$
    2. $\textit{Clostridium butylicum}$
    3. $\textit{Aspergillus niger}$
    4. $\textit{Streptococcus cerevisiae}$
    Show answer and solution

    Answer: (1)

    Cyclosporin A, used as an immunosuppressant in organ transplant patients, is produced by the fungus Trichoderma polysporum.
