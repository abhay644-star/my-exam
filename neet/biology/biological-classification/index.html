  1. NEET (UG) 2026, 21 June (re-exam), Code 50 · Question 92
    Symbiotic association between fungi and algae are called ________.

    1. lichens
    2. sponges
    3. mycorrhiza
    4. chrysophytes
    Show answer and solution

    Answer: (1)

    A lichen is a mutualistic partnership between an alga (phycobiont), which makes food, and a fungus (mycobiont), which gives shelter and absorbs water and minerals. Mycorrhiza is a fungus–plant-root association, sponges are animals and chrysophytes are protists.

  2. NEET (UG) 2026, 21 June (re-exam), Code 50 · Question 101
    Mad cow disease is caused by _______.

    1. prions
    2. viroids
    3. Aspergillus sp.
    4. Mycoplasma sp.
    Show answer and solution

    Answer: (1)

    Mad cow disease (bovine spongiform encephalopathy) is caused by prions, which are abnormally folded infectious proteins. Viroids are free RNA agents that cause plant diseases such as potato spindle tuber.

  3. NEET (UG) 2026, 21 June (re-exam), Code 50 · Question 112
    Match List-I with List-II.

    List-IList-II
    A.SphericalI.Vibrio
    B.RodII.Cocci
    C.CommaIII.Spirilla
    D.SpirillumIV.Bacilli
    Choose the correct answer from the options given below :

    1. A-I, B-III, C-II, D-IV
    2. A-III, B-II, C-I, D-IV
    3. A-II, B-I, C-IV, D-III
    4. A-II, B-IV, C-I, D-III
    Show answer and solution

    Answer: (4)

    Bacterial shapes: spherical bacteria are cocci (A-II), rod-shaped are bacilli (B-IV), comma-shaped are vibrio (C-I), and spiral ones are spirilla (D-III).

  4. NEET (UG) 2026, 21 June (re-exam), Code 50 · Question 126
    Which of the following is not a prokaryote?

    1. Bacteria
    2. Blue green algae
    3. Mycoplasma
    4. Fungi
    Show answer and solution

    Answer: (4)

    Bacteria, blue-green algae (cyanobacteria) and mycoplasma are prokaryotes in Kingdom Monera. Fungi have a membrane-bound nucleus and organelles, so they are eukaryotes.

  5. NEET (UG) 2026, 21 June (re-exam), Code 50 · Question 129
    Match List-I with List-II.

    List-IList-II
    A.Fusion of protoplasms between gametesI.Meiosis
    B.Fusion of two nucleiII.Plasmogamy
    C.Generation of haploid sporesIII.Karyogamy
    Choose the correct answer from the options given below :

    1. A-II, B-III, C-I
    2. A-II, B-I, C-III
    3. A-III, B-II, C-I
    4. A-I, B-III, C-II
    Show answer and solution

    Answer: (1)

    In fungal sexual reproduction, protoplasm fusion is plasmogamy (A-II) and nuclear fusion is karyogamy (B-III). The zygote then undergoes meiosis to produce haploid spores (C-I).

  6. NEET (UG) 2025, 4 May, Code 45 · Question 113
    Which of following organisms $\textit{cannot}$ fix nitrogen?
    A. $\textit{Azotobacter}$
    B. $\textit{Oscillatoria}$
    C. $\textit{Anabaena}$
    D. $\textit{Volvox}$
    E. $\textit{Nostoc}$
    Choose the $\textit{\textbf{correct}}$ answer from the options given below:

    1. A only
    2. D only
    3. B only
    4. E only
    Show answer and solution

    Answer: (2)

    $\textit{Azotobacter}$ is a free-living nitrogen-fixing bacterium, and $\textit{Oscillatoria}$, $\textit{Anabaena}$ and $\textit{Nostoc}$ are cyanobacteria that fix nitrogen.
    $\textit{Volvox}$ is a green alga (a eukaryote) and cannot fix nitrogen. Hence D only.

  7. NEET (UG) 2025, 4 May, Code 45 · Question 132
    Each of the following characteristics represent a Kingdom proposed by Whittaker. Arrange the following in increasing order of complexity of body organization.
    A. Multicellular heterotrophs with cell wall made of chitin.
    B. Heterotrophs with tissue/organ/organ system level of body organization.
    C. Prokaryotes with cell wall made of polysaccharides and amino acids.
    D. Eukaryotic autotrophs with tissue/organ level of body organization.
    E. Eukaryotes with cellular body organization.
    Choose the $\textbf{correct}$ answer from the options given below :

    1. A, C, E, B, D
    2. C, E, A, D, B
    3. A, C, E, D, B
    4. C, E, A, B, D
    Show answer and solution

    Answer: (2)

    C is Monera (prokaryotes; peptidoglycan wall), E is Protista (unicellular eukaryotes), A is Fungi (chitin wall), D is Plantae (tissue/organ level) and B is Animalia (tissue/organ/organ system level).
    Increasing complexity: C, E, A, D, B.

  8. NEET (UG) 2024, 5 May, Code T1 · Question 110
    Match List I with List II

    List IList II
    A.$\textit{Rhizopus}$I.Mushroom
    B.$\textit{Ustilago}$II.Smut fungus
    C.$\textit{Puccinia}$III.Bread mould
    D.$\textit{Agaricus}$IV.Rust fungus
    Choose the correct answer from the options given below:

    1. A-III, B-II, C-I, D-IV
    2. A-IV, B-III, C-II, D-I
    3. A-III, B-II, C-IV, D-I
    4. A-I, B-III, C-II, D-IV
    Show answer and solution

    Answer: (3)

    $\textit{Rhizopus}$ is the bread mould (A-III), $\textit{Ustilago}$ the smut fungus (B-II), $\textit{Puccinia}$ the rust fungus (C-IV) and $\textit{Agaricus}$ the mushroom (D-I).

  9. NEET (UG) 2024, 5 May, Code T1 · Question 125
    Which one of the following is $\underline{\text{not}}$ a criterion for classification of fungi?

    1. Mode of spore formation
    2. Fruiting body
    3. Morphology of mycelium
    4. Mode of nutrition
    Show answer and solution

    Answer: (4)

    Kingdom Fungi is divided into classes on the basis of the morphology of the mycelium, the mode of spore formation and the fruiting bodies. Mode of nutrition is not used, as all fungi are heterotrophic.
