  1. NEET (UG) 2026, 21 June (re-exam), Code 50 · Question 106
    Match List-I with List-II.

    List-IList-II
    A.StarchI.Fights infection
    B.AntibodyII.Energy storage
    C.Concanavalin AIII.Glucose transport
    D.Glut-4IV.Lectin
    Choose the correct answer from the options given below :

    1. A-I, B-II, C-IV, D-III
    2. A-II, B-I, C-IV, D-III
    3. A-II, B-I, C-III, D-IV
    4. A-I, B-II, C-III, D-IV
    Show answer and solution

    Answer: (2)

    Starch is a storage polysaccharide (A-II). Antibodies fight infection (B-I). Concanavalin A is a lectin (C-IV). GLUT-4 lets glucose into cells (D-III).

  2. NEET (UG) 2026, 21 June (re-exam), Code 50 · Question 134
    Arrange the following elements in descending order of their contribution to percentage weight of the human body.
    (a) Oxygen
    (b) Carbon
    (c) Hydrogen
    (d) Nitrogen
    Choose the correct answer from the options given below :

    1. (a), (b), (c), (d)
    2. (c), (a), (b), (d)
    3. (b), (c), (d), (a)
    4. (b), (a), (c), (d)
    Show answer and solution

    Answer: (1)

    By weight, the human body is about 65% oxygen, 18.5% carbon, 9.5% hydrogen and 3.3% nitrogen. So the descending order is (a), (b), (c), (d).

  3. NEET (UG) 2025, 4 May, Code 45 · Question 95
    Which one of the following statements refers to Reductionist Biology?

    1. Physico-chemical approach to study and understand living organisms.
    2. Physiological approach to study and understand living organisms.
    3. Chemical approach to study and understand living organisms.
    4. Behavioural approach to study and understand living organisms.
    Show answer and solution

    Answer: (1)

    Describing biological processes in terms of the physical and chemical principles underlying them is the physico-chemical approach; this is called reductionist biology.

  4. NEET (UG) 2025, 4 May, Code 45 · Question 117
    Name the class of enzyme that usually catalyze the following reaction :
    $\mathrm{S - G + S^{\#} \rightarrow S + S^{\#} - G}$
    Where, G $\rightarrow$ a group other than hydrogen
    S $\rightarrow$ a substrate
    $\mathrm{S^{\#}}$ $\rightarrow$ another substrate

    1. Hydrolase
    2. Lyase
    3. Transferase
    4. Ligase
    Show answer and solution

    Answer: (3)

    Transferases catalyse the transfer of a group G (other than hydrogen) from one substrate S to another substrate $\mathrm{S^{\#}}$: $\mathrm{S - G + S^{\#} \rightarrow S + S^{\#} - G}$.

  5. NEET (UG) 2025, 4 May, Code 45 · Question 131
    Which one of the following enzymes contains ‘Haem’ as the prosthetic group?

    1. RuBisCo
    2. Carbonic anhydrase
    3. Succinate dehydrogenase
    4. Catalase
    Show answer and solution

    Answer: (4)

    Peroxidase and catalase have haem as the prosthetic group; they break down hydrogen peroxide to water and oxygen. Carbonic anhydrase contains zinc, and succinate dehydrogenase has FAD.

  6. NEET (UG) 2025, 4 May, Code 45 · Question 137
    Match $\textbf{List I}$ with $\textbf{List II}$.

    List IList II
    A.AdenosineI.Nitrogen base
    B.Adenylic acidII.Nucleotide
    C.AdenineIII.Nucleoside
    D.AlanineIV.Amino acid
    Choose the option with all $\textbf{correct}$ matches.

    1. A-III, B-IV, C-II, D-I
    2. A-III, B-II, C-IV, D-I
    3. A-III, B-II, C-I, D-IV
    4. A-II, B-III, C-I, D-IV
    Show answer and solution

    Answer: (3)

    Adenosine (adenine + sugar) is a nucleoside; adenylic acid (adenosine + phosphate) is a nucleotide; adenine is a nitrogen base; alanine is an amino acid.
    So A-III, B-II, C-I, D-IV.

  7. NEET (UG) 2025, 4 May, Code 45 · Question 149
    The protein portion of an enzyme is called :

    1. Cofactor
    2. Coenzyme
    3. Apoenzyme
    4. Prosthetic group
    Show answer and solution

    Answer: (3)

    In a holoenzyme the protein portion is the apoenzyme; the non-protein part is the cofactor, which may be a prosthetic group, a coenzyme or a metal ion.

  8. NEET (UG) 2024, 5 May, Code T1 · Question 116
    Lecithin, a small molecular weight organic compound found in living tissues, is an example of:

    1. Glycerides
    2. Carbohydrates
    3. Amino acids
    4. Phospholipids
    Show answer and solution

    Answer: (4)

    Lecithin is a phospholipid: glycerol esterified with fatty acids and a phosphate group linked to choline.

  9. NEET (UG) 2024, 5 May, Code T1 · Question 118
    The cofactor of the enzyme carboxypeptidase is:

    1. Flavin
    2. Haem
    3. Zinc
    4. Niacin
    Show answer and solution

    Answer: (3)

    Zinc is the metal ion cofactor of the proteolytic enzyme carboxypeptidase.

  10. NEET (UG) 2024, 5 May, Code T1 · Question 119
    Inhibition of Succinic dehydrogenase enzyme by malonate is a classical example of:

    1. Competitive inhibition
    2. Enzyme activation
    3. Cofactor inhibition
    4. Feedback inhibition
    Show answer and solution

    Answer: (1)

    Malonate closely resembles the substrate succinate and competes with it for the active site of succinic dehydrogenase. This is competitive inhibition.

    List IList II
    A.GLUT-4I.Hormone

  12. NEET (UG) 2024, 5 May, Code T1 · Question 174
    Match List I with List II :

    List IList II
    A.LipaseI.Peptide bond
    B.NucleaseII.Ester bond
    C.ProteaseIII.Glycosidic bond
    D.AmylaseIV.Phosphodiester bond
    Choose the correct answer from the options given below :

    1. A-II, B-IV, C-I, D-III
    2. A-IV, B-I, C-III, D-II
    3. A-IV, B-II, C-III, D-I
    4. A-III, B-II, C-I, D-IV

    Lipases hydrolyse the ester bonds of fats (A-II). Nucleases break the phosphodiester bonds of nucleic acids (B-IV). Proteases break peptide bonds (C-I). Amylase breaks the glycosidic bonds of starch (D-III).

  13. NEET (UG) 2024, 5 May, Code T1 · Question 189
    Regarding catalytic cycle of an enzyme action, select the correct sequential steps :
    A. Substrate enzyme complex formation.
    B. Free enzyme ready to bind with another substrate.
    C. Release of products.
    D. Chemical bonds of the substrate broken.
    E. Substrate binding to active site.
    Choose the correct answer from the options given below :

    1. B, A, C, D, E
    2. E, D, C, B, A
    3. E, A, D, C, B
    4. A, E, B, D, C
    Show answer and solution

    Answer: (3)

    The substrate first binds to the active site (E), forming the enzyme–substrate complex (A). The enzyme then strains the substrate so that its chemical bonds are broken (D), the products are released (C), and the free enzyme is ready to bind another substrate molecule (B). So E, A, D, C, B.

  14. NEET (UG) 2023, 7 May, Code E1 · Question 116
    Cellulose does not form blue colour with Iodine because

    1. It is a disaccharide.
    2. It is a helical molecule.
    3. It does not contain complex helices and hence cannot hold iodine molecules.
    4. It breakes down when iodine reacts with it.
    Show answer and solution

    Answer: (3)

    Starch forms helical secondary structures that can hold iodine, giving a blue colour. Cellulose is a polymer of glucose with straight chains that do not form such complex helices, so it cannot hold iodine and gives no blue colour.

  15. NEET (UG) 2023, 7 May, Code E1 · Question 144
    Melonate inhibits the growth of pathogenic bacteria by inhibiting the activity of

    1. Succinic dehydrogenase
    2. Amylase
    3. Lipase
    4. Dinitrogenase
    Show answer and solution

    Answer: (1)

    Malonate closely resembles succinate in structure, so it acts as a competitive inhibitor of succinic dehydrogenase; such inhibitors are used to control bacterial pathogens.

  16. NEET (UG) 2023, 7 May, Code E1 · Question 158
    Given below are two statements:
    $\textbf{Statement I:}$ A protein is imagined as a line, the left end represented by first amino acid (C-terminal) and the right end represented by last amino acid (N-terminal)
    $\textbf{Statement II:}$ Adult human haemoglobin, consists of 4 subunits (two subunits of $\alpha$ type and two subunits of $\beta$ type.)
    In the light of the above statements, choose the $\textbf{correct}$ answer from the options given below:

    1. Both Statement I and Statement II are true.
    2. Both Statement I and Statement II are false.
    3. Statement I is true but Statement II is false.
    4. Statement I is false but Statement II is true.
    Show answer and solution

    Answer: (4)

    Statement I is false: the first amino acid at the left end is the N-terminal amino acid and the last one at the right end is the C-terminal amino acid; the statement reverses them.
    Statement II is true: adult haemoglobin has quaternary structure with two $\alpha$ and two $\beta$ subunits.

  17. NEET (UG) 2023, 7 May, Code E1 · Question 164
    Given below are two statements:
    $\textbf{Statement I:}$ Low temperature preserves the enzyme in a temporarily inactive state whereas high temperature destroys enzymatic activity because proteins are denatured by heat.
    $\textbf{Statement II:}$ When the inhibitor closely resembles the substrate in its molecular structure and inhibits the activity of the enzyme, it is known as competitive inhibitor.
    In the light of the above statements, choose the $\textbf{correct}$ answer from the options given below:

    1. Both Statement I and Statement II are true.
    2. Both Statement I and Statement II are false.
    3. Statement I is true but Statement II is false.
    4. Statement I is false but Statement II is true.
    Show answer and solution

    Answer: (1)

    Both statements are the standard NCERT descriptions: low temperature keeps an enzyme temporarily inactive while heat denatures it, and an inhibitor that resembles the substrate and competes for the active site is a competitive inhibitor (for example malonate with succinic dehydrogenase).

  18. NEET (UG) 2022, 17 July, Code Q1 · Question 123
    Exoskeleton of arthropods is composed of :

    1. Cutin
    2. Cellulose
    3. Chitin
    4. Glucosamine
    Show answer and solution

    Answer: (3)

    The exoskeleton of arthropods is made of chitin, a complex polysaccharide (a polymer of N-acetylglucosamine).

  19. NEET (UG) 2022, 17 July, Code Q1 · Question 145
    Read the following statements on lipids and find out correct set of statements:
    (a) Lecithin found in the plasma membrane is a glycolipid
    (b) Saturated fatty acids possess one or more c = c bonds
    (c) Gingely oil has lower melting point, hence remains as oil in winter
    (d) Lipids are generally insoluble in water but soluble in some organic solvents
    (e) When fatty acid is esterified with glycerol, monoglycerides are formed
    Choose the correct answer from the option given below:

    1. (a), (b) and (c) only
    2. (a), (d) and (e) only
    3. (c), (d) and (e) only
    4. (a), (b) and (d) only
    Show answer and solution

    Answer: (3)

    (a) is wrong: lecithin is a phospholipid. (b) is wrong: saturated fatty acids have no C=C bonds.
    (c), (d) and (e) are correct (one fatty acid esterified with glycerol gives a monoglyceride).

  20. NEET (UG) 2022, 17 July, Code Q1 · Question 171
    A dehydration reaction links two glucose molecules to product maltose. If the formula for glucose is C$_6$H$_{12}$O$_6$ then what is the formula for maltose?

    1. C$_{12}$H$_{20}$O$_{10}$
    2. C$_{12}$H$_{24}$O$_{12}$
    3. C$_{12}$H$_{22}$O$_{11}$
    4. C$_{12}$H$_{24}$O$_{11}$
    Show answer and solution

    Answer: (3)

    Two glucose molecules lose one molecule of water: 2 C₆H₁₂O₆ − H₂O = C₁₂H₂₂O₁₁.

  21. NEET (UG) 2022, 17 July, Code Q1 · Question 190
    Match $\textbf{List-I}$ with $\textbf{List-II}$

    List-I
    (Biological Molecules)    		List-II
    (Biological functions)
    (a)Glycogen(i)Hormone
    (b)Globulin(ii)Biocatalyst
    (c)Steroids(iii)Antibody
    (d)Thrombin(iv)Storage product
    Choose the $\textbf{correct answer}$ from the options given below:

    1. (a) - (iii), (b) - (ii), (c) - (iv), (d) - (i)
    2. (a) - (iv), (b) - (ii), (c) - (i), (d) - (iii)
