Solved questions from this paper

A few questions with their official answers and worked solutions. All 75 are in the online test.

  1. Question 1 · Mathematics · Sets
    Let $A=\{1, 2, 3, \ldots, 10\}$ and $B=\left\{\dfrac{m}{n}: m, n\in A, m<n \text{ and } \gcd(m, n)=1\right\}$. Then $n(B)$ is equal to :

    1. $29$
    2. $31$
    3. $36$
    4. $37$
    Show answer and solution

    Answer: (b)

    For each denominator $n$ ($2\le n\le10$), the admissible numerators are the $m<n$ coprime to $n$, i.e. $\varphi(n)$ of them, and different reduced fractions are different numbers.
    $n(B)=\varphi(2)+\cdots+\varphi(10)=1+2+2+4+2+6+4+6+4=31$.

  2. Question 2 · Mathematics · Relations and Functions
    The number of non-empty equivalence relations on the set $\{1, 2, 3\}$ is :

    1. $4$
    2. $5$
    3. $6$
    4. $7$
    Show answer and solution

    Answer: (b)

    Equivalence relations on a set correspond one-to-one with its partitions.
    Partitions of $\{1,2,3\}$: one block (1 way), a pair and a singleton (3 ways), three singletons (1 way).
    Total $=5$ (every equivalence relation on a non-empty set is non-empty).

  3. Question 26 · Physics · Moving Charges and Magnetism
    If B is magnetic field and $\mu_0$ is permeability of free space, then the dimensions of $(B/\mu_0)$ is

    1. $\mathrm{ML^2T^{-2}A^{-1}}$
    2. $\mathrm{MT^{-2}A^{-1}}$
    3. $\mathrm{LT^{-2}A^{-1}}$
    4. $\mathrm{L^{-1}A}$
    Show answer and solution

    Answer: (d)

    From $B=\dfrac{\mu_0 I}{2\pi r}$, $\dfrac{B}{\mu_0}=\dfrac{I}{2\pi r}$ has the dimensions of current per length.
    $[B/\mu_0]=\mathrm{L^{-1}A}$.

  4. Question 27 · Physics · Units and Measurements
    Given below are two statements :
    Statement I : In a vernier callipers, one vernier scale division is always smaller than one main scale division.
    Statement II : The vernier constant is given by one main scale division multiplied by the number of vernier scale divisions.
    In the light of the above statements, choose the correct answer from the options given below.

    1. Both Statement I and Statement II are true
    2. Both Statement I and Statement II are false
    3. Statement I is true but Statement II is false
    4. Statement I is false but Statement II is true
    Show answer and solution

    Answer: (c)

    In a vernier callipers, $N$ vernier divisions equal $(N-1)$ main scale divisions, so one VSD is smaller than one MSD: Statement I is true.
    The vernier constant is $1\text{ MSD}-1\text{ VSD}=\dfrac{1\text{ MSD}}{N}$, i.e. one MSD divided (not multiplied) by the number of vernier divisions: Statement II is false.

  5. Question 51 · Chemistry · Structure of Atom
    Radius of the first excited state of Helium ion is given as :
    $a_0\rightarrow$ radius of first stationary state of hydrogen atom.

    1. $r=4a_0$
    2. $r=\dfrac{a_0}{2}$
    3. $r=\dfrac{a_0}{4}$
    4. $r=2a_0$
    Show answer and solution

    Answer: (d)

    For a hydrogen-like ion $r_n=\dfrac{n^2}{Z}a_0$.
    $\mathrm{He^+}$: $Z=2$; first excited state $n=2$: $r=\dfrac{4}{2}a_0=2a_0$.

  6. Question 52 · Chemistry · Thermodynamics
    A liquid when kept inside a thermally insulated closed vessel at $25^\circ$C was mechanically stirred from outside. What will be the correct option for the following thermodynamic parameters ?

    1. $\Delta U>0$, $q=0$, $w>0$
    2. $\Delta U<0$, $q=0$, $w>0$
    3. $\Delta U=0$, $q=0$, $w=0$
    4. $\Delta U=0$, $q<0$, $w>0$
    Show answer and solution

    Answer: (a)

    The vessel is insulated, so $q=0$.
    Stirring does work on the liquid: $w>0$.
    $\Delta U=q+w=w>0$.
