Solved questions from this paper

A few questions with their official answers and worked solutions. All 75 are in the online test.

  1. Question 1 · Mathematics · Trigonometric Functions
    The sum of all the elements in the range of $f(x)=\mathrm{Sgn}(\sin x)+\mathrm{Sgn}(\cos x)+\mathrm{Sgn}(\tan x)+\mathrm{Sgn}(\cot x)$, $x\ne\dfrac{n\pi}{2}$, $n\in\mathbf{Z}$, where $\mathrm{Sgn}(t)=\begin{cases}1, & \text{if } t>0\\-1, & \text{if } t<0\end{cases}$, is :

    1. $2$
    2. $4$
    3. $-2$
    4. $0$
    Show answer and solution

    Answer: (a)

    First quadrant: $1+1+1+1=4$. Second: $1-1-1-1=-2$. Third: $-1-1+1+1=0$. Fourth: $-1+1-1-1=-2$.
    Range $=\{-2,0,4\}$, sum $=2$.

  2. Question 2 · Mathematics · Relations and Functions
    Given below are two statements :
    Statement I : The function $f:\mathbf{R}\to\mathbf{R}$ defined by $f(x)=\dfrac{x}{1+|x|}$ is one-one.
    Statement II : The function $f:\mathbf{R}\to\mathbf{R}$ defined by $f(x)=\dfrac{x^2+4x-30}{x^2-8x+18}$ is many-one.
    In the light of the above statements, choose the correct answer from the options given below :

    1. Both Statement I and Statement II are true
    2. Both Statement I and Statement II are false
    3. Statement I is true but Statement II is false
    4. Statement I is false but Statement II is true
    Show answer and solution

    Answer: (a)

    Statement I: for $x\ge0$, $f(x)=\dfrac{x}{1+x}$ and for $x<0$, $f(x)=\dfrac{x}{1-x}$; both pieces are strictly increasing and $f$ keeps the sign of $x$, so $f$ is one-one. True.
    Statement II: the denominator has discriminant $64-72<0$, so $f$ is defined on all of $\mathbf{R}$. $f(x)=c$ gives $(1-c)x^2+(4+8c)x-(30+18c)=0$, which has two distinct real roots for suitable $c$ (e.g. $c=0$: $x^2+4x-30=0$). So $f$ is many-one. True.

  3. Question 26 · Physics · Units and Measurements
    In an experiment, a set of reading are obtained as follows - 1.24 mm, 1.25 mm, 1.23 mm, 1.21 mm. The expected least count of the instrument used in recording these readings is _______ mm.

    1. $0.1$
    2. $0.001$
    3. $0.05$
    4. $0.01$
    Show answer and solution

    Answer: (d)

    The readings are recorded to two decimal places of a millimetre, so the smallest division read is 0.01 mm.

  4. Question 30 · Physics · Motion in a Straight Line
    A particle starts moving from time $t=0$ and its coordinate is given as $x(t)=4t^3-3t$
    A. The particle returns to its original position (origin) 0.866 units later
    B. The particle is 1 unit away from origin at its turning point
    C. Acceleration of the particle is non-negative
    D. The particle is 0.5 units away from origin at its turning point
    E. Particle never turns back as acceleration is non-negative
    Choose the correct answer from the options given below :

    1. A, C Only
    2. A, C, D Only
    3. A, B, C Only
    4. C, E Only
    Show answer and solution

    Answer: (c)

    $x=0$ again at $4t^2=3$, $t=\dfrac{\sqrt3}{2}\approx0.866$: A true.
    $v=12t^2-3=0$ at $t=0.5$, where $x=0.5-1.5=-1$: 1 unit from the origin, so B true and D false; the particle does turn back, so E false.
    $a=24t\ge0$ for $t\ge0$: C true. Answer: A, B, C.

  5. Question 51 · Chemistry · Some Basic Concepts of Chemistry
    For the given reaction;
    $\mathrm{CaCO_3+2HCl\longrightarrow CaCl_2+H_2O+CO_2}$
    If 90 g $\mathrm{CaCO_3}$ is added to 300 mL of HCl which contains 38.55% HCl by mass and has density 1.13 g mL$^{-1}$, then which of the following option is correct ?
    Given molar mass of H, Cl, Ca and O are 1, 35.5, 40 and 16 g mol$^{-1}$ respectively.

    1. 60.32 g of HCl remains unreacted
    2. 64.97 g of HCl remains unreacted
    3. 32.85 g of $\mathrm{CaCO_3}$ remains unreacted
    4. 97.30 g of HCl reacted
    Show answer and solution

    Answer: (b)

    Mass of HCl $=300\times1.13\times0.3855=130.68$ g. $\mathrm{CaCO_3}=0.9$ mol needs $1.8$ mol $=65.7$ g HCl, so $\mathrm{CaCO_3}$ is the limiting reagent.
    HCl left $=130.68-65.7\approx64.97$ g.

  6. Question 52 · Chemistry · Structure of Atom
    The wavelength of photon 'A' is 400 nm. The frequency of photon 'B' is $10^{16}\ \mathrm s^{-1}$. The wave number of photon 'C' is $10^4\ \mathrm{cm^{-1}}$. The correct order of energy of these photons is :

    1. A > B > C
    2. C > B > A
    3. B > A > C
    4. A > C > B
    Show answer and solution

    Answer: (c)

    Compare frequencies: A: $\nu=\dfrac{3\times10^8}{400\times10^{-9}}=7.5\times10^{14}$ Hz. B: $10^{16}$ Hz. C: $\lambda=10^{-4}$ cm $=1000$ nm, so $\nu=3\times10^{14}$ Hz.
    $E=h\nu$, so B $>$ A $>$ C.
