  1. JEE Main 2026, 2 April, Shift 2 · Question 21
    Let $A=\{2, 3, 4, 5, 6\}$. Let R be a relation on the set $A\times A$ given by $(x, y)R(z, w)$ if and only if $x$ divides $z$ and $y \le w$. Then the number of elements in R is __________.

    Show answer and solution

    Answer: 120

    Pairs $(x,z)$ with $x \mid z$: $x=2$: $z=2,4,6$; $x=3$: $z=3,6$; $x=4,5,6$: one each. Total $3+2+1+1+1=8$.
    Pairs $(y,w)$ with $y\le w$: $\dfrac{5\cdot6}{2}=15$.
    Number of elements $=8\times15=120$.

  2. JEE Main 2026, 4 April, Shift 1 · Question 4
    The number of functions $f:\{1,2,3,4\}\to\{a,b,c\}$, which are not onto, is:

    1. $48$
    2. $45$
    3. $51$
    4. $35$
    Show answer and solution

    Answer: (b)

    Total functions: $3^4=81$.
    Onto functions: $3^4-\binom31 2^4+\binom32 1^4=81-48+3=36$.
    Not onto: $81-36=45$.

  3. JEE Main 2026, 4 April, Shift 2 · Question 1
    For the function $f:[1,\infty)\to[1,\infty)$ defined by $f(x)=(x-1)^4+1$, among the two statements:
    (I) The set $S=\{x\in[1,\infty): f(x)=f^{-1}(x)\}$ contains exactly two elements, and
    (II) The set $S=\{x\in[1,\infty): f(x)=f^{-1}(x+1)\}$ is an empty set,

    1. only (I) is TRUE
    2. only (II) is TRUE
    3. both (I) and (II) are TRUE
    4. neither (I) nor (II) is TRUE
    Show answer and solution

    Answer: (a)

    $f$ is strictly increasing on $[1,\infty)$, so $f(x)=f^{-1}(x)\iff f(x)=x$.
    $(x-1)^4+1=x\iff (x-1)^4=x-1\iff x=1$ or $x=2$. So (I) is true.
    For (II): $f(x)=f^{-1}(x+1)\iff f(f(x))=x+1$. Let $h(x)=f(f(x))-x-1$.
    $h(2)=f(2)-3=2-3=-1<0$, while $h(x)\to\infty$ as $x\to\infty$, and $h$ is continuous, so $h$ has a root in $(2,\infty)$.
    So the set in (II) is not empty: (II) is false. Only (I) is TRUE.

  4. JEE Main 2026, 6 April, Shift 2 · Question 1
    Let $f : \mathbf{R} \to \mathbf{R}$ be defined as $f(x) = \dfrac{2x^2-3x+2}{3x^2+x+3}$. Then $f$ is :

    1. both one-one and onto
    2. one-one but not onto
    3. onto but not one-one
    4. neither one-one nor onto
    Show answer and solution

    Answer: (d)

    $3x^2+x+3>0$ for all $x$, so $f$ is continuous on $\mathbf{R}$, and $f(x)\to\dfrac23$ as $x\to\infty$.
    $f(0)=\dfrac23$, $f(1)=\dfrac17$: every value between $\dfrac17$ and $\dfrac23$ is taken once in $(0,1)$ and again in $(1,\infty)$, so $f$ is not one-one.
    Range: $y(3x^2+x+3)=2x^2-3x+2 \Rightarrow (3y-2)x^2+(y+3)x+(3y-2)=0$; real $x$ needs $(y+3)^2\ge4(3y-2)^2$, a bounded interval of $y$.
    So the range is a bounded interval, not $\mathbf{R}$: $f$ is not onto.
    Hence $f$ is neither one-one nor onto.

  5. JEE Main 2026, 6 April, Shift 2 · Question 21
    Let $R=\left\{(x,y)\in\mathbf{N}\times\mathbf{N} : \log_e(x+y)\le2\right\}$. Then the minimum number of elements, required to be added in R to make it a transitive relation, is __________.

    Show answer and solution

    Answer: 15

    $x+y\le e^2\approx7.39 \Rightarrow x+y\le7$; $R$ has $6+5+4+3+2+1=21$ pairs, all with $x,y\in\{1,\ldots,6\}$.
    For any $a, c\in\{1,\ldots,6\}$: $(a,1)\in R$ and $(1,c)\in R$, so transitivity forces $(a,c)$.
    So the smallest transitive relation containing $R$ is $\{1,\ldots,6\}^2$, with $36$ pairs (it is transitive).
    Elements to add $=36-21=15$.

  6. JEE Main 2026, 8 April, Shift 2 · Question 1
    Consider the relation R on the set $\{-2,-1,0,1,2\}$ defined by $(a,b)\in R$ if and only if $1+ab>0$. Then, among the statements :
    I. The number of elements in R is 17
    II. R is an equivalence relation

    1. Only I is true
    2. Only II is true
    3. Both I and II are true
    4. Neither I nor II is true
    Show answer and solution

    Answer: (a)

    $1+ab>0 \iff ab\ge 0$ (as $ab$ is an integer).
    Pairs with $ab<0$: $a,b$ non-zero with opposite signs: $2\cdot2\cdot2=8$ pairs. So $|R|=25-8=17$: I is true.
    $R$ is reflexive ($1+a^2>0$) and symmetric, but $(1,0),(0,-1)\in R$ while $(1,-1)\notin R$ ($1-1=0$). Not transitive, so II is false.
    Only I is true.

  7. JEE Main 2026, 21 January, Shift 1 · Question 1
    The number of relations, defined on the set $\{a, b, c, d\}$, which are both reflexive and symmetric, is equal to :

    1. $16$
    2. $64$
    3. $256$
    4. $1024$
    Show answer and solution

    Answer: (b)

    A reflexive relation must contain all 4 pairs $(x,x)$.
    Symmetry means the off-diagonal pairs come in pairs $\{(x,y),(y,x)\}$; there are $\binom{4}{2}=6$ such pairs, each either in or out.
    Number of relations $=2^6=64$.

  8. JEE Main 2026, 21 January, Shift 2 · Question 1
    Let $A=\{2, 3, 5, 7, 9\}$. Let R be the relation on A defined by $xRy$ if and only if $2x\le3y$. Let $l$ be the number of elements in R, and m be the minimum number of elements required to be added in R to make it a symmetric relation. Then $l+m$ is equal to :

    1. $21$
    2. $23$
    3. $25$
    4. $27$
    Show answer and solution

    Answer: (c)

    Count pairs with $y\ge\dfrac{2x}{3}$: $x=2$: 5; $x=3$: 5; $x=5$: $y\in\{5,7,9\}$, 3; $x=7$: $y\in\{5,7,9\}$, 3; $x=9$: $y\in\{7,9\}$, 2. So $l=18$.
    A pair $(x,y)\in R$ needs $(y,x)$ added when $2y>3x$: $(2,5),(2,7),(2,9),(3,5),(3,7),(3,9),(5,9)$, so $m=7$.
    $l+m=25$.

  9. JEE Main 2026, 22 January, Shift 1 · Question 1
    Let the relation R on the set $M=\{1, 2, 3, \ldots, 16\}$ be given by
    $R=\{(x, y): 4y=5x-3,\ x, y \in M\}$.
    Then the minimum number of elements required to be added in R, in order to make the relation symmetric, is equal to

    1. $2$
    2. $3$
    3. $4$
    4. $1$
    Show answer and solution

    Answer: (a)

    $4y=5x-3$ needs $5x\equiv3 \pmod 4$, i.e. $x\equiv3 \pmod 4$.
    $x=3\Rightarrow y=3$; $x=7\Rightarrow y=8$; $x=11\Rightarrow y=13$; $x=15\Rightarrow y=18\notin M$.
    $R=\{(3,3),(7,8),(11,13)\}$. For symmetry add $(8,7)$ and $(13,11)$: $2$ elements.

  10. JEE Main 2026, 22 January, Shift 2 · Question 1
    The number of elements in the relation $R=\{(x, y): 4x^2+y^2<52,\ x, y\in\mathbf{Z}\}$ is

    1. $67$
    2. $77$
    3. $86$
    4. $89$
    Show answer and solution

    Answer: (b)

    $4x^2<52$ gives $|x|\le3$. Count integers $y$ with $y^2<52-4x^2$:
    $x=0$: $y^2<52$, $|y|\le7$: 15. $x=\pm1$: $y^2<48$, $|y|\le6$: $2\times13=26$.
    $x=\pm2$: $y^2<36$, $|y|\le5$: $2\times11=22$. $x=\pm3$: $y^2<16$, $|y|\le3$: $2\times7=14$.
    Total $=15+26+22+14=77$.

  11. JEE Main 2026, 23 January, Shift 1 · Question 1
    Let $A=\{-2, -1, 0, 1, 2, 3, 4\}$. Let R be a relation on A defined by $xRy$ if and only if $2x+y\le2$. Let $l$ be the number of elements in R. Let m and n be the minimum number of elements required to be added in R to make it reflexive and symmetric relations respectively. Then $l+m+n$ is equal to :

    1. $35$
    2. $32$
    3. $33$
    4. $34$
    Show answer and solution

    Answer: (c)

    For each $x$, count $y\in A$ with $y\le2-2x$: $x=-2$: 7; $x=-1$: 7; $x=0$: 5; $x=1$: 3; $x=2$: 1; $x=3,4$: 0. So $l=23$.
    $(x,x)\in R$ needs $3x\le2$, i.e. $x\le0$; the pairs $(1,1),(2,2),(3,3),(4,4)$ are missing, so $m=4$.
    Pairs in R whose reverse is not in R: $(-2,3),(-2,4),(-1,2),(-1,3),(-1,4),(0,2)$, so $n=6$.
    $l+m+n=23+4+6=33$.

  12. JEE Main 2026, 23 January, Shift 2 · Question 1
    Let $A=\{0, 1, 2, \ldots, 9\}$. Let R be a relation on A defined by $(x, y)\in R$ if and only if $|x-y|$ is a multiple of 3.
    Given below are two statements:
    Statement I: $n(R)=36$.
    Statement II: R is an equivalence relation.
    In the light of the above statements, choose the correct answer from the options given below

    1. Both Statement I and Statement II are correct
    2. Both Statement I and Statement II are incorrect
    3. Statement I is correct but Statement II is incorrect
    4. Statement I is incorrect but Statement II is correct
    Show answer and solution

    Answer: (d)

    $(x,y)\in R$ exactly when $x$ and $y$ leave the same remainder on division by 3. The classes are $\{0,3,6,9\}$, $\{1,4,7\}$, $\{2,5,8\}$.
    $n(R)=4^2+3^2+3^2=34$, so Statement I is incorrect.
    "Same remainder" is reflexive, symmetric and transitive, so R is an equivalence relation: Statement II is correct.

  13. JEE Main 2026, 23 January, Shift 2 · Question 2
    Consider two sets $A=\{x\in\mathbb{Z}: \left|\left(|x-3|-3\right)\right|\le1\}$ and $B=\left\{x\in\mathbb{R}-\{1, 2\}: \dfrac{(x-2)(x-4)}{x-1}\log_e\left(|x-2|\right)=0\right\}$. Then the number of onto functions $f: A\rightarrow B$ is equal to

    1. $32$
    2. $62$
    3. $79$
    4. $81$
    Show answer and solution

    Answer: (b)

    A: $2\le|x-3|\le4$, so $x-3\in\{-4,-3,-2,2,3,4\}$ and $A=\{-1,0,1,5,6,7\}$ (6 elements).
    B: $x=4$ (from $x-4=0$) or $|x-2|=1$, i.e. $x=3$ ($x=1$ and $x=2$ are excluded). So $B=\{3,4\}$.
    Onto functions from a 6-element set to a 2-element set: $2^6-2=62$.

  14. JEE Main 2026, 24 January, Shift 1 · Question 1
    Let R be a relation defined on the set $\{1, 2, 3, 4\}\times\{1, 2, 3, 4\}$ by
    $R=\{((a, b), (c, d)) : 2a+3b=3c+4d\}$.
    Then the number of elements in R is

    1. $6$
    2. $12$
    3. $15$
    4. $18$
    Show answer and solution

    Answer: (b)

    $2a+3b=3c+4d \iff 2(a-2d)=3(c-b)$, so $a-2d$ is a multiple of 3 and $c-b=\dfrac{2(a-2d)}{3}$.
    With $a,d\in\{1,\ldots,4\}$, $a-2d\in\{-7,\ldots,2\}$, so $a-2d\in\{-6,-3,0\}$, giving $c-b\in\{-4,-2,0\}$; $-4$ is impossible.
    $a-2d=0$: $(a,d)=(2,1),(4,2)$ with $c=b$ (4 ways): 8 elements.
    $a-2d=-3$: $(a,d)=(1,2),(3,3)$ with $c=b-2$, $b\in\{3,4\}$: 4 elements.
    Total $=12$.

  15. JEE Main 2026, 28 January, Shift 2 · Question 2
    Given below are two statements :
    Statement I : The function $f:\mathbf{R}\to\mathbf{R}$ defined by $f(x)=\dfrac{x}{1+|x|}$ is one-one.
    Statement II : The function $f:\mathbf{R}\to\mathbf{R}$ defined by $f(x)=\dfrac{x^2+4x-30}{x^2-8x+18}$ is many-one.
    In the light of the above statements, choose the correct answer from the options given below :

    1. Both Statement I and Statement II are true
    2. Both Statement I and Statement II are false
    3. Statement I is true but Statement II is false
    4. Statement I is false but Statement II is true
    Show answer and solution

    Answer: (a)

    Statement I: for $x\ge0$, $f(x)=\dfrac{x}{1+x}$ and for $x<0$, $f(x)=\dfrac{x}{1-x}$; both pieces are strictly increasing and $f$ keeps the sign of $x$, so $f$ is one-one. True.
    Statement II: the denominator has discriminant $64-72<0$, so $f$ is defined on all of $\mathbf{R}$. $f(x)=c$ gives $(1-c)x^2+(4+8c)x-(30+18c)=0$, which has two distinct real roots for suitable $c$ (e.g. $c=0$: $x^2+4x-30=0$). So $f$ is many-one. True.

  16. JEE Main 2025, 22 January, Shift 1 · Question 2
    The number of non-empty equivalence relations on the set $\{1, 2, 3\}$ is :

    1. $4$
    2. $5$
    3. $6$
    4. $7$
    Show answer and solution

    Answer: (b)

    Equivalence relations on a set correspond one-to-one with its partitions.
    Partitions of $\{1,2,3\}$: one block (1 way), a pair and a singleton (3 ways), three singletons (1 way).
    Total $=5$ (every equivalence relation on a non-empty set is non-empty).

  17. JEE Main 2025, 22 January, Shift 2 · Question 1
    Let $A=\{1, 2, 3, 4\}$ and $B=\{1, 4, 9, 16\}$. Then the number of many-one functions $f:A\to B$ such that $1\in f(A)$ is equal to :

    1. $127$
    2. $139$
    3. $151$
    4. $163$
    Show answer and solution

    Answer: (c)

    Functions $A\to B$ whose range contains 1: $4^4-3^4=256-81=175$.
    The one-one functions (bijections, $4!=24$) all contain 1 in the range and must be excluded.
    Many-one functions: $175-24=151$.

  18. JEE Main 2025, 22 January, Shift 2 · Question 25
    Let $A=\{1, 2, 3\}$. The number of relations on A, containing $(1, 2)$ and $(2, 3)$, which are reflexive and transitive but not symmetric, is __________.

    Show answer and solution

    Answer: 3

    Reflexivity and transitivity force $(1,1), (2,2), (3,3)$ and $(1,3)$. The only other pairs are $(2,1)$, $(3,2)$, $(3,1)$.
    Adding nothing, only $(2,1)$, or only $(3,2)$ keeps the relation transitive. Adding $(3,1)$ forces $(3,2)$ and then $(2,1)$; adding both $(2,1)$ and $(3,2)$ forces $(3,1)$, giving the full relation, which is symmetric.
    Number $=3$.

  19. JEE Main 2025, 23 January, Shift 1 · Question 1
    Let $f(x)=\log_e x$ and $g(x)=\dfrac{x^4-2x^3+3x^2-2x+2}{2x^2-2x+1}$. Then the domain of $fog$ is

    1. $\mathbb{R}$
    2. $[0,\infty)$
    3. $(0,\infty)$
    4. $[1,\infty)$
    Show answer and solution

    Answer: (a)

    $f\circ g$ needs $g(x)>0$.
    Denominator: $2x^2-2x+1=x^2+(x-1)^2>0$ for every $x$.
    Numerator: $x^4-2x^3+3x^2-2x+2=(x^2-x)^2+2(x^2-x+1)>0$, since $x^2-x+1>0$ always.
    So $g(x)>0$ for all real $x$ and the domain is $\mathbb{R}$.

  20. JEE Main 2025, 23 January, Shift 1 · Question 2
    Let $R=\{(1,2),(2,3),(3,3)\}$ be a relation defined on the set $\{1,2,3,4\}$. Then the minimum number of elements, needed to be added in $R$ so that $R$ becomes an equivalence relation, is:

    1. $7$
    2. $8$
    3. $9$
    4. $10$
    Show answer and solution

    Answer: (a)

    Since $1R2$ and $2R3$, transitivity and symmetry force $1,2,3$ into one class, so all 9 pairs of $\{1,2,3\}\times\{1,2,3\}$ are needed; 4 needs only $(4,4)$.
    The smallest equivalence relation has $9+1=10$ pairs.
    $R$ already has 3 of them, so $10-3=7$ must be added: $(1,1),(2,2),(2,1),(3,2),(1,3),(3,1),(4,4)$.

  21. JEE Main 2025, 23 January, Shift 2 · Question 2
    Let $X=\mathbf{R}\times\mathbf{R}$. Define a relation R on X as :
    $(a_1, b_1)\,R\,(a_2, b_2)\Leftrightarrow b_1=b_2$.
    Statement I : R is an equivalence relation.
    Statement II : For some $(a, b)\in X$, the set $S=\{(x, y)\in X:(x, y)\,R\,(a, b)\}$ represents a line parallel to $y=x$.
    In the light of the above statements, choose the correct answer from the options given below :

    1. Both Statement I and Statement II are true
    2. Both Statement I and Statement II are false
    3. Statement I is true but Statement II is false
    4. Statement I is false but Statement II is true
    Show answer and solution

    Answer: (c)

    "Same second coordinate" is reflexive, symmetric and transitive, so R is an equivalence relation: Statement I is true.
    $S=\{(x,y): y=b\}$ is the horizontal line $y=b$, which is parallel to the $x$-axis, never to $y=x$: Statement II is false.

  22. JEE Main 2025, 24 January, Shift 2 · Question 1
    The function $f:(-\infty, \infty)\to(-\infty, 1)$, defined by $f(x)=\dfrac{2^x-2^{-x}}{2^x+2^{-x}}$ is :

    1. One-one but not onto
    2. Onto but not one-one
    3. Both one-one and onto
    4. Neither one-one nor onto
    Show answer and solution

    Answer: (a)

    $f(x)=\dfrac{4^x-1}{4^x+1}=1-\dfrac{2}{4^x+1}$ is strictly increasing, so it is one-one.
    As $x\to\pm\infty$, $f(x)\to\pm1$, so the range is $(-1,1)$, which is smaller than the codomain $(-\infty,1)$: not onto.

  23. JEE Main 2025, 28 January, Shift 1 · Question 1
    The relation $R=\{(x, y): x, y\in\mathbf{Z} \text{ and } x+y \text{ is even}\}$ is:

    1. reflexive and transitive but not symmetric
    2. reflexive and symmetric but not transitive
    3. symmetric and transitive but not reflexive
    4. an equivalence relation
    Show answer and solution

    Answer: (d)

    Reflexive: $x+x=2x$ is even.
    Symmetric: $x+y=y+x$.
    Transitive: if $x+y$ and $y+z$ are even, then $x+z=(x+y)+(y+z)-2y$ is even.
    So $R$ is an equivalence relation.

  24. JEE Main 2025, 28 January, Shift 2 · Question 2
    Let $f:[0, 3]\to A$ be defined by $f(x)=2x^3-15x^2+36x+7$ and $g:[0, \infty)\to B$ be defined by $g(x)=\dfrac{x^{2025}}{x^{2025}+1}$. If both the functions are onto and $S=\{x\in\mathbf{Z}: x\in A \text{ or } x\in B\}$, then $n(S)$ is equal to :

    1. $36$
    2. $31$
    3. $30$
    4. $29$
    Show answer and solution

    Answer: (c)

    $f'(x)=6x^2-30x+36=6(x-2)(x-3)$, so $f$ rises on $[0,2]$ and falls on $[2,3]$.
    $f(0)=7$, $f(2)=35$, $f(3)=34$, so $A=[7,35]$.
    $g(x)=1-\dfrac{1}{x^{2025}+1}$ takes every value in $[0,1)$, so $B=[0,1)$.
    Integers in $A\cup B$: $0$ and $7,8,\ldots,35$, i.e. $1+29=30$.

  25. JEE Main 2025, 29 January, Shift 1 · Question 1
    Define a relation R on the interval $\left[0, \dfrac{\pi}{2}\right)$ by $x$ R $y$ if and only if $\sec^2x-\tan^2y=1$. Then R is :

    1. reflexive but neither symmetric not transitive
    2. both reflexive and symmetric but not transitive
    3. both reflexive and transitive but not symmetric
    4. an equivalence relation
    Show answer and solution

    Answer: (d)

    $\sec^2x-\tan^2y=1\iff\tan^2x=\tan^2y$. On $\left[0,\tfrac\pi2\right)$, $\tan$ is non-negative and increasing, so this means $x=y$.
    Equality is reflexive, symmetric and transitive: R is an equivalence relation.
