  1. JEE Main 2026, 2 April, Shift 2 · Question 21
    Let $A=\{2, 3, 4, 5, 6\}$. Let R be a relation on the set $A\times A$ given by $(x, y)R(z, w)$ if and only if $x$ divides $z$ and $y \le w$. Then the number of elements in R is __________.

    Show answer and solution

    Answer: 120

    Pairs $(x,z)$ with $x \mid z$: $x=2$: $z=2,4,6$; $x=3$: $z=3,6$; $x=4,5,6$: one each. Total $3+2+1+1+1=8$.
    Pairs $(y,w)$ with $y\le w$: $\dfrac{5\cdot6}{2}=15$.
    Number of elements $=8\times15=120$.

  2. JEE Main 2026, 4 April, Shift 1 · Question 4
    The number of functions $f:\{1,2,3,4\}\to\{a,b,c\}$, which are not onto, is:

    1. $48$
    2. $45$
    3. $51$
    4. $35$
    Show answer and solution

    Answer: (b)

    Total functions: $3^4=81$.
    Onto functions: $3^4-\binom31 2^4+\binom32 1^4=81-48+3=36$.
    Not onto: $81-36=45$.

  3. JEE Main 2026, 4 April, Shift 2 · Question 1
    For the function $f:[1,\infty)\to[1,\infty)$ defined by $f(x)=(x-1)^4+1$, among the two statements:
    (I) The set $S=\{x\in[1,\infty): f(x)=f^{-1}(x)\}$ contains exactly two elements, and
    (II) The set $S=\{x\in[1,\infty): f(x)=f^{-1}(x+1)\}$ is an empty set,

    1. only (I) is TRUE
    2. only (II) is TRUE
    3. both (I) and (II) are TRUE
    4. neither (I) nor (II) is TRUE
    Show answer and solution

    Answer: (a)

    $f$ is strictly increasing on $[1,\infty)$, so $f(x)=f^{-1}(x)\iff f(x)=x$.
    $(x-1)^4+1=x\iff (x-1)^4=x-1\iff x=1$ or $x=2$. So (I) is true.
    For (II): $f(x)=f^{-1}(x+1)\iff f(f(x))=x+1$. Let $h(x)=f(f(x))-x-1$.
    $h(2)=f(2)-3=2-3=-1<0$, while $h(x)\to\infty$ as $x\to\infty$, and $h$ is continuous, so $h$ has a root in $(2,\infty)$.
    So the set in (II) is not empty: (II) is false. Only (I) is TRUE.

  4. JEE Main 2026, 6 April, Shift 2 · Question 1
    Let $f : \mathbf{R} \to \mathbf{R}$ be defined as $f(x) = \dfrac{2x^2-3x+2}{3x^2+x+3}$. Then $f$ is :

    1. both one-one and onto
    2. one-one but not onto
    3. onto but not one-one
    4. neither one-one nor onto
    Show answer and solution

    Answer: (d)

    $3x^2+x+3>0$ for all $x$, so $f$ is continuous on $\mathbf{R}$, and $f(x)\to\dfrac23$ as $x\to\infty$.
    $f(0)=\dfrac23$, $f(1)=\dfrac17$: every value between $\dfrac17$ and $\dfrac23$ is taken once in $(0,1)$ and again in $(1,\infty)$, so $f$ is not one-one.
    Range: $y(3x^2+x+3)=2x^2-3x+2 \Rightarrow (3y-2)x^2+(y+3)x+(3y-2)=0$; real $x$ needs $(y+3)^2\ge4(3y-2)^2$, a bounded interval of $y$.
    So the range is a bounded interval, not $\mathbf{R}$: $f$ is not onto.
    Hence $f$ is neither one-one nor onto.

  5. JEE Main 2026, 6 April, Shift 2 · Question 21
    Let $R=\left\{(x,y)\in\mathbf{N}\times\mathbf{N} : \log_e(x+y)\le2\right\}$. Then the minimum number of elements, required to be added in R to make it a transitive relation, is __________.

    Show answer and solution

    Answer: 15

    $x+y\le e^2\approx7.39 \Rightarrow x+y\le7$; $R$ has $6+5+4+3+2+1=21$ pairs, all with $x,y\in\{1,\ldots,6\}$.
    For any $a, c\in\{1,\ldots,6\}$: $(a,1)\in R$ and $(1,c)\in R$, so transitivity forces $(a,c)$.
    So the smallest transitive relation containing $R$ is $\{1,\ldots,6\}^2$, with $36$ pairs (it is transitive).
    Elements to add $=36-21=15$.

  6. JEE Main 2026, 8 April, Shift 2 · Question 1
    Consider the relation R on the set $\{-2,-1,0,1,2\}$ defined by $(a,b)\in R$ if and only if $1+ab>0$. Then, among the statements :
    I. The number of elements in R is 17
    II. R is an equivalence relation

    1. Only I is true
    2. Only II is true
    3. Both I and II are true
    4. Neither I nor II is true
    Show answer and solution

    Answer: (a)

    $1+ab>0 \iff ab\ge 0$ (as $ab$ is an integer).
    Pairs with $ab<0$: $a,b$ non-zero with opposite signs: $2\cdot2\cdot2=8$ pairs. So $|R|=25-8=17$: I is true.
    $R$ is reflexive ($1+a^2>0$) and symmetric, but $(1,0),(0,-1)\in R$ while $(1,-1)\notin R$ ($1-1=0$). Not transitive, so II is false.
    Only I is true.
