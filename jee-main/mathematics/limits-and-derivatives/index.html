  1. JEE Main 2026, 2 April, Shift 1 · Question 16
    If $\displaystyle\lim_{x\to2}\frac{\sin\left(x^3-5x^2+ax+b\right)}{\left(\sqrt{x-1}-1\right)\log_e(x-1)}=m$, then $a+b+m$ is equal to :

    1. $5$
    2. $6$
    3. $8$
    4. $10$
    Show answer and solution

    Answer: (b)

    As $x\to2$: $\sqrt{x-1}-1\sim\dfrac{x-2}{2}$ and $\log_e(x-1)\sim x-2$, so the denominator $\sim\dfrac{(x-2)^2}{2}$.
    For a finite limit, $p(x)=x^3-5x^2+ax+b$ must have a double root at $2$: $p(2)=2a+b-12=0$, $p'(2)=a-8=0$.
    So $a=8,\ b=-4$ and $p(x)=(x-2)^2(x-1)$.
    $m=\lim\dfrac{(x-2)^2(x-1)}{(x-2)^2/2}=2$.
    $a+b+m=8-4+2=6$.

  2. JEE Main 2026, 5 April, Shift 1 · Question 17
    The product of all possible values of $\alpha$, for which

    $\displaystyle \lim_{x \to 0}\left(\frac{1-\cos(\alpha x)\cos((\alpha+1)x)\cos((\alpha+2)x)}{\sin^2((\alpha+1)x)}\right) = 2,$
    is:

    1. $-2$
    2. $1$
    3. $-1$
    4. $\dfrac{5}{4}$
    Show answer and solution

    Answer: (c)

    For small $x$: $\cos(\alpha x)\cos((\alpha+1)x)\cos((\alpha+2)x)\approx1-\dfrac{x^2}{2}\left[\alpha^2+(\alpha+1)^2+(\alpha+2)^2\right]$.
    So the limit is $\dfrac{3\alpha^2+6\alpha+5}{2(\alpha+1)^2}=2$.
    $3\alpha^2+6\alpha+5=4\alpha^2+8\alpha+4 \Rightarrow \alpha^2+2\alpha-1=0$.
    Product of the roots $=-1$.

  3. JEE Main 2026, 5 April, Shift 2 · Question 17
    Let $f(x)=\displaystyle\lim_{y\to0}\dfrac{(1-\cos(xy))\tan(xy)}{y^3}$. Then the number of solutions of the equation $f(x)=\sin x$, $x\in\mathbb{R}$ is :

    1. $0$
    2. $2$
    3. $3$
    4. $1$
    Show answer and solution

    Answer: (c)

    With $u=xy$: $(1-\cos u)\tan u\approx\dfrac{u^2}{2}\cdot u=\dfrac{x^3y^3}{2}$, so $f(x)=\dfrac{x^3}{2}$.
    Solve $\dfrac{x^3}{2}=\sin x$. $x=0$ is a root. For small $x>0$, $\dfrac{x^3}{2}<\sin x$; at $x=1.5$, $\dfrac{x^3}{2}\approx1.69>\sin x$; for $x>\sqrt[3]{2}$, $\dfrac{x^3}{2}>1\ge\sin x$. So exactly one positive root.
    Both sides are odd, giving one negative root too.
    Number of solutions $=3$.

  4. JEE Main 2026, 6 April, Shift 1 · Question 17
    The value of $\lim\limits_{x\to0}\left(\dfrac{x^2\sin^2x}{x^2-\sin^2x}\right)$ is:

    1. $2$
    2. $3$
    3. $4$
    4. $6$
    Show answer and solution

    Answer: (b)

    $\sin^2x=x^2-\dfrac{x^4}{3}+O(x^6)$, so $x^2-\sin^2x=\dfrac{x^4}{3}+O(x^6)$.
    Numerator $x^2\sin^2x=x^4+O(x^6)$.
    Limit $=\dfrac{1}{1/3}=3$.

  5. JEE Main 2026, 6 April, Shift 2 · Question 16
    Let $\displaystyle\lim_{x\to2}\dfrac{(\tan(x-2))\left(rx^2+(p-2)x-2p\right)}{(x-2)^2}=5$ for some $r, p\in\mathbf{R}$. If the set of all possible values of $q$, such that the roots of the equation $rx^2-px+q=0$ lie in $(0,2)$, be the interval $(\alpha,\beta]$, then $4(\alpha+\beta)$ equals :

    1. $11$
    2. $13$
    3. $17$
    4. $21$
    Show answer and solution

    Answer: (c)

    Since $\dfrac{\tan(x-2)}{x-2}\to1$, we need $\dfrac{rx^2+(p-2)x-2p}{x-2}\to5$.
    The numerator must vanish at $x=2$: $4r+2p-4-2p=0 \Rightarrow r=1$; then $x^2+(p-2)x-2p=(x-2)(x+p)$, so $2+p=5$, $p=3$.
    $x^2-3x+q=0$ with both roots in $(0,2)$: $D\ge0 \Rightarrow q\le\dfrac94$; vertex $\dfrac32\in(0,2)$; $f(0)=q>0$; $f(2)=q-2>0$.
    So $q\in\left(2,\dfrac94\right]$ and $4(\alpha+\beta)=4\left(2+\dfrac94\right)=17$.

  6. JEE Main 2026, 21 January, Shift 1 · Question 20
    Let $f:\mathbf{R}\to(0,\infty)$ be a twice differentiable function such that $f(3)=18$, $f'(3)=0$ and $f''(3)=4$. Then $\displaystyle\lim_{x\to1}\left(\log_e\left(\frac{f(2+x)}{f(3)}\right)^{\frac{18}{(x-1)^2}}\right)$ is equal to :

    1. $1$
    2. $2$
    3. $9$
    4. $18$
    Show answer and solution

    Answer: (b)

    Let $h=x-1$ and $g=\log_e f$. The limit is $\displaystyle\lim_{h\to0}\frac{18\left[g(3+h)-g(3)\right]}{h^2}$.
    $g'(3)=\dfrac{f'(3)}{f(3)}=0$ and $g''(3)=\dfrac{f''(3)f(3)-f'(3)^2}{f(3)^2}=\dfrac{4}{18}=\dfrac29$.
    So $g(3+h)-g(3)\approx\dfrac{g''(3)}{2}h^2=\dfrac{h^2}{9}$ and the limit is $18\cdot\dfrac19=2$.

  7. JEE Main 2026, 21 January, Shift 2 · Question 17
    Let $f(x)=x^3+x^2f'(1)+2xf''(2)+f'''(3)$, $x\in\mathbf{R}$. Then the value of $f'(5)$ is :

    1. $\dfrac{2}{5}$
    2. $\dfrac{62}{5}$
    3. $\dfrac{657}{5}$
    4. $\dfrac{117}{5}$
    Show answer and solution

    Answer: (d)

    Let $p=f'(1)$, $q=f''(2)$. Then $f'(x)=3x^2+2px+2q$ and $f''(x)=6x+2p$.
    $p=3+2p+2q$ and $q=12+2p$, so $p+2q=-3$ gives $5p=-27$: $p=-\dfrac{27}{5}$, $q=\dfrac65$.
    $f'(5)=75+10p+2q=75-54+\dfrac{12}{5}=\dfrac{117}{5}$.

  8. JEE Main 2026, 22 January, Shift 2 · Question 17
    If $\displaystyle\lim_{x\to0}\dfrac{e^{(a-1)x}+2\cos bx+(c-2)e^{-x}}{x\cos x-\log_e(1+x)}=2$, then $a^2+b^2+c^2$ is equal to :

    1. $3$
    2. $5$
    3. $7$
    4. $9$
    Show answer and solution

    Answer: (c)

    Denominator: $x\left(1-\dfrac{x^2}{2}\right)-\left(x-\dfrac{x^2}{2}+\ldots\right)=\dfrac{x^2}{2}+O(x^3)$.
    So the numerator must start at $x^2$: constant term $1+2+c-2=0\Rightarrow c=-1$; $x$ term $(a-1)+3=0\Rightarrow a=-2$.
    Numerator $=e^{-3x}+2\cos bx-3e^{-x}$, whose $x^2$ coefficient is $\dfrac92-b^2-\dfrac32=3-b^2$.
    Limit $=\dfrac{3-b^2}{1/2}=2\Rightarrow b^2=2$. Hence $a^2+b^2+c^2=4+2+1=7$.

  9. JEE Main 2026, 28 January, Shift 1 · Question 18
    The value of $\displaystyle\lim_{x\to0}\dfrac{\log_e\left(\sec(ex)\cdot\sec\left(e^2x\right)\cdot\ldots\cdot\sec\left(e^{10}x\right)\right)}{e^2-e^{2\cos x}}$ is equal to

    1. $\dfrac{e^{20}-1}{2\left(e^2-1\right)}$
    2. $\dfrac{e^{20}-1}{2e^2\left(e^2-1\right)}$
    3. $\dfrac{e^{10}-1}{2\left(e^2-1\right)}$
    4. $\dfrac{e^{10}-1}{2e^2\left(e^2-1\right)}$
    Show answer and solution

    Answer: (a)

    $\ln\sec\theta\approx\theta^2/2$, so the numerator $\approx\dfrac{x^2}{2}\displaystyle\sum_{k=1}^{10}e^{2k}=\dfrac{x^2}{2}\cdot\dfrac{e^2(e^{20}-1)}{e^2-1}$.
    Denominator $=e^2\left(1-e^{2\cos x-2}\right)\approx e^2(2-2\cos x)\approx e^2x^2$.
    Limit $=\dfrac{e^{20}-1}{2(e^2-1)}$.

  10. JEE Main 2025, 2 April, Shift 1 · Question 7
    For $\alpha, \beta, \gamma\in\mathbf{R}$, if $\displaystyle\lim_{x\to0}\frac{x^2\sin\alpha x+(\gamma-1)e^{x^2}}{\sin2x-\beta x}=3$, then $\beta+\gamma-\alpha$ is equal to :

    1. $-1$
    2. $4$
    3. $6$
    4. $7$
    Show answer and solution

    Answer: (d)

    The denominator tends to 0, so the numerator must too: $\gamma-1=0$, $\gamma=1$.
    The numerator is then $x^2\sin\alpha x\approx\alpha x^3$. The denominator is $(2-\beta)x-\dfrac{4}{3}x^3+\cdots$; for a finite non-zero limit we need $\beta=2$.
    Limit $=\dfrac{\alpha}{-4/3}=3$, so $\alpha=-4$.
    $\beta+\gamma-\alpha=2+1+4=7$.

  11. JEE Main 2025, 2 April, Shift 2 · Question 17
    If $\displaystyle\lim_{x\to0}\frac{\cos(2x)+a\cos(4x)-b}{x^4}$ is finite, then $(a+b)$ is equal to :

    1. $\dfrac12$
    2. $0$
    3. $\dfrac34$
    4. $-1$
    Show answer and solution

    Answer: (a)

    $\cos2x=1-2x^2+\dfrac23x^4-\cdots$ and $\cos4x=1-8x^2+\dfrac{32}{3}x^4-\cdots$.
    The numerator is $(1+a-b)-(2+8a)x^2+\cdots$; for a finite limit both brackets vanish: $a=-\dfrac14$, $b=\dfrac34$.
    $a+b=\dfrac12$.

  12. JEE Main 2025, 3 April, Shift 2 · Question 25
    If $\displaystyle\lim_{x\to0}\left(\frac{\tan x}{x}\right)^{\frac{1}{x^2}}=p$, then $96\log_ep$ is equal to __________

    Show answer and solution

    Answer: 32

    $\dfrac{\tan x}{x}=1+\dfrac{x^2}{3}+\cdots$, so $\log_ep=\displaystyle\lim_{x\to0}\frac{1}{x^2}\cdot\frac{x^2}{3}=\frac13$.
    $96\log_ep=32$.

  13. JEE Main 2025, 4 April, Shift 1 · Question 17
    If $\displaystyle\lim_{x\to1^+}\frac{(x-1)\left(6+\lambda\cos(x-1)\right)+\mu\sin(1-x)}{(x-1)^3}=-1$, where $\lambda, \mu\in\mathbb{R}$, then $\lambda+\mu$ is equal to

    1. $17$
    2. $18$
    3. $19$
    4. $20$
    Show answer and solution

    Answer: (b)

    Put $t=x-1\to0^+$. The numerator is $t(6+\lambda\cos t)-\mu\sin t=(6+\lambda-\mu)t+\left(\dfrac{\mu}{6}-\dfrac{\lambda}{2}\right)t^3+\cdots$.
    For a finite limit, $6+\lambda-\mu=0$; then $\dfrac{\mu}{6}-\dfrac{\lambda}{2}=-1$.
    With $\mu=6+\lambda$: $1+\dfrac{\lambda}{6}-\dfrac{\lambda}{2}=-1$, so $\lambda=6$, $\mu=12$ and $\lambda+\mu=18$.

  14. JEE Main 2025, 4 April, Shift 1 · Question 18
    Let $f:\mathbb{R}\to\mathbb{R}$ be a continuous function satisfying $f(0)=1$ and $f(2x)-f(x)=x$ for all $x\in\mathbb{R}$. If $\displaystyle\lim_{n\to\infty}\left\{f(x)-f\left(\frac{x}{2^n}\right)\right\}=G(x)$, then $\displaystyle\sum_{r=1}^{10}G(r^2)$ is equal to

    1. $215$
    2. $385$
    3. $420$
    4. $540$
    Show answer and solution

    Answer: (b)

    Replacing $x$ by $\dfrac{x}{2^k}$: $f\left(\dfrac{x}{2^{k-1}}\right)-f\left(\dfrac{x}{2^k}\right)=\dfrac{x}{2^k}$.
    Adding for $k=1, \ldots, n$: $f(x)-f\left(\dfrac{x}{2^n}\right)=x\left(1-\dfrac{1}{2^n}\right)\to x$, so $G(x)=x$.
    $\displaystyle\sum_{r=1}^{10}r^2=385$.

  15. JEE Main 2025, 4 April, Shift 2 · Question 16
    Let f be a differentiable function on $\mathbb{R}$ such that $f(2)=1$, $f'(2)=4$. Let $\displaystyle\lim_{x\to0}\left(f(2+x)\right)^{3/x}=e^\alpha$. Then the number of times the curve $y=4x^3-4x^2-4(\alpha-7)x-\alpha$ meets x-axis is :

    1. $0$
    2. $1$
    3. $2$
    4. $3$
    Show answer and solution

    Answer: (c)

    The limit is of the form $1^\infty$: $\alpha=\displaystyle\lim_{x\to0}\frac{3\left(f(2+x)-1\right)}{x}=3f'(2)=12$.
    $y=4x^3-4x^2-20x-12=4(x+1)^2(x-3)$.
    The curve touches the x-axis at $x=-1$ and crosses it at $x=3$: it meets the axis at 2 points.

  16. JEE Main 2025, 7 April, Shift 1 · Question 16
    $\displaystyle\lim_{x\to0^+}\frac{\tan\left(5(x)^{\frac13}\right)\log_e\left(1+3x^2\right)}{\left(\tan^{-1}3\sqrt{x}\right)^2\left(e^{5(x)^{\frac43}}-1\right)}$ is equal to

    1. $1$
    2. $\dfrac13$
    3. $\dfrac53$
    4. $\dfrac{1}{15}$
    Show answer and solution

    Answer: (b)

    Use $\tan u\sim u$, $\log_e(1+u)\sim u$, $\tan^{-1}u\sim u$, $e^u-1\sim u$ as $u\to0$.
    Numerator $\sim 5x^{1/3}\cdot3x^2=15x^{7/3}$; denominator $\sim 9x\cdot5x^{4/3}=45x^{7/3}$.
    Limit $=\dfrac{15}{45}=\dfrac13$.

  17. JEE Main 2025, 7 April, Shift 2 · Question 23
    For $t>-1$, let $\alpha_t$ and $\beta_t$ be the roots of the equation $\left((t+2)^{1/7}-1\right)x^2+\left((t+2)^{1/6}-1\right)x+\left((t+2)^{1/21}-1\right)=0$. If $\displaystyle\lim_{t\to-1^+}\alpha_t=a$ and $\displaystyle\lim_{t\to-1^+}\beta_t=b$, then $72(a+b)^2$ is equal to ______.

    Show answer and solution

    Answer: 98

    Put $h=t+1\to0^+$; $(1+h)^{1/k}-1\sim\dfrac hk$. Dividing the equation by $h$, the limiting equation is $\dfrac{x^2}{7}+\dfrac x6+\dfrac1{21}=0$, i.e. $6x^2+7x+2=0$.
    $a+b=-\dfrac76$, so $72(a+b)^2=72\cdot\dfrac{49}{36}=98$.

  18. JEE Main 2025, 7 April, Shift 2 · Question 25
    If the function $f(x)=\dfrac{\tan(\tan x)-\sin(\sin x)}{\tan x-\sin x}$ is continuous at $x=0$, then $f(0)$ is equal to ______.

    Show answer and solution

    Answer: 2

    Near 0: $\tan x=x+\dfrac{x^3}3+\cdots$, so $\tan(\tan x)=x+\dfrac{2x^3}{3}+\cdots$; $\sin x=x-\dfrac{x^3}6+\cdots$, so $\sin(\sin x)=x-\dfrac{x^3}{3}+\cdots$.
    Numerator $\sim x^3$; denominator $\tan x-\sin x\sim\dfrac{x^3}{2}$.
    $f(0)=\lim\limits_{x\to0}f(x)=2$.

  19. JEE Main 2025, 8 April, Shift 2 · Question 16
    Given below are two statements:
    Statement I : $\displaystyle\lim_{x\to0}\left(\frac{\tan^{-1}x+\log_e\sqrt{\frac{1+x}{1-x}}-2x}{x^5}\right)=\frac25$
    Statement II : $\displaystyle\lim_{x\to1}\left(x^{\frac{2}{1-x}}\right)=\frac{1}{e^2}$
    In the light of the above statements, choose the correct answer from the options given below

    1. Both Statement I and Statement II are true
    2. Both Statement I and Statement II are false
    3. Statement I is true but Statement II is false
    4. Statement I is false but Statement II is true
    Show answer and solution

    Answer: (a)

    Statement I: $\tan^{-1}x=x-\dfrac{x^3}{3}+\dfrac{x^5}{5}-\cdots$ and $\log_e\sqrt{\dfrac{1+x}{1-x}}=x+\dfrac{x^3}{3}+\dfrac{x^5}{5}+\cdots$, so the numerator is $\dfrac{2x^5}{5}+\cdots$ and the limit is $\dfrac25$. True.
    Statement II: the limit is $\exp\left(\displaystyle\lim_{x\to1}\frac{2\log_e x}{1-x}\right)=e^{-2}$. True.

  20. JEE Main 2025, 22 January, Shift 2 · Question 16
    If $\displaystyle\lim_{x\to\infty}\left(\left(\frac{e}{1-e}\right)\left(\frac{1}{e}-\frac{x}{1+x}\right)\right)^x=\alpha$, then the value of $\dfrac{\log_e\alpha}{1+\log_e\alpha}$ equals :

    1. $e^{-1}$
    2. $e$
    3. $e^2$
    4. $e^{-2}$
    Show answer and solution

    Answer: (b)

    The base is $g(x)=\dfrac{1}{1-e}\cdot\dfrac{1+(1-e)x}{1+x}\to1$, a $1^\infty$ form.
    $g(x)-1=\dfrac{e}{(1-e)(1+x)}$, so $\log_e\alpha=\displaystyle\lim_{x\to\infty}x\,(g(x)-1)=\frac{e}{1-e}$.
    $\dfrac{\log_e\alpha}{1+\log_e\alpha}=\dfrac{e/(1-e)}{1/(1-e)}=e$.

  21. JEE Main 2025, 23 January, Shift 2 · Question 14
    $\displaystyle\lim_{x\to\infty}\frac{(2x^2-3x+5)(3x-1)^{\frac{x}{2}}}{(3x^2+5x+4)\sqrt{(3x+2)^x}}$ is equal to :

    1. $\dfrac{2e}{3}$
    2. $\dfrac{2}{3\sqrt e}$
    3. $\dfrac{2}{\sqrt{3e}}$
    4. $\dfrac{2e}{\sqrt3}$
    Show answer and solution

    Answer: (b)

    $\dfrac{2x^2-3x+5}{3x^2+5x+4}\to\dfrac23$.
    $\dfrac{(3x-1)^{x/2}}{(3x+2)^{x/2}}=\left(1-\dfrac{3}{3x+2}\right)^{x/2}\to e^{\lim\left(-\frac{3}{3x+2}\cdot\frac x2\right)}=e^{-1/2}$.
    Limit $=\dfrac{2}{3\sqrt e}$.

  22. JEE Main 2025, 24 January, Shift 1 · Question 12
    $\displaystyle\lim_{x\to0}\operatorname{cosec}x\left(\sqrt{2\cos^2x+3\cos x}-\sqrt{\cos^2x+\sin x+4}\right)$ is:

    1. $0$
    2. $\dfrac{1}{2\sqrt5}$
    3. $-\dfrac{1}{2\sqrt5}$
    4. $\dfrac{1}{\sqrt{15}}$
    Show answer and solution

    Answer: (c)

    Both roots tend to $\sqrt5$, so the bracket $g(x)\to0$ and $\operatorname{cosec}x\sim\dfrac1x$; the limit is $g'(0)$.
    $\dfrac{d}{dx}\left(2\cos^2x+3\cos x\right)=-4\cos x\sin x-3\sin x\to0$; $\dfrac{d}{dx}\left(\cos^2x+\sin x+4\right)=-2\cos x\sin x+\cos x\to1$.
    $g'(0)=\dfrac{0}{2\sqrt5}-\dfrac{1}{2\sqrt5}=-\dfrac{1}{2\sqrt5}$.

  23. JEE Main 2025, 24 January, Shift 1 · Question 16
    Let $f:\mathbb{R}-\{0\}\to\mathbb{R}$ be a function such that $f(x)-6f\left(\dfrac1x\right)=\dfrac{35}{3x}-\dfrac52$. If the $\displaystyle\lim_{x\to0}\left(\dfrac{1}{\alpha x}+f(x)\right)=\beta$; $\alpha, \beta\in\mathbb{R}$, then $\alpha+2\beta$ is equal to

    1. $3$
    2. $4$
    3. $5$
    4. $6$
    Show answer and solution

    Answer: (b)

    Replace $x$ by $\dfrac1x$: $f\left(\dfrac1x\right)-6f(x)=\dfrac{35x}{3}-\dfrac52$.
    Eliminating $f\left(\dfrac1x\right)$: $f(x)=36f(x)+70x-15+\dfrac{35}{3x}-\dfrac52$, so $f(x)=-2x-\dfrac{1}{3x}+\dfrac12$.
    $\dfrac{1}{\alpha x}+f(x)=\left(\dfrac1\alpha-\dfrac13\right)\dfrac1x-2x+\dfrac12$ has a finite limit only if $\alpha=3$; then $\beta=\dfrac12$.
    $\alpha+2\beta=4$.

  24. JEE Main 2025, 28 January, Shift 2 · Question 24
    Let $f(x)=\displaystyle\lim_{n\to\infty}\sum_{r=0}^{n}\left(\frac{\tan\left(x/2^{r+1}\right)+\tan^3\left(x/2^{r+1}\right)}{1-\tan^2\left(x/2^{r+1}\right)}\right)$. Then $\displaystyle\lim_{x\to0}\frac{e^x-e^{f(x)}}{(x-f(x))}$ is equal to __________.

    Show answer and solution

    Answer: 1

    With $t=\tan\theta$: $\tan2\theta-\tan\theta=t\left(\dfrac{2}{1-t^2}-1\right)=\dfrac{t(1+t^2)}{1-t^2}$, which is the given term for $\theta=x/2^{r+1}$.
    So the sum telescopes: $\tan x-\tan\left(x/2^{n+1}\right)\to\tan x$, i.e. $f(x)=\tan x$.
    $\dfrac{e^x-e^{\tan x}}{x-\tan x}=e^{\tan x}\cdot\dfrac{e^{x-\tan x}-1}{x-\tan x}\to1\cdot1=1$.

  25. JEE Main 2025, 29 January, Shift 1 · Question 24
    Let [t] be the greatest integer less than or equal to t. Then the least value of $p\in\mathbf{N}$ for which
    $\displaystyle\lim_{x\to0^+}\left(x\left(\left[\frac1x\right]+\left[\frac2x\right]+\ldots+\left[\frac px\right]\right)-x^2\left(\left[\frac1{x^2}\right]+\left[\frac{2^2}{x^2}\right]+\ldots+\left[\frac{9^2}{x^2}\right]\right)\right)\ge1$ is equal to __________.

    Show answer and solution

    Answer: 24

    $x\left[\tfrac kx\right]\to k$ and $x^2\left[\tfrac{k^2}{x^2}\right]\to k^2$ as $x\to0^+$.
    The limit is $\dfrac{p(p+1)}{2}-(1^2+\ldots+9^2)=\dfrac{p(p+1)}{2}-285$.
    Need $p(p+1)\ge572$: $23\cdot24=552$ fails, $24\cdot25=600$ works. So $p=24$.
