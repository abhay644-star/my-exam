  1. JEE Main 2026, 2 April, Shift 1 · Question 3
    Let $\alpha, \beta \in \mathbb{R}$ be such that the system of linear equations $$\begin{aligned} x+2y+z&=5\\ 2x+y+\alpha z&=5\\ 8x+4y+\beta z&=18 \end{aligned}$$ has no solution. Then $\dfrac{\beta}{\alpha}$ is equal to :

    1. $-4$
    2. $4$
    3. $8$
    4. $-8$
    Show answer and solution

    Answer: (b)

    For no solution, $\Delta=\begin{vmatrix}1&2&1\\2&1&\alpha\\8&4&\beta\end{vmatrix}=12\alpha-3\beta=0$, so $\beta=4\alpha$.
    Then the third equation's LHS is $4\times$ the second's: $8x+4y+4\alpha z$, but $4\times5=20\neq18$, so the system is inconsistent.
    Hence $\dfrac{\beta}{\alpha}=4$.

  2. JEE Main 2026, 2 April, Shift 2 · Question 3
    If the system of equations

    $\displaystyle x+5y+6z=4,\quad 2x+3y+4z=7,\quad x+6y+az=b$
    has infinitely many solutions, then the point $(a, b)$ lies on the line

    1. $y-x=3$
    2. $x-y=3$
    3. $x+y=11$
    4. $x+y=12$
    Show answer and solution

    Answer: (b)

    For infinitely many solutions the third equation must be a combination $p(\text{I})+q(\text{II})$.
    Coefficients of $x, y$: $p+2q=1$, $5p+3q=6 \Rightarrow q=-\dfrac17,\ p=\dfrac97$.
    $a=6p+4q=\dfrac{54-4}{7}=\dfrac{50}{7}$, $b=4p+7q=\dfrac{36-7}{7}=\dfrac{29}{7}$.
    $a-b=\dfrac{21}{7}=3$, so $(a,b)$ lies on $x-y=3$.

  3. JEE Main 2026, 4 April, Shift 1 · Question 6
    Let $A=\begin{bmatrix}1&1&2\\-2&0&1\\1&3&5\end{bmatrix}$. Then the sum of all elements of the matrix $\operatorname{adj}\left(\operatorname{adj}\left(2(\operatorname{adj}A)^{-1}\right)\right)$ is equal to:

    1. $3$
    2. $4$
    3. $-4$
    4. $-3$
    Show answer and solution

    Answer: (d)

    $|A|=1(0-3)-1(-10-1)+2(-6-0)=-3+11-12=-4$.
    $(\operatorname{adj}A)^{-1}=\dfrac{A}{|A|}=-\dfrac{A}{4}$, so $B=2(\operatorname{adj}A)^{-1}=-\dfrac{A}{2}$.
    For a $3\times3$ matrix, $\operatorname{adj}(\operatorname{adj}B)=|B|\,B$, and $|B|=\left(-\dfrac12\right)^3(-4)=\dfrac12$.
    So $\operatorname{adj}(\operatorname{adj}B)=\dfrac12\left(-\dfrac A2\right)=-\dfrac A4$.
    Sum of elements of $A$ $=1+1+2-2+0+1+1+3+5=12$, so the required sum is $-\dfrac{12}{4}=-3$.

  4. JEE Main 2026, 4 April, Shift 2 · Question 3
    If the system of equations:
    $x+y+z=5$
    $x+2y+3z=9$
    $x+3y+\lambda z=\mu$
    has infinitely many solutions, then the value of $\lambda+\mu$ is:

    1. $16$
    2. $18$
    3. $19$
    4. $21$
    Show answer and solution

    Answer: (b)

    Subtracting the first equation: $y+2z=4$ and $2y+(\lambda-1)z=\mu-5$.
    For infinitely many solutions the second must be twice the first: $\lambda-1=4$, $\mu-5=8$.
    So $\lambda=5$, $\mu=13$ and $\lambda+\mu=18$.

  5. JEE Main 2026, 4 April, Shift 2 · Question 6
    Let $A=\begin{bmatrix}1&2&7\\4&-2&8\\3&8&-7\end{bmatrix}$ and $\det(A-\alpha I)=0$, where $\alpha$ is a real number. If the largest possible value of $\alpha$ is $p$, then the circle $(x-p)^2+(y-2p)^2=320$, intersects the co-ordinate axes at

    1. 1 point
    2. 2 points
    3. 3 points
    4. 4 points
    Show answer and solution

    Answer: (c)

    Expanding, $\det(A-\alpha I)=-(\alpha^3+8\alpha^2-88\alpha-320)=-(\alpha-8)(\alpha^2+16\alpha+40)$.
    Roots: $8$ and $-8\pm2\sqrt6$, so $p=8$.
    Circle: $(x-8)^2+(y-16)^2=320$. On $y=0$: $(x-8)^2=64\Rightarrow x=0,16$. On $x=0$: $(y-16)^2=256\Rightarrow y=0,32$.
    The points are $(0,0)$, $(16,0)$, $(0,32)$ (the origin is common): $3$ points.

  6. JEE Main 2026, 5 April, Shift 1 · Question 3
    Let A be a $3 \times 3$ matrix such that $$A^{T}\begin{bmatrix}1\\0\\1\end{bmatrix}=\begin{bmatrix}5\\2\\2\end{bmatrix},\ A^{T}\begin{bmatrix}0\\0\\1\end{bmatrix}=\begin{bmatrix}3\\1\\1\end{bmatrix},\ A\begin{bmatrix}1\\0\\1\end{bmatrix}=\begin{bmatrix}3\\4\\4\end{bmatrix} \text{ and } A\begin{bmatrix}0\\0\\1\end{bmatrix}=\begin{bmatrix}1\\3\\1\end{bmatrix}.$$ If $\det(A) = 1$, then $\det(\operatorname{adj}(A^2 + A))$ is equal to:

    1. $16$
    2. $25$
    3. $49$
    4. $64$
    Show answer and solution

    Answer: (d)

    $A^T e_3$ is row 3 of $A$: $R_3=(3,1,1)$; $A^T(e_1+e_3)=R_1+R_3=(5,2,2) \Rightarrow R_1=(2,1,1)$.
    $Ae_3$ is column 3: $C_3=(1,3,1)^T$; $C_1+C_3=(3,4,4)^T \Rightarrow C_1=(2,1,3)^T$.
    So $A=\begin{bmatrix}2&1&1\\1&k&3\\3&1&1\end{bmatrix}$ and $\det A=2(k-3)-1(1-9)+1(1-3k)=3-k=1 \Rightarrow k=2$.
    $\det(\operatorname{adj}B)=(\det B)^2$ for a $3\times3$ matrix, and $\det(A^2+A)=\det A\cdot\det(A+I)$.
    $\det(A+I)=\begin{vmatrix}3&1&1\\1&3&3\\3&1&2\end{vmatrix}=3(3)-1(-7)+1(-8)=8$.
    $\det(\operatorname{adj}(A^2+A))=(1\cdot8)^2=64$.

  7. JEE Main 2026, 5 April, Shift 1 · Question 4
    Consider the system of linear equations in $x, y, z$:
    $x + 2y + tz = 0$,
    $6x + y + 5tz = 0$,
    $3x + t^2y + f(t)z = 0$,
    where $f : \mathbb{R} \to \mathbb{R}$ is a differentiable function. If this system has infinitely many solutions for all $t \in \mathbb{R}$, then $f$

    1. is a constant function
    2. is strictly increasing on $\mathbb{R}$
    3. is strictly decreasing on $\mathbb{R}$
    4. has two critical points
    Show answer and solution

    Answer: (b)

    A homogeneous system has infinitely many solutions iff the coefficient determinant is $0$:
    $\begin{vmatrix}1&2&t\\6&1&5t\\3&t^2&f\end{vmatrix}=(f-5t^3)-2(6f-15t)+t(6t^2-3)=-11f+t^3+27t=0$.
    So $f(t)=\dfrac{t^3+27t}{11}$ and $f'(t)=\dfrac{3t^2+27}{11}>0$ for all $t$.
    Hence $f$ is strictly increasing on $\mathbb{R}$.

  8. JEE Main 2026, 5 April, Shift 2 · Question 3
    If $f:\mathbb{N}\to\mathbb{Z}$ is defined by $$f(n)=\begin{vmatrix} n & -1 & -5 \\ -2n^2 & 3(2k+1) & 2k+1 \\ -3n^3 & 3k(2k+1) & 3k(k+2)+1 \end{vmatrix},\ k\in\mathbb{N},$$ and $\displaystyle\sum_{n=1}^{k} f(n)=98$, then $k$ is equal to :

    1. $3$
    2. $4$
    3. $5$
    4. $6$
    Show answer and solution

    Answer: (a)

    Only the first column depends on $n$, so $\sum_{n=1}^k f(n)$ is the determinant with first column $\left(\sum n,\ -2\sum n^2,\ -3\sum n^3\right)=\left(\dfrac{k(k+1)}{2},\ -\dfrac{k(k+1)(2k+1)}{3},\ -\dfrac{3k^2(k+1)^2}{4}\right)$.
    For $k=3$ the first column is $(6, -28, -108)$ and the determinant is $\begin{vmatrix} 6 & -1 & -5 \\ -28 & 21 & 7 \\ -108 & 63 & 46 \end{vmatrix}$.
    $=6(966-441)+1(-1288+756)-5(-1764+2268)=3150-532-2520=98$.
    Hence $k=3$.

  9. JEE Main 2026, 6 April, Shift 1 · Question 21
    Let $A=\begin{bmatrix}-1&1&-1\\1&0&1\\0&0&1\end{bmatrix}$ satisfy $$A^2+\alpha\big(adj(adj(A))\big)+\beta\big(adj(A)\,(adj(adj(A)))\big)=\begin{bmatrix}2&-2&2\\-2&0&-1\\0&0&-1\end{bmatrix}$$ for some $\alpha,\beta\in\mathbb{R}$.
    Then $(\alpha-\beta)^2$ is equal to ________

    Show answer and solution

    Answer: 4

    $|A|=-1(0)-1(1)+(-1)(0)=-1$.
    $adj(adj A)=|A|^{n-2}A=-A$ and $adj(A)\,(adj(adj A))=-adj(A)A=-|A|I=I$.
    $A^2=\begin{bmatrix}2&-1&1\\-1&1&0\\0&0&1\end{bmatrix}$, so $A^2-\alpha A+\beta I$ must equal the given matrix.
    Entry $(1,2)$: $-1-\alpha=-2\Rightarrow\alpha=1$; entry $(1,1)$: $2+\alpha+\beta=2\Rightarrow\beta=-1$ (all other entries agree).
    $(\alpha-\beta)^2=4$.

  10. JEE Main 2026, 6 April, Shift 2 · Question 4
    The sum of all possible values of $\theta \in [0, 2\pi]$, for which the system of equations :
    $x\cos3\theta-8y-12z=0$
    $x\cos2\theta+3y+3z=0$
    $x+y+3z=0$
    has a non-trivial solution, is equal to :

    1. $\pi$
    2. $2\pi$
    3. $3\pi$
    4. $4\pi$
    Show answer and solution

    Answer: (d)

    Non-trivial solution $\iff \begin{vmatrix}\cos3\theta&-8&-12\\\cos2\theta&3&3\\1&1&3\end{vmatrix}=0$.
    $6\cos3\theta+8(3\cos2\theta-3)-12(\cos2\theta-3)=6\cos3\theta+12\cos2\theta+12=0$.
    With $c=\cos\theta$: $4c^3-3c+2(2c^2-1)+2=4c^3+4c^2-3c=c(2c-1)(2c+3)=0$.
    $c=0$: $\theta=\dfrac\pi2,\dfrac{3\pi}2$; $c=\dfrac12$: $\theta=\dfrac\pi3,\dfrac{5\pi}3$ ($c=-\dfrac32$ impossible).
    Sum $=2\pi+2\pi=4\pi$.

  11. JEE Main 2026, 8 April, Shift 2 · Question 3
    If the system of linear equations :
    $x+y+z=6,$
    $x+2y+5z=10,$
    $2x+3y+\lambda z=\mu$
    has infinitely many solutions, then the value of $\lambda+\mu$ equals :

    1. $12$
    2. $16$
    3. $22$
    4. $28$
    Show answer and solution

    Answer: (c)

    $\Delta=\begin{vmatrix}1&1&1\\1&2&5\\2&3&\lambda\end{vmatrix}=(2\lambda-15)-(\lambda-10)+(3-4)=\lambda-6=0\Rightarrow\lambda=6$.
    Then the third left side is the sum of the first two: $2x+3y+6z=6+10=16$, so for infinitely many solutions $\mu=16$.
    $\lambda+\mu=22$.

  12. JEE Main 2026, 8 April, Shift 2 · Question 4
    Let $A=\begin{bmatrix}\alpha&1&2\\2&3&0\\0&4&5\end{bmatrix}$ and $B=\begin{bmatrix}1&0&0\\0&-5\alpha&0\\0&4\alpha&-2\alpha\end{bmatrix}+\operatorname{adj}(A)$. If $\det(B)=66$, then $\det(\operatorname{adj}(A))$ equals :

    1. $289$
    2. $361$
    3. $441$
    4. $529$
    Show answer and solution

    Answer: (c)

    Cofactors of $A$ give $\operatorname{adj}(A)=\begin{bmatrix}15&3&-6\\-10&5\alpha&4\\8&-4\alpha&3\alpha-2\end{bmatrix}$.
    So $B=\begin{bmatrix}16&3&-6\\-10&0&4\\8&0&\alpha-2\end{bmatrix}$.
    Expanding along the second column: $\det B=-3\left[-10(\alpha-2)-32\right]=30\alpha+36=66\Rightarrow\alpha=1$.
    $\det A=15\alpha+6=21$, so $\det(\operatorname{adj}A)=(\det A)^2=441$.
