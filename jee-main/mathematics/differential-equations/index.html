  1. JEE Main 2026, 2 April, Shift 1 · Question 17
    If the curve $y=f(x)$ passes through the point $(1,e)$ and satisfies the differential equation $dy=y\left(2+\log_e x\right)dx,\ x>0$, then $f(e)$ is equal to :

    1. $e^{e}$
    2. $e^{e^2}$
    3. $e^{2e}$
    4. $e^{2^e}$
    Show answer and solution

    Answer: (c)

    $\dfrac{dy}{y}=(2+\log_e x)\,dx \Rightarrow \log_e y=2x+x\log_e x-x+C=x+x\log_e x+C$.
    At $(1,e)$: $1=1+0+C \Rightarrow C=0$.
    At $x=e$: $\log_e y=e+e=2e$, so $f(e)=e^{2e}$.

  2. JEE Main 2026, 2 April, Shift 1 · Question 20
    Let $y=y(x)$ be the solution curve of the differential equation $(1+\sin x)\dfrac{dy}{dx}+(y+1)\cos x=0,\ y(0)=0$. If the curve $y=y(x)$ passes through the point $\left(\alpha,\dfrac{-1}{2}\right)$, then a value of $\alpha$ is :

    1. $\dfrac{\pi}{6}$
    2. $\dfrac{\pi}{4}$
    3. $\dfrac{\pi}{3}$
    4. $\dfrac{\pi}{2}$
    Show answer and solution

    Answer: (d)

    The equation is $\dfrac{d}{dx}\left[(1+\sin x)(y+1)\right]=0$, so $(1+\sin x)(y+1)=C$.
    $y(0)=0 \Rightarrow C=1$.
    At $y=-\dfrac12$: $(1+\sin\alpha)\cdot\dfrac12=1 \Rightarrow \sin\alpha=1$.
    So $\alpha=\dfrac{\pi}{2}$.

  3. JEE Main 2026, 2 April, Shift 2 · Question 20
    Let $x=x(y)$ be the solution of the differential equation $2y^2\dfrac{dx}{dy}-2xy+x^2=0$, $y>1$, $x(e)=e$. Then $x(e^2)$ is equal to :

    1. $\dfrac32e^2$
    2. $\dfrac23e^2$
    3. $e^2$
    4. $2e^2$
    Show answer and solution

    Answer: (b)

    $\dfrac{dx}{dy}=\dfrac xy-\dfrac{x^2}{2y^2}$. Put $x=vy$: $v+y\dfrac{dv}{dy}=v-\dfrac{v^2}{2}$.
    $\dfrac{dv}{v^2}=-\dfrac{dy}{2y} \Rightarrow \dfrac1v=\dfrac12\ln y+C$.
    $x(e)=e \Rightarrow v=1$ at $y=e$: $1=\dfrac12+C \Rightarrow C=\dfrac12$.
    At $y=e^2$: $\dfrac1v=1+\dfrac12=\dfrac32 \Rightarrow v=\dfrac23$, so $x(e^2)=\dfrac23e^2$.

  4. JEE Main 2026, 4 April, Shift 1 · Question 20
    Let $y=y(x)$ be the solution of the differential equation $\dfrac{dy}{dx}=(1+x+x^2)(1-y+y^2)$, $y(0)=\dfrac12$. Then $(2y(1)-1)$ is equal to

    1. $\sqrt3\tan\left(\dfrac{11\sqrt3}{6}\right)$
    2. $\dfrac{\sqrt3}{2}\tan\left(\dfrac{11\sqrt3}{12}\right)$
    3. $\sqrt3\tan\left(\dfrac{11\sqrt3}{12}\right)$
    4. $\dfrac{\sqrt3}{2}\tan\left(\dfrac{11\sqrt3}{6}\right)$
    Show answer and solution

    Answer: (c)

    Separate: $\dfrac{dy}{\left(y-\frac12\right)^2+\frac34}=(1+x+x^2)\,dx$.
    Integrate: $\dfrac{2}{\sqrt3}\tan^{-1}\left(\dfrac{2y-1}{\sqrt3}\right)=x+\dfrac{x^2}{2}+\dfrac{x^3}{3}+c$, and $y(0)=\dfrac12$ gives $c=0$.
    At $x=1$: $\tan^{-1}\left(\dfrac{2y-1}{\sqrt3}\right)=\dfrac{\sqrt3}{2}\cdot\dfrac{11}{6}=\dfrac{11\sqrt3}{12}$.
    So $2y(1)-1=\sqrt3\tan\left(\dfrac{11\sqrt3}{12}\right)$.

  5. JEE Main 2026, 4 April, Shift 2 · Question 19
    Let $y=y(x)$ be the solution of the differential equation:

    $\displaystyle \dfrac{dy}{dx}+\left(\dfrac{6x^2+(3x^2+2x^3+4)e^{-2x}}{(x^3+2)(2+e^{-2x})}\right)y=2+e^{-2x},$
    $x\in(-1,2)$, satisfying $y(0)=\dfrac32$. If $y(1)=\alpha(2+e^{-2})$, then $\alpha$ is equal to:

    1. $\dfrac{13}{8}$
    2. $\dfrac{6}{13}$
    3. $\dfrac{12}{13}$
    4. $\dfrac{13}{12}$
    Show answer and solution

    Answer: (d)

    Split the coefficient: $\dfrac{3x^2(2+e^{-2x})+2(x^3+2)e^{-2x}}{(x^3+2)(2+e^{-2x})}=\dfrac{3x^2}{x^3+2}+\dfrac{2e^{-2x}}{2+e^{-2x}}$.
    Its integral is $\ln(x^3+2)-\ln(2+e^{-2x})$, so I.F. $=\dfrac{x^3+2}{2+e^{-2x}}$.
    $y\cdot\dfrac{x^3+2}{2+e^{-2x}}=\displaystyle\int(x^3+2)\,dx=\dfrac{x^4}{4}+2x+C$; $y(0)=\dfrac32\Rightarrow C=1$.
    At $x=1$: $y\cdot\dfrac{3}{2+e^{-2}}=\dfrac{13}{4}\Rightarrow y(1)=\dfrac{13}{12}(2+e^{-2})$.
    $\alpha=\dfrac{13}{12}$.

  6. JEE Main 2026, 4 April, Shift 2 · Question 25
    Let $f$ be a twice differentiable function such that

    $\displaystyle f(x)=\int_0^x\tan(t-x)\,dt-\int_0^x f(t)\tan t\,dt,\quad x\in\left(-\dfrac\pi2,\dfrac\pi2\right).$
    Then $f''\left(\dfrac\pi6\right)+12f'\left(-\dfrac\pi6\right)+f\left(\dfrac\pi6\right)$ is equal to __________

    Show answer and solution

    Answer: 5

    $\displaystyle\int_0^x\tan(t-x)\,dt=\int_{-x}^{0}\tan u\,du=\ln\cos x$, so $f(x)=\ln\cos x-\displaystyle\int_0^x f(t)\tan t\,dt$, $f(0)=0$.
    Differentiating: $f'(x)=-\tan x\,(1+f(x))$. With $g=1+f$: $g'=-g\tan x\Rightarrow g=\cos x$ (as $g(0)=1$).
    So $f(x)=\cos x-1$, $f'(x)=-\sin x$, $f''(x)=-\cos x$.
    $f''\left(\dfrac\pi6\right)+12f'\left(-\dfrac\pi6\right)+f\left(\dfrac\pi6\right)=-\dfrac{\sqrt3}{2}+6+\dfrac{\sqrt3}{2}-1=5$.

  7. JEE Main 2026, 5 April, Shift 1 · Question 25
    Let $y = y(x)$ be the solution of the differential equation $x\sin\left(\dfrac{y}{x}\right)dy=\left(y\sin\left(\dfrac{y}{x}\right)-x\right)dx$, $y(1)=\dfrac{\pi}{2}$ and let $\alpha=\cos\left(\dfrac{y(e^{12})}{e^{12}}\right)$. Then the number of integral value of $p$, for which the equation $x^2+y^2-2px+2py+\alpha+2=0$ represents a circle of radius $r \le 6$, is________.

    Show answer and solution

    Answer: Any non-negative integer (intended answer 6)

    Homogeneous: put $y=vx$, $dy=v\,dx+x\,dv$: $x\sin v\,(v\,dx+x\,dv)=(vx\sin v-x)\,dx \Rightarrow \sin v\,dv=-\dfrac{dx}{x}$.
    $\cos v=\log_ex+c$; $y(1)=\dfrac\pi2$ gives $c=0$, so $\cos\dfrac yx=\log_ex$.
    Formally $\alpha=\log_e e^{12}=12$ (strictly, $\cos\dfrac yx=\log_ex$ needs $\log_ex\le1$, so the solution does not reach $x=e^{12}$).
    Circle $x^2+y^2-2px+2py+14=0$: $r^2=2p^2-14$. Need $0<r^2\le36$: $7<p^2\le25$.
    $p=\pm3,\pm4,\pm5$: $6$ values (intended answer).
    The official final key accepts any non-negative integer.

    Note: Official final key: "Any non-negative integer" — any answer you enter scores full marks; a blank scores zero. The intended answer is 6.

  8. JEE Main 2026, 5 April, Shift 2 · Question 19
    Let $f:[1,\infty)\to\mathbb{R}$ be a differentiable function defined as $f(x)=\displaystyle\int_1^x f(t)\,dt+(1-x)(\log_e x-1)+e$. Then the value of $f(f(1))$ is :

    1. $(1+e^e)$
    2. $(1+e)$
    3. $(1+e+e^e)$
    4. $1+2e$
    Show answer and solution

    Answer: (a)

    $f(1)=0+0+e=e$.
    Differentiating: $f'(x)=f(x)-(\ln x-1)+\dfrac{1-x}{x}=f(x)-\ln x+\dfrac1x$.
    So $f'-f=\dfrac1x-\ln x$; $\ln x$ is a particular solution (since $(\ln x)'-\ln x=\dfrac1x-\ln x$), hence $f(x)=\ln x+Ce^x$.
    $f(1)=Ce=e \Rightarrow C=1$, so $f(x)=\ln x+e^x$.
    $f(f(1))=f(e)=1+e^e$.

    Let $y=y(x)$ be the solution of the differential equation

    $\displaystyle (\tan x)^{1/2}\,dy=\left(\sec^3x-(\tan x)^{3/2}\,y\right)dx,\quad 0<x<\dfrac\pi2,\quad y\left(\dfrac\pi4\right)=\dfrac{6\sqrt2}{5}.$

    Show answer and solution

    Answer: 48

    $y\sec x=\displaystyle\int\dfrac{\sec^4x}{\sqrt{\tan x}}dx=\displaystyle\int\dfrac{1+t^2}{\sqrt t}dt=2\sqrt t+\dfrac25t^{5/2}+C$, with $t=\tan x$.

    $\alpha=2\cdot3^{1/4}$, $\alpha^4=48$.

    Let $y=y(x)$ be the solution of the differential equation

    $\displaystyle \left(x^2-x\sqrt{x^2-1}-1\right)dy+\left(y\left(x-\sqrt{x^2-1}\right)-x\right)dx=0,\ x\ge1.$

    Show answer and solution

    Answer: 3

    Let $s=\sqrt{x^2-1}$ and $u=x-s$, so $\dfrac1u=x+s$ and $x^2-1-xs=-su$.
    The equation becomes $\dfrac{dy}{dx}-\dfrac{y}{s}=-\dfrac{x(x+s)}{s}$.
    Integrating factor $e^{-\int dx/s}=\dfrac{1}{x+s}=u$: $\dfrac{d(yu)}{dx}=-\dfrac{x}{s}\Rightarrow yu=1-\sqrt{x^2-1}$ (using $y(1)=1$).
    So $y=(1-\sqrt{x^2-1})(x+\sqrt{x^2-1})$, and $y(\sqrt5)=-(2+\sqrt5)\approx-4.24$.
    As printed, this gives $-5$; the official final key gives $3$, which this equation does not lead to. Official answer: $3$.

    Note: The official final key gives 3. Solving the equation exactly as printed gives y(√5) = −(2 + √5) ≈ −4.24, i.e. −5; the key is followed for marking.

    1. $\dfrac{13}{8}$
    2. $\dfrac{11}{16}$
    3. $\dfrac{15}{32}$
    4. $\dfrac{17}{64}$
    Show answer and solution
