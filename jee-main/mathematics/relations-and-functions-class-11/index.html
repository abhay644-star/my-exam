  1. JEE Main 2026, 2 April, Shift 1 · Question 21
    If the domain of the function $f(x)=\sqrt{\log_{(0.6)}\left(\left|\dfrac{2x-5}{x^2-4}\right|\right)}$ is $(-\infty,a]\cup\{b\}\cup[c,d)\cup(e,\infty)$, then the value of $a+b+c+d+e$ is __________.

    Show answer and solution

    Answer: 4

    Need $0<\left|\dfrac{2x-5}{x^2-4}\right|\le1$, with $x\neq\pm2$, $x\neq\dfrac52$.
    $(2x-5)^2\le(x^2-4)^2 \iff (x^2-2x+1)(x^2+2x-9)\ge0 \iff (x-1)^2(x^2+2x-9)\ge0$.
    So $x\le-1-\sqrt{10}$, or $x=1$, or $x\ge-1+\sqrt{10}$ (and $\pm2$ are not in these sets).
    Removing $x=\dfrac52$: domain $=(-\infty,-1-\sqrt{10}]\cup\{1\}\cup\left[-1+\sqrt{10},\dfrac52\right)\cup\left(\dfrac52,\infty\right)$.
    $a+b+c+d+e=-2+1+\dfrac52+\dfrac52=4$.

  2. JEE Main 2026, 4 April, Shift 1 · Question 2
    If the set of all solutions of $|x^2+x-9|=|x|+|x^2-9|$ is $[\alpha,\beta]\cup[\gamma,\infty)$, then $(\alpha^2+\beta^2+\gamma^2)$ is equal to:

    1. $9$
    2. $18$
    3. $36$
    4. $72$
    Show answer and solution

    Answer: (b)

    $x^2+x-9 = x+(x^2-9)$, and $|a+b|=|a|+|b|$ holds exactly when $ab\ge 0$.
    So we need $x(x^2-9)\ge 0 \iff x(x-3)(x+3)\ge0 \iff x\in[-3,0]\cup[3,\infty)$.
    $\alpha=-3,\ \beta=0,\ \gamma=3$, so $\alpha^2+\beta^2+\gamma^2=9+0+9=18$.

  3. JEE Main 2026, 4 April, Shift 2 · Question 16
    Let for some $\alpha\in\mathbb{R}$, $f:\mathbb{R}\to\mathbb{R}$ be a function satisfying $f(x+y)=f(x)+2y^2+y+\alpha xy$ for all $x,y\in\mathbb{R}$. If $f(0)=-1$ and $f(1)=2$, then the value of $\displaystyle\sum_{n=1}^{5}\left(\alpha+f(n)\right)$ is:

    1. $110$
    2. $140$
    3. $150$
    4. $170$
    Show answer and solution

    Answer: (b)

    Put $x=0$: $f(y)=2y^2+y-1$ (and $f(1)=2$ checks).
    Then $f(x+y)-f(x)=2(2xy+y^2)+y=2y^2+y+4xy$, so $\alpha=4$.
    $\sum_{n=1}^{5}(4+2n^2+n-1)=15+2(55)+15=140$.

  4. JEE Main 2026, 5 April, Shift 2 · Question 21
    Let $A=\{1,4,7\}$ and $B=\{2,3,8\}$. Then the number of elements, in the relation $R=\{((a_1,b_1),(a_2,b_2))\in((A\times B)\times(A\times B)) : a_1+b_2 \text{ divides } a_2+b_1\}$ is __________.

    Show answer and solution

    Answer: 18

    As $(a_1,b_2)$ runs over $A\times B$, $s=a_1+b_2$ takes the values $3,4,9,6,7,12,9,10,15$; independently $t=a_2+b_1$ takes the same 9 values.
    Count pairs with $s\mid t$: $s=3$: 6 values of $t$ ($3,9,6,12,9,15$); $s=4$: 2 ($4,12$); $s=9$ (twice): $2\times2=4$; $s=6$: 2 ($6,12$); $s=7,12,10,15$: 1 each.
    Total $=6+2+4+2+4=18$.

  5. JEE Main 2026, 8 April, Shift 2 · Question 21
    The sum of squares of all the real solutions of the equation

    $\displaystyle \log_{(x+1)}\left(2x^2+5x+3\right)=4-\log_{(2x+3)}\left(x^2+2x+1\right)$
    is equal to __________.

    Show answer and solution

    Answer: 2

    $2x^2+5x+3=(2x+3)(x+1)$ and $x^2+2x+1=(x+1)^2$. Let $t=\log_{(x+1)}(2x+3)$.
    The equation becomes $1+t=4-\dfrac2t\Rightarrow t^2-3t+2=0\Rightarrow t=1$ or $2$.
    $t=1$: $2x+3=x+1\Rightarrow x=-2$, rejected (base negative).
    $t=2$: $2x+3=(x+1)^2\Rightarrow x^2=2$; the domain needs $x>-1$, $x\ne0$, so $x=\sqrt2$ only.
    Sum of squares $=2$.

  6. JEE Main 2026, 22 January, Shift 1 · Question 3
    The number of distinct real solutions of the equation $x|x+4|+3|x+2|+10=0$ is

    1. $0$
    2. $1$
    3. $2$
    4. $3$
    Show answer and solution

    Answer: (b)

    $x\ge-2$: $x^2+7x+16=0$, discriminant $49-64<0$, no root.
    $-4\le x<-2$: $x^2+4x-3x-6+10=x^2+x+4=0$, no real root.
    $x<-4$: $-x^2-4x-3x-6+10=0 \Rightarrow x^2+7x-4=0$, $x=\dfrac{-7\pm\sqrt{65}}{2}$; only $\dfrac{-7-\sqrt{65}}{2}\approx-7.53$ is below $-4$.
    So there is exactly $1$ solution.

  7. JEE Main 2026, 22 January, Shift 2 · Question 4
    Let the domain of the function $f(x)=\log_3\log_5\left(7-\log_2\left(x^2-10x+85\right)\right)+\sin^{-1}\left(\left|\dfrac{3x-7}{17-x}\right|\right)$ be $(\alpha, \beta]$. Then $\alpha+\beta$ is equal to :

    1. $8$
    2. $9$
    3. $10$
    4. $12$
    Show answer and solution

    Answer: (b)

    $\log_3$ needs $\log_5(\ldots)>0$, i.e. $7-\log_2(x^2-10x+85)>1$, so $x^2-10x+85<64\Rightarrow(x-3)(x-7)<0\Rightarrow3<x<7$.
    $\sin^{-1}$ needs $|3x-7|\le|17-x|$; on $(3,7)$ both are positive, so $3x-7\le17-x\Rightarrow x\le6$.
    Domain $(3,6]$, so $\alpha+\beta=9$.

  8. JEE Main 2026, 22 January, Shift 2 · Question 18
    Let $f(x)=[x]^2-[x+3]-3$, $x\in\mathbf{R}$, where $[\cdot]$ is the greatest integer funtion. Then

    1. $f(x)=0$ for finitely many values of $x$
    2. $f(x)<0$ only for $x\in[-1, 3)$
    3. $f(x)>0$ only for $x\in[4, \infty)$
    4. $\displaystyle\int_0^2f(x)\,dx=-6$
    Show answer and solution

    Answer: (b)

    With $n=[x]$: $f=n^2-(n+3)-3=n^2-n-6=(n-3)(n+2)$.
    $f=0$ for $n=3$ or $n=-2$, i.e. on whole intervals: infinitely many $x$. $f<0$ for $n=-1,0,1,2$, i.e. exactly $x\in[-1,3)$. $f>0$ also for $x<-2$.
    $\int_0^2f=(-6)+(-6)=-12$.
    Only the second statement is true.

  9. JEE Main 2026, 24 January, Shift 1 · Question 2
    If the domain of the function
    $f(x)=\log_{(10x^2-17x+7)}\left(18x^2-11x+1\right)$
    is $(-\infty, a)\cup(b, c)\cup(d, \infty)-\{e\}$, then
    $90(a+b+c+d+e)$ equals:

    1. $316$
    2. $307$
    3. $170$
    4. $177$
    Show answer and solution

    Answer: (a)

    Base positive: $(10x-7)(x-1)>0 \Rightarrow x<\dfrac{7}{10}$ or $x>1$.
    Argument positive: $(9x-1)(2x-1)>0 \Rightarrow x<\dfrac19$ or $x>\dfrac12$.
    Base $\neq1$: $10x^2-17x+6=0 \Rightarrow x=\dfrac12,\ \dfrac65$.
    Domain $=\left(-\infty,\dfrac19\right)\cup\left(\dfrac12,\dfrac{7}{10}\right)\cup(1,\infty)-\left\{\dfrac65\right\}$.
    $90\left(\dfrac19+\dfrac12+\dfrac7{10}+1+\dfrac65\right)=10+45+63+90+108=316$.

  10. JEE Main 2026, 24 January, Shift 2 · Question 2
    Let $f$ be a function such that $3f(x)+2f\left(\dfrac{m}{19x}\right)=5x,\ x\neq0$, where
    $m=\displaystyle\sum_{i=1}^{9}(i)^2$. Then $f(5)-f(2)$ is equal to

    1. $-9$
    2. $9$
    3. $18$
    4. $36$
    Show answer and solution

    Answer: (c)

    $m=\dfrac{9\cdot10\cdot19}{6}=285$, so $\dfrac{m}{19x}=\dfrac{15}{x}$.
    $3f(x)+2f\left(\dfrac{15}x\right)=5x$ and, replacing $x$ by $\dfrac{15}x$, $3f\left(\dfrac{15}x\right)+2f(x)=\dfrac{75}x$.
    Eliminating: $5f(x)=15x-\dfrac{150}{x}$, so $f(x)=3x-\dfrac{30}{x}$.
    $f(5)-f(2)=(15-6)-(6-15)=18$.

  11. JEE Main 2026, 28 January, Shift 1 · Question 2
    If $g(x)=3x^2+2x-3$, $f(0)=-3$ and $4g(f(x))=3x^2-32x+72$, then $f(g(2))$ is equal to:

    1. $\dfrac{25}{6}$
    2. $-\dfrac72$
    3. $\dfrac72$
    4. $-\dfrac{25}{6}$
    Show answer and solution

    Answer: (c)

    $4(3f^2+2f-3)=3x^2-32x+72$ gives $12f^2+8f=3x^2-32x+84$, so $f$ is linear: $f(x)=px-3$.
    Constant term: $12(9)-24=84$ (checks). $x^2$: $12p^2=3$; $x$: $-72p+8p=-32$, so $p=\tfrac12$.
    $f(x)=\tfrac x2-3$, $g(2)=13$, $f(13)=\tfrac72$.

  12. JEE Main 2025, 2 April, Shift 2 · Question 1
    If the domain of the function $f(x)=\dfrac{1}{\sqrt{10+3x-x^2}}+\dfrac{1}{\sqrt{x+|x|}}$ is $(a, b)$, then $(1+a)^2+b^2$ is equal to :

    1. $26$
    2. $25$
    3. $29$
    4. $30$
    Show answer and solution

    Answer: (a)

    $10+3x-x^2>0$ gives $(x-5)(x+2)<0$, i.e. $-2<x<5$.
    $x+|x|>0$ holds only for $x>0$.
    Domain $(0, 5)$: $a=0$, $b=5$, so $(1+a)^2+b^2=1+25=26$.

  13. JEE Main 2025, 3 April, Shift 2 · Question 2
    If the domain of the function $f(x)=\log_7\left(1-\log_4\left(x^2-9x+18\right)\right)$ is $(\alpha, \beta)\cup(\gamma, \delta)$, then $\alpha+\beta+\gamma+\delta$ is equal to

    1. $15$
    2. $16$
    3. $17$
    4. $18$
    Show answer and solution

    Answer: (d)

    We need $1-\log_4(x^2-9x+18)>0$, i.e. $0<x^2-9x+18<4$.
    $x^2-9x+18>0$: $x<3$ or $x>6$. $x^2-9x+14<0$: $2<x<7$.
    Domain $(2,3)\cup(6,7)$, so the sum is $2+3+6+7=18$.

  14. JEE Main 2025, 4 April, Shift 1 · Question 2
    Let $f, g: (1, \infty)\to\mathbb{R}$ be defined as $f(x)=\dfrac{2x+3}{5x+2}$ and $g(x)=\dfrac{2-3x}{1-x}$. If the range of the function $fog: [2, 4]\to\mathbb{R}$ is $[\alpha, \beta]$, then $\dfrac{1}{\beta-\alpha}$ is equal to

    1. $2$
    2. $29$
    3. $56$
    4. $68$
    Show answer and solution

    Answer: (c)

    $2g(x)+3=\dfrac{7-9x}{1-x}$ and $5g(x)+2=\dfrac{12-17x}{1-x}$, so $f(g(x))=\dfrac{7-9x}{12-17x}$.
    Its derivative has numerator $(-9)(12-17x)+17(7-9x)=11>0$, so it is increasing on $[2, 4]$.
    $\alpha=f(g(2))=\dfrac{-11}{-22}=\dfrac12$, $\beta=f(g(4))=\dfrac{-29}{-56}=\dfrac{29}{56}$.
    $\beta-\alpha=\dfrac{1}{56}$, so $\dfrac1{\beta-\alpha}=56$.

  15. JEE Main 2025, 4 April, Shift 2 · Question 1
    Let the domains of the functions $f(x)=\log_4\log_3\log_7\left(8-\log_2(x^2+4x+5)\right)$ and $g(x)=\sin^{-1}\left(\dfrac{7x+10}{x-2}\right)$ be $(\alpha, \beta)$ and $[\gamma, \delta]$, respectively. Then $\alpha^2+\beta^2+\gamma^2+\delta^2$ is equal to :

    1. $13$
    2. $14$
    3. $15$
    4. $16$
    Show answer and solution

    Answer: (c)

    $f$: we need $\log_3\log_7(\cdots)>0$, i.e. $\log_7\left(8-\log_2(x^2+4x+5)\right)>1$, i.e. $\log_2(x^2+4x+5)<1$, i.e. $x^2+4x+3<0$: $x\in(-3, -1)$. So $\alpha=-3$, $\beta=-1$.
    $g$: $\dfrac{7x+10}{x-2}\le1\iff\dfrac{6x+12}{x-2}\le0\iff-2\le x<2$; $\dfrac{7x+10}{x-2}\ge-1\iff\dfrac{8x+8}{x-2}\ge0\iff x\le-1$ or $x>2$. So the domain is $[-2, -1]$: $\gamma=-2$, $\delta=-1$.
    $9+1+4+1=15$.

  16. JEE Main 2025, 7 April, Shift 2 · Question 2
    If the range of the function $f(x)=\dfrac{5-x}{x^2-3x+2}$, $x\ne1, 2$, is $(-\infty, \alpha]\cup[\beta, \infty)$, then $\alpha^2+\beta^2$ is equal to :

    1. $188$
    2. $190$
    3. $192$
    4. $194$
    Show answer and solution

    Answer: (d)

    $y=\dfrac{5-x}{x^2-3x+2}\iff yx^2+(1-3y)x+(2y-5)=0$ must have a real root $x\ne1, 2$.
    Discriminant: $(1-3y)^2-4y(2y-5)=y^2+14y+1\ge0$, so $y\le-7-4\sqrt3$ or $y\ge-7+4\sqrt3$ (the excluded $x=1, 2$ do not satisfy the equation, and $y=0$ comes from $x=5$).
    $\alpha^2+\beta^2=(7+4\sqrt3)^2+(7-4\sqrt3)^2=2(49+48)=194$.

  17. JEE Main 2025, 24 January, Shift 1 · Question 1
    Let $f(x)=\dfrac{2^{x+2}+16}{2^{2x+1}+2^{x+4}+32}$. Then the value of $8\left(f\left(\dfrac{1}{15}\right)+f\left(\dfrac{2}{15}\right)+\ldots+f\left(\dfrac{59}{15}\right)\right)$ is equal to

    1. $118$
    2. $108$
    3. $102$
    4. $92$
    Show answer and solution

    Answer: (a)

    Put $t=2^x$: $f(x)=\dfrac{4(t+4)}{2(t+4)^2}=\dfrac{2}{t+4}$.
    For $4-x$, $2^{4-x}=\dfrac{16}{t}$, so $f(4-x)=\dfrac{2t}{16+4t}=\dfrac{t}{2(t+4)}$. Hence $f(x)+f(4-x)=\dfrac12$.
    The arguments $\dfrac{k}{15}$ and $\dfrac{60-k}{15}$ add to 4, giving 29 pairs ($k=1,\ldots,29$) and the middle term $f(2)=\dfrac{2}{8}=\dfrac14$.
    Sum $=\dfrac{29}{2}+\dfrac14=\dfrac{59}{4}$, and $8\times\dfrac{59}{4}=118$.

  18. JEE Main 2025, 28 January, Shift 1 · Question 2
    If $f(x)=\dfrac{2^x}{2^x+\sqrt{2}}$, $x\in\mathbf{R}$, then $\displaystyle\sum_{k=1}^{81}f\left(\frac{k}{82}\right)$ is equal to

    1. $41$
    2. $\dfrac{81}{2}$
    3. $82$
    4. $81\sqrt{2}$
    Show answer and solution

    Answer: (b)

    $f(1-x)=\dfrac{2^{1-x}}{2^{1-x}+\sqrt2}=\dfrac{2}{2+\sqrt2\cdot2^x}=\dfrac{\sqrt2}{\sqrt2+2^x}$, so $f(x)+f(1-x)=1$.
    Pair $k$ with $82-k$ for $k=1,\ldots,40$: 40 pairs give 40. The middle term is $f\left(\dfrac12\right)=\dfrac{\sqrt2}{2\sqrt2}=\dfrac12$.
    Sum $=40+\dfrac12=\dfrac{81}{2}$.

  19. JEE Main 2025, 28 January, Shift 1 · Question 19
    Let $f:\mathbf{R}\to\mathbf{R}$ be a function defined by $f(x)=(2+3a)x^2+\left(\dfrac{a+2}{a-1}\right)x+b$, $a\neq1$. If $f(x+y)=f(x)+f(y)+1-\dfrac{2}{7}xy$, then the value of $28\displaystyle\sum_{i=1}^{5}|f(i)|$ is

    1. $545$
    2. $675$
    3. $715$
    4. $735$
    Show answer and solution

    Answer: (b)

    For $f(x)=Ax^2+Bx+b$: $f(x+y)-f(x)-f(y)=2Axy-b$. Comparing with $1-\dfrac27xy$: $A=-\dfrac17$, $b=-1$.
    $2+3a=-\dfrac17 \Rightarrow a=-\dfrac57$, so $B=\dfrac{a+2}{a-1}=\dfrac{9/7}{-12/7}=-\dfrac34$.
    $f(x)=-\dfrac{x^2}{7}-\dfrac{3x}{4}-1$, negative for $x>0$, so $|f(i)|=\dfrac{i^2}{7}+\dfrac{3i}{4}+1$.
    $28\displaystyle\sum_{i=1}^{5}|f(i)|=28\left(\dfrac{55}{7}+\dfrac{45}{4}+5\right)=220+315+140=675$.

  20. JEE Main 2025, 28 January, Shift 2 · Question 3
    Let $f:\mathbf{R}-\{0\}\to(-\infty, 1)$ be a polynomial of degree 2, satisfying $f(x)f\left(\dfrac{1}{x}\right)=f(x)+f\left(\dfrac{1}{x}\right)$. If $f(K)=-2K$, then the sum of squares of all possible values of K is :

    1. $1$
    2. $7$
    3. $6$
    4. $9$
    Show answer and solution

    Answer: (c)

    A polynomial with $f(x)f(1/x)=f(x)+f(1/x)$ has the form $f(x)=1\pm x^n$; degree 2 gives $1\pm x^2$.
    The values must be less than 1, so $f(x)=1-x^2$.
    $1-K^2=-2K \Rightarrow K^2-2K-1=0$, roots with sum 2 and product $-1$.
    Sum of squares $=2^2-2(-1)=6$.

  21. JEE Main 2025, 29 January, Shift 2 · Question 1
    If the domain of the function $\log_5(18x-x^2-77)$ is $(\alpha, \beta)$ and the domain of the function $\log_{(x-1)}\left(\dfrac{2x^2+3x-2}{x^2-3x-4}\right)$ is $(\gamma, \delta)$, then $\alpha^2+\beta^2+\gamma^2$ is equal to :

    1. $174$
    2. $186$
    3. $179$
    4. $195$
    Show answer and solution

    Answer: (b)

    $18x-x^2-77>0\iff(x-7)(x-11)<0$: $(\alpha,\beta)=(7,11)$.
    Base: $x>1$, $x\neq2$. Argument $\dfrac{(2x-1)(x+2)}{(x-4)(x+1)}>0$; for $x>1$ this needs $x>4$. So $\gamma=4$.
    $\alpha^2+\beta^2+\gamma^2=49+121+16=186$.
