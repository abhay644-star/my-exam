  1. JEE Main 2026, 2 April, Shift 1 · Question 18
    The number of critical points of the function $f(x)=\begin{cases}\left|\dfrac{\sin x}{x}\right|, & x\neq0\\ 1, & x=0\end{cases}$ in the interval $(-2\pi,2\pi)$ is equal to :

    1. $1$
    2. $3$
    3. $5$
    4. $7$
    Show answer and solution

    Answer: (c)

    $g(x)=\dfrac{\sin x}{x}$ (with $g(0)=1$) is smooth and even, and $f=|g|$.
    $x=0$: $f'(0)=0$ (local maximum) — one critical point.
    $x=\pm\pi$: $g=0$ changes sign, $f$ is not differentiable — two critical points.
    In $(\pi,2\pi)$, $g'(x)=0 \iff \tan x=x$ has exactly one root ($x\approx4.49$), and by symmetry one in $(-2\pi,-\pi)$; none in $(0,\pi)$.
    Total $=5$.

  2. JEE Main 2026, 2 April, Shift 2 · Question 18
    Let $f(x)$ be a polynomial of degree 5, and have extrema at $x=1$ and $x=-1$. If $\displaystyle\lim_{x\to0}\left(\dfrac{f(x)}{x^3}\right)=-5$, then $f(2)-f(-2)$ is equal to :

    1. $0$
    2. $50$
    3. $92$
    4. $112$
    Show answer and solution

    Answer: (d)

    The limit forces $f(x)=-5x^3+ax^4+bx^5$.
    $f'(x)=-15x^2+4ax^3+5bx^4$; $f'(1)=f'(-1)=0$: $-15+4a+5b=0$ and $-15-4a+5b=0 \Rightarrow a=0,\ b=3$.
    $f(x)=3x^5-5x^3$ is odd: $f(2)=96-40=56$.
    $f(2)-f(-2)=112$.

  3. JEE Main 2026, 4 April, Shift 2 · Question 12
    $\displaystyle\max_{0\le x\le\pi}\left(16\sin\left(\dfrac x2\right)\cos^3\left(\dfrac x2\right)\right)$ is equal to:

    1. $\dfrac{3\sqrt3}{2}$
    2. $3\sqrt3$
    3. $4\sqrt3$
    4. $6\sqrt3$
    Show answer and solution

    Answer: (b)

    Let $t=\dfrac x2\in\left[0,\dfrac\pi2\right]$, $g(t)=16\sin t\cos^3t$.
    $g'(t)=16\cos^2t(\cos^2t-3\sin^2t)=0\Rightarrow\tan t=\dfrac1{\sqrt3}$, $t=\dfrac\pi6$ (a maximum, as $g=0$ at both ends).
    $g\left(\dfrac\pi6\right)=16\cdot\dfrac12\cdot\dfrac{3\sqrt3}{8}=3\sqrt3$.

  4. JEE Main 2026, 5 April, Shift 1 · Question 19
    Let $f : \mathbb{R} \to \mathbb{R}$ be a differentiable function such that $f\left(\dfrac{x+y}{3}\right) = \dfrac{f(x)+f(y)}{3}$ for all $x, y \in \mathbb{R}$, and $f'(0) = 3$. Then the minimum value of the function $g(x) = 3 + e^x f(x)$, is:

    1. $3\left(\dfrac{e+1}{e}\right)$
    2. $3\left(\dfrac{e-1}{e}\right)$
    3. $\dfrac{3-e}{e}$
    4. $3e$
    Show answer and solution

    Answer: (b)

    $x=y=0$: $f(0)=\dfrac{2f(0)}{3} \Rightarrow f(0)=0$. Then $y=0$ gives $f\left(\dfrac x3\right)=\dfrac{f(x)}{3}$.
    So $\dfrac{f(x+y)}{3}=\dfrac{f(x)+f(y)}{3}$, i.e. $f$ is additive and differentiable, hence $f(x)=f'(0)x=3x$.
    $g(x)=3+3xe^x$, $g'(x)=3e^x(1+x)=0$ at $x=-1$ (a minimum, as $g'$ changes from $-$ to $+$).
    $g(-1)=3-\dfrac3e=3\left(\dfrac{e-1}{e}\right)$.

  5. JEE Main 2026, 6 April, Shift 2 · Question 17
    Let $A=\begin{bmatrix}1&3&-1\\2&1&\alpha\\0&1&-1\end{bmatrix}$ be a singular matrix. Let $f(x)=\displaystyle\int_0^x\left(t^2+2t+3\right)dt$, $x\in[1,\alpha]$. If M and m are respectively the maximum and the minimum values of $f$ in $[1,\alpha]$, then $3(M-m)$ is equal to :

    1. $64$
    2. $68$
    3. $72$
    4. $76$
    Show answer and solution

    Answer: (b)

    $|A|=1(-1-\alpha)-3(-2)+(-1)(2)=3-\alpha=0 \Rightarrow \alpha=3$.
    $f'(x)=x^2+2x+3>0$, so $f$ is increasing: $M-m=f(3)-f(1)=\displaystyle\int_1^3(t^2+2t+3)\,dt$.
    $=\left[\dfrac{t^3}{3}+t^2+3t\right]_1^3=27-\dfrac{13}{3}=\dfrac{68}{3}$.
    $3(M-m)=68$.

  6. JEE Main 2026, 21 January, Shift 1 · Question 24
    Let $f:\mathbf{R}\to\mathbf{R}$ be a twice differentiable function such that the quadratic equation $f(x)m^2-2f'(x)m+f''(x)=0$ in m, has two equal roots for every $x\in\mathbf{R}$. If $f(0)=1$, $f'(0)=2$, and $(\alpha, \beta)$ is the largest interval in which the function $f(\log_ex-x)$ is increasing, then $\alpha+\beta$ is equal to __________.

    Show answer and solution

    Answer: 1

    Equal roots: $4f'^2=4ff''$, so $\left(\dfrac{f'}{f}\right)'=\dfrac{ff''-f'^2}{f^2}=0$ and $\dfrac{f'}{f}$ is constant $=\dfrac{f'(0)}{f(0)}=2$. Hence $f(x)=e^{2x}$.
    $f(\log_ex-x)=e^{2(\log_ex-x)}$ increases where $\log_ex-x$ does: $\dfrac1x-1>0 \iff 0<x<1$.
    So $(\alpha,\beta)=(0,1)$ and $\alpha+\beta=1$.

  7. JEE Main 2026, 21 January, Shift 2 · Question 18
    Let $f:\mathbf{R}\to\mathbf{R}$ be a twice differentiable function such that $f''(x)>0$ for all $x\in\mathbf{R}$ and $f'(a-1)=0$, where a is a real number. Let $g(x)=f(\tan^2x-2\tan x+a)$, $0<x<\dfrac{\pi}{2}$.
    Consider the following two statements :
    (I) g is increasing in $\left(0, \dfrac{\pi}{4}\right)$
    (II) g is deceasing in $\left(\dfrac{\pi}{4}, \dfrac{\pi}{2}\right)$
    Then,

    1. Only (I) is True
    2. Only (II) is True
    3. Both (I) and (II) are True
    4. Neither (I) nor (II) is True
    Show answer and solution

    Answer: (d)

    Let $u=\tan^2x-2\tan x+a=(\tan x-1)^2+a-1\ge a-1$. Since $f'$ is increasing and $f'(a-1)=0$, $f'(u)\ge0$ (zero only at $x=\dfrac\pi4$).
    $g'(x)=f'(u)\cdot2(\tan x-1)\sec^2x$: negative on $\left(0,\dfrac\pi4\right)$, positive on $\left(\dfrac\pi4,\dfrac\pi2\right)$.
    So g decreases then increases; neither statement is true.

  8. JEE Main 2026, 22 January, Shift 1 · Question 16
    Let $f(x)=x^{2025}-x^{2000}$, $x\in[0, 1]$ and the minimum value of the function $f(x)$ in the interval $[0, 1]$ be $(80)^{80}(n)^{-81}$. Then $n$ is equal to

    1. $-80$
    2. $-81$
    3. $-40$
    4. $-41$
    Show answer and solution

    Answer: (b)

    $f'(x)=x^{1999}(2025x^{25}-2000)=0\Rightarrow x^{25}=\dfrac{80}{81}$, where $f$ is least ($f(0)=f(1)=0$).
    $f_{\min}=x^{2000}(x^{25}-1)=\left(\dfrac{80}{81}\right)^{80}\left(-\dfrac{1}{81}\right)=-\dfrac{80^{80}}{81^{81}}=80^{80}(-81)^{-81}$.
    So $n=-81$.

  9. JEE Main 2026, 24 January, Shift 1 · Question 24
    Let $(2\alpha, \alpha)$ be the largest interval in which the function $f(t)=\dfrac{|t+1|}{t^2}$, $t<0$, is strictly decreasing. Then the local maximum value of the function
    $g(x)=2\log_e(x-2)+\alpha x^2+4x-\alpha$, $x>2$, is __________

    Show answer and solution

    Answer: 4

    For $t<-1$, $f=-\dfrac{t+1}{t^2}$ and $f'(t)=\dfrac{t+2}{t^3}$, which is negative only for $-2<t<-1$. For $-1<t<0$, $f'(t)=-\dfrac{t+2}{t^3}>0$.
    So the interval is $(-2,-1)$ and $\alpha=-1$.
    $g(x)=2\log_e(x-2)-x^2+4x+1$, $g'(x)=\dfrac2{x-2}-2(x-2)=0 \Rightarrow x=3$ (a maximum since $g''<0$).
    $g(3)=0-9+12+1=4$.

  10. JEE Main 2026, 24 January, Shift 2 · Question 17
    Consider the following three statements for the function $f:(0,\infty)\to\mathbb{R}$ defined by $f(x)=|\log_e x|-|x-1|$:
    (I) $f$ is differentiable at all $x>0$.
    (II) $f$ is increasing in $(0, 1)$.
    (III) $f$ is decreasing in $(1, \infty)$.
    Then.

    1. Only (I) is TRUE.
    2. Only (II) and (III) are TRUE.
    3. Only (I) and (III) are TRUE.
    4. All (I), (II) and (III) are TRUE.
    Show answer and solution

    Answer: (c)

    On $(0,1)$: $f=-\ln x-1+x$, $f'=1-\dfrac1x<0$, so $f$ decreases: (II) is false.
    On $(1,\infty)$: $f=\ln x-x+1$, $f'=\dfrac1x-1<0$: (III) is true.
    At $x=1$ both one-sided derivatives are 0, so $f$ is differentiable everywhere: (I) is true.

  11. JEE Main 2026, 28 January, Shift 2 · Question 25
    Let $f$ be a differentiable function satisfying $f(x)=1-2x+\displaystyle\int_0^x e^{(x-t)}f(t)\,dt$, $x\in\mathbf{R}$ and let $g(x)=\displaystyle\int_0^x(f(t)+2)^{15}(t-4)^6(t+12)^{17}\,dt$, $x\in\mathbf{R}$. If p and q are respectively the points of local minima and local maxima of g, then the value of $|p+q|$ is equal to _________.

    Show answer and solution

    Answer: 9

    Multiply by $e^{-x}$ and differentiate: $f'=2f+2x-3$ with $f(0)=1$. Trying $f=Ax+B$: $A=-1$, $B=1$, and this satisfies $f(0)=1$, so $f(x)=1-x$.
    $g'(x)=(3-x)^{15}(x-4)^6(x+12)^{17}$. The sign changes from $-$ to $+$ at $x=-12$ (local minimum) and from $+$ to $-$ at $x=3$ (local maximum); $x=4$ is not an extremum (even power).
    $|p+q|=|-12+3|=9$.

  12. JEE Main 2025, 22 January, Shift 2 · Question 17
    Let $f(x)=\displaystyle\int_0^{x^2}\frac{t^2-8t+15}{e^t}\,dt$, $x\in\mathbf{R}$. Then the numbers of local maximum and local minimum points of $f$, respectively, are :

    1. 3 and 2
    2. 2 and 3
    3. 2 and 2
    4. 1 and 3
    Show answer and solution

    Answer: (b)

    $f'(x)=2x\,(x^4-8x^2+15)e^{-x^2}=2x(x^2-3)(x^2-5)e^{-x^2}$, with simple zeros at $0, \pm\sqrt3, \pm\sqrt5$.
    Sign of $f'$ from left to right: $-, +, -, +, -, +$.
    Minima at $-\sqrt5, 0, \sqrt5$ and maxima at $\pm\sqrt3$: 2 maxima and 3 minima.

  13. JEE Main 2025, 23 January, Shift 1 · Question 25
    If the set of all values of $a$, for which the equation $5x^3-15x-a=0$ has three distinct real roots, is the interval $(\alpha,\beta)$, then $\beta-2\alpha$ is equal to __________

    Show answer and solution

    Answer: 30

    Let $f(x)=5x^3-15x$. $f'(x)=15(x^2-1)=0$ at $x=\pm1$, with $f(-1)=10$ (local maximum) and $f(1)=-10$ (local minimum).
    $f(x)=a$ has three distinct real roots when $-10<a<10$.
    $\beta-2\alpha=10+20=30$.

  14. JEE Main 2025, 23 January, Shift 2 · Question 15
    A spherical chocolate ball has a layer of ice-cream of uniform thickness around it. When the thickness of the ice-cream layer is 1 cm, the ice-cream melts at the rate of 81 cm$^3$/min and the thickness of the ice-cream layer decreases at the rate of $\dfrac{1}{4\pi}$ cm/min. The surface area (in cm$^2$) of the chocolate ball (without the ice-cream layer) is :

    1. $196\pi$
    2. $128\pi$
    3. $256\pi$
    4. $225\pi$
    Show answer and solution

    Answer: (c)

    Let the ball have radius $r$ and the layer thickness $h$. The ice-cream volume is $\dfrac43\pi(r+h)^3-\dfrac43\pi r^3$, so $\dfrac{dV}{dt}=4\pi(r+h)^2\dfrac{dh}{dt}$.
    $81=4\pi(r+1)^2\cdot\dfrac{1}{4\pi} \Rightarrow (r+1)^2=81 \Rightarrow r=8$.
    Surface area $=4\pi r^2=256\pi$.

  15. JEE Main 2025, 24 January, Shift 1 · Question 17
    Consider the region $R=\left\{(x,y): x\le y\le9-\dfrac{11}{3}x^2, x\ge0\right\}$.
    The area, of the largest rectangle of sides parallel to the coordinate axes and inscribed in R, is:

    1. $\dfrac{567}{121}$
    2. $\dfrac{625}{111}$
    3. $\dfrac{730}{119}$
    4. $\dfrac{821}{123}$
    Show answer and solution

    Answer: (a)

    Take the rectangle $0\le x\le t$, $t\le y\le9-\dfrac{11}{3}t^2$ (its lower-right corner on $y=x$, upper-right corner on the parabola).
    Area $A(t)=t\left(9-t-\dfrac{11}{3}t^2\right)$. $A'(t)=9-2t-11t^2=0 \Rightarrow t=\dfrac{9}{11}$.
    $A=\dfrac{9}{11}\left(9-\dfrac{9}{11}-\dfrac{27}{11}\right)=\dfrac{9}{11}\cdot\dfrac{63}{11}=\dfrac{567}{121}$.

  16. JEE Main 2025, 24 January, Shift 2 · Question 18
    Let $(2, 3)$ be the largest open interval in which the function $f(x)=2\log_e(x-2)-x^2+ax+1$ is strictly increasing and $(b, c)$ be the largest open interval, in which the function $g(x)=(x-1)^3(x+2-a)^2$ is strictly decreasing. Then $100(a+b-c)$ is equal to :

    1. $160$
    2. $280$
    3. $360$
    4. $420$
    Show answer and solution

    Answer: (c)

    $f'(x)=\dfrac{2}{x-2}-2x+a$ must vanish at $x=3$: $2-6+a=0 \Rightarrow a=4$.
    $g(x)=(x-1)^3(x-2)^2$, $g'(x)=(x-1)^2(x-2)\left[3(x-2)+2(x-1)\right]=(x-1)^2(x-2)(5x-8)$.
    $g'<0$ on $\left(\dfrac85,2\right)$, so $b=\dfrac85$, $c=2$.
    $100\left(4+\dfrac85-2\right)=360$.

  17. JEE Main 2025, 28 January, Shift 1 · Question 16
    The sum of all local minimum values of the function
    $f(x)=\begin{cases}1-2x, & x<-1\\ \dfrac{1}{3}(7+2|x|), & -1\le x\le2\\ \dfrac{11}{18}(x-4)(x-5), & x>2\end{cases}$
    is

    1. $\dfrac{167}{72}$
    2. $\dfrac{131}{72}$
    3. $\dfrac{157}{72}$
    4. $\dfrac{171}{72}$
    Show answer and solution

    Answer: (c)

    $f$ decreases on $x<0$ (from $1-2x$, then $\dfrac{7-2x}{3}$), increases on $[0,2]$ to $\dfrac{11}{3}$, and for $x>2$ the parabola starts at $\dfrac{11}{18}\cdot2\cdot3=\dfrac{11}{3}$ and has its vertex at $x=\dfrac92$.
    Local minima: $x=0$ with $f=\dfrac73$, and $x=\dfrac92$ with $f=\dfrac{11}{18}\cdot\dfrac12\cdot\left(-\dfrac12\right)=-\dfrac{11}{72}$. ($x=2$ is a local maximum.)
    Sum $=\dfrac{168-11}{72}=\dfrac{157}{72}$.

  18. JEE Main 2025, 29 January, Shift 2 · Question 18
    Let $f(x)=\displaystyle\int_0^xt\left(t^2-9t+20\right)dt$, $1\le x\le5$. If the range of $f$ is $[\alpha, \beta]$, then $4(\alpha+\beta)$ equals :

    1. $125$
    2. $154$
    3. $253$
    4. $157$
    Show answer and solution

    Answer: (d)

    $f'(x)=x(x-4)(x-5)$: positive on $(1,4)$, negative on $(4,5)$.
    $f(x)=\dfrac{x^4}{4}-3x^3+10x^2$: $f(1)=7.25$, $f(4)=32$, $f(5)=31.25$.
    Range $[7.25,32]$, so $4(\alpha+\beta)=4(39.25)=157$.
