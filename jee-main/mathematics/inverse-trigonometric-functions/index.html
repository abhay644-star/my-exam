  1. JEE Main 2026, 4 April, Shift 1 · Question 1
    Let $[\cdot]$ denote the greatest integer function. If the domain of the function $f(x)=\cos^{-1}\left(\dfrac{4x+2[x]}{3}\right)$ is $[\alpha,\beta]$, then $12(\alpha+\beta)$ is equal to:

    1. $6$
    2. $8$
    3. $9$
    4. $4$
    Show answer and solution

    Answer: (a)

    Need $-3\le 4x+2[x]\le 3$. Write $x=n+f$, $n=[x]$, $0\le f<1$: $-3\le 6n+4f\le 3$.
    $n=0$: $0\le 4f\le 3 \Rightarrow x\in\left[0,\dfrac34\right]$.
    $n=-1$: $-3\le -6+4f \Rightarrow f\ge\dfrac34 \Rightarrow x\in\left[-\dfrac14,0\right)$.
    Other $n$ give no solutions, so the domain is $\left[-\dfrac14,\dfrac34\right]$.
    $12(\alpha+\beta)=12\cdot\dfrac12=6$.

  2. JEE Main 2026, 5 April, Shift 1 · Question 24
    If $\dfrac{\pi}{4}+\displaystyle\sum_{p=1}^{11}\tan^{-1}\left(\frac{2^{p-1}}{1+2^{2p-1}}\right)=\alpha$, then $\tan\alpha$ is equal to __________.

    Show answer and solution

    Answer: 2048

    $\dfrac{2^{p-1}}{1+2^{2p-1}}=\dfrac{2^p-2^{p-1}}{1+2^p\cdot2^{p-1}}$, so each term is $\tan^{-1}2^p-\tan^{-1}2^{p-1}$.
    The sum telescopes: $\tan^{-1}2^{11}-\tan^{-1}1=\tan^{-1}2048-\dfrac\pi4$.
    $\alpha=\tan^{-1}2048$, so $\tan\alpha=2048$.

  3. JEE Main 2026, 6 April, Shift 1 · Question 1
    Let $[\cdot]$ denote the greatest integer function. If the domain of the function $f(x)=\sin^{-1}\left(\dfrac{x+[x]}{3}\right)$ is $[\alpha,\beta)$, then $\alpha^2+\beta^2$ is equal to:

    1. $2$
    2. $5$
    3. $10$
    4. $13$
    Show answer and solution

    Answer: (b)

    Need $-3\le x+[x]\le3$. Write $x=n+f$, $n=[x]$, $0\le f<1$: $-3\le 2n+f\le3$.
    $n=1$: $2+f\le3$ always holds, so $[1,2)$ works; $n=2$ gives $4+f>3$ (fails).
    $n=-1$: $-2+f\ge-3$ holds, so $[-1,0)$ works; $n=-2$ needs $f\ge1$ (fails). $n=0$ works.
    Domain $=[-1,2)$, so $\alpha=-1$, $\beta=2$ and $\alpha^2+\beta^2=5$.

  4. JEE Main 2026, 6 April, Shift 1 · Question 13
    Let $0<\alpha<1$, $\beta=\dfrac{1}{3\alpha}$ and $\tan^{-1}(1-\alpha)+\tan^{-1}(1-\beta)=\dfrac{\pi}{4}$. Then $6(\alpha+\beta)$ is equal to:

    1. $6$
    2. $7$
    3. $8$
    4. $9$
    Show answer and solution

    Answer: (b)

    $\dfrac{(1-\alpha)+(1-\beta)}{1-(1-\alpha)(1-\beta)}=1\Rightarrow2-\alpha-\beta=\alpha+\beta-\alpha\beta$.
    $2(\alpha+\beta)=2+\alpha\beta=2+\dfrac13=\dfrac73\Rightarrow\alpha+\beta=\dfrac76$.
    (Check: $\alpha+\dfrac1{3\alpha}=\dfrac76$ gives $\alpha=\dfrac12$ or $\dfrac23$, both in $(0,1)$.)
    $6(\alpha+\beta)=7$.

  5. JEE Main 2026, 6 April, Shift 2 · Question 13
    If $\sin\left(\tan^{-1}\left(x\sqrt2\right)\right)=\cot\left(\sin^{-1}\sqrt{1-x^2}\right)$, $x\in(0,1)$, then the value of $x$ is :

    1. $\dfrac12$
    2. $\dfrac13$
    3. $\dfrac23$
    4. $\dfrac58$
    Show answer and solution

    Answer: (a)

    $\sin\left(\tan^{-1}x\sqrt2\right)=\dfrac{x\sqrt2}{\sqrt{1+2x^2}}$.
    If $\sin\theta=\sqrt{1-x^2}$ ($\theta$ acute) then $\cos\theta=x$, so $\cot\theta=\dfrac{x}{\sqrt{1-x^2}}$.
    $\dfrac{\sqrt2}{\sqrt{1+2x^2}}=\dfrac1{\sqrt{1-x^2}} \Rightarrow 2-2x^2=1+2x^2 \Rightarrow x^2=\dfrac14$.
    $x=\dfrac12$.

  6. JEE Main 2026, 8 April, Shift 2 · Question 12
    Let $\alpha=3\sin^{-1}\left(\dfrac{6}{11}\right)$ and $\beta=3\cos^{-1}\left(\dfrac{4}{9}\right)$, where inverse trigonometric functions take only the principal values.
    Given below are two statements :
    Statement I : $\cos(\alpha+\beta)>0$.
    Statement II : $\cos(\alpha)<0$.
    In the light of the above statements, choose the correct answer from the options given below :

    1. Both Statement I and Statement II are true
    2. Both Statement I and Statement II are false
    3. Statement I is true but Statement II is false
    4. Statement I is false but Statement II is true
    Show answer and solution

    Answer: (a)

    $\dfrac12<\dfrac6{11}<\dfrac1{\sqrt2}$, so $\dfrac\pi6<\sin^{-1}\dfrac6{11}<\dfrac\pi4$ and $\dfrac\pi2<\alpha<\dfrac{3\pi}4$. Hence $\cos\alpha<0$: Statement II is true.
    $\cos\dfrac{5\pi}{12}\approx0.26<\dfrac49<\dfrac12$, so $\dfrac\pi3<\cos^{-1}\dfrac49<\dfrac{5\pi}{12}$ and $\pi<\beta<\dfrac{5\pi}4$.
    Then $\dfrac{3\pi}2<\alpha+\beta<2\pi$, so $\cos(\alpha+\beta)>0$: Statement I is true.
    Both statements are true.

  7. JEE Main 2026, 21 January, Shift 1 · Question 2
    If the domain of the function $f(x)=\cos^{-1}\left(\dfrac{2x-5}{11-3x}\right)+\sin^{-1}\left(2x^2-3x+1\right)$ is the interval $[\alpha, \beta]$, then $\alpha+2\beta$ is equal to :

    1. $1$
    2. $2$
    3. $3$
    4. $5$
    Show answer and solution

    Answer: (c)

    $\sin^{-1}$ term: $-1\le 2x^2-3x+1\le 1$. The left inequality always holds; the right gives $x(2x-3)\le0$, i.e. $0\le x\le\dfrac32$.
    On $\left[0,\dfrac32\right]$, $11-3x>0$, so $-1\le\dfrac{2x-5}{11-3x}\le1 \iff 3x-11\le 2x-5\le 11-3x \iff x\le6$ and $x\le\dfrac{16}{5}$, both true.
    Domain $=\left[0,\dfrac32\right]$, so $\alpha+2\beta=0+3=3$.

  8. JEE Main 2026, 21 January, Shift 2 · Question 23
    Let the maximum value of $(\sin^{-1}x)^2+(\cos^{-1}x)^2$ for $x\in\left[-\dfrac{\sqrt{3}}{2}, \dfrac{1}{\sqrt{2}}\right]$ be $\dfrac{m}{n}\pi^2$, where $\gcd(m, n)=1$. Then $m+n$ is equal to __________.

    Show answer and solution

    Answer: 65

    Let $t=\sin^{-1}x\in\left[-\dfrac\pi3,\dfrac\pi4\right]$; then $\cos^{-1}x=\dfrac\pi2-t$ and the expression is $2t^2-\pi t+\dfrac{\pi^2}{4}$, an upward parabola, so the maximum is at an end point.
    $t=-\dfrac\pi3$: $\dfrac{2\pi^2}{9}+\dfrac{\pi^2}{3}+\dfrac{\pi^2}{4}=\dfrac{29\pi^2}{36}$; $t=\dfrac\pi4$: $\dfrac{\pi^2}{8}$.
    So $\dfrac mn=\dfrac{29}{36}$ and $m+n=65$.

  9. JEE Main 2026, 22 January, Shift 1 · Question 2
    If the domain of the function $f(x)=\sin^{-1}\left(\dfrac{5-x}{3+2x}\right)+\dfrac{1}{\log_e(10-x)}$ is $(-\infty, \alpha] \cup [\beta, \gamma)-\{\delta\}$, then $6(\alpha+\beta+\gamma+\delta)$ is equal to

    1. $66$
    2. $67$
    3. $68$
    4. $70$
    Show answer and solution

    Answer: (d)

    $\dfrac{5-x}{3+2x}\le1 \iff \dfrac{3x-2}{2x+3}\ge0 \iff x<-\dfrac32$ or $x\ge\dfrac23$.
    $\dfrac{5-x}{3+2x}\ge-1 \iff \dfrac{x+8}{2x+3}\ge0 \iff x\le-8$ or $x>-\dfrac32$.
    Together: $x\le-8$ or $x\ge\dfrac23$. The log term needs $x<10$ and $10-x\ne1$, i.e. $x\ne9$.
    Domain $(-\infty,-8]\cup\left[\dfrac23,10\right)-\{9\}$, so $6\left(-8+\dfrac23+10+9\right)=6\cdot\dfrac{35}{3}=70$.

  10. JEE Main 2026, 22 January, Shift 1 · Question 12
    The number of solutions of $\tan^{-1}4x+\tan^{-1}6x=\dfrac{\pi}{6}$, where $-\dfrac{1}{2\sqrt6}<x<\dfrac{1}{2\sqrt6}$, is equal to

    1. $0$
    2. $1$
    3. $2$
    4. $3$
    Show answer and solution

    Answer: (b)

    In the given range $24x^2<1$, so $\tan^{-1}4x+\tan^{-1}6x=\tan^{-1}\dfrac{10x}{1-24x^2}$.
    $\dfrac{10x}{1-24x^2}=\dfrac{1}{\sqrt3}\Rightarrow24x^2+10\sqrt3\,x-1=0\Rightarrow x=\dfrac{-10\sqrt3\pm\sqrt{396}}{48}$.
    $x\approx0.054$ lies in the range; $x\approx-0.776$ does not. So $1$ solution.

  11. JEE Main 2026, 24 January, Shift 2 · Question 1
    If the domain of the function $f(x)=\sin^{-1}\left(\dfrac{1}{x^2-2x-2}\right)$, is
    $(-\infty, \alpha]\cup[\beta, \gamma]\cup[\delta, \infty)$, then $\alpha+\beta+\gamma+\delta$ is equal to

    1. $2$
    2. $3$
    3. $4$
    4. $5$
    Show answer and solution

    Answer: (c)

    Need $\left|\dfrac{1}{x^2-2x-2}\right|\le1$, i.e. $|x^2-2x-2|\ge1$.
    $x^2-2x-2\ge1 \iff (x-3)(x+1)\ge0 \iff x\le-1$ or $x\ge3$.
    $x^2-2x-2\le-1 \iff x^2-2x-1\le0 \iff 1-\sqrt2\le x\le1+\sqrt2$.
    Domain $=(-\infty,-1]\cup\left[1-\sqrt2,1+\sqrt2\right]\cup[3,\infty)$, so the sum is $-1+2+3=4$.

  12. JEE Main 2026, 28 January, Shift 1 · Question 22
    If $k=\tan\left(\dfrac\pi4+\dfrac12\cos^{-1}\left(\dfrac23\right)\right)+\tan\left(\dfrac12\sin^{-1}\left(\dfrac23\right)\right)$, then the number of solutions of the equation $\sin^{-1}(kx-1)=\sin^{-1}x-\cos^{-1}x$ is _________

    Show answer and solution

    Answer: 1

    With $\cos\theta=\tfrac23$: $\tan\left(\tfrac\pi4+\tfrac\theta2\right)=\sec\theta+\tan\theta=\tfrac32+\tfrac{\sqrt5}{2}$.
    With $\sin\phi=\tfrac23$: $\tan\tfrac\phi2=\dfrac{\sin\phi}{1+\cos\phi}=\dfrac{2}{3+\sqrt5}=\tfrac32-\tfrac{\sqrt5}{2}$. So $k=3$.
    RHS $=2\sin^{-1}x-\tfrac\pi2$ must lie in $[-\tfrac\pi2,\tfrac\pi2]$, so $0\le x\le1$. Taking sine: $3x-1=-\cos(2\sin^{-1}x)=2x^2-1$, so $x=0$ or $x=\tfrac32$.
    Only $x=0$ is valid (both sides equal $-\tfrac\pi2$): 1 solution.

  13. JEE Main 2026, 28 January, Shift 2 · Question 11
    Considering the principal values of inverse trigonometric functions, the value of the expression $\tan\left(2\sin^{-1}\left(\dfrac{2}{\sqrt{13}}\right)-2\cos^{-1}\left(\dfrac{3}{\sqrt{10}}\right)\right)$ is equal to :

    1. $\dfrac{16}{63}$
    2. $\dfrac{33}{56}$
    3. $-\dfrac{16}{63}$
    4. $-\dfrac{33}{56}$
    Show answer and solution

    Answer: (b)

    $\sin^{-1}\dfrac{2}{\sqrt{13}}=\tan^{-1}\dfrac23$ and $\cos^{-1}\dfrac{3}{\sqrt{10}}=\tan^{-1}\dfrac13$.
    $\tan\left(\tan^{-1}\tfrac23-\tan^{-1}\tfrac13\right)=\dfrac{1/3}{1+2/9}=\dfrac{3}{11}$.
    $\tan(2\theta)=\dfrac{2(3/11)}{1-9/121}=\dfrac{6/11}{112/121}=\dfrac{33}{56}$.

  14. JEE Main 2025, 22 January, Shift 1 · Question 14
    Using the principal values of the inverse trigonometric functions, the sum of the maximum and the minimum values of $16\left(\left(\sec^{-1}x\right)^2+\left(\operatorname{cosec}^{-1}x\right)^2\right)$ is :

    1. $18\pi^2$
    2. $22\pi^2$
    3. $24\pi^2$
    4. $31\pi^2$
    Show answer and solution

    Answer: (b)

    For $|x|\ge1$, $\operatorname{cosec}^{-1}x=\dfrac\pi2-\sec^{-1}x$. Let $\theta=\sec^{-1}x\in[0, \pi]$, $\theta\ne\dfrac\pi2$.
    $g(\theta)=\theta^2+\left(\dfrac\pi2-\theta\right)^2$ has its minimum $\dfrac{\pi^2}{8}$ at $\theta=\dfrac\pi4$ and its maximum $\pi^2+\dfrac{\pi^2}{4}=\dfrac{5\pi^2}{4}$ at $\theta=\pi$.
    $16\left(\dfrac{\pi^2}{8}+\dfrac{5\pi^2}{4}\right)=2\pi^2+20\pi^2=22\pi^2$.

  15. JEE Main 2025, 23 January, Shift 1 · Question 10
    If $\dfrac{\pi}{2}\le x\le\dfrac{3\pi}{4}$, then $\cos^{-1}\left(\dfrac{12}{13}\cos x+\dfrac{5}{13}\sin x\right)$ is equal to

    1. $x-\tan^{-1}\dfrac43$
    2. $x+\tan^{-1}\dfrac45$
    3. $x-\tan^{-1}\dfrac{5}{12}$
    4. $x+\tan^{-1}\dfrac{5}{12}$
    Show answer and solution

    Answer: (c)

    Let $\alpha=\tan^{-1}\dfrac{5}{12}$, so $\cos\alpha=\dfrac{12}{13}$, $\sin\alpha=\dfrac{5}{13}$ and $\alpha\approx0.39$.
    The bracket is $\cos(x-\alpha)$.
    For $\dfrac{\pi}{2}\le x\le\dfrac{3\pi}{4}$, $x-\alpha$ lies between about 1.18 and 1.96, inside $[0,\pi]$.
    So $\cos^{-1}(\cos(x-\alpha))=x-\tan^{-1}\dfrac{5}{12}$.

  16. JEE Main 2025, 24 January, Shift 1 · Question 24
    If for some $\alpha, \beta$; $\alpha\le\beta$, $\alpha+\beta=8$ and $\sec^2(\tan^{-1}\alpha)+\operatorname{cosec}^2(\cot^{-1}\beta)=36$, then $\alpha^2+\beta$ is _____.

    Show answer and solution

    Answer: 14

    $\sec^2(\tan^{-1}\alpha)=1+\alpha^2$ and $\operatorname{cosec}^2(\cot^{-1}\beta)=1+\beta^2$, so $\alpha^2+\beta^2=34$.
    With $\alpha+\beta=8$: $\alpha\beta=15$, so $\alpha=3$, $\beta=5$.
    $\alpha^2+\beta=14$.

  17. JEE Main 2025, 24 January, Shift 2 · Question 14
    If $\alpha>\beta>\gamma>0$, then the expression
    $\cot^{-1}\left\{\beta+\dfrac{(1+\beta^2)}{(\alpha-\beta)}\right\}+\cot^{-1}\left\{\gamma+\dfrac{(1+\gamma^2)}{(\beta-\gamma)}\right\}+\cot^{-1}\left\{\alpha+\dfrac{(1+\alpha^2)}{(\gamma-\alpha)}\right\}$ is equal to :

    1. $3\pi$
    2. $0$
    3. $\dfrac{\pi}{2}-(\alpha+\beta+\gamma)$
    4. $\pi$
    Show answer and solution

    Answer: (d)

    $\beta+\dfrac{1+\beta^2}{\alpha-\beta}=\dfrac{1+\alpha\beta}{\alpha-\beta}>0$, so the first term is $\tan^{-1}\dfrac{\alpha-\beta}{1+\alpha\beta}=\tan^{-1}\alpha-\tan^{-1}\beta$. Similarly the second is $\tan^{-1}\beta-\tan^{-1}\gamma$.
    In the third, $\dfrac{1+\alpha\gamma}{\gamma-\alpha}<0$, so $\cot^{-1}$ of it equals $\pi+\tan^{-1}\dfrac{\gamma-\alpha}{1+\alpha\gamma}=\pi+\tan^{-1}\gamma-\tan^{-1}\alpha$.
    Sum $=\pi$.

  18. JEE Main 2025, 28 January, Shift 1 · Question 13
    $\cos\left(\sin^{-1}\dfrac{3}{5}+\sin^{-1}\dfrac{5}{13}+\sin^{-1}\dfrac{33}{65}\right)$ is equal to:

    1. $0$
    2. $1$
    3. $\dfrac{32}{65}$
    4. $\dfrac{33}{65}$
    Show answer and solution

    Answer: (a)

    Let $\theta=\sin^{-1}\dfrac35+\sin^{-1}\dfrac{5}{13}$. Then $\cos\theta=\dfrac45\cdot\dfrac{12}{13}-\dfrac35\cdot\dfrac5{13}=\dfrac{33}{65}$ (and $\theta$ is acute).
    So $\theta=\cos^{-1}\dfrac{33}{65}$, and $\theta+\sin^{-1}\dfrac{33}{65}=\dfrac{\pi}{2}$.
    The value is $\cos\dfrac{\pi}{2}=0$.

  19. JEE Main 2025, 28 January, Shift 2 · Question 1
    Let $[x]$ denote the greatest integer less than or equal to $x$. Then the domain of $f(x)=\sec^{-1}(2[x]+1)$ is :

    1. $(-\infty, \infty)$
    2. $(-\infty, \infty)-\{0\}$
    3. $(-\infty, -1]\cup[0, \infty)$
    4. $(-\infty, -1]\cup[1, \infty)$
    Show answer and solution

    Answer: (a)

    $\sec^{-1}t$ needs $|t|\ge1$. With $t=2[x]+1$ (an odd integer), $|2[x]+1|\ge1$ always holds, since an odd integer is never 0.
    Check: $[x]\ge0$ gives $t\ge1$; $[x]\le-1$ gives $t\le-1$.
    So the domain is $(-\infty,\infty)$.

  20. JEE Main 2025, 29 January, Shift 1 · Question 23
    Let $S=\{x:\cos^{-1}x=\pi+\sin^{-1}x+\sin^{-1}(2x+1)\}$. Then $\displaystyle\sum_{x\in S}(2x-1)^2$ is equal to __________.

    Show answer and solution

    Answer: 5

    With $\cos^{-1}x=\tfrac\pi2-\sin^{-1}x$ and $\theta=\sin^{-1}x$: $\sin^{-1}(2x+1)=-\tfrac\pi2-2\theta$.
    This needs $-\tfrac\pi2\le\theta\le0$, and then $2x+1=-\cos2\theta=2x^2-1$, so $x^2-x-1=0$.
    Only $x=\dfrac{1-\sqrt5}{2}$ lies in $[-1,0]$, and $(2x-1)^2=5$.
