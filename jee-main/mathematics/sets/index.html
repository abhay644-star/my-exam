  1. JEE Main 2026, 21 January, Shift 2 · Question 8
    Let $A=\{x:|x^2-10|\le6\}$ and $B=\{x:|x-2|>1\}$. Then

    1. $A-B=[2, 3)$
    2. $A\cap B=[-4, -2]\cup[3, 4]$
    3. $A\cup B=(-\infty, 1]\cup(2, \infty)$
    4. $B-A=(-\infty, -4)\cup(-2, 1)\cup(4, \infty)$
    Show answer and solution

    Answer: (d)

    $A$: $4\le x^2\le16$, i.e. $A=[-4,-2]\cup[2,4]$. $B$: $x<1$ or $x>3$.
    $A-B=[2,3]$, $A\cap B=[-4,-2]\cup(3,4]$, $A\cup B=(-\infty,1)\cup[2,\infty)$, so options (1)-(3) fail.
    $B-A=(-\infty,-4)\cup(-2,1)\cup(4,\infty)$, which is option (4).

  2. JEE Main 2025, 7 April, Shift 2 · Question 1
    Let $A=\{(\alpha, \beta)\in\mathbf{R}\times\mathbf{R} : |\alpha-1|\le4 \text{ and } |\beta-5|\le6\}$ and $B=\{(\alpha, \beta)\in\mathbf{R}\times\mathbf{R} : 16(\alpha-2)^2+9(\beta-6)^2\le144\}$. Then

    1. $A\subset B$
    2. $B\subset A$
    3. $A\cup B=\{(x, y) : -4\le x\le4, -1\le y\le11\}$
    4. neither $A\subset B$ nor $B\subset A$
    Show answer and solution

    Answer: (b)

    A is the rectangle $-3\le\alpha\le5$, $-1\le\beta\le11$.
    B is the region inside the ellipse $\dfrac{(\alpha-2)^2}{9}+\dfrac{(\beta-6)^2}{16}\le1$, which lies within $-1\le\alpha\le5$, $2\le\beta\le10$.
    So $B\subset A$ (and $A\not\subset B$, e.g. the corner $(-3, -1)$).

  3. JEE Main 2025, 22 January, Shift 1 · Question 1
    Let $A=\{1, 2, 3, \ldots, 10\}$ and $B=\left\{\dfrac{m}{n}: m, n\in A, m<n \text{ and } \gcd(m, n)=1\right\}$. Then $n(B)$ is equal to :

    1. $29$
    2. $31$
    3. $36$
    4. $37$
    Show answer and solution

    Answer: (b)

    For each denominator $n$ ($2\le n\le10$), the admissible numerators are the $m<n$ coprime to $n$, i.e. $\varphi(n)$ of them, and different reduced fractions are different numbers.
    $n(B)=\varphi(2)+\cdots+\varphi(10)=1+2+2+4+2+6+4+6+4=31$.

  4. JEE Main 2025, 23 January, Shift 2 · Question 1
    Let $A=\{(x, y)\in\mathbf{R}\times\mathbf{R}:|x+y|\geq3\}$ and $B=\{(x, y)\in\mathbf{R}\times\mathbf{R}:|x|+|y|\leq3\}$.
    If $C=\{(x, y)\in A\cap B: x=0$ or $y=0\}$, then $\displaystyle\sum_{(x, y)\in C}|x+y|$ is :

    1. $24$
    2. $18$
    3. $15$
    4. $12$
    Show answer and solution

    Answer: (d)

    On $x=0$: $|y|\ge3$ and $|y|\le3$, so $y=\pm3$. On $y=0$: likewise $x=\pm3$.
    $C=\{(0,3),(0,-3),(3,0),(-3,0)\}$, and each point has $|x+y|=3$.
    Sum $=4\times3=12$.
