  1. JEE Main 2026, 2 April, Shift 1 · Question 4
    Let $A=\begin{bmatrix}1&2\\1&\alpha\end{bmatrix}$ and $B=\begin{bmatrix}3&3\\\beta&2\end{bmatrix}$. If $A^2-4A+I=O$ and $B^2-5B-6I=O$, then among the two statements :
    $(\text{S1}): \left[(B-A)(B+A)\right]^T=\begin{bmatrix}13&15\\7&10\end{bmatrix}$
    and
    $(\text{S2}): \det\left(\operatorname{adj}(A+B)\right)=-5$,

    1. only (S1) is correct
    2. only (S2) is correct
    3. both (S1) and (S2) are correct
    4. both (S1) and (S2) are wrong
    Show answer and solution

    Answer: (b)

    By Cayley–Hamilton, $A^2-(\operatorname{tr}A)A+(\det A)I=O$, so $\operatorname{tr}A=1+\alpha=4 \Rightarrow \alpha=3$ (and $\det A=1$ ✓).
    For $B$: $\det B=6-3\beta=-6 \Rightarrow \beta=4$.
    $B-A=\begin{bmatrix}2&1\\3&-1\end{bmatrix}$, $B+A=\begin{bmatrix}4&5\\5&5\end{bmatrix}$, product $=\begin{bmatrix}13&15\\7&10\end{bmatrix}$; its transpose is $\begin{bmatrix}13&7\\15&10\end{bmatrix}$, so (S1) is wrong.
    $\det(A+B)=20-25=-5$ and for $2\times2$, $\det(\operatorname{adj}M)=\det M=-5$, so (S2) is correct.

  2. JEE Main 2026, 2 April, Shift 2 · Question 22
    Consider the matrices $A=\begin{bmatrix}2&-2\\4&-2\end{bmatrix}$ and $B=\begin{bmatrix}3&9\\1&3\end{bmatrix}$. If matrices P and Q are such that $PA=B$ and $AQ=B$, then the absolute value of the sum of the diagonal elements of $2(P+Q)$ is __________.

    Show answer and solution

    Answer: 34

    $|A|=-4+8=4$, $A^{-1}=\dfrac14\begin{bmatrix}-2&2\\-4&2\end{bmatrix}$.
    $P=BA^{-1}$, $Q=A^{-1}B$, and $\operatorname{tr}(BA^{-1})=\operatorname{tr}(A^{-1}B)$.
    Diagonal of $A^{-1}B$: $\dfrac14(-6+2)=-1$ and $\dfrac14(-36+6)=-\dfrac{15}{2}$; trace $=-\dfrac{17}{2}$.
    $\operatorname{tr}\,2(P+Q)=2\left(-\dfrac{17}{2}-\dfrac{17}{2}\right)=-34$; absolute value $34$.

  3. JEE Main 2026, 4 April, Shift 1 · Question 5
    Let $$S=\left\{A=\begin{bmatrix} a & b\\ c & d\end{bmatrix} : a,b,c,d\in\{0,1,2,3,4\} \text{ and } A^2-4A+3I=0\right\}$$ be a set of $2\times2$ matrices. Then the number of matrices in $S$, for which the sum of the diagonal elements is equal to $4$, is:

    1. $20$
    2. $17$
    3. $21$
    4. $19$
    Show answer and solution

    Answer: (d)

    By the Cayley–Hamilton theorem, $A^2-(\operatorname{tr}A)A+(\det A)I=0$.
    With $\operatorname{tr}A=a+d=4$: $A^2-4A+3I=(3-\det A)I$, so we need $\det A=ad-bc=3$.
    $(a,d)=(0,4),(4,0)$: $bc=-3$, impossible.
    $(a,d)=(1,3),(3,1)$: $bc=0$, which has $5+5-1=9$ choices of $(b,c)$ each, giving $18$.
    $(a,d)=(2,2)$: $bc=1 \Rightarrow b=c=1$, giving $1$.
    Total $=19$.

  4. JEE Main 2026, 5 April, Shift 2 · Question 4
    Let M be a $3\times3$ matrix such that $$M\begin{pmatrix}1\\0\\0\end{pmatrix}=\begin{pmatrix}1\\2\\3\end{pmatrix},\ M\begin{pmatrix}0\\1\\0\end{pmatrix}=\begin{pmatrix}0\\1\\2\end{pmatrix} \text{ and } M\begin{pmatrix}0\\0\\1\end{pmatrix}=\begin{pmatrix}-1\\1\\1\end{pmatrix}.$$ If $M\begin{pmatrix}x\\y\\z\end{pmatrix}=\begin{pmatrix}1\\7\\11\end{pmatrix}$, then $x+y+z$ equals :

    1. $4$
    2. $5$
    3. $7$
    4. $11$
    Show answer and solution

    Answer: (b)

    The given products are the columns of $M$: $M=\begin{pmatrix}1&0&-1\\2&1&1\\3&2&1\end{pmatrix}$.
    So $x-z=1$, $2x+y+z=7$, $3x+2y+z=11$.
    Subtracting the last two: $x+y=4$. With $x=1+z$: $y=3-z$ and $2(1+z)+(3-z)+z=7 \Rightarrow z=1$.
    $x=2$, $y=2$, $z=1$, so $x+y+z=5$.

  5. JEE Main 2026, 6 April, Shift 2 · Question 5
    Let $A=\begin{bmatrix}1&0&0\\3&1&0\\9&3&1\end{bmatrix}$ and $B=[b_{ij}]$, $1\le i, j\le3$. If $B=A^{99}-I$, then the value of $\dfrac{b_{31}-b_{21}}{b_{32}}$ is :

    1. $99$
    2. $199$
    3. $149$
    4. $159$
    Show answer and solution

    Answer: (c)

    $A=I+N$ with $N=\begin{bmatrix}0&0&0\\3&0&0\\9&3&0\end{bmatrix}$, $N^2=\begin{bmatrix}0&0&0\\0&0&0\\9&0&0\end{bmatrix}$, $N^3=O$.
    $A^{99}=I+99N+\binom{99}{2}N^2=I+99N+4851N^2$.
    $B=99N+4851N^2$: $b_{21}=297$, $b_{32}=297$, $b_{31}=99\cdot9+4851\cdot9=44550$.
    $\dfrac{44550-297}{297}=150-1=149$.
