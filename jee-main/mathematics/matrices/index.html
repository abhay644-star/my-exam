  1. JEE Main 2026, 2 April, Shift 1 · Question 4
    Let $A=\begin{bmatrix}1&2\\1&\alpha\end{bmatrix}$ and $B=\begin{bmatrix}3&3\\\beta&2\end{bmatrix}$. If $A^2-4A+I=O$ and $B^2-5B-6I=O$, then among the two statements :
    $(\text{S1}): \left[(B-A)(B+A)\right]^T=\begin{bmatrix}13&15\\7&10\end{bmatrix}$
    and
    $(\text{S2}): \det\left(\operatorname{adj}(A+B)\right)=-5$,

    1. only (S1) is correct
    2. only (S2) is correct
    3. both (S1) and (S2) are correct
    4. both (S1) and (S2) are wrong
    Show answer and solution

    Answer: (b)

    By Cayley–Hamilton, $A^2-(\operatorname{tr}A)A+(\det A)I=O$, so $\operatorname{tr}A=1+\alpha=4 \Rightarrow \alpha=3$ (and $\det A=1$ ✓).
    For $B$: $\det B=6-3\beta=-6 \Rightarrow \beta=4$.
    $B-A=\begin{bmatrix}2&1\\3&-1\end{bmatrix}$, $B+A=\begin{bmatrix}4&5\\5&5\end{bmatrix}$, product $=\begin{bmatrix}13&15\\7&10\end{bmatrix}$; its transpose is $\begin{bmatrix}13&7\\15&10\end{bmatrix}$, so (S1) is wrong.
    $\det(A+B)=20-25=-5$ and for $2\times2$, $\det(\operatorname{adj}M)=\det M=-5$, so (S2) is correct.

  2. JEE Main 2026, 2 April, Shift 2 · Question 22
    Consider the matrices $A=\begin{bmatrix}2&-2\\4&-2\end{bmatrix}$ and $B=\begin{bmatrix}3&9\\1&3\end{bmatrix}$. If matrices P and Q are such that $PA=B$ and $AQ=B$, then the absolute value of the sum of the diagonal elements of $2(P+Q)$ is __________.

    Show answer and solution

    Answer: 34

    $|A|=-4+8=4$, $A^{-1}=\dfrac14\begin{bmatrix}-2&2\\-4&2\end{bmatrix}$.
    $P=BA^{-1}$, $Q=A^{-1}B$, and $\operatorname{tr}(BA^{-1})=\operatorname{tr}(A^{-1}B)$.
    Diagonal of $A^{-1}B$: $\dfrac14(-6+2)=-1$ and $\dfrac14(-36+6)=-\dfrac{15}{2}$; trace $=-\dfrac{17}{2}$.
    $\operatorname{tr}\,2(P+Q)=2\left(-\dfrac{17}{2}-\dfrac{17}{2}\right)=-34$; absolute value $34$.

  3. JEE Main 2026, 4 April, Shift 1 · Question 5
    Let $$S=\left\{A=\begin{bmatrix} a & b\\ c & d\end{bmatrix} : a,b,c,d\in\{0,1,2,3,4\} \text{ and } A^2-4A+3I=0\right\}$$ be a set of $2\times2$ matrices. Then the number of matrices in $S$, for which the sum of the diagonal elements is equal to $4$, is:

    1. $20$
    2. $17$
    3. $21$
    4. $19$
    Show answer and solution

    Answer: (d)

    By the Cayley–Hamilton theorem, $A^2-(\operatorname{tr}A)A+(\det A)I=0$.
    With $\operatorname{tr}A=a+d=4$: $A^2-4A+3I=(3-\det A)I$, so we need $\det A=ad-bc=3$.
    $(a,d)=(0,4),(4,0)$: $bc=-3$, impossible.
    $(a,d)=(1,3),(3,1)$: $bc=0$, which has $5+5-1=9$ choices of $(b,c)$ each, giving $18$.
    $(a,d)=(2,2)$: $bc=1 \Rightarrow b=c=1$, giving $1$.
    Total $=19$.

  4. JEE Main 2026, 5 April, Shift 2 · Question 4
    Let M be a $3\times3$ matrix such that $$M\begin{pmatrix}1\\0\\0\end{pmatrix}=\begin{pmatrix}1\\2\\3\end{pmatrix},\ M\begin{pmatrix}0\\1\\0\end{pmatrix}=\begin{pmatrix}0\\1\\2\end{pmatrix} \text{ and } M\begin{pmatrix}0\\0\\1\end{pmatrix}=\begin{pmatrix}-1\\1\\1\end{pmatrix}.$$ If $M\begin{pmatrix}x\\y\\z\end{pmatrix}=\begin{pmatrix}1\\7\\11\end{pmatrix}$, then $x+y+z$ equals :

    1. $4$
    2. $5$
    3. $7$
    4. $11$
    Show answer and solution

    Answer: (b)

    The given products are the columns of $M$: $M=\begin{pmatrix}1&0&-1\\2&1&1\\3&2&1\end{pmatrix}$.
    So $x-z=1$, $2x+y+z=7$, $3x+2y+z=11$.
    Subtracting the last two: $x+y=4$. With $x=1+z$: $y=3-z$ and $2(1+z)+(3-z)+z=7 \Rightarrow z=1$.
    $x=2$, $y=2$, $z=1$, so $x+y+z=5$.

  5. JEE Main 2026, 6 April, Shift 2 · Question 5
    Let $A=\begin{bmatrix}1&0&0\\3&1&0\\9&3&1\end{bmatrix}$ and $B=[b_{ij}]$, $1\le i, j\le3$. If $B=A^{99}-I$, then the value of $\dfrac{b_{31}-b_{21}}{b_{32}}$ is :

    1. $99$
    2. $199$
    3. $149$
    4. $159$
    Show answer and solution

    Answer: (c)

    $A=I+N$ with $N=\begin{bmatrix}0&0&0\\3&0&0\\9&3&0\end{bmatrix}$, $N^2=\begin{bmatrix}0&0&0\\0&0&0\\9&0&0\end{bmatrix}$, $N^3=O$.
    $A^{99}=I+99N+\binom{99}{2}N^2=I+99N+4851N^2$.
    $B=99N+4851N^2$: $b_{21}=297$, $b_{32}=297$, $b_{31}=99\cdot9+4851\cdot9=44550$.
    $\dfrac{44550-297}{297}=150-1=149$.

  6. JEE Main 2026, 21 January, Shift 1 · Question 21
    For some $\alpha, \beta\in\mathbf{R}$, let $A=\begin{bmatrix}\alpha&2\\1&2\end{bmatrix}$ and $B=\begin{bmatrix}1&1\\1&\beta\end{bmatrix}$ be such that $A^2-4A+2I=B^2-3B+I=O$. Then $\left(\det\left(\operatorname{adj}\left(A^3-B^3\right)\right)\right)^2$ is equal to __________.

    Show answer and solution

    Answer: 225

    For a $2\times2$ matrix, $M^2-(\operatorname{tr}M)M+(\det M)I=O$. So $\alpha+2=4$, $\alpha=2$ ($\det A=2$ checks); $1+\beta=3$, $\beta=2$ ($\det B=1$ checks).
    $A^3=4A^2-2A=14A-8I$ and $B^3=3B^2-B=8B-3I$.
    $A^3-B^3=14A-8B-5I=\begin{bmatrix}15&20\\6&7\end{bmatrix}$, determinant $105-120=-15$.
    For $2\times2$, $\det(\operatorname{adj}M)=\det M=-15$, and its square is $225$.

  7. JEE Main 2026, 21 January, Shift 2 · Question 5
    For the matrices $A=\begin{bmatrix}3&-4\\1&-1\end{bmatrix}$ and $B=\begin{bmatrix}-29&49\\-13&18\end{bmatrix}$, if $\left(A^{15}+B\right)\begin{bmatrix}x\\y\end{bmatrix}=\begin{bmatrix}0\\0\end{bmatrix}$, then among the following which one is true ?

    1. $x=5, y=7$
    2. $x=16, y=3$
    3. $x=11, y=2$
    4. $x=18, y=11$
    Show answer and solution

    Answer: (c)

    Write $A=I+N$ with $N=\begin{bmatrix}2&-4\\1&-2\end{bmatrix}$; $N^2=O$.
    So $A^{15}=I+15N=\begin{bmatrix}31&-60\\15&-29\end{bmatrix}$ and $A^{15}+B=\begin{bmatrix}2&-11\\2&-11\end{bmatrix}$.
    The system reduces to $2x=11y$; among the options only $x=11, y=2$ satisfies it.

  8. JEE Main 2026, 22 January, Shift 1 · Question 4
    If $A=\begin{bmatrix}2 & 3\\ 3 & 5\end{bmatrix}$, then the determinant of the matrix $\left(A^{2025}-3A^{2024}+A^{2023}\right)$ is

    1. $12$
    2. $16$
    3. $24$
    4. $28$
    Show answer and solution

    Answer: (b)

    $\operatorname{tr}A=7$, $|A|=1$, so (Cayley-Hamilton) $A^2=7A-I$.
    $A^{2025}-3A^{2024}+A^{2023}=A^{2023}(A^2-3A+I)=A^{2023}\cdot4A=4A^{2024}$.
    Determinant $=4^2\cdot|A|^{2024}=16$.

  9. JEE Main 2026, 23 January, Shift 2 · Question 21
    Let $A=\begin{bmatrix}0&2&-3\\-2&0&1\\3&-1&0\end{bmatrix}$ and B be a matrix such that $B(I-A)=I+A$. Then the sum of the diagonal elements of $B^TB$ is equal to ____

    Show answer and solution

    Answer: 3

    $A^T=-A$ (A is skew-symmetric), and $I-A$ is invertible, so $B=(I+A)(I-A)^{-1}$.
    $B^T=\left((I-A)^{-1}\right)^T(I-A)=(I+A)^{-1}(I-A)$.
    $I+A$ and $I-A$ commute, so $B^TB=(I+A)^{-1}(I-A)(I+A)(I-A)^{-1}=I$.
    Trace of $B^TB=3$.

  10. JEE Main 2026, 24 January, Shift 1 · Question 21
    The number of $3\times2$ matrices A, which can be formed using the elements of the set $\{-2, -1, 0, 1, 2\}$ such that the sum of all the diagonal elements of $A^TA$ is 5, is __________

    Show answer and solution

    Answer: 312

    $\operatorname{tr}(A^TA)$ is the sum of the squares of all 6 entries, and each square is 0, 1 or 4.
    Sum 5 = $4+1$: choose the positions of $\pm2$ and $\pm1$ ($6\times5$) and signs ($4$): $120$.
    Sum 5 = five 1s: choose the zero entry (6) and signs ($2^5$): $192$.
    Total $=312$.

  11. JEE Main 2026, 28 January, Shift 1 · Question 5
    Let A, B and C be three $2\times2$ matrices with real entries such that $\mathrm{B}=(\mathrm{I}+\mathrm{A})^{-1}$ and $\mathrm{A}+\mathrm{C}=\mathrm{I}$. If $\mathrm{BC}=\begin{bmatrix}1&-5\\-1&2\end{bmatrix}$ and $\mathrm{CB}\begin{bmatrix}x_1\\x_2\end{bmatrix}=\begin{bmatrix}12\\-6\end{bmatrix}$, then $x_1+x_2$ is

    1. $0$
    2. $2$
    3. $-2$
    4. $4$
    Show answer and solution

    Answer: (a)

    $\mathrm{C}=\mathrm{I}-\mathrm{A}$ and $\mathrm{B}=(\mathrm{I}+\mathrm{A})^{-1}$ are both functions of A, so they commute: $\mathrm{CB}=\mathrm{BC}$.
    $x_1-5x_2=12$ and $-x_1+2x_2=-6$ give $x_2=-2$, $x_1=2$.
    $x_1+x_2=0$.

  12. JEE Main 2026, 28 January, Shift 2 · Question 21
    Let $\mathrm A=\begin{bmatrix}3&-4\\1&-1\end{bmatrix}$ and B be two matrices such that $\mathrm A^{100}=100\mathrm B+\mathrm I$. Then the sum of all the elements of $\mathrm B^{100}$ is _________

    Show answer and solution

    Answer: 0

    $\mathrm A=\mathrm I+\mathrm N$ with $\mathrm N=\begin{bmatrix}2&-4\\1&-2\end{bmatrix}$ and $\mathrm N^2=\mathrm O$.
    So $\mathrm A^{100}=\mathrm I+100\mathrm N$, giving $\mathrm B=\mathrm N$ and $\mathrm B^{100}=\mathrm O$.
    Sum of elements $=0$.

  13. JEE Main 2025, 23 January, Shift 2 · Question 5
    Let $A=[a_{ij}]$ be a $3\times3$ matrix such that $A\begin{bmatrix}0\\1\\0\end{bmatrix}=\begin{bmatrix}0\\0\\1\end{bmatrix}$, $A\begin{bmatrix}4\\1\\3\end{bmatrix}=\begin{bmatrix}0\\1\\0\end{bmatrix}$ and $A\begin{bmatrix}2\\1\\2\end{bmatrix}=\begin{bmatrix}1\\0\\0\end{bmatrix}$, then $a_{23}$ equals :

    1. $0$
    2. $1$
    3. $-1$
    4. $2$
    Show answer and solution

    Answer: (c)

    Let $c_1,c_2,c_3$ be the columns of $A$ and $e_1,e_2,e_3$ the unit vectors. Then $c_2=e_3$.
    $4c_1+c_2+3c_3=e_2$ and $2c_1+c_2+2c_3=e_1$.
    Subtracting: $2c_1+c_3=e_2-e_1$. The second equation gives $2c_1+2c_3=e_1-e_3$.
    So $c_3=(e_1-e_3)-(e_2-e_1)=2e_1-e_2-e_3=(2,-1,-1)^T$.
    $a_{23}$ is the second entry of $c_3$: $a_{23}=-1$.

  14. JEE Main 2025, 24 January, Shift 1 · Question 22
    Let A be a $3\times3$ matrix such that $X^TAX=O$ for all nonzero $3\times1$ matrices $X=\begin{bmatrix}x\\y\\z\end{bmatrix}$. If $A\begin{bmatrix}1\\1\\1\end{bmatrix}=\begin{bmatrix}1\\4\\-5\end{bmatrix}$, $A\begin{bmatrix}1\\2\\1\end{bmatrix}=\begin{bmatrix}0\\4\\-8\end{bmatrix}$, and $\det(\operatorname{adj}(2(A+I)))=2^\alpha3^\beta5^\gamma$, $\alpha, \beta, \gamma\in\mathbb{N}$, then $\alpha^2+\beta^2+\gamma^2$ is _____.

    Show answer and solution

    Answer: 44

    $X^TAX=0$ for all $X$ means A is skew-symmetric: $A=\begin{bmatrix}0&a&b\\-a&0&c\\-b&-c&0\end{bmatrix}$.
    From the data: $a+b=1$, $c-a=4$, $2a+b=0$, so $a=-1$, $b=2$, $c=3$ (the remaining equations check).
    For a skew-symmetric $3\times3$ matrix, $\det(I+A)=1+a^2+b^2+c^2=15$.
    $\det(\operatorname{adj}M)=(\det M)^2$ for $3\times3$: $(2^3\cdot15)^2=120^2=2^6\,3^2\,5^2$.
    $36+4+4=44$.

  15. JEE Main 2025, 28 January, Shift 1 · Question 21
    Let M denote the set of all real matrices of order $3\times3$ and let $S=\{-3, -2, -1, 1, 2\}$. Let
    $S_1=\{A=[a_{ij}]\in M: A=A^T \text{ and } a_{ij}\in S, \forall\, i, j\}$,
    $S_2=\{A=[a_{ij}]\in M: A=-A^T \text{ and } a_{ij}\in S, \forall\, i, j\}$,
    $S_3=\{A=[a_{ij}]\in M: a_{11}+a_{22}+a_{33}=0 \text{ and } a_{ij}\in S, \forall\, i, j\}$.
    If $n(S_1\cup S_2\cup S_3)=125\,\alpha$, then $\alpha$ equls ______.

    Show answer and solution

    Answer: 1613

    $S_2=\varnothing$: a skew-symmetric matrix has zero diagonal, and $0\notin S$.
    $n(S_1)=5^6$ (diagonal and upper triangle free).
    Diagonals from $S$ with sum 0: $\{-3,1,2\}$ (6 orders), $\{-2,1,1\}$ (3), $\{-1,-1,2\}$ (3), i.e. 12. So $n(S_3)=12\cdot5^6$ and $n(S_1\cap S_3)=12\cdot5^3$.
    $n=5^6+12\cdot5^6-12\cdot5^3=125(13\cdot125-12)=125\cdot1613$, so $\alpha=1613$.

  16. JEE Main 2025, 28 January, Shift 2 · Question 5
    Let $A=\begin{bmatrix}\dfrac{1}{\sqrt{2}}&-2\\0&1\end{bmatrix}$ and $P=\begin{bmatrix}\cos\theta&-\sin\theta\\\sin\theta&\cos\theta\end{bmatrix}$, $\theta>0$. If $B=PAP^T$, $C=P^TB^{10}P$ and the sum of the diagonal elements of C is $\dfrac{m}{n}$, where $\gcd(m, n)=1$, then $m+n$ is :

    1. $2049$
    2. $258$
    3. $127$
    4. $65$
    Show answer and solution

    Answer: (d)

    $P$ is orthogonal ($P^TP=I$), so $B^{10}=PA^{10}P^T$ and $C=P^TB^{10}P=A^{10}$.
    $A$ is upper triangular, so $A^{10}$ has diagonal $\left(\dfrac{1}{\sqrt2}\right)^{10}=\dfrac1{32}$ and $1$.
    Trace $=\dfrac{33}{32}$, so $m+n=65$.

  17. JEE Main 2025, 29 January, Shift 1 · Question 21
    Let $S=\left\{m\in\mathbf{Z}:A^{m^2}+A^m=3I-A^{-6}\right\}$, where $A=\begin{bmatrix}2&-1\\1&0\end{bmatrix}$. Then n(S) is equal to __________.

    Show answer and solution

    Answer: 2

    $A=I+N$ with $N=\begin{bmatrix}1&-1\\1&-1\end{bmatrix}$, $N^2=O$, so $A^m=I+mN$ for every integer $m$.
    LHS $=2I+(m^2+m)N$; RHS $=3I-(I-6N)=2I+6N$.
    $m^2+m=6\Rightarrow m=2,-3$. So $n(S)=2$.

  18. JEE Main 2025, 29 January, Shift 2 · Question 4
    Let $A=[a_{ij}]$ be a matrix of order $3\times3$, with $a_{ij}=\left(\sqrt2\right)^{i+j}$. If the sum of all the elements in the third row of $A^2$ is $\alpha+\beta\sqrt2$, $\alpha, \beta\in\mathbf{Z}$, then $\alpha+\beta$ is equal to :

    1. $168$
    2. $210$
    3. $224$
    4. $280$
    Show answer and solution

    Answer: (c)

    $A=uu^T$ with $u=(\sqrt2,2,2\sqrt2)^T$, so $A^2=(u^Tu)A=14A$.
    Third row sum of $A$: $2\sqrt2(\sqrt2+2+2\sqrt2)=12+4\sqrt2$.
    For $A^2$: $14(12+4\sqrt2)=168+56\sqrt2$, so $\alpha+\beta=224$.
