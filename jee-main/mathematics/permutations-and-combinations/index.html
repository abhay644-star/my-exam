  1. JEE Main 2026, 2 April, Shift 1 · Question 6
    The number of seven-digit numbers, that can be formed by using the digits $1, 2, 3, 5$ and $7$ such that each digit is used at least once, is :

    1. $15400$
    2. $17800$
    3. $16800$
    4. $29400$
    Show answer and solution

    Answer: (c)

    Five distinct digits fill seven places, so the extra two places give pattern $(3,1,1,1,1)$ or $(2,2,1,1,1)$.
    Pattern $(3,1,1,1,1)$: $5\cdot\dfrac{7!}{3!}=4200$.
    Pattern $(2,2,1,1,1)$: $\binom{5}{2}\cdot\dfrac{7!}{2!\,2!}=12600$.
    Total $=16800$.

  2. JEE Main 2026, 2 April, Shift 1 · Question 7
    The number of elements in the set $S=\left\{(r,k)\ :\ k \in \mathbb{Z} \text{ and } {}^{36}C_{r+1}=\dfrac{6\left({}^{35}C_r\right)}{\left(k^2-3\right)}\right\}$, is :

    1. $2$
    2. $4$
    3. $8$
    4. $16$
    Show answer and solution

    Answer: (b)

    ${}^{36}C_{r+1}=\dfrac{36}{r+1}\,{}^{35}C_r$, so $\dfrac{36}{r+1}=\dfrac{6}{k^2-3}$, i.e. $r+1=6(k^2-3)$.
    Need $0\le r\le35$, so $1\le 6(k^2-3)\le36 \Rightarrow 4\le k^2\le 9$.
    $k^2=4$: $r=5$, $k=\pm2$; $k^2=9$: $r=35$, $k=\pm3$.
    So $S$ has $4$ elements.

  3. JEE Main 2026, 2 April, Shift 2 · Question 7
    Let $p_n$ denote the total number of triangles formed by joining the vertices of an $n$-side regular polygon. If $p_{n+1}-p_n=66$, then the sum of all distinct prime divisors of $n$ is :

    1. $7$
    2. $8$
    3. $5$
    4. $6$
    Show answer and solution

    Answer: (c)

    $p_n={}^nC_3$, so $p_{n+1}-p_n={}^{n+1}C_3-{}^nC_3={}^nC_2$.
    $\dfrac{n(n-1)}{2}=66 \Rightarrow n=12$.
    $12=2^2\cdot 3$; sum of distinct prime divisors $=2+3=5$.

    1. $121$
    2. $124$
    3. $144$
    4. $169$
    Show answer and solution

    Answer: (c)

  6. JEE Main 2026, 5 April, Shift 1 · Question 21
    Let $A = \{1, 2, 3, 4, 5, 6\}$. The number of one-one functions $f : A \to A$ such that $f(1) \ge 3$, $f(3) \le 4$ and $f(2) + f(3) = 5$, is __________.

    Show answer and solution

    Answer: 72

    $(f(2),f(3))\in\{(1,4),(2,3),(3,2),(4,1)\}$, all with $f(3)\le4$.
    In each case $f(1)\ge3$ must avoid the two used values: $(1,4)$: $f(1)\in\{3,5,6\}$; $(2,3)$: $\{4,5,6\}$; $(3,2)$: $\{4,5,6\}$; $(4,1)$: $\{3,5,6\}$ — $3$ choices each.
    The remaining $3$ elements map one-one onto the remaining $3$ values in $3!=6$ ways.
    Total $=4\times3\times6=72$.

  7. JEE Main 2026, 5 April, Shift 1 · Question 22
    Two players A and B play a series of games of badminton. The player, who wins $5$ games first, wins the series. Assuming that no game ends in a draw, the number of ways, in which player A wins the series is________.

    Show answer and solution

    Answer: 126

    A wins the last game and exactly $4$ of the earlier games; B wins $k$ games, $k=0,1,2,3,4$.
    The earlier $4+k$ games can be arranged in $\binom{4+k}{k}$ ways.
    Total $=\binom40+\binom51+\binom62+\binom73+\binom84=1+5+15+35+70=126$.

  11. JEE Main 2026, 8 April, Shift 2 · Question 9
    A person has three different bags and four different books. The number of ways, in which he can put these books in the bags so that no bag is empty, is :

    1. $18$
    2. $36$
    3. $39$
    4. $72$
    Show answer and solution

    Answer: (b)

    Count onto maps from 4 books to 3 bags: $3^4-\binom31 2^4+\binom32 1^4=81-48+3=36$.
    (Equivalently: choose the pair of books that share a bag, $\binom42=6$, then arrange 3 groups in 3 bags, $3!=6$: $36$.)

  12. JEE Main 2026, 21 January, Shift 1 · Question 6
    The number of strictly increasing functions $f$ from the set $\{1, 2, 3, 4, 5, 6\}$ to the set $\{1, 2, 3, \ldots, 9\}$ such that $f(i)\neq i$ for $1\le i\le 6$, is equal to :

    1. $21$
    2. $22$
    3. $27$
    4. $28$
    Show answer and solution

    Answer: (d)

    For a strictly increasing $f$ into $\{1,\ldots,9\}$, $i\le f(i)\le i+3$. Let $g(i)=f(i)-i$; then $g$ is non-decreasing with values in $\{0,1,2,3\}$.
    $f(i)\neq i$ means $g(i)\ge1$, so $g$ is a non-decreasing sequence of length 6 from $\{1,2,3\}$.
    Number of such sequences $=\binom{6+2}{2}=28$.

    Let $S=\{(m, n): m, n\in\{1, 2, 3, \ldots, 50\}\}$. If the number of elements $(m, n)$ in S such that $6^m+9^n$ is a multiple of 5 is p and the number of elements $(m, n)$ in S such that $m+n$ is a square of a prime number is q, then $p+q$ is equal to __________.

    Show answer and solution

    Answer: 1333

    Modulo 5: $6^m\equiv1$ and $9^n\equiv(-1)^n$, so $6^m+9^n\equiv0$ exactly when $n$ is odd: $p=50\times25=1250$.
    $m+n\in[2,100]$ is a prime square for $m+n=4,9,25,49$; the number of pairs with sum $s\le51$ is $s-1$.
    $q=3+8+24+48=83$.
    $p+q=1333$.

    The number of numbers greater than 5000, less than 9000 and divisible by 3, that can be formed using the digits 0, 1, 2, 5, 9, if the repetition of the digits is allowed, is __________

    Show answer and solution

    Answer: 42

    Total $=12+6+24=42$.

    Let $\mathrm{S}=\{1, 2, 3, 4, 5, 6, 7, 8, 9\}$. Let $x$ be the number of 9-digit numbers formed using the digits of the set S such that only one digit is repeated and it is repeated exactly twice. Let $y$ be the number of 9-digit numbers formed using the digits of the set S such that only two digits are repeated and each of these is repeated exactly twice. Then,

    1. $21x=4y$
    2. $45x=7y$
    3. $56x=9y$
    4. $29x=5y$
    Show answer and solution

    Answer: (a)

    $x/y=36/189=4/21$, i.e. $21x=4y$.

    Answer: (b)

    $p+q=\binom n3+\binom n4=\binom{n+1}{4}=126=\binom94$, so $n=8$.
    For $\dfrac{x^2}{16}+\dfrac{y^2}{8}=1$: $e=\sqrt{1-\dfrac8{16}}=\dfrac1{\sqrt2}$.

  35. JEE Main 2025, 8 April, Shift 2 · Question 7
    There are 12 points in a plane, no three of which are in the same straight line, except 5 points which are collinear. Then the total number of triangles that can be formed with the vertices at any three of these 12 points is

    1. $210$
    2. $220$
    3. $200$
    4. $230$
    Show answer and solution

    Answer: (a)

    Choose any 3 of the 12 points and remove the choices lying on the line of 5: ${}^{12}C_3-{}^5C_3=220-10=210$.

  36. JEE Main 2025, 22 January, Shift 1 · Question 7
    From all the English alphabets, five letters are chosen and are arranged in alphabetical order. The total number of ways, in which the middle letter is 'M', is :

    1. $14950$
    2. $4356$
    3. $6084$
    4. $5148$
    Show answer and solution

    Answer: (d)

    M is the 13th letter: 12 letters come before it and 13 after it.
    Choose 2 letters from the 12 before and 2 from the 13 after; the alphabetical arrangement is then fixed.
    Number of ways $=\binom{12}{2}\binom{13}{2}=66\times78=5148$.

  37. JEE Main 2025, 22 January, Shift 2 · Question 7
    In a group of 3 girls and 4 boys, there are two boys $B_1$ and $B_2$. The number of ways, in which these girls and boys can stand in a queue such that all the girls stand together, all the boys stand together, but $B_1$ and $B_2$ are not adjacent to each other, is :

    1. $72$
    2. $96$
    3. $120$
    4. $144$
    Show answer and solution

    Answer: (d)

    The girls' block and the boys' block can be in 2 orders; the girls can be arranged in $3!=6$ ways.
    Boys with $B_1$, $B_2$ not adjacent: $4!-2\cdot3!=24-12=12$.
    Total $=2\times6\times12=144$.

  38. JEE Main 2025, 23 January, Shift 1 · Question 7
    The number of words, which can be formed using all the letters of the word "DAUGHTER", so that all the vowels never come together, is

    1. $34000$
    2. $35000$
    3. $36000$
    4. $37000$
    Show answer and solution

    Answer: (c)

    DAUGHTER has 8 different letters, with vowels A, U, E.
    All arrangements: $8!=40320$.
    Vowels together (treat them as one block): $6!\times3!=4320$.
    Vowels not all together: $40320-4320=36000$.

  39. JEE Main 2025, 23 January, Shift 2 · Question 23
    The number of ways, 5 boys and 4 girls can sit in a row so that either all the boys sit together or no two boys sit together, is __________.

    Show answer and solution

    Answer: 17280

    All boys together: treat the boys as one block with the 4 girls, $5!$ ways, times $5!$ inside the block: $14400$.
    No two boys together: arrange the girls in $4!$ ways; the 5 gaps take the 5 boys in $5!$ ways: $2880$.
    The two cases cannot happen together, so the total is $14400+2880=17280$.

  40. JEE Main 2025, 24 January, Shift 1 · Question 21
    Let $S=\{p_1, p_2, \ldots, p_{10}\}$ be the set of first ten prime numbers. Let $A=S\cup P$, where P is the set of all possible products of distinct elements of S. Then the number of all ordered pairs $(x, y)$, $x\in S$, $y\in A$, such that $x$ divides $y$, is _____.

    Show answer and solution

    Answer: 5120

    A consists of the products of the primes in every non-empty subset of S (single primes included).
    For a fixed prime $x$, $x\mid y$ exactly when the subset for $y$ contains $x$: $2^9=512$ choices.
    Total $=10\times512=5120$.

  41. JEE Main 2025, 24 January, Shift 1 · Question 23
    The number of 3-digit numbers, that are divisible by 2 and 3, but not divisible by 4 and 9, is _____.

    Show answer and solution

    Answer: 125

    Divisible by 2 and 3 means divisible by 6: $102,\ldots,996$, that is $150$ numbers.
    Divisible by both 4 and 9 means divisible by 36: $108,\ldots,972$, that is $25$ numbers.
    $150-25=125$.

    Note: NTA final key gives 125, which reads "not divisible by 4 and 9" as "not divisible by both 4 and 9" (that is, not by 36). Read as "divisible by neither 4 nor 9", the count would be $150-75-50+25=50$.

  42. JEE Main 2025, 24 January, Shift 2 · Question 10
    Group A consists of 7 boys and 3 girls, while group B consists of 6 boys and 5 girls. The number of ways, 4 boys and 4 girls can be invited for a picnic if 5 of them must be from group A and the remaining 3 from group B, is equal to :

    1. $8575$
    2. $8750$
    3. $8925$
    4. $9100$
    Show answer and solution

    Answer: (c)

    From A take $(b, 5-b)$ boys and girls, from B the remaining $(4-b, b-1)$; girls from A are at most 3.
    $b=2$: $\binom72\binom33\binom62\binom51=21\cdot1\cdot15\cdot5=1575$.
    $b=3$: $\binom73\binom32\binom61\binom52=35\cdot3\cdot6\cdot10=6300$.
    $b=4$: $\binom74\binom31\binom60\binom53=35\cdot3\cdot1\cdot10=1050$.
    Total $=8925$.

  43. JEE Main 2025, 24 January, Shift 2 · Question 21
    Number of functions $f:\{1, 2, \ldots, 100\}\to\{0, 1\}$, that assign 1 to exactly one of the positive integers less than or equal to 98, is equal to __________.

    Show answer and solution

    Answer: 392

    Choose the one integer in $\{1,\ldots,98\}$ that maps to 1: 98 ways (the other 97 map to 0).
    99 and 100 are free: $2^2=4$ ways.
    Total $=98\times4=392$.

  44. JEE Main 2025, 28 January, Shift 1 · Question 7
    The number of different 5 digit numbers greater than 50000 that can be formed using the digits 0, 1, 2, 3, 4, 5, 6, 7, such that the sum of their first and last digits should not be more than 8, is

    1. $4607$
    2. $4608$
    3. $5719$
    4. $5720$
    Show answer and solution

    Answer: (a)

    The first digit is 5, 6 or 7 (repetition allowed).
    First 5: last digit 0-3 (4 ways); first 6: 0-2 (3 ways); first 7: 0-1 (2 ways). That is 9 choices of first and last digits.
    The middle three digits: $8^3=512$ ways. Total $9\times512=4608$.
    This includes 50000 itself, which is not greater than 50000, so the answer is $4608-1=4607$.

  45. JEE Main 2025, 28 January, Shift 2 · Question 22
    The number of natural numbers, between 212 and 999, such that the sum of their digits is 15, is __________.

    Show answer and solution

    Answer: 64

    Three-digit numbers $\overline{abc}$ with $a+b+c=15$: for each $a$, count pairs $(b,c)$ of digits with $b+c=15-a$.
    $a=1,\ldots,9$ give $5,6,7,8,9,10,9,8,7$: total $69$.
    Those not above 212: all 5 with $a=1$; with $a=2$ we need $b+c=13$, so $b\ge4$ and the number exceeds 212.
    Answer $=69-5=64$.

  46. JEE Main 2025, 29 January, Shift 1 · Question 7
    Let P be the set of seven digit numbers with sum of their digits equal to 11. If the numbers in P are formed by using the digits 1, 2 and 3 only, then the number of elements in the set P is :

    1. $158$
    2. $161$
    3. $164$
    4. $173$
    Show answer and solution

    Answer: (b)

    Start with seven 1s (sum 7); the extra 4 is shared out with each digit getting $+0$, $+1$ or $+2$.
    Four digits get $+1$: $\binom74=35$. One gets $+2$ and two get $+1$: $7\binom62=105$. Two get $+2$: $\binom72=21$.
    Total $=35+105+21=161$.

  47. JEE Main 2025, 29 January, Shift 1 · Question 22
    The number of 6-letter words, with or without meaning, that can be formed using the letters of the word MATHS such that any letter that appears in the word must appear at least twice, is __________.

    Show answer and solution

    Answer: 1405

    Split 6 into parts of at least 2.
    One letter 6 times: $5$. Pattern 4+2: $5\cdot4\cdot\dfrac{6!}{4!2!}=300$. Pattern 3+3: $\binom52\cdot\dfrac{6!}{3!3!}=200$. Pattern 2+2+2: $\binom53\cdot\dfrac{6!}{2!2!2!}=900$.
    Total $=5+300+200+900=1405$.

  48. JEE Main 2025, 29 January, Shift 2 · Question 6
